# 人工智能优先聚合

**人工智能优先聚合（AI-First Aggregation）** 是 [[智能先行-丰塔纳|丰塔纳]] 描述 AI 优先公司市场支配力的概念：通过聚合数据、智能管理、广泛分发，构建比传统聚合器（如 Netflix）更快的自我强化回路。

## 三个零成本特征

1. **零边际成本服务客户**：生产成本随自动化程度提高而降低
   - 线下出版物需翻译人员逐页翻译
   - 线上出版物使用自动语言翻译，交付给世界各地更多客户

2. **零分销成本**：通过将产品与客户已使用的产品集成或搭接
   - AI 优先应用从 JIRA 获取身份票据，学习发送给合适工程师
   - 现有公司必须花钱营销才能把产品卖给客户

3. **零交易成本**：在其他供应商的基础设施上运行系统
   - AI 优先产品接入 Salesforce，在 Salesforce 计算基础设施上提取处理数据
   - 现有公司实际上是 AI 优先产品获取数据的数据库

## 与传统聚合理论的对比

Netflix 聚合回路：
```
临界客户（需求） → 激励产品生产（供应） → 更多内容 → 更多客户
```

AI 优先聚合回路：
```
临界客户（需求方+供给方） → 生成数据 → AI 更准预测 → 客户更多使用 → 更多数据 → ...
```

**关键差异**：AI 优先聚合器的客户既是回路的需求方，又是回路的供给方。客户生成足够数据启动 AI 飞轮，然后 AI 自动生成数据提高准确度，提高产品认可度，快速建立市场统治力。

## 人工智能优先聚合器的特点

- **与客户建立直接关系**：客户每天使用预测决策；现有公司只是 AI 优先产品背后的记录系统
- **以零边际成本服务客户**：自动化程度提高 → 生产成本降低
- **零分销成本**：产品与客户已使用产品集成搭接
- **零交易成本**：在其他供应商基础设施上运行

## 人工智能优先的破坏三波次

基于 [[创新者的窘境-克里斯坦森]] 的破坏理论，丰塔纳提出 AI 优先破坏的三个波次：

1. **第一波：价格破坏**
   - 数据学习效应降低生产成本
   - 例：智能系统自动化药物开发所有步骤，降低药物生产成本
   - 较低价格吸引客户离开竞争对手

2. **第二波：质量破坏**
   - 数据学习效应创造高质量功能（个性化、观点生成）
   - 现有公司低估这些高级功能的价值
   - 例：谷歌广告平台最初低于横幅成本，现在因个性化收费高很多

3. **第三波：自动化破坏**
   - 数据学习效应带来满足最苛刻用例的产品：完全自动化
   - AI 优先公司拥有自动化解决方案的新市场
   - 现有公司在旧市场中渐渐萎缩

## 人才回路

构建智能系统需要有智慧的人。人才回路：
```
最好的数据 → 吸引最好的机器学习工程师/研究员/数据科学家 → 更有用模型 → 更多数据 → ...
```

向潜在候选人宣传数据资产价值可以开启人才回路。收集可能解决重要问题（如癌症）的专有数据集可以吸引高素质人才。

## 与其他概念的关系

- 是 [[数据学习效应-丰塔纳]] 在市场层面的体现：DLE 是公司内部机制，聚合是市场支配力
- 与 [[聚合理论]]（Stratechery）：丰塔纳将聚合理论从需求侧扩展到供需合一
- 与 [[创新者的窘境-克里斯坦森]]：丰塔纳把克里斯坦森的破坏理论升级为三波次 AI 破坏
- 与 [[纵向整合是AI优先公司获取价值的核心策略-丰塔纳]]：聚合与纵向整合是 AI 优先公司市场策略的互补两面
