# 故事演讲设计系统

把故事从单个素材，组合成一场有结构、有目标、能改变听众的完整演讲，需要一套系统化的设计方法。

## 1G2W2H 模型：演讲设计前的五问

在开始设计演讲内容之前，先回答五个问题：

- **1G（Goal）**：这场演讲的目标是什么？听完后，我希望听众做什么/相信什么/感受什么？
- **2W（Who + What）**：听众是谁？他们当前对这个话题的认知和情绪状态是什么？
- **2H（How + How much）**：我有多少时间？用什么形式传达最有效？

目标不清晰，故事再好也打不中。1G 是整场演讲设计的锚点。

## 三段式演讲地图（序幕 / 大戏 / 余音）

故事演讲的宏观结构，对应听众的注意力曲线：

### 序幕（开场，约10-15%时间）
目标：抓住注意力，建立期待

1. **引发兴趣**：用钩子（悬念/问题/反常数据/故事片段）制造信息缺口
2. **明确主题**：直接说出"今天我要解决的问题/分享的主题"

序幕失败 = 听众分心，后面再好也白费。

### 大戏（主体，约70-80%时间）
目标：用三个"钉子"论点说服听众

三论点结构：每个论点 = 观点陈述 + 故事支撑 + 过渡回收

**333 原则**：每场演讲不超过 3 个核心论点，每个论点用 3 个以内的故事支撑，每个故事不超过 3 分钟。

### 余音（收尾，约10-15%时间）
目标：强化记忆，触发行动

1. **回顾总结**：简要重述三个论点
2. **主题升华**：用一个情感更强的故事或金句，把主题提升到更高维度
3. **行动呼吁**（可选）：明确告诉听众你希望他们做什么

余音决定留存记忆——根据峰终定律，结尾的故事/金句会成为听众对整场演讲的"锚定记忆"。

## 钉子三原则

"钉子"= 每个论点的核心概念词（通常2-4个字的短语），让听众记住论点的最小单位。

- **对称**：三个钉子字数相同或结构平行（如：看激情/看信任/看实力）
- **分离**：每个钉子指向不同维度，不重叠
- **一致**：钉子方向与演讲目标一致，不能偏题

## 多场景应用：三段式 × 不同场景的钉子设计

### 向下管理演讲
目标：激励团队，建立凝聚力
典型钉子：同目标（统一发展目标）/ 更信任（彼此信任鼓励）/ 不内耗（消除内部消耗）

### 销售演讲
目标：引导客户决策，促成购买
设计要点：到位客户分析 + 清晰价值传达 + 故事强化 + 激发购买情绪
案例：雷军小米9发布会——"速度"切入 → 三大技术优势 → "前所未有的快感"

### 创业融资演讲
目标：获得投资者信任和资金
典型钉子（张一鸣字节跳动案例）：
- 看激情（创业方向有未来，让投资者激动）
- 看信任（本人经历可信，让投资者放心）
- 看实力（团队可靠，让投资者认可）

### 产品发布会演讲
目标：唤起用户兴趣，呼吁购买
典型钉子：智慧"脑"（差异化技术）/ 生活"心"（解决用户痛点）/ 价值"体"（性价比）

### 工作汇报演讲
目标：让上级快速理解成果，获得支持
要点：结论先行（SCQA 结构）+ 数据 + 故事案例佐证

## 故事影响力矩阵

选择故事的优先级框架（二维）：
- **X 轴**：故事与演讲目标的相关度
- **Y 轴**：故事的情感强度

优先选相关度高 × 情感强度高的故事；相关但情感弱的故事需要"包装"提升；情感强但不相关的故事舍弃。

## 成咖四步法

把普通经历打磨成有传播力故事的流程：
1. **原料**：找到一段真实经历
2. **提炼**：挖出这段经历中的冲突/转折/意外
3. **放大**：强化感官细节，找到"那一刻"
4. **收束**：明确这个故事要支撑的观点，设计过渡语

> 洞见：演讲设计的本质是"逆向工程"——先确定你想让听众记住什么，再往前推什么故事能自然导向这个结论。
