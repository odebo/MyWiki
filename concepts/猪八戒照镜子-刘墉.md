# 猪八戒照镜子

**核心**：猪八戒照镜子——里外不是人。刘墉用这个隐喻描述"忌无原则"章里那些胳膊肘朝外弯、当老好人却两头得罪的人。

**典型场景**：

1. **当和事佬翻车**：父母吵架，孩子站出来主持公道，结果两边都不被领情，反而被骂"你懂什么"
2. **当传话筒受伤**：A让你传话给B，B听了不高兴，反过来骂你"谁让你传的"
3. **当调解人失格**：朋友闹矛盾找你评理，你各打五十大板，结果两边都认为你偏袒对方
4. **当知情人被牵连**：知道朋友的秘密，朋友A问你朋友B说了什么，你说了被骂"出卖"，不说被骂"不信任"

**猪八戒照镜子的根源**：
- 角色错位——不是裁判却要裁判，不是当事人却要担责
- 立场模糊——既想讨好这边又想讨好那边，结果两边都不讨好
- 原则缺失——没有"情是情，理是理"的边界

**刘墉的处方**：
- **不要当个猪八戒**：宁可不被需要，也不要里外不是人
- **情是情，理是理**：你不是当事人就不要替人做主
- **讨价还价没了价**：原则一旦破例就再也立不起来
- **没有特权才有民主**：让一个人破例就得让所有人破例

**与相关概念的关系**：
- 与 [[百忌哲学-刘墉]] 同源——"忌无原则"是百忌之一
- 与 [[角色的错位]] 同向——角色错位是猪八戒化的根因
- 与 [[内控型人格-罗特]] 互补——内控者不靠讨好别人定位自己
- 与 [[讨好型人格-布琳]] 形成——讨好型人格是猪八戒化的心理基础
