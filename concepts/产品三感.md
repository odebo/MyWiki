# 产品三感

李想《产品实战16讲》第05讲提出的产品标准框架：一款好产品必须同时具备**安全感、价值感、向往感**。

## 三感定义

### 安全感（底线）

用户使用产品时不会感到担忧、焦虑或不确定。

分两层：
- **底线安全**：产品不会伤害用户（质量/安全/可靠性）
- **突破惯性安全**：帮助用户克服对新事物的恐惧

理想ONE的案例：增程器解决"充电焦虑"——这是最核心的安全感。市面上没有里程焦虑的电动车，用户春节回家可以不在高速服务区排队充电，这是一个真实的安全感痛点。

### 价值感（完整体验）

用户能清晰感知到产品在为自己创造价值，且体验是完整的、不打折的。

- 不只是某个功能点好用，而是整个使用链路流畅
- 理想ONE的案例：大六座空间 × 家庭出行场景 = 完整的"家庭最好的移动空间"价值

### 向往感（唤起场景）

产品让用户想起了某个他们渴望的生活场景，并渴望拥有。

- 不是功能描述，而是场景唤起
- 理想ONE的案例：带着孩子露营、全家自驾旅行、车上用家电——这些画面让用户产生向往，而不是"6座SUV，增程动力"的参数描述
- 类似梁宁的"痒点"：满足虚拟自我的想象

## 三感的层次关系

```
向往感（拉动购买）
    ↑
价值感（支撑使用体验）
    ↑
安全感（必要底线，缺失则崩溃）
```

三感必须同时具备。缺少任何一个：
- 缺安全感 → 用户不敢用/买了后悔
- 缺价值感 → 买了用一次就放弃
- 缺向往感 → 理性上可以买，但就是不想买

## 与品牌的关系

产品三感必须在两个地方得到体现（第03讲）：
1. **产品本身**：用户真实使用中感受到
2. **触达方式**：传播内容/门店体验/销售话术必须一致传达

品牌三问作为前置条件：
- 我们是谁？
- 为谁服务？
- 创造什么价值？

验证方法：把品牌定位讲给10个目标用户听，他们脑海里浮现的画面是否高度一致？

## 与梁宁框架的对照

| 李想·产品三感 | 梁宁·用户情绪 |
|-------------|------------|
| 安全感（消除焦虑） | 恐惧的反面 |
| 价值感（完整体验） | 满足（爽点的持续） |
| 向往感（场景唤起） | 痒点（虚拟自我） |
