# 绿区与红区

**定义**：里克·汉森提出的大脑两种模式——绿区（响应模式）和红区（应激模式）。绿区是大脑的"大本营"——平静、满足、联结；红区是大脑的"警报模式"——战斗、逃跑、僵住。复原力的核心是进入绿区、守住大本营。

**核心命题**：
- 大脑应对挑战有两种方式
- 绿区是响应模式——平静、满足、联结
- 红区是应激模式——战斗、逃跑、僵住
- 复原力的核心是进入绿区、守住大本营

**绿区（响应模式）**：
- 平静：心率正常，呼吸均匀
- 满足：多巴胺、血清素水平稳定
- 联结：催产素活跃，感到与他人连接
- 副交感神经主导——"休息与消化"
- 大脑前额叶皮层活跃——理性思考

**红区（应激模式）**：
- 战斗：愤怒、攻击
- 逃跑：焦虑、回避
- 僵住：抑郁、麻木
- 交感神经主导——"战斗或逃跑"
- 杏仁核活跃——恐惧反应
- 皮质醇升高——压力激素

**纸老虎偏执症**：
- 现代生活的"威胁"大多是纸老虎——但大脑反应如同真实老虎
- 一封邮件、一个会议、一条短信——大脑进入红区
- 长期红区导致：免疫力下降、心血管疾病、焦虑抑郁
- "认清纸老虎偏执症"是进入绿区的第一步

**红区的演化根源**：
- 演化让大脑对威胁高度敏感——生存优势
- 负面偏好：负面体验比积极体验反应更强
- " Velcro for negative, Teflon for positive"——负面体验如魔术贴粘得牢，积极体验如不粘锅滑走
- 现代环境无真实老虎——但大脑仍按老虎模式反应

**进入绿区的方法**：

**1. 放松，集中精力**：
- 深呼吸——激活副交感神经
- 肌肉放松——降低皮质醇
- 注意力集中——前额叶皮层活跃

**2. 认清纸老虎偏执症**：
- 询问自己：这是真老虎还是纸老虎？
- 大多数现代威胁是纸老虎
- 认清后大脑自动降低应激

**3. 增加安全感**：
- 找到你的庇护所
- 回忆被关怀的时刻
- 坚信自己内心的美好

**4. 平息愤怒**：
- 愤怒是红区的典型表现
- 接纳愤怒——不要压抑
- 用呼吸和自我关怀平息

**绿区的累积效应**：
- 多次进入绿区——大脑神经回路改变
- 绿区逐渐成为默认模式——大本营稳固
- 即使遇到真威胁——也能快速回到绿区
- 这就是复原力的神经基础

**响应vs应激的关键区别**：

| 维度 | 响应（绿区） | 应激（红区） |
|------|-------------|-------------|
| 神经系统 | 副交感神经 | 交感神经 |
| 大脑区域 | 前额叶皮层 | 杏仁核 |
| 激素 | 催产素、血清素 | 皮质醇、肾上腺素 |
| 心率 | 正常 | 加快 |
| 思考 | 理性 | 反射式 |
| 持续性 | 可持续 | 短期爆发 |
| 健康影响 | 增强 | 损害 |

**与卡尼曼系统1/系统2的对照**：
- 卡尼曼[[系统1与系统2-卡尼曼]]：系统1快速自动；系统2缓慢理性
- 汉森：红区快速反应；绿区理性响应
- 共通：都把大脑分为快速反应和理性模式
- 区别：卡尼曼偏认知；汉森偏神经生理
- 整合：红区≈系统1失控；绿区≈系统2主导

**与卡巴金"接受现实"的呼应**：
- 卡巴金[[疗愈即接受现实-卡巴金]]：接受现实而非抗拒
- 汉森：进入绿区是接受现实的基础
- 共通：都把接纳作为应对挑战的核心

**与自我关怀的关联**：
- 自我关怀是进入绿区的核心方法
- 接纳自己的痛苦——红区降级
- 给自己温柔——绿区稳固
- 见 [[自我关怀-汉森]]

**适用边界**：
- 适用于：慢性压力、焦虑、人际关系冲突
- 适用于：现代生活中的纸老虎威胁
- 不适用于：真实威胁（火灾、袭击）——红区有生存价值
- 不适用于：创伤后应激——需要专业治疗

**实践步骤**：
1. 觉察你何时进入红区——身体信号（心率、呼吸、肌肉紧张）
2. 询问自己：这是真老虎还是纸老虎？
3. 深呼吸——激活副交感神经
4. 找到你的庇护所
5. 用自我关怀平息情绪
6. 多次练习——让绿区成为默认模式
