# PARA 系统

**定义**：**PARA 系统**是蒂亚戈·福特提出的以行动为导向的信息组织法——将所有信息分为四大类：项目（Project）、领域（Area）、资源（Resource）、存档（Archive）。它颠覆了按主题分类的传统（如杜威十进分类法），转而按"信息如何服务当前行动"分类。

**四大类别**：

1. **项目（Project）—— 正在从事的短期活动**
   - 特征：有始有终，明确结果（"定案""许可""发动""出版"）
   - 例：网页设计、会议幻灯片、度假攻略、博客文章
   - 同时进行的项目数量：5-15 个
   - "好莱坞模式"：项目为中心的工作方式渗透到各类脑力工作

2. **领域（Area）—— 长期致力的事项**
   - 特征：无结束日期，但有需坚持的**标准**
   - 例：理财（标准=按时支付账单）、健康（标准=每周锻炼N次）、家庭（标准=周末与家人共度）
   - 与项目的区别：领域是"责任田"，项目是"任务包"

3. **资源（Resource）—— 具有潜在参考价值的信息**
   - 特征：兴趣话题、研究课题、参考信息、个人爱好
   - 例：建筑学、习惯养成、咖啡、经典影碟
   - 不属于当前项目或领域，但日后可能用上

4. **存档（Archive）—— 完结或搁置的事项**
   - 来源：完结项目、不再介入领域、边缘化资源
   - 数字世界中永久保存闲置信息并非坏事
   - 几秒钟内可唤醒沉睡信息

**核心设计原则**：

- **以行动为导向**：组织服务当前正在运作的项目，不服务抽象主题
- **跨平台一致性**：项目就是项目，不因存储载体不同而变化
- **抓取与组织分离**：抓取时存入"收件箱"暂存，组织时再分流到 PARA
- **三层结构**：顶层 PARA 类别 → 子文件夹 → 具体笔记

**核心理念**：
> "为何不将这种[按项目分类的]文件组织方法一直沿用下去呢？既然按照项目分类是最省事也最自然的信息管理办法，那么把它设为默认不就可以了么？"
