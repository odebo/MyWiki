# 人生价值图 Ikigai

**定义**：源自日语"人生价值"（ikigai），近年来欧美广泛使用的反思框架。由四个圆圈重叠组成：**自己喜欢的事**、**社会需要的事**、**能赚钱的事**、**自己擅长的事**。四圆重叠的核心区即人生价值——既能忘记时间、又能判断重要程度的活动。

**四圆与四重叠区**：
- **热情** = 喜欢的事 + 擅长的事：容易获得满足感，但难感受社会贡献，无金钱报酬故不持续。
- **使命** = 喜欢的事 + 社会需要的事：能感受人生喜悦充实，但收入和经济稳定性不足。
- **职业** = 能赚钱的事 + 社会需要的事：能获得生活收入，但无热情，易感空虚。
- **专业** = 擅长的事 + 能赚钱的事：易获工作成就感，但对他人贡献少，易感无聊。
- **人生价值** = 四圆重叠：忘记时间 + 判断重要 + 持续收入 + 社会贡献。

**两大核心功能**：

**1. 让我们忘记时间**：
- 沉浸在快乐事情中时不关注时间流逝——几小时仿佛一瞬间。
- 制作请款单等枯燥任务时频繁看表（"才过了10分钟？"），留下消极回忆，感觉时间过得慢。
- 大脑进入专注状态时只关注眼前工作，从追求效率的思维陷阱中解放出来。

**2. 帮助判断重要的事情**：
- 现代人每6分钟看一次时间，一天查看时间150次。
- 贝尔实验室罗伯特·拉奇估算：意识每秒只能处理约**120比特**信息。
- 一天可消费174份报纸内容（1986年数据量的5倍）。
- 神经科学家丹尼尔·列维廷："在一切都发生得太快、太多的世界里，我们很难区分无关紧要的事情和重要的事情。"
- 人生价值提供明确标准：遇到新信息时问"这与我的人生价值有关吗"，可过滤无关信息。

**研究证据**：
- 人生价值感越强的人：抗压能力越强、免疫系统越健全、寿命越长、幸福指数越高。
- 维多利亚大学101人实验：关注微成功的小组人生满足感增加、抑郁症状减轻。
- 耶鲁大学研究：定期关注微成功的小组积极情绪增加，越消极的人效果越明显。

**实践步骤**：
1. 填写四圆（用提示问题挖掘：什么活动让我不会厌倦？我被身边的人感谢过吗？我曾因为什么赚到钱？我练习过100小时以上的技能是什么？）
2. 寻找重叠答案，移入"使命/职业/专业/热情"区域
3. 挖掘人生价值——若某圆缺失，针对缺失部分提问（不够喜欢→扩大乐趣面；不擅长→寻找良师；赚不到钱→他人如何赚钱；社会需求不足→如何对他人有价值）
4. 有意识地增加花在人生价值活动上的时间（工作间隙、睡前1小时、起床后30分钟）
