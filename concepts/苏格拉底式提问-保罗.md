# 苏格拉底式提问（保罗）

保罗将"苏格拉底式诘问"作为批判性思维的核心方法。它为一般提问方式增加了**系统性、深度和强烈的提问兴趣**，提供批判性思考者**内在的论证需求**——理性地监控、评估、反思思考、感受和行为。

## 苏格拉底式诘问的四个原则

1. **理解根本基础**——尽最大可能去理解所说或所信事物的根本基础，并通过更深入的问题弄清这些基础的蕴含
   - "你形成这个观点的依据是什么？"
   - "你能详细地向我解释你的推理过程，从而让我更全面地理解你的观点吗？"

2. **找联系**——任何思维都只能完全存在于相互联系的思维网络。把所有断言看作进一步思考的连接点
   - "如果你说的是真的，为什么X或Y不是真的呢？"

3. **考虑所有观点**——不断论证的需求让你考虑所有的观点
   - "你能够详细阐释从而让我更好地理解你的观点吗？"

4. **追问之前的问题**——所有的问题都以之前的问题为基础，所有的思维也都以之前的思维为基础
   - "为了回答这个复杂的问题，我们还需要回答哪些其他问题？"

## 五种提问聚焦法

保罗指出，受过训练的提问方式可以从五个角度聚焦：

1. **聚焦问题类型**——事实类、偏好类、判断类
2. **聚焦理智的标准**——按清晰性、准确性、精确性等评估
3. **聚焦思维的要素**——按目的、问题、信息、概念等分析
4. **聚焦"拆解"复杂问题**——优先回答对获得最终答案最有效的问题
5. **聚焦问题涉及的领域**——抓住复杂问题涉及的领域

## 三种问题类型

| 类型 | 特征 | 示例 |
|------|------|------|
| **事实类** | 有唯一正确答案，可在准确界定的系统中寻找 | "中国的GDP是多少？" |
| **偏好类** | 需要主观意见或个人观点 | "你更喜欢绿茶还是红茶？" |
| **判断类** | 可从不同角度有差别地回答，需考虑所有情况后给出最佳答案 | "死刑应被废除吗？" |

**关键洞察**：当问题需要开展论证时，某人说不需要论证自己的答案，他可能把**判断类问题**当作**偏好类问题**了；把判断类问题当作只存在唯一正确答案的事实类问题，是过度简化问题。

## 按理智标准提问的模板

| 标准 | 提问模板 |
|------|----------|
| 清晰性 | 你能详细阐释吗？能举例吗？ |
| 精确性 | 能给我多一些细节吗？能更明确吗？ |
| 准确性 | 我们怎样检查信息是否真实？怎样核实？ |
| 相关性 | 你所说的与问题如何关联？ |
| 深度 | 这个问题是简单还是复杂？是什么让它复杂？ |
| 广度 | 哪些视角与这个问题相关？忽略了哪些角度？ |

## 按思维要素提问的模板

- **目的**：之所以这么说，是因为你想要达到什么目标？
- **信息**：你根据什么信息得出了这个评价？
- **推论**：你是如何得出那个结论的？存在其他可信结果吗？
- **概念**：你论证中使用的主要观点是什么？
- **假设**：你觉得什么是理所当然的？为什么做出这样的假设？
- **蕴含**：你在持这样观点的时候意味着什么？
- **角度**：你是依据哪个角度得到这个结论的？存在其他角度吗？

## 苏格拉底式提问 vs 一般提问

| 维度 | 一般提问 | 苏格拉底式提问 |
|------|----------|----------------|
| 目的 | 获取答案 | 揭示思维结构 |
| 系统性 | 零散 | 系统化 |
| 深度 | 表面 | 追问根本基础 |
| 联系性 | 孤立 | 找观点间联系 |
| 对回应 | 接受 | 进一步追问 |
| 训练 | 无需训练 | 需大量练习 |

## 与已有体系的关联

- 与 [[学会提问-尼尔布朗]] 同源——布朗的10个批判性问题即苏格拉底式提问的具体化
- 与 [[提问-韦德尔-韦德尔斯堡]] 互补——韦德尔强调"重新定义问题"，保罗强调"系统追问"
- 与 [[提问者掌握大局用问题来回答问题是最有力的沟通方式-保罗·斯隆]] 同源——皆强调提问的力量
- 与 [[教练式提问-惠特默]] 互补——教练式提问偏启发行动，苏格拉底式偏揭示结构
- 与 [[向自己提问是最高级的学习方法-费曼]] 同源——费曼的自我提问是苏格拉底式的内化
