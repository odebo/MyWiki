# PAC三种自我状态

**定义**：**PAC 三种自我状态**是伯恩沟通分析理论的基础——每个人在任意时刻都处于三种自我状态之一：**父母（Parent）、成人（Adult）、儿童（Child）**。不同状态对应不同的思维、情感、行为模式。沟通冲突多源于自我状态的错位。

## 三种自我状态

### 1. 父母（Parent, P）
- **来源**：内化的父母或权威形象
- **特征**：批判、规范、照顾、传统
- **语言**："应该"、"必须"、"不可以"
- **情绪**：威严、关怀、愤怒
- **两类**：
  - 养育型父母（Nurturing Parent）：关怀、照顾
  - 批判型父母（Critical Parent）：规则、批判

### 2. 成人（Adult, A）
- **来源**：当下的理性思考
- **特征**：客观、逻辑、事实导向、当下
- **语言**："根据数据"、"我观察到"、"理性看"
- **情绪**：平静、清醒、无情绪干扰
- **功能**：信息处理、决策、现实检验

### 3. 儿童（Child, C）
- **来源**：童年记录的经验与情感
- **特征**：直觉、情感、创造、冲动
- **语言**："我想要"、"我不喜欢"、"好好玩"
- **情绪**：欢乐、恐惧、愤怒、好奇
- **两类**：
  - 自由儿童（Free Child）：自然、创造性
  - 适应儿童（Adapted Child）：顺从或反叛

## 三状态的切换

- 同一人不同时刻处于不同状态
- 状态切换常无意识
- 压力下多退行至 P 或 C
- 成熟者能稳定在 A

## 与弗洛伊德的对应

- 父母 ≈ 超我（Superego）
- 成人 ≈ 自我（Ego）
- 儿童 ≈ 本我（Id）
- 但伯恩强调可观察的行为，非内在结构

## 识别自我状态

### 父母的信号
- 指手画脚
- "你应该"
- 模仿父母语气
- 皱眉、抱臂

### 成人的信号
- 提问
- "根据数据"
- 平静专注
- 眼神接触稳定

### 儿童的信号
- "我想要"
- 情绪化
- 皱眉、撅嘴
- 笑容灿烂或哭闹

## 三状态与健康

- **健康**：能灵活切换，多数时间在 A
- **僵化**：固定某一状态
  - 长期 P：批判、控制
  - 长期 A：冷漠、机械
  - 长期 C：幼稚、依赖
- **成熟**：A 主导，P 与 C 辅助
