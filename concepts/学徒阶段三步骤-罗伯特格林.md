# 学徒阶段三步骤 - 罗伯特·格林

格林将学徒阶段（通往精通的第一个关键阶段）分解为三个递进步骤和八条策略。

**第一步：深入观察/被动模式（Deep Observation）**。沉入新环境，安静地观察一切——权力关系、不成文规则、成功所需的隐性知识。先观察后行动，像狩猎采集者一样用心看，克服急于表现的本能冲动。

**第二步：获得技能/练习模式（Skills Acquisition）**。开始动手，反复练习基本功。这里的核心原则是"学习重于金钱"——选择能学到最多东西的位置，而不是薪资最高的位置。关键是要拥抱阻碍和痛苦，在失败中训练自己。

**第三步：实验/主动模式（Experimentation）**。技能积累到一定程度后，开始试验自己的想法，融入自己的风格和个性，不再只是模仿他人。把"如何"与"什么"结合起来——既精通技术细节，也理解整体目的。

**八条学徒策略**：学习重于金钱 / 不断拓宽视野 / 重新认识自身不足 / 信任自然学习过程 / 拥抱阻碍和痛苦 / 在失败中训练自己 / 将"如何"与"什么"结合 / 在试错中进步。
