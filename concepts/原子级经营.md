# 原子级经营

李想《产品实战16讲》第15讲（利润）的核心方法论：**把每个经营指标拆分到不能再拆的最小单元，在过程中实时干预，而非等结果揭晓后事后复盘**。

## 核心思想

> 传统管理：看整体结果→发现问题→事后改善（滞后1个月到1个季度）
>
> 原子级经营：拆到最小颗粒→每个原子健康→整体健康（实时干预）

## 双向拆分验证

**顺向**（从产品整体往下拆）：
- 总毛利目标 → 单车毛利 → 各成本项 → 单个人效/工时

**逆向**（从最小单元往上推）：
- 一个产品专家每月需要卖多少车来覆盖工资成本？
- → 需要多少次试驾？
- → 需要多少条线索？
- → 线索处理+试驾安排需要多少工时？
- → 是否符合正常工作量标准？

两套数据交叉验证：如果顺向和逆向不吻合，说明预算中存在不合理假设。

## 应用案例

### 人员成本拆分

不只看"人员成本整体占比"，而是拆到：
- 单个员工的具体工作产出是否能覆盖其薪资
- 每个环节的转化率是否合理
- 工时是否与工作量匹配

### 市场占有率拆分

不只看最终交付市占率，而是从前到后全链路拆分：
```
传播平台市占率 → 客流市占率 → 线索市占率 → 订单市占率 → 交付市占率
```
每一层与预期不符就立即干预，不等到最后才发现问题。

## 最佳实践提炼

**流程**：
1. 通过数字化系统找到各环节数据最好的人/团队
2. 深入了解他们的做法，总结成最佳实践
3. 金牌/银牌/铜牌评选制度 + 分享大会
4. 最佳实践案例集供所有人学习
5. 每半年刷新最高标准

**案例**：某产品专家电话预约试驾率极高 → 话术被标注重音和语调打印贴在电脑上 → 推广给所有人 → 几个月内大部分人数据接近最高值。

**关键**：制造分享场域（金牌评比、分享会），而非强制推广——人的分享欲需要被激活。

## 不刷存在感原则

**原则**：所有成本投入必须对应用户价值，没有清晰用户价值的功能/零部件一律不加。

**识别刷存在感的方法**：
- 这个功能改进有用户反馈说不好吗？
- 如果没有，为什么要改？
- → 是你在刷存在感，不是在创造价值

**NPS权重系统**：
- 详细记录用户在转推荐和反馈中感知的每个功能点
- 赋予权重
- 研发计划严格按权重制定

**李想的追问**：
> "我们的用户是谁？为他们创造什么价值？团队有没有就用户价值达成统一共识？"
>
> 这些问题没想清楚，后期每个决策都在堆积成本。
