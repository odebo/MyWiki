# Hook 模型

Hook 模型是尼尔·埃亚尔在《上瘾》中提出的产品习惯化设计框架，描述如何将产品使用变成用户自发的习惯性行为，无需昂贵的广告推动。

## 四阶段循环

```
触发(Trigger) → 行动(Action) → 多变的酬赏(Variable Reward) → 投入(Investment) → [下一次触发]
```

每一次循环都加深用户与产品的连接，降低下次使用的心理门槛。

### 触发（Trigger）

**外部触发**四类，按习惯化潜力排序：
- **付费触发**：广告、推广位（高成本，短期有效）
- **回馈性触发**：PR、媒体报道（中等成本，影响力强但不可控）
- **人际触发**：口碑、社交分享（边际成本低，传播自然）
- **自主触发**：通知、图标、书签（已获得用户许可，习惯化核心）

**内部触发**：与负面情绪挂钩——孤独感、无聊、FOMO（错过恐惧）、不确定感。Instagram 案例：用户孤独时拍照分享，产品与"孤独"这一内部触发绑定。内部触发是最持久的触发形式，也是习惯真正形成的标志。

### 行动（Action）

基于福格行为模型 B=MAT（行为 = 动机 × 能力 × 触发）。

核心原则：**永远先简化能力，而非强化动机**。减少摩擦比激励用户更有效。

六大能力要素（能力的"最少阻力路径"）：
1. 时间——完成行为所需时间
2. 金钱——财务成本
3. 体力——身体消耗
4. 脑力——认知负荷
5. 社会偏差——是否符合社会规范
6. 非常规——与常规行为的偏离程度

### 多变的酬赏（Variable Reward）

不可预测的奖励比固定奖励更能持续激活神经奖励回路。三类：
- **社交酬赏**：他人认可（点赞、评论、关注）
- **猎物酬赏**：信息/资源（刷社交媒体信息流、搜索结果）
- **自我酬赏**：掌控感/成就（完成任务、游戏升级）

### 投入（Investment）

用户在产品中存入时间、精力、数据、社会资本，形成**存储价值**，并改变下次触发的性质（个性化外部触发更精准，内部依恋感更深）。

## 习惯区间

习惯 = **使用频率足够高** + **感知效用超过替代品**。频率与效用两个维度缺一不可。低频但效用高的产品（如保险）难以形成习惯；高频但效用不明显的产品会被用户抛弃。

## 习惯的商业价值

- **提升用户终身价值（LTV）**：习惯用户流失率低
- **降低获客成本**：口碑和自主触发取代付费广告
- **提高定价权**：习惯性产品替代成本高
- **带来口碑增长**：习惯用户更愿意推荐

## 与福格行为模型的关系

Hook 模型的「行动」阶段直接采用 B=MAT 框架，但比福格模型更进一步：将单次行为触发扩展为**多次循环的习惯化系统**，并加入了酬赏和投入两个维度来解释为何循环会自我强化。
