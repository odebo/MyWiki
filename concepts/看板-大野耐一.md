# 看板

**定义**：看板（Kanban）是丰田生产方式中确保准时化（JIT）落地的核心运用手段。它是一张随零部件流转的卡片/标签，承担"领取指令"和"生产指令"两种信息功能，使后工序拉动前工序的逆向流程可视化、可执行。

**核心误解澄清**：大野耐一强调——"看板方式只是丰田生产方式的运用手段之一，并不是说仅仅采用看板方式就能提高生产效率。"把"丰田生产方式"与"看板方式"画等号是片面理解。看板是手段，准时化和自働化才是支柱。

**看板的灵感起源——超市**：大野耐一从超市得到的启发——超市按顾客需要补充货架商品，不会预先堆积。看板就是生产线上的"超市补货机制"——后工序像顾客一样从前工序"购买"所需零部件。

**看板与台车的搭档**：看板不是孤立的卡片，而是与台车（搬运工具）配套使用——零部件装在贴有看板的台车里，看板随台车流转，前台一目了然地知道当前零件信息、下一道工序的需求。

**看板的两类功能**：
1. **领取指令**——后工序拿着看板去前工序领取所需零部件
2. **生产指令**——前工序看到返回的看板后开始生产对应数量

**看板工作的前提**：
- 必须先构建流水作业生产线（不能在工序混乱的状态下引入看板）
- 必须实现均衡化生产（生产数量和种类尽量平均，避免大幅波动）
- 必须有标准作业（每个工序的节拍明确）

**看板的灵活性（应对变化）**：
- 微调作用——通过看板数量微调应对小幅需求变化
- 赋予企业"反射神经"——能快速响应市场变化
- 在需要的时间提供所需的信息——信息流与物流同步

**"一知半解后患无穷"**：大野耐一警告——只看到看板的"形式"而忽视其底层理念（拉动、JIT、均衡化、自働化）就贸然引入，非但不会成功反而造成混乱。许多企业模仿丰田引入看板失败，根本原因是没理解看板只是表象，理念才是基础。

**看板的多重价值**：
- 缩减工时——通过看板控制产出，自然消除产出过剩
- 减少库存——后工序不领前工序不产
- 消灭次品——看板随不合格品停止流转
- 防止故障再次发生——异常时看板流转中断，问题暴露
- 目视化管理——任何人都可一抬头看到当前状态

**与已有体系的关联**：
- 与 [[准时化JIT-大野耐一]] 不可分——看板是JIT的信息载体
- 与 [[自働化-大野耐一]] 互补——自働化暴露问题，看板控制流转
- 与 [[七大浪费-大野耐一]] 同源——看板主要消除"产出过剩"和"库存"浪费
- 与 [[五个为什么-大野耐一]] 互补——看板暴露异常，五个为什么追溯根因
- 与 [[丰田4P模型-莱克]] 互补——莱克4P模型将看板纳入流程维度
- 与 [[现场Gemba与改善Kaizen-莱克]] 同源——看板是现场目视化的核心工具
