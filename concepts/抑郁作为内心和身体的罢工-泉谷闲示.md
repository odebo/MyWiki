# 抑郁作为内心和身体的罢工

**定义**：泉谷闲示颠覆传统精神医学的抑郁观——抑郁不是脑化学失衡或心理脆弱，而是**内心和身体的"罢工"**。当头脑的独裁统治让内心和身体无法承受时，它们选择罢工——身体某天早晨突然无法动弹、反复迟到缺勤、失眠、躯体化症状都是罢工的形式。抑郁是内心和身体的呼救信号——疾病本身在拯救患者。治疗不应是消除症状让患者"恢复原状"——因为"原状"正是导致抑郁的环境。

**抑郁罢工的典型形式**：

1. **身体罢工**：身体在某天早晨突然无法动弹——不是懒惰而是身体拒绝服从头脑
2. **行动罢工**：反复迟到、无故缺勤——内心拒绝工作环境的信号
3. **睡眠罢工**：失眠——内心和身体用拒绝睡觉的方式反抗头脑；睡眠是内心和身体的事情不能被头脑命令
4. **情绪罢工**：冷漠、丧失兴趣——内心关闭感受通道以自我保护
5. **躯体化症状**：身体症状（头痛、胃痛、心悸）是内心在"呼救"——破解躯体化症状的"密码"指向未表达的情绪

**"抑郁是疾病在拯救患者"的核心命题**：
- 传统精神医学：抑郁是疾病——需要被消除
- 泉谷：抑郁是内心和身体的呼救——疾病本身在拯救患者
- 如果用药物强行消除症状——相当于关掉警报系统而火灾还在燃烧
- "恢复原来的状态"会导致抑郁症复发——因为"原状"就是致病环境

**抑郁的"假性抑郁"问题**：
- 抑郁症的定义不断变化——DSM各版本诊断标准不同
- 诊断范围有扩大的趋势——把正常悲伤也病理化
- 存在"假性抑郁"——表面症状像抑郁但本质不同
- 只凭表面症状做出诊断会导致误诊

**"心灵感冒"比喻的问题**：
- 把抑郁症比喻成"心灵感冒"——暗示是临时性疾病
- 比喻与现实之间的巨大落差——感冒几天就好，抑郁需要深层转变
- 抑郁症的治疗目标不是消除症状——而是让内心和身体找回主导权
- 最重要的工作几乎都是患者自己承担的——药物只能辅助

**容易抑郁的人格特征**：
- **做事追求准确与周密**——头脑独裁最彻底
- **责任感强、回避冲突**——内心被压抑最深
- **扮演"好孩子"的反作用**——长期扮演导致自我否定
- **精神力量强的人更加危险**——他们的头脑独裁更顽固

**"因为患抑郁症在家休假为什么还能出去玩"的悖论**：
- 传统观点：能出去玩就不是真抑郁——是装病
- 泉谷：能出去玩是病情改善的证明——内心在重新激活
- 抑郁患者不能工作但能玩——因为工作环境是致病源而玩是内心喜欢的
- 这一悖论揭示了"罢工"的选择性——内心拒绝伤害它的事物

**与"适应"概念的对照**：
- 传统观点：康复=适应社会
- 泉谷：**适应是麻痹的别名**——把对不合理环境的麻木误认为康复
- 将适应视为正常是危险的认知——它让患者继续承受致病环境
- 真正的康复不是适应——而是改变环境或改变自己

**治疗原则**：
1. **不要鼓励**——他人的鼓励会让患者感到更深的孤立
2. **不要急于复职**——"早日复职"是头脑的目标不是内心的目标
3. **不要"战胜抑郁"**——战胜是头脑的姿态，内心需要的是被倾听
4. **享受"不知道自己想做什么"的状态**——这是从骆驼到狮子的过渡
5. **坚持"昼夜颠倒"**——打破头脑强加的规律生活
6. **坚持"虎头蛇尾"**——放弃头脑的完美主义
