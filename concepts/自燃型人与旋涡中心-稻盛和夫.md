# 自燃型人与旋涡中心

**定义**：稻盛和夫对工作者的三类划分——**可燃型**（点火就着）、**不燃型**（点火也不着）、**自燃型**（自己燃烧）。"自燃型"是稻盛的理想型——不需要外部激励就能自我驱动的人。进一步，自燃型人应主动进入"旋涡中心"——成为团队工作的核心推动者，把周围人裹挟进工作中。

**三类人**：

1. **自燃型**：自己能燃烧的人——主动、有目标、不需外部督促
2. **可燃型**：被点火就燃烧的人——需要外部激励但能跟上
3. **不燃型**：点火也不着的人——冷漠、被动、消耗团队

**自燃型的两个特征**：
1. **热爱工作**——对自己的工作注入深沉关爱之情
2. **持有明确目标**——不只是按上司指示办，有自主努力的冲动

**旋涡中心——从自燃到引领**：
- 旋涡：工作中自然形成的核心议题/任务流
- 不在旋涡中心：只在四周咕噜咕噜跟着大家转，很难体会工作真正的乐趣
- 进入旋涡中心：积极把周围人裹挟进去，充分体会工作乐趣
- 旋涡中心的人有希望成为团队领导

**如何"卷起旋涡"**：
- 主动开口："我想这么做""让我们把这件事干完吧"
- 不等指令，自主制造工作议题
- 把周围人吸引到自己的议题中

**稻盛的"抱着产品睡"**：
- 早期研发新型陶瓷时，对产品注入深沉关爱
- "抱着产品睡"——把产品当作生命对待
- "倾听产品的哭泣声"——敏锐感知产品的问题
- 这是自燃型的极致体现——人与工作对象融为一体

**机制——为什么需要自燃型**：
1. **工作性质变化**：现代知识工作无法靠监督驱动
2. **创新需要内驱**：突破性创新只能来自自我驱动者
3. **团队动力学**：一个自燃型可点燃整个团队
4. **意义感来源**：自燃型从工作本身获得意义，而非外部回报

**与其他动机理论的对照**：
- 心流[[心流-契克森米哈伊]]：能力与挑战匹配时进入心流
- 自燃型：进入心流的前提是自我驱动
- 共通：都强调内在动机
- 区别：心流描述状态；自燃型描述人格类型

**与"痴迷"的呼应**：
- 多贝里[[能力圈与痴迷-多贝里]]："痴迷是引擎而非故障"
- 稻盛"自燃型"：对工作痴迷的人
- 共通：都把强烈投入视为正面而非病态
- 区别：多贝里强调在能力圈内痴迷；稻盛强调对眼前工作的痴迷

**与"热爱"的层级**：
1. **喜欢**：浅层好感
2. **热爱**：深层投入
3. **迷恋**：稻盛常用——"应该迷恋工作、热爱工作、拥抱工作"
4. **抱着产品睡**：迷恋的极致——人与工作对象不分

**稻盛的转变故事**：
- 大学专攻有机化学，想去公司不肯录用
- 不得已就职松风工业（无机化学/绝缘瓷瓶）
- 起初对新型陶瓷无兴趣
- 决定改变"心态"——"埋头到工作中去！"
- 先排除"厌恶工作"的负面情绪
- 倾注全力先把眼前工作做好
- 通过努力让自己喜欢上工作——心态转变后命运戏剧性变化

**适用边界**：
- 适用于：知识工作、创新工作、领导岗位
- 适用于：职业初期建立工作态度
- 不适用于：严重有毒的工作环境——不应"自燃"于剥削
- 不适用于：纯粹机械执行的工作——自燃与不燃差别不大
- 与"工作生活平衡"的张力：稻盛主张工作即修行；现代平衡观主张边界——需个体平衡

**实践含义**：
- 主动开口提议——而不是等待指令
- 把自己置于工作核心议题——而非边缘
- 对产品/工作对象注入关爱——而非把它当客体
- 改变心态——即使起初不喜欢，先排除厌恶情绪
- 让自己成为团队中的"点火源"——而非"耗氧者"
