# 创意四源法

安佳提出的新媒体文案创意来源分类——爆款文案的创意 90% 可归入四个源头，把"灵感式写作"重构为"方法驱动的系统生产"。

## 四个源头

### 1. 反常识（Cognitive Subversion）
颠覆用户的默认认知。例："为什么越努力的人越穷？"
- 机制：制造认知冲突，触发系统2介入（卡尼曼）
- 适用：科普类、知识付费类、观点类内容
- 风险：过度使用导致"标题党"反噬

### 2. 强共鸣（Emotional Resonance）
说出用户说不出口的话。例："成年人的崩溃，都是静音的。"
- 机制：用户转发=替自己表态
- 适用：情感类、生活方式类、职场类
- 关键：必须基于真实洞察而非编造情绪

### 3. 高密度信息差（Information Asymmetry）
提供独家视角或方法。例："99%的人不知道，这个 Excel 公式能省 3 小时。"
- 机制：转发=社交货币（用户借此展示"我知道"）
- 适用：干货类、教程类、行业分析类
- 关键：信息差必须真实存在且可验证

### 4. 情绪势能（Emotional Potential）
高强度情绪——愤怒、感动、自豪、焦虑。例："看完这个视频，我哭了三遍。"
- 机制：高强度情绪突破转发阈值
- 适用：社会议题、品牌共情、节日营销
- 风险：情绪操控易翻车，必须真诚

## 创作应用

四源法不是选择题而是组合题——顶级文案通常叠加两个源头：
- 反常识 + 强共鸣 = 观点爆款
- 高密度信息差 + 情绪势能 = 干货爆款
- 强共鸣 + 情绪势能 = 情感爆款

四源叠加是极少见的"现象级爆款"配方。

## 与创新方法论的关联

四源法与乃斯《走出思维泥腊》PIG In MuD 创新六步法属同一类——都是把"灵感"拆解为可训练的路径。区别在于：乃斯面向科学创新，安佳面向传播文案；前者重"识别框架→打破框架"，后者重"识别情绪→激活情绪"。
