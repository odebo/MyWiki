# 8周正念禅修

**定义**：8周正念禅修是基于正念认知疗法（MBCT, Mindfulness-Based Cognitive Therapy）设计的标准化课程——由马克·威廉姆斯、约翰·蒂斯代尔、津戴尔·赛戈尔在卡巴金MBSR基础上开发，专门用于**预防抑郁症复发**。课程把禅修、认知疗法、习惯破除训练整合为8周可执行的结构化计划，每天20-30分钟。被英国NICE（国家健康和临床质量研究所）认证为抑郁症复发预防的有效疗法。

## 8周课程结构

| 周 | 主题 | 核心练习 | 习惯破除 |
|----|------|---------|---------|
| 第1周 | 认识自动导航状态 | 身体与呼吸的正念禅修 | 小水果大内涵 |
| 第2周 | 关注你的身体 | 身体扫描 | 出去散步 |
| 第3周 | 迷宫中的老鼠 | 3分钟呼吸空间 | 电视评估 |
| 第4周 | 离开谣言工厂 | 声音和想法禅修 | 去看一场电影 |
| 第5周 | 直面困难 | 悄悄靠近接受 | 播撒种子/照料植物 |
| 第6周 | 深陷过去还是活在当下 | 把呼吸空间拓展到消极想法 | 习惯破除 |
| 第7周 | 你是从什么时候不再跳舞的 | 只工作不娱乐/再次舞蹈 | 尝试再次舞蹈 |
| 第8周 | 喧嚣但珍贵的生活 | 把所学运用到日常 | 终身实践 |

## MBCT vs MBSR

| 维度 | MBSR（卡巴金） | MBCT（威廉姆斯等） |
|------|---------------|-------------------|
| 起源 | 1979年马萨诸塞大学医学院 | 1990年代牛津大学等 |
| 目标人群 | 慢性疼痛、压力、广泛人群 | 抑郁症康复期患者防复发 |
| 理论基础 | 佛教正念传统 | 正念+认知疗法 |
| 时长 | 8周 | 8周 |
| 每日练习 | 45分钟 | 20-30分钟 |
| 核心工具 | 身体扫描、坐禅、瑜伽 | 身体扫描、3分钟呼吸空间、习惯破除 |
| 独特设计 | — | 三分钟呼吸空间、习惯破除训练 |

## 四个核心理论支柱

1. **行动模式 vs 存在模式**——行动模式处理情绪会陷入恶性循环
2. **苦思冥想是问题**——解决问题的努力反而加固问题
3. **想法只是想法**——不把想法当现实
4. **接近而非回避**——靠近困难情绪让其消散

## 循证基础

- **NICE认证**：英国国家健康和临床质量研究所推荐MBCT用于抑郁症复发预防
- **复发率降低**：研究显示MBCT显著降低抑郁症复发率
- **停药后保护**：停服抗抑郁剂的患者进行8周MBCT训练，复发率显著降低
- **大脑变化**：8周训练足以改变大脑关键区域的作用方式
- **日常效果**：每天20-30分钟，8周即可看到效果

## 8周课程的整体逻辑

```
第1-2周：训练注意力，认识自动导航
    ↓
第3-4周：学会换挡（呼吸空间），离开谣言工厂
    ↓
第5-6周：直面困难，接近情绪，破除过去束缚
    ↓
第7-8周：恢复生活活力，把正念作为终身实践
```

前4周更侧重训练注意力、了解行动模式、体会存在模式；后4周更侧重把所学运用到具体困境（消极想法、压力、疲惫、深层关系模式）。
