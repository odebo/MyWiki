# 微小习惯设计

**主题**：[[个人成长]] [[学习策略]]

## 核心思想

微小习惯（Tiny Habits）是福格行为模型最重要的应用方法。**习惯不需要靠动机驱动，而是靠设计驱动。** 把行为缩到足够小，让它在动机最低时也能被执行——这是绕过意志力的根本路径。

> "要从小处着手，不要责怪自己缺乏动力或意志力，我们所做的一切就是设计和重新设计。"

## 微小化的两条路径

### 路径一：入门步骤（Starter Step）

只做开头那个最小动作，不要求完成整件事：
- 想要养成跑步习惯 → 只穿上跑鞋
- 想要养成冥想习惯 → 只坐到冥想垫上
- 想要写作 → 只打开文档

入门步骤降低了"开始的阻力"，一旦开始，后续往往自然发生。

### 路径二：缩小规模（Scale Back）

把行为本身缩到象征性的最小单位：
- 想要做100个俯卧撑 → 先做2个
- 想要冥想30分钟 → 先冥想1次呼吸
- 想要读书 → 只读1段

**关键原则**：行为必须小到"即使你最累最忙最没动机的时候，也绝对能做到"。

## ABC微习惯配方

每个微习惯由三部分构成：

```
Anchor（锚点时刻）→ Behavior（微行为）→ Celebration（即时庆祝）
```

**配方格式**："在我……之后，我会……"

例：
- 在我刷完牙之后，我会用牙线清洁一颗牙齿。
- 在我倒上咖啡之后，我会做2个深蹲。
- 在我停好车之后，我会闭上眼睛深呼吸3次。

## 习惯生长的原理

微小习惯一旦建立，会自然生长：
1. 成功体验积累 → 身份认同转变（"我是个每天运动的人"）
2. 身份认同 → 内在动机增强
3. 内在动机 → 行为自然扩展

**不要强迫自己扩展**。当微习惯感觉"太简单了，我想多做一点"时，自然增加。

## 常见错误

- **设计太大**：想一步到位，结果动机低时就失败，积累失败感
- **依赖动机**：等到"有感觉的时候再做"——那个时候永远不会稳定到来
- **忽略庆祝**：完成后没有即时积极情绪，大脑不会编码成习惯

## 与《掌控习惯》的关系

克利尔的"两分钟规则"和福格的微小习惯是同一思路的不同表述。福格更强调**情绪/庆祝**对习惯编码的神经机制，克利尔更强调**身份认同**的作用。两者互补。
