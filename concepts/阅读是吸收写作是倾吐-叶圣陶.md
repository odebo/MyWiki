# 阅读是吸收，写作是倾吐

叶圣陶提出的读写关系论：**阅读是吸收，写作是倾吐**——倾吐的质量取决于吸收的厚薄。读写不是两件事，而是同一件事的两个方向。

## 核心命题

- **阅读** = 把外部的见闻思想吸收到内在
- **写作** = 把内在的见闻思想倾吐到外部

两者构成一个完整的循环——没有吸收就没有倾吐的内容，没有倾吐则吸收无法内化。读和写互为根茎。

## 推论

1. **写作不好根在阅读不够**：写不出/写不好的人，问题通常不在写作技巧，而在阅读量不足或阅读质量不高
2. **阅读必须主动**：被动阅读（看情节/看热闹）无法吸收，必须主动阅读（思辨/质疑/对照）
3. **阅读必须广泛**：只读一种文体/一个作者会导致吸收偏狭，倾吐必然贫乏
4. **阅读必须精读与略读结合**：精读训练吸收深度，略读训练吸收广度

## 与"读一千本书才能写一本书"的对应

斋藤孝《写作全技术》提出"读一千本书才能写一本书"——这一论断与叶圣陶的"吸收倾吐"论完全同构。两人都指出：
- 写作的根在阅读
- 阅读量决定写作上限
- 阅读质量决定写作质量

差异：叶圣陶从教育学角度讲读写关系，斋藤孝从实战写作角度讲读写比例。

## 阅读的方法

叶圣陶特别强调"精读"的方法：
1. **通读**：先通读一遍，把握大意
2. **复读**：再读时关注细节，圈点批注
3. **研读**：第三遍带着问题研读，与作者对话
4. **复读反思**：合上书回想，写下自己的思考

精读的目的不是"读完"而是"吸收"——一本书读三遍胜过三本书各读一遍。

## 现代意义

信息爆炸时代的"伪阅读"——刷短视频/读标题/看摘要——本质是"无效吸收"，无法支撑任何有质量的写作。叶圣陶的"读写循环"论提醒：写作质量下降的根因往往不在写作训练不足，而在阅读深度被信息流稀释。
