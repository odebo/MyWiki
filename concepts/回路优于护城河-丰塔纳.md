# 回路优于护城河

**回路（Loop）** 是 [[智能先行-丰塔纳|丰塔纳]] 用来描述 [[数据学习效应-丰塔纳|数据学习效应]] 动态运动特性的概念，主张 AI 优先公司的竞争优势应理解为"自我强化的环状运动"而非巴菲特式的静态"护城河"。

## 数据学习回路的三个组成部分

1. **输入**：访问独特的数据
2. **处理**：处理数据的能力
3. **网络**：针对经过处理的数据进行学习的模型

前两部分可以有自己的内部回路（如机器人环游世界收集数据，或使用机器学习处理数据）。但只有前两部分完成、模型创造了数据网络效应之后，更高级别的回路才会开始。

## 回路的物理学特征（与蒸汽引擎类比）

1. **两种东西必须相互作用才能产生另一种东西**：锅炉里的水沸腾产生蒸汽产生热量 → 数据与模型反应生成预测
2. **必须有两种以上的东西相互作用，否则能量消散**：气缸和活塞 → 依据预测行事的人
3. **协调一致行动，避免激烈反应或过度耗能**：蒸汽刚好充满气缸 → 数据、模型、人、现实协调
4. **中间的熵步骤**：曲柄几乎停止时形成临界蒸汽量 → 模型与现实之间的反馈延迟
5. **必须在现实世界中有所作为**：活塞推动曲柄 → 预测影响现实
6. **必须回到最初状态才能重新开始**：活塞回到初始位置 → 模型接收新反馈数据

## 回路的自我强化机制

```
数据 → 模型 → 预测 → 人依据预测行动 → 现实反馈 → 模型学习 → 新预测 → ...
```

超市补货案例：
1. AI 预测：15分钟后意大利面断货
2. 售货员核查确认，补货
3. 摄像机 + 应用程序 + 售货员笔记反馈给 AI
4. AI 增加下一次预测的信心，提前几小时预警
5. 补货时间从几小时缩短到几分钟

## 重复性是回路的核心

> "重复性是回路运动固有特征；回路不停地循环往复。如果不重复，竞争优势就不会复合。"

数据学习回路与每一批反馈数据一起循环。每次循环生成预测 → 客户带入真实世界 → 影响产生 → 模型学习 → 新预测。

## 与护城河的对比

| 维度 | 护城河 | 回路 |
|------|-------|------|
| 性质 | 静态防御 | 动态运动 |
| 复合 | 不复合 | 每次循环复合 |
| 失效 | 被攻破即失效 | 停止循环即失效 |
| 测量 | 难以量化 | 可通过回路速度、数据量、准确度测量 |
| 适用对象 | 传统企业 | AI 优先公司 |

## 回路崩溃的应对

当回路崩溃时，需要"点亮整个回路"——这是第七章的核心主题：
- 测量机器学习模型准确度（混淆矩阵等）
- 计算建立 AI 优先公司的各种成本
- 选择正确的问题用 AI 解决（回报、数据需求、漂移可能性）

## 与其他概念的关系

- 是 [[数据学习效应-丰塔纳]] 的动态视角：DLE 是静态结构，回路是运动方式
- 与 [[飞轮效应]] 概念家族：回路是飞轮在 AI 时代的精确化表述
- 与 [[在成功之前你必须先生存下来-索普]] 精神呼应：索普关注不破产，丰塔纳关注回路不崩溃
