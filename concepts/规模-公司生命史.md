# 规模-公司生命史

公司的规模法则与城市截然相反——公司更像生物体（亚线性扩展），最终停止增长并走向死亡。死亡率遵循与行业、规模、死亡原因均无关的普遍指数规律。

## 公司的规模法则：亚线性

基于标普Compustat数据库（1950-2009年28,853家美国上市公司）：

| 财务指标 | 幂指数β | 含义 |
|---------|---------|------|
| 净收入 | 0.79 | 亚线性，规模经济 |
| 总利润 | 0.92 | 亚线性 |
| 总资产 | 0.86 | 亚线性 |
| 销售额 | ~0.99 | 近似线性 |

**结论**：公司规模放大→规模经济主导→收益递减→增长最终停止，与生物S型曲线同构。中国上市公司数据（β=0.83）与美国高度相似——跨越不同市场、制度、文化的普遍规律。

## 公司增长的S型曲线

- 年轻公司快速增长（"棒球棍"式）
- 随规模扩大，维护成本从亚线性变为线性，增长持续放缓
- 幸存的成熟公司进入缓慢的指数级增长（而非暴增）
- 相对于整个市场扩张，大型公司停止了增长（图9-12）

**公司生长方程**：收入（新陈代谢）近似线性增长，支出（维护）逐渐从亚线性变为线性 → 净利润驱动力随时间减弱 → S型曲线

## 公司的普遍死亡率

**数据**（1950-2009年28,853家上市公司）：
- 22,469家（78%）到2009年已消亡
- 45%被并购，9%破产清算，3%私有化
- 半衰期：**约10.5年**（任何时候上市，一半的公司会在10.5年内消失）
- 不足5%存活超过30年

**最关键发现**：无论行业（信息技术/金融/能源/交通）、规模（销售额从<100万到>100亿）、死亡方式（破产/并购），所有公司的生存/死亡曲线呈近似相同的**指数衰减**形状——死亡率恒定，不随年龄增加（这被称为公司版"不老化"）。

公司的普适动力学与其所处行业无关。

## 为何公司必死而城市不死

**公司死亡的机制链**：
```
追求利润效率
→ 自上而下层级结构
→ 随规模增加规则/协议增多
→ 官僚控制增强
→ 维护成本超过创新支出（研发占比随规模系统性下降）
→ 多维→一维化（多样性丧失）
→ 市场波动时极度脆弱
→ 被并购或破产
```

**城市不死的机制链**：
```
分散权力，多中心
→ 社会互动驱动
→ 超线性扩展
→ 多样性随规模增加
→ 新兴业态不断出现
→ 开放式增长
→ 永不停止
```

## 标普500的衰退速度

- 1958年：一家公司在标普500榜单上的平均停留时间 = **61年**
- 今天：平均停留时间 = **18年**
- 1955年榜单仅12%存活至2014年

"没有任何事物能够保持不变"——世间流传着在阿姆斯特丹橡胶公司或太平洋蔬菜公司的名字还有几人记得？

## 长寿公司的特征

全球约有4500家公司能够存活100年，但没有任何公司能存活200年。5586家拥有200年以上历史的公司中，超过一半是日本公司，多数规模小，高度专注单一细分市场（葡萄酒庄、旅馆、糖果店）。它们存活的原因不是多样化或创新，而是凭借声誉和连贯性在极高专业利基市场中长期运营，几乎没有增长。

## 创造性破坏

从进化角度看，公司死亡是**必要的**——所有公司都必须消亡或改变，以使新的创新变体繁荣发展。"大到不能倒"的公司（政府托管）正是对这一自然进程的干预，会带来更大的长期系统风险。
