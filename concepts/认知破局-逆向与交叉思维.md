# 认知破局——逆向与交叉思维

> 只要你敢于颠覆那些陈规滥俗，就没有什么事情是不可以改变的。

## 逆向思维

**定义：** 与"顺向思维"相对，敢于对司空见惯的事物进行"反其道而思之"，也叫求异思维。

**洗衣机案例：** 洗衣机脱水缸转轴最初是硬的，后来发现"弃硬就软"反而效果更好。这种"弃硬怕软"的技术改进，就是逆向思维诞生的发明创造。

**查理·芒格的逆向应用：**
> 从结论往回推，反过来去思考。先从目标出发，再反向推演，然后步步链接：战略→战术→方法→条件。

**逆向思维的心理机制：** 立足于对对方心理预测的一种反馈——出其不意，先攻其防不胜防，就可以反将一军。

**亲和思维4法（逆向应用）：**
1. **换愤怒为友善** — 用理性的一面去对待，反而能更好地处理双方矛盾
2. **回避争论法** — 承认对方观点是对的，让对方平静，双方沟通才能真正开始
3. **善静听多鼓励** — 真正听完，理解心情，再趁机鼓励
4. **兴趣聚焦法** — 了解对方最感兴趣的，谈他想谈的，才能让他接受你的建议

> 一滴蜂蜜远比一加仑的胆汁更能捕到更多的苍蝇。

## 贫穷思维的6个特征（逆向视角）

贫富差距不只是钱的问题，更是**思维定式与行为惯性**的差距。贫穷是一种生活状态，更是一种思维方式。

| 特征 | 表现 |
|------|------|
| 缺少独立意识 | 遇事依赖他人，借钱物后还账一拖再拖 |
| 过度溺爱孩子 | 向富供孩子，削弱独立意志和赚钱养家能力 |
| 打肿脸充胖子 | 死要面子，条件不好却不承认 |
| 思想固执 | 以经验论者自居，用过去框住未来 |
| 愤世嫉俗 | 整天处于抱怨中，无心事业与发展 |
| 爱做白日梦 | 空想家，想着不劳而获，行动力弱 |

**突破贫穷思维三要素：** 长远眼光 + 独特认知能力 + 超强自我控制能力

## 多角度思维：换个角度想问题

**哲学基础：** "一千个读者有一千个哈姆雷特"——每个人的认识无法完全真实地反映客观世界，每个人对同一事物的反映都不一样。

**实践价值：**
- 很多让自己感到不快、不好解决的事，换个角度看，就可以使一切迎刃而解
- 换角度是一种豁达，更是一种睿智
- 凡事要从不同的角度去看，凡事多问几个为什么，先搞清楚来龙去脉再下结论

**哲理升级：**
帕斯卡尔："人是一根会思想的芦苇"——人因思想而伟大，拥有思想才拥有尊严。离开哲学，人生是盲目的。

## 交叉思维

**定义：** 将来自不同领域、不同学科、不同文化的现有概念联系在一起，组成大量不同凡响的新想法。

**夏奇拉案例：** 把阿拉伯音乐和拉丁音乐完美结合，创造出独一无二的音乐风格。

**交叉思维的运作方式：**
1. 从一头寻找答案
2. 在某一点暂时停顿
3. 从另一头寻找答案
4. 当两头或多头交叉形成沟通思路时，找到正确答案

**为什么有效：** 在不同领域和文化的交叉领域，创意最容易产生。因为交叉点的存在，才创造出了更优越的文化思维。

> "汝若欲学诗，功夫在诗外" — 通过引入别的领域的知识或技能，去突破自己的领域，为自己开创一个新局面。

**与多维竞争的关系：** 参见[[多维竞争]]——跨界即增维，各维60分优于单维100分。交叉思维是增维的思维工具。

## 创意思维8种类型

| 类型 | 特征 |
|------|------|
| 跳跃性 | 潜意识长期积累达到饱和后的迸发 |
| 独创性 | 天生与众不同，具有个性色彩 |
| 偶发性 | 突然出现，一瞬即逝，要及时抓住 |
| 纵向性 | 确定创意点后，按方向路线深入钻研到底 |
| 横向性 | 发现特定现象后，联想相似情景，从更多角度寻找创意 |
| 陌生化 | 主动找陌生事物研究，给人新颖感 |
| 逆向性 | 用完全相反的方式思考 |
| 综合性 | 某思路受阻后，马上调整换另一条思路 |

**创意的本质：** 在已有知识/认知的基础上，发现新联系、新事物、新答案。要建立创意思维，首先要彻底抛弃旧习。
