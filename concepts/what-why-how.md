# What / Why / How 三点疑问法

任何文件、任何工作的底层骨架。工作的本质，就是在"拓展"与"锁定"的重复中解决这三点疑问。

## 三点的含义

| 疑问 | 含义 | 丰田对应步骤 |
|---|---|---|
| **What?** | 问题是什么？具体发生了什么？ | STEP1+STEP2：问题澄清→现状把握 |
| **Why?** | 为什么会发生？根本原因是什么？ | STEP4：真正原因分析 |
| **How?** | 如何解决？对策是什么？ | STEP5+STEP6：制定对策→实施 |

可将英文替换为汉字：
- What? → "具体问题？" "问题点？"
- Why? → "为何发生？" "问题的原因？"
- How? → "如何解决？" "对策？"

## 三点的动态关系

**Why?是刹车，How?是油门：**

- 丰田"反复提5次为什么"的文化诞生于**生产线**，为纠正流水线工人过于强调How?（立刻恢复生产）的惯性
- 但在**办公室工作**中，过度追求Why?会导致工作毫无进展——确认根本原因后要立刻切换到How?
- 每个人、每个情境的三点权重不同：根据现实需要灵活调整

## 不同人的短板对应不同的练习

| 短板表现 | 应关注的点 | 练习建议 |
|---|---|---|
| 摸石头也不过河（过度分析不行动） | How? | 练习STEP5对策制定 |
| 不摸石头就过河（盲目行动不思考） | Why? | 练习STEP4真正原因分析 |
| 不知道自己摸的是哪块石头（对现实漠然） | What? | 练习STEP2现状把握 |

## 简易版一页纸框架（第9章）

适合日常使用的最简化版本：

```
| 日期/主题 | What? | Why? | How? |
|----------|-------|------|------|
|          |       |      |      |
```

操作步骤：
1. 确定主题
2. 蓝色笔拓展思维，尽可能多地写出内容
3. 红色笔串联锁定，圈出最重要的
4. 7格不够用可直接延伸到下一列

## 与阳明学的关联

阳明学主张"理论＜实践"，与三点疑问的关系：
- 过于重视Why?而忽视How?=朱子学式（理论＞实践）
- 根据现实情况在三者之间动态调整=阳明学式（理论＜实践）

从"深度思考"到"深度实践"，需要在具体现实中把握好三者的轻重缓急。

## 应用场景举例

- **策划类工作**：策划的目的及背景（Why?）/ 策划的概要与重点（What?）/ 策划的实施（How?）
- **向上汇报**：汇报内容的总结（What?）/ 为何联系上司（Why?）/ 汇报之后该如何处理（How?）
