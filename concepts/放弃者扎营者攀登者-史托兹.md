# 放弃者 / 扎营者 / 攀登者

史托兹用登山隐喻把人面对逆境的反应分为三类。分布约 **放弃者 10% / 扎营者 75-80% / 攀登者 10%**。

## 三类

- **放弃者（Quitters）**：放弃攀登，拒绝挑战，逃避困难。习得性无助的典型表现——"做什么都没用"内化为信念。
- **扎营者（Campers）**：攀登到一定高度后停下来扎营。曾努力过，但被某个逆境（晋升失败、Burnout、家庭变故）打住，转而维护现状。**占人口绝大多数**——社会主体。特征：抱怨、维护既得利益、抗拒变革、把"系统"当作借口。
- **攀登者（Climbers）**：持续向上，无论境遇。不一定最快、不一定最强，但**持续**。Beck Weathers（珠峰暴风雪幸存）、Erik Weihenmayer（盲人登顶麦金利峰）、吉姆·阿伯特（独臂棒球大联盟投手）都是攀登者。

## 关键洞察

- **三类不是固定人格**：攀登者会变扎营者（最危险的岔道之一），扎营者也能再启程。AQ 是潜意识模式的快照，可改变。
- **扎营者占多数**揭示了社会默认状态——大多数人在某次大逆境后选择"安全"。扎营舒适，但代价是失去成长。
- **攀登者不等于成功人士**：很多 CEO、名人其实是高功能的扎营者——他们攀到某个位置就停了。攀登由**反应方式**决定，不是地位。
- **攀登者也会倒下**：心理韧性强的人能从失望疲惫中恢复，重新选路，必要时以退为进。区别不在不倒，而在能起来。
- **教练也猜不准 AQ**：史托兹的游泳运动员研究——认识运动员四年的教练预测谁会进步谁会退步，正确率仅 25%（瞎猜 50%）。AQ 必须科学测量，不能靠直觉。

## 与已有知识的关联

- 与马斯洛需求层次呼应：扎营者卡在某个需求层不再向上。
- 与 [[习得性无助]] 互为表里：放弃者是习得性无助的极端表现；对无助感免疫的人永远不放弃（塞利格曼发现某些狗天然免疫）。
- 与 [[抗逆性三要素]]（奥雷特）一致：攀登者有承诺度、挑战意识、掌控感。
