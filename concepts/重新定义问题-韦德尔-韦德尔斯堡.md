# 重新定义问题

**定义**：**重新定义问题**（Problem Reframing）是韦德尔-韦德尔斯堡提出的核心方法论——在动手解决之前，先停下来重新审视问题本身是什么。多数人一遇问题即跳入"如何解决"，作者反转：先问"我是在解决正确的问题吗？"

**与"解决问题"的区别**：
- 解决问题：给定问题 → 找方案
- 重新定义问题：质疑问题本身 → 重新表述 → 再找方案

**核心步骤**：
1. **暂停**：抵制立即动手的冲动
2. **外化**：把问题写下来，远观而非内化
3. **检视**：检查问题表述的隐藏假设
4. **重述**：从他人视角、反面、更大或更小尺度重新表述
5. **验证**：新表述是否更触及本质？

**经典案例——慢电梯**：
- 原始问题：电梯太慢，如何提速？
- 重新定义：用户实际抱怨的是"等待的烦躁"
- 解决方案：在电梯旁装镜子（人们照镜子时感不到时间流逝）
- 结果：投诉锐减，无需提速

**为何有效**：
- 多数问题表述携带未经验证的假设
- 同一情境有多个等价表述，有的更易解
- 错误问题再高效解决也是浪费

**与已有概念的关联**：
- 与[[第一性原理-帕里什]]对话：都是回到本质
- 与[[逆向思考-帕里什]]对话：都是反主流路径
- 与[[二阶思维-帕里什]]对话：都追问"然后呢"
- 与[[地图不等于疆域-帕里什]]对话：问题表述=地图，非疆域

**应用场景**：
- 个人决策（职业选择、关系问题）
- 产品设计（用户痛点的真实表述）
- 组织管理（绩效问题、文化问题）
- 战略规划（竞争格局的重述）
