# 公地悲剧与个体群体利益冲突

**定义**：当个体基于自身利益最大化做出的理性选择，系统性地损害整个群体的利益时，就形成了"公地悲剧"。亚当·斯密的"看不见的手"只在个体回报取决于**绝对绩效**时成立——但生活中大多数事情是以**相对位置**定高下的。

**军备竞赛逻辑**：
- **雄海象体格竞赛**：个体大块头突变基因能在争夺雌性中获胜 → 所有雄海象越来越大 → 面对大白鲨时集体更难逃脱。如果所有雄海象体重减半，竞争结果不变，生存率却更高——但没有个体会单方面放弃优势
- **高跟鞋军备竞赛**：女性穿高跟鞋在社交/职场获得相对优势 → 所有女性都穿 → 所有人更不舒服，但没人敢先放弃
- **运动员兴奋剂**：一人用药获优势 → 所有人用药抵消 → 成绩不变，健康全损

**核心机制**：
- 个体优势 → 集体劣势
- 竞争会持续到成本超出收益的临界点
- 没有个体能单方面退出而不受损

**现实案例**：抗生素过度使用（个体多开药获好评vs集体耐药性灾难）、24小时超市（一家延长营业时间抢客户vs所有店利润下降）、校服制度（约束个体表达自由vs降低群体攀比成本）。重要的是，强制执法的成本往往决定了是自由放任还是集体约束。
