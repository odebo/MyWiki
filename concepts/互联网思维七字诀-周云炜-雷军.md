# 互联网思维七字诀

**定义**：雷军提炼的互联网产品方法论——**专注、极致、口碑、快**（"专注"是入口，"极致"是标准，"口碑"是放大器，"快"是节奏）。这七个字不是并列关系，而是因果链：专注才能极致，极致才有口碑，口碑需要快速迭代维持。

## 七字逐解

### 1. 专注
- **少即是多**：抗拒多做产品的诱惑，把一个产品做到第一
- **少就是多**：抗拒多功能堆砌，把一个功能做到极致
- 雷军实践：小米早期只做一款手机，每年只发一代

### 2. 极致
- **做到自己能力的极限**：不是相对竞品好一点，是把自己逼到死角
- **极致不是完美**：是"在这个维度上无人能及"
- 雷军实践：MIUI每周五更新，工程师凌晨仍在改bug

### 3. 口碑
- **超越预期才有口碑**：达到预期=无感；超越预期=传播
- **口碑的本质是情绪**：用户愿意"显摆"才有自发传播
- 雷军实践：1999元定价冲击2000元价格带，超越用户预期

### 4. 快
- **快是互联网的节奏**：传统行业以年为单位，互联网以周为单位
- **快不是慌乱**：是高效迭代，每次小步快跑
- 雷军实践：MIUI一年52个版本，远超传统手机厂商

## 七字诀的内在逻辑

```
专注 → 资源集中 → 极致
极致 → 超越预期 → 口碑
口碑 → 用户增长 → 反馈增多
反馈 → 快速迭代 → 更专注
```

形成正向飞轮。任何一环断裂，整套机制失效。

## 与传统思维的对比

| 维度 | 传统思维 | 互联网思维 |
|------|----------|------------|
| 产品线 | 多产品覆盖市场 | 单产品极致 |
| 功能 | 大而全 | 少而精 |
| 营销 | 广告投放 | 口碑传播 |
| 节奏 | 季度/年度 | 周/月 |
| 决策 | 自上而下 | 数据+用户反馈 |

## 七字诀的边界

### 适用：消费互联网
- 用户量大、反馈快、迭代成本低
- 2C产品，特别是高频产品

### 不适用：行业互联网
- 决策链长、试错成本高
- 2B产品、低频产品
- 雷军自己承认：七字诀在小米之家线下零售上要调整

### 不适用：硬科技/基础设施
- 长周期、高门槛
- 不能"每周迭代"芯片、不能"极致"实验室技术
- 七字诀是产品思维，不是技术思维

## 与"小步快跑"方法论的关系

七字诀的"快"对应硅谷的"小步快跑、快速迭代"，但雷军加了"专注+极致"作为前置约束——防止"快"沦为"快糙猛"。这是中国互联网产品方法论的本地化升级。
