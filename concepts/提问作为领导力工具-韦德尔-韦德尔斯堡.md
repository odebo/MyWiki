# 提问作为领导力工具

**定义**：**提问作为领导力工具**指领导者通过提问而非命令、给答案、宣示来引导团队。韦德尔-韦德尔斯堡主张：好领导者用问题塑造组织思考方式，提问是放大的杠杆——一个问题激发整团队的认知产出。

**与"领导者=答案提供者"的对比**：
- 旧模式：领导者给出方案 → 团队执行
- 新模式：领导者提出好问题 → 团队共同求解

**为何有效**：
1. **认知放大**：一个问题调动所有人的脑力
2. **所有权建构**：被问者感到被信任，主动担责
3. **文化塑造**：长期提问塑造"思考型"组织
4. **信息获取**：提问是领导者获取真相的渠道
5. **方向校准**：问题本身就是战略指引

**提问的层次**：

### L1：事实性提问
- 信息收集
- 例：数据是多少？

### L2：解释性提问
- 理解机制
- 例：为什么是这个数字？

### L3：假设性提问
- 检视前提
- 例：我们假设了什么？这个假设可靠吗？

### L4：创造性提问
- 打开新空间
- 例：若没有这些约束，我们会怎么做？

### L5：反思性提问
- 元层级
- 例：我们为什么把这当问题？

**提问的风险**：
1. **质问感**：下属感到被审，闭口不言
2. **修辞提问**：实为伪装的命令
3. **提问过多**：显得无主见
4. **缺乏跟进**：问了不做，信任流失

**好问题的特征**：
- 真诚不知道答案（非修辞）
- 短：不超过 15 字
- 开放：不暗示正确答案
- 指向思考过程，非结果
- 可被反驳，欢迎挑战
