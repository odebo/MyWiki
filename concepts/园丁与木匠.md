# 园丁与木匠

艾莉森·高普尼克的核心隐喻：做父母就像做园丁，而非木匠。

## 木匠模式（教养模式）

木匠的工作是将材料精确塑造成符合计划的最终产品。混乱和变异是敌人，精确和控制力是盟友。教养模式下的父母也一样：有明确的目标（培养特定类型的成年人），相信有正确的技术可以达到目标。

**问题**：孩子的未来不可预测。试图将孩子塑造成特定模样的努力不仅徒劳，还会产生反作用。

## 园丁模式

园丁为植物创造一个受保护的培育空间，但无法控制最终结果。罂粟可能长成霓虹橙而非淡粉色，玫瑰可能爬不上栏杆。但"事故"正是优秀园艺的标志。

好父母不会一定把孩子变成聪明、快乐或成功的成年人，但可以打造出强健、具有高适应性和韧性的生命。

## 关键差异

| 木匠 | 园丁 |
|------|------|
| 塑造特定产品 | 培育生态系统 |
| 控制与精确 | 提供安全环境与资源 |
| 目标是特定的成年人 | 目标是强健、可适应的生命 |
| 混乱是敌人 | 混乱是养分 |
