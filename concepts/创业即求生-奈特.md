# 创业即求生

奈特在《鞋狗》中颠覆"创业英雄叙事"的核心命题：**创业不是成功故事,是濒临破产的求生史**——耐克 18 年间多次濒临倒闭,所谓"成功"只是活下来的副产品。

## 反英雄叙事

主流创业叙事偏重"英雄故事"——创始人有远见、抓住机遇、一举成功。奈特反转:
- 没有远见,只有"不想给别人打工"
- 没有抓住机遇,只有"被供应商背叛"
- 没有一举成功,只有"18 年濒临破产"

## 耐克的濒死时刻

奈特记录的多次濒临破产:
1. **1965 年银行拒绝贷款**——加州银行突然撤资,公司差点关门
2. **1971 年鬼冢虎背叛**——主要供应商单方面断供,被迫独立
3. **1975 年日商岩井危机**——日商岩井内部质疑耐克还款能力
4. **1980 年上市前夕**——劳动力成本激增,毛利率崩溃

每次危机都不是"克服困难",是"勉强活下来"。

## 求生 vs 成功的本质差异

- **成功叙事**:目标导向,失败是意外
- **求生叙事**:生存导向,成功是意外

奈特的论点:多数创业者不是"选择成功",是"被迫求生"——成功只是求生的副产品。

## 求生心态的特征

1. **现金流至上**——账上的钱比战略更重要
2. **短期主义优先**——先活过这个月再谈明年
3. **危机常态化**——不是"危机公关",是"日常求生"
4. **幸运者偏差**——活下来的成为"成功案例",死掉的被遗忘

## 与"精益创业"的对话

精益创业讲"持续验证、快速迭代"——奈特讲"持续求生、勉强活下来"。两者层次不同:
- 精益创业:方法论层面（如何做对）
- 创业即求生:存在层面（如何不死）
- 共同点:都反对"完美计划"叙事

## 局限性

- 求生叙事容易浪漫化"苦难"——苦难本身不值得追求
- 奈特是幸存者,死人无法写回忆录——存在幸存者偏差
- "求生"心态在成长期可能成为束缚——规模化需要主动战略,不只是求生
