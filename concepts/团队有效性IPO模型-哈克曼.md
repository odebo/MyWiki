# 团队有效性IPO模型（哈克曼）

哈克曼为世界贡献了**团队有效性的Input-Process-Output模型**（IPO模型），为如何塑造高效团队提供了科学的理论方向。

## 三层结构

### 输入端 Input — 6个条件

提升团队有效性的6个条件（详见 [[团队有效性六条件-哈克曼]]）：
- **必要条件3个**：真正的团队 / 富有感召力的团队目标 / 合适的成员
- **赋能条件3个**：明确的行为规范 / 必要的组织支持 / 适时的团队指导

前3个条件是必要条件，缺一不可；后3个条件为团队提供支持，帮助发挥效能。企业应首先梳理必要条件，然后才能完成赋能条件。

### 过程端 Process — 3个关键团队过程

团队领导者需要把握好过程监控，监控3个方面：
- **精力投入**（Effort）—— 完成集体工作时团队成员的努力程度
- **绩效策略适配性**（Performance Strategy）—— 团队工作决策与任务的匹配度
- **人才利用率**（Talent Utilization）—— 团队工作中应用的知识和技能水平

每个过程都有"过程损失"和"协同效应"两面。例如精力投入的过程损失是社会惰怠；绩效策略的过程损失是过度依赖习惯程序；人才利用率的过程损失是未充分利用成员专长。

### 输出端 Output — 3项有效性标准

判断团队有效性的3项标准：
1. **团队成果**（产品、服务或决策）满足或超出客户在数量、质量和时效上的要求
2. **团队共事经历**增强了成员未来相互依存、共同工作的能力
3. **团队经验**对成员的学习和职业发展有积极贡献

如果团队在这3项标准中有任何一项失败，都不是完全有效的团队。3项标准的相对权重因时间和环境而异——临时任务组第一项最重要；培训团队第二、三项更重要。

## IPO模型的核心洞察

**输入端最重要**：6个条件的设计质量决定了团队的上限。哈克曼强调，过程端的监控和干预虽然重要，但作用有限——"一旦火箭离开发射台，它就会进入预定轨道。那些发射火箭的人所能做的，只是在过程中做出一些小的修正"。

**先诊断再开方**：哈克曼与韦格曼基于数十年研究，研发出"6个条件团队诊断TDS"测评工具，可预测80%的团队有效性。先测评再对症下药，而不是凭感觉提建议。

## 与传统团队管理理论的对比

| 维度 | 传统管理 | IPO模型 |
|------|----------|---------|
| 焦点 | 过程指导 | 输入设计 |
| 干预时机 | 工作中 | 创建前+启动期 |
| 评估标准 | 业绩完成 | 三项标准综合 |
| 领导者角色 | 实时指挥 | 园丁（创设条件） |
| 一招鲜 | 单点方案 | 系统化6条件 |

## 与已有体系的关联

- 与 [[赫茨伯格双因素理论]] 同构——必要条件类似保健因素，赋能条件类似激励因素
- 与 [[首先打破一切常规-白金汉]] 互补——白金汉关注个体才干发挥，哈克曼关注团队条件创设
- 与 [[马斯洛需求层次]] 部分映射——6条件对团队如需求层次对个体
- 与 [[真北原则与农事规律-柯维]] 共鸣——团队塑造遵循"农事规律"无法跳过准备阶段
- 与 [[打造第二大脑]] CODE法则呼应——Capture/Organize对应Input，Distill对应Process，Express对应Output
