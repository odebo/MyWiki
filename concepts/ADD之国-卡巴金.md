# ADD之国

**定义**：ADD之国是卡巴金对现代社会的诊断——整个社会正在患上"注意力缺陷障碍"（ADD/ADHD），这不是个体的神经病理学问题，而是环境病。成人世界被无尽选择和数字联结逼得分心；孩子从出生起就与分心的成人节奏相匹配；大量幼儿接受ADD/ADHD药物治疗，其中甚至有不到3岁的孩子。

**核心命题**：
- 注意力缺陷是环境病而非个体病
- ADD/ADHD 的"正常化"——"如果这些行为未得到规范，有没有可能是成人诱使孩子分心和多动，因此严格来说，注意力缺陷在当前的环境中是正常的？"
- 儿童的行为可能只是家庭生活更普遍疾病症状，也是这代人总体生活的样子

**成人世界的分心机制**：
- 待办事项清单永远在加长
- 总是从这一刻赶向下一刻
- 数字化将工作转化为"巨大的劳动力片段"
- 即刻产出指标加大赌注
- 被打搅、分心、高度"响应能力"
- 对微不足道的琐事也紧追不舍
- 写邮件时点发送下一秒就想起忘了加内容
- 技术破坏了反思的任何时间

**儿童 ADD/ADHD 诊断的反思**：
- 大量幼儿在接受ADD/ADHD药物治疗
- 甚至有不到3岁的孩子
- "孩子们压根并非真的得了ADD，至少在他们接触手机和即时信息之前不是这样"
- 他们可能只是精力充沛的普通孩子
- 但成年人不再有时间、意愿或耐心应付童年时期正常的旺盛精力
- "孩子们的行为只是家庭生活的一种更为普遍的疾病症状"

**代际传递的分心**：
- 父母忙得不可开交、迷失在头脑中（即便身体在当下）
- 大部分时间总是在工作，包括夜晚和周末
- 在家煲电话粥，兼顾家人所有需求并组织安排家务
- "做父母的很少能临在"
- 孩子遭受完全失去父母的痛苦，以及背后巨大的、几乎是遗传的悲伤
- "缺乏的是父母的关注，缺乏真实地活着、呼吸着、感觉着、身体依偎着的感受"
- 孩子的节奏从新生儿时期就和父母相匹配

**ADD 之国的连锁效应**：
1. 成人世界分心 → 孩子从出生起匹配分心节奏
2. 孩子表现出"注意力问题" → 被诊断为ADD/ADHD
3. 学校"过度管理患有ADD/ADHD" → 孩子屈从于不安
4. 巨量碎片化、非整合信息 → 进入"患有ADD/ADHD的社会"
5. 以"有效、可行的方式"联结工作和人际关系 → 整个社会循环

**与肥胖流行病的类比**：
- 儿童和成人中猖獗的肥胖流行病
- ADD/ADHD 是同一类"环境病"——都不是个体道德问题，而是环境塑造的结果
- 改变环境比治疗个体更根本

**正念作为环境病的解药**：
- 不是给每个孩子开药
- 而是改变"ADD/ADHD 家庭"和"ADD/ADHD 学校"的环境
- 成人先学会临在
- 给孩子"真实地活着、呼吸着、感觉着、身体依偎着的感受"
- 不再用药物应付童年旺盛精力

**与已有体系的关联**：
- 与 [[部分持续注意力-卡巴金]] 同源——CPA 是 ADD 之国的认知机制
- 与 [[临在-卡巴金]] 互补——临在是 ADD 的解药
- 与 [[正念的本质-卡巴金]] 同源——正念本质就是抗 ADD 的训练
- 与 [[刻意专注-阿米希杰哈]] 互补——杰哈从认知科学论证专注力可训练
- 与 [[正念注意力最低有效剂量-阿米希杰哈]] 同源——杰哈的最低有效剂量针对 ADD 之国
