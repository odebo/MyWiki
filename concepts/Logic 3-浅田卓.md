# Logic 3：1P + Q1Q2Q3 框架

浅田卓在 Excel 1 基础上开发的进阶框架，专注于"有逻辑地整理思维、简单明了地传达"。借鉴商学院"Logic Tree"（逻辑树），但简化为易掌握的模式。

## 框架结构

Logic 3 基于 16 格 Excel 1，包含 4 个问题 + 3 个方向的箭头：

```
        Q1？→① ② ③
1P？    Q2？→① ② ③
        Q3？→① ② ③
```

## 四个核心问题

### 1P？（1 Phrase）
"用一句话来说是什么？"

这是 Logic 3 的起点。先用一句话概括主题，让大脑开始运转寻找答案。

### Q1？/ Q2？/ Q3？
三个问题对应三个突破口：

- **What？**——是什么？
- **Why？**——为什么？
- **How？**——怎么做？

丰田员工在所有一页纸上反复出现的三个内容：
- ① 现在为什么需要这项工作？→ 目的（Why）
- ② 现在有什么样的课题？→ 课题（What）
- ③ 对于这些课题要采取什么样的方法？→ 解决方案（How）

## 工作五要素

浅田卓从丰田前辈的一页纸中发现 5 个共同点（构成"MY 一页纸"格式）：

1. **目的**（Why）
2. **现状**
3. **课题**（What）
4. **对策**（How）
5. **日程**

所有工作攻克这 5 个课题就能完成。这把工作从"无限复杂"还原为"5 个填空题"。

## Why/What/How 顺序可变

Logic 3 不强制按 What→Why→How 顺序。可根据情况灵活调整：
- 演讲资料先 What（商品优点）→ Why（为何是优点）→ How（如何销售）
- 研讨会报告先 Why（为何参加）→ What（学到什么）→ How（如何运用）

思考原本是 Q&A 的连锁反应——出现一个疑问，解答后又带来新疑问。固定顺序会限制思考。

## "3"的魔法数字

为什么答案最多选 3 个？

1. **记忆容量**：人一次能掌握的信息数不超过 3 个。《高效能人士的七个习惯》几乎没人能完整记住 7 个——多半不超过 3 个
2. **三级跳惊喜**：举 1 个例子很多人会，举 2 个大幅减少，举出第 3 个会超出对方满意程度带来惊喜
3. **超过 4 个就饱了**：听者会有"够了，已经饱了"的感觉

## "传达"的本质如同登山

浅田卓用三角形比喻传达：

**登山（整理总结阶段）**：
- 想传达的事情 15 个 → 7 个 → 3 个 → 1 个
- 自下而上筛选

**下山（传达阶段）**：
- 从山顶 1 个开始："用一句话来说就是……"
- 分 3 个阶段论述
- 仍不充分再下行至 7 个、15 个

Logic 3 / Excel 1 所做的，都是登山——把想传达的事情限定为对方更容易理解的内容。

## 应用场景

- 制作演讲稿（自我介绍/汇报/PPT）
- 理解复杂语言（开会/客户交流时记录关键词再整理）
- 决定工作优先顺序（16 格填待办→红笔圈重要/紧急/不能拖延）
- 新企划案演讲资料
- 公司外研讨会结果报告
