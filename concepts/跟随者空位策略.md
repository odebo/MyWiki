# 跟随者空位策略

跟随者不应正面攻击领导者——那是用弱点打强点。正确策略是找到心智地图中领导者没有占据的真实价值位置，或借助领导者位置给自己定向。

## 三种策略

### 策略一：寻找空位

| 空位类型 | 逻辑 | 案例 |
|----------|------|------|
| 高价空位 | "最贵"本身是定位，传递稀缺感 | 皇家芝华士 |
| 低价空位 | 价格敏感市场的简化产品 | 一次性打火机 |
| 性别空位 | 转向另一性别 | 万宝路（女→男）|
| 年龄空位 | 切儿童/老年/青少年 | Aim牙膏（定位儿童）|
| 时间段空位 | 细分使用场景到时段 | 奈奎尔夜间感冒药 |
| 渠道空位 | 用不同渠道触达新用户 | L'eggs超市卖袜子 |

### 策略二：反向定位

借助领导者位置给自己导航，不试图否定领导者：
- 艾维斯："第二名，所以更努力"（弱势→优势）
- 七喜："非可乐"（定义了碳酸饮料的第二品类）

**关键洞见：** 消费者心智已有领导者坐标，说"我在领导者旁边/对面"，消费者立刻理解你，无需额外解释。

### 策略三：重新定位竞争对手

找到竞争对手定位中真实存在的弱点 → 放大传播 → 填充空出的位置。

**泰诺 vs 阿司匹林：**
- 泰诺广告列出阿司匹林副作用（刺激胃粘膜/过敏反应）
- "安全止痛药"位置被重写
- 泰诺自动占据"更安全的止痛药"

**原则：** 必须基于真实弱点（客观事实），虚假攻击会引发反弹。

## 选择策略的决策树

```
心智地图中存在真实价值的空白位置？
    是 → 空位策略
    否 → 领导者有真实可公开的弱点？
              是 → 重新定位策略
              否 → 反向定位（"非X"）
```

## 与其他框架的关系

- 空位策略 ↔ [[战略-破局点]]（梁宁）：破局点=广谱+高频+体验可控；空位策略也要求找真实需求的空缺，而非伪需求
- 重新定位 ↔ [[市场竞争分析框架]]：竞品分析的终极目的是找可以重新定位的弱点
