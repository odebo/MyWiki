# 清单编制原则

葛文德从航空、建筑、医疗、投资等行业提炼的清单设计六大原则：

1. **权力下放**：面对极端复杂问题，中央集权行不通——决策权应分散到一线人员。沃尔玛在卡特里娜飓风中成功救援的关键：CEO只发了一条指令"做正确的事情"，让一线经理便宜行事；而FEMA坚持传统指令模式导致灾难性延误。

2. **简单至上**：清单不能面面俱到，必须聚焦"杀手项目"——最关键、最容易被忽略的步骤。5-9个项目是最佳长度，超过则失去焦点。波音299的飞行清单一开始也不是今天这个样子，是通过无数次迭代简化而来。

3. **团队沟通激活**：术前每人自我介绍姓名和角色——这看似矫情的步骤被心理学研究证明能显著提升团队主动参与度（"激活现象"）。不知道彼此姓名的人不能很好合作。

4. **人为根本**：清单是工具不是主人。飞行员使用清单而非被清单使用；在紧急情况中（如发动机起火），判断力优先于清单。

5. **持续改善**：清单必须根据实际情况不断迭代。世卫组织手术清单经过多轮测试修改才定型，保持清单的自我进化能力。

6. **关键点优先于大而全**：好的清单不是百科全书，而是精确定位在流程中失败率最高的几个节点。找到"杀手项目"比列出所有步骤重要得多。
