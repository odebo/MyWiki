# 手艺人工具选择法则

卡尔·纽波特提出的技术/工具筛选框架，对抗"任何好处都足以采用某工具"的任何收益法。

**核心原则**：只有当某个工具对你核心目标的正面影响显著超过负面影响时，才使用它。

**背后逻辑**：每个工具都有隐性成本——使用它需要维护（检查更新、管理通知）、训练（学习使用）和注意力（被动干扰）。互联网服务商将"保持用户注意力"作为核心商业目标，所以他们提供的免费工具对用户时间是掠夺性的，而非中性的。

**实践步骤**：
1. 明确列出你工作和生活中的**核心目标**（通常2-3个）
2. 对每个目标，列出**关键支持活动**
3. 对每个工具，评估：它是否对关键支持活动有实质性正面影响？
4. 只有答案明确为"是"的工具才保留

**对社交媒体的应用**：社交媒体提供的价值通常是浅层的（娱乐、被动连接），而代价是持续的注意力分散和深度工作能力的侵蚀。对大多数知识工作者而言，按手艺人法则评估，应该放弃或极度限制使用。

**类比**：铁匠不会因为某把锤子"有时候有用"就带着它工作——他只携带完成任务所必需的最少工具。
