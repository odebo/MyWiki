# 腾讯——产品哲学

腾讯有两套并行运转的产品哲学体系，分别由马化腾和张小龙代表，彼此高度契合却风格迥异。

---

## 马化腾的产品哲学

### 邮件狂人
马化腾是腾讯内部著名的"邮件狂人"：他每天深夜刷手机，发现产品细节问题就立刻发邮件给相关负责人，常常是凌晨2-3点的消息。他的部下们习惯了随时可能收到他对某个细节的挑剔和建议。

这不是管理方式，而是产品直觉的直接表达——他始终保持"瞬间变成白痴级用户"的能力，以最普通用户的眼光审视自己的产品。

### 10-100-1000法则
马化腾自创的产品迭代法则：
- 每个月必须**体验10**款竞品（保持市场感知）
- 关注**100**个用户的反馈（不是统计平均，是真实声音）
- 阅读**1000**条用户评论（建立感性的用户理解）

### Don't Make Me Think
马化腾最喜欢的产品原则，来自Web可用性大师Steve Krug：产品设计的最高境界，是让用户不需要思考就知道该怎么做。任何让用户"想一想"的设计，都是需要优化的地方。

### 四大产品原则
1. **不打扰**：不主动推送不必要的内容，让用户感到被尊重
2. **可感知**：产品的每次更新必须让用户有清晰的感知，让用户知道"你在进步"
3. **不炫技**：功能服务于用户需求，不为了展示技术而添加功能
4. **口碑第一**：用户自发传播胜过一切广告

### 灰度法则的七个维度

2012年，马化腾向合作伙伴发布"灰度法则的七个维度"（受KK《失控》启发），是腾讯产品/组织哲学的最完整表达：

| 维度 | 核心逻辑 |
|------|---------|
| **需求度** | 用户需求是产品核心；产品对需求的体现程度，就是企业被生态所需要的程度 |
| **速度** | 快速单点突破；"小步快跑，快速迭代"；在互联网时代，谁都不比你笨傻5秒钟 |
| **灵活度** | 主动变化比应变能力更重要；管理者能更早预见问题并主动变化，就不会在市场中陷入被动 |
| **冗余度** | 容忍失败、允许适度浪费、鼓励内部竞争；微信与深圳内部团队的同步研发就是冗余度的体现 |
| **开放协作度** | 最大限度扩展协作；互联网很多恶性竞争都可以转向协作型创新；平台生态>封闭帝国 |
| **进化度** | 构建生物型组织，让企业组织本身在无控过程中拥有自进化、自组织的能力 |
| **创新度** | 创新非刻意为之，而是充满可能性、多样性的生物型组织的必然产物 |

> 马化腾：「创新就是，一个企业已经成为生态型企业，开放协作度、进化度、冗余度、速度、需求度都比较高，创新就会从灰度空间里不断涌出。从这个意义上讲，创新不是原因，而是产物。」

## 张小龙的产品哲学

张小龙是腾讯最具独立人格的产品人，他从Foxmail到QQ邮箱再到微信的进化轨迹，代表了中国最高水平的产品思维。

### 极简主义美学
张小龙的核心审美：极简主义是互联网最好的审美观。

他曾思考一个问题：「为什么苹果手机只有一个按钮？」他感觉乔布斯的性格有点偏执，他追求一种极致的简洁，可能跟他的理念有关系。如果他有一个按钮可以实现的话，他绝对不会用两个按钮来实现。

具体实践：
- 微信每一个功能发布前，张小龙会追问："这个功能能不能做到让竞争对手无法超越我们？"
- "做到什么都没有，你要超越我们总要加东西吧，你一加，就超不过我们了。"
- Pony发来的邮件里说他对某个功能还在考虑，「我回复说，我们现在这个功能已经做到极简化了，竞争对手不可能超过我们了，因为我们是做到什么都没有，你要超过我们总要加东西吧，你一加，就超不过我们了」

### 五维产品素养（2012年8小时演讲）

2012年7月24日，张小龙在腾讯内部做了一场8个多小时的长篇演讲，主题是"微信背后的产品观"，腾讯为此开设17个分会场同步直播。通过180页PPT，张小龙对产品经理的素养提出了极具个人色彩的解读：

1. **敏锐感知潮流变化**：移动互联网产品会从相对匮乏时代进入相对富足时代，产品经理若是沉醉于各种新鲜玩意儿之中、追逐新奇，很可能错过真实的时代潮流
2. **用户感知需求**：移动互联网的最大特点是变化极快；人类群落本身也在迁移演变，产品经理更应该依靠直觉和感性，而非图表和分析
3. **海量的实践**：目前没有任何人可以自称是领域内的专家，但这并不意味着可以寄希望于天降天才；他们需要开展超过千次的产品实践，才能称得上了解产品设计
4. **博而不专的积累**：美术、音乐、阅读、摄影、旅游等文艺行为貌似不能直接转化为生产力，但合格的产品经理需要广博的知识储备，以此来了解和认识大量人群，理解时代的审美，让自己的所思所感符合普通用户的思维范式
5. **负责的态度**：拥有合适的方法论和合适的素养，成功的产品经理还应该有对自己和产品负责的态度；唯有如此，产品经理才能够偏执，清楚地知道自己究竟要做什么，抵抗住来自上级和绩效考核的压力，按照自己的意志不变形、不妥协地执行产品策略

> 张小龙名言：「我所说的，都是错的。」
> ——这句话是张小龙对产品人认知的极致表达：移动互联网时代变化太快，今天正确的方法论明天可能就是错的，真正的智慧是保持不断学习的空杯心态

### 微信开屏的哲学

微信的开屏画面——一个孤独的身影立在地平线上，面对蓝色星球——是张小龙亲自选定的。

他希望传递的感觉：一种期待来自宇宙同类呼唤的孤独感，连接欲望的原始起点。这不是设计，这是产品哲学的视觉化表达。

## 马化腾与张小龙的对比

| 维度 | 马化腾 | 张小龙 |
|------|--------|--------|
| 风格 | 务实/工程师思维/沉静 | 文艺/极简主义/偏执 |
| 核心能力 | 白痴级用户视角/快速迭代 | 极简美学/潮流直觉 |
| 产品方法 | 10-100-1000/邮件反馈/灰度迭代 | 海量实践/博而不专/负责的态度 |
| 代表产品 | QQ生态（QQ秀/QQ空间/QQ游戏） | Foxmail/QQ邮箱/微信 |
| 信条 | 「Don't make me think」 | 「我所说的，都是错的」 |
| 共同点 | 极度以用户体验为核心；都是极简主义者；都对细节有近乎偏执的执着 | |
