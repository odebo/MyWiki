# 人生使命与天生倾向 - 罗伯特·格林

格林认为，每个人生来独一无二，基因组成空前绝后。这种独特性通过童年时期的**天生倾向（Inclination）**体现出来——对某种活动的天然偏爱，如音乐、数学、运动、建造、写作等。

**人生使命（Life's Task）**是让这粒独特性种子开花，通过工作展现自己的独特性。历史上所有大师都有一条共同线索：年轻时对某事物的热爱或偏好 → 一个偶然机会使其发现如何运用 → 一段让他们保持活力与专注的学徒经历。

**达尔文vs高尔顿**是核心案例。高尔顿是超级天才神童，但从未在任何领域达到精通，因为"样样都通，样样稀松"。达尔文自认"非常普通的男孩，智力低于一般人"，但他对收集生物标本有强烈天职般的倾向，最终彻底改变了人类对生命的看法。

**关键机制**：强烈倾向带来的情感因素——欲望、耐心、毅力和信心——比纯粹理性思维能力对成功的影响更大。这种倾向使大师们能够经受住自我怀疑、单调乏味的练习、挫折和嫉妒者的冷嘲热讽。

**五种发现使命的策略**：回归本源找到天生倾向 / 占领属于自己的领域 / 不走父母选择的歧路 / 放下过去适应变化 / 生死攸关时迷途知返。
