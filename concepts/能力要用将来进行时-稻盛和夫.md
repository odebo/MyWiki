# 能力要用将来进行时

**定义**：稻盛和夫的目标设定原则——设定目标时要用"将来的能力"估量，而非"现在的能力"。具体做法：**从应该到达的未来某一点倒算 → 评估自己现有的能力 → 再考虑用何种方法提高自己的能力**。始终把跨越的栏杆设置在比自己现有能力高两三成的高度。

**核心命题**：人的能力绝不是一成不变的——"能力"应该采用"将来进行时"来估量。

**为什么用将来进行时**：
1. **能力的可塑性**：人的能力在未来一定会提高、一定会进步
2. **目标的功能**：目标不是描述现状，而是引导成长
3. **保守估计的陷阱**：用现有能力判断"能/不能"——不可能挑战新事业或更高目标
4. **回看验证**：今天做的工作，几年前看会觉得"我不会做"——现在驾轻就熟

**稻盛的京瓷实践**：
- 主动接别的公司认为"不能做"的产品订单
- 客户拿出被别的陶瓷厂拒绝的、难度很高的产品问能否开发
- 稻盛立即回答："行，我们能做"——不这么说对方再不搭理
- 员工惊讶："连设备也没有，如何做得了？"
- 稻盛："相信能做，然后加紧努力，不久的将来就一定能做成"
- 把"不能做的工作"当作"能做的工作"接下，然后发奋努力
- "靠踮起脚尖来拔长身高"——看似荒唐，有效提升京瓷技术

**绝对不要说"自己不行"**：
- 几乎所有人面临困难问题时脱口而出"我不行"
- 稻盛：绝对不要说这种话
- 首先要做的就是相信自己
- "现在也许不行，但只要努力一定能行"
- 然后必须对"自己解决问题的能力怎样才能提高"进行具体深入思考

**"已经不行了"的时候才是真正的开始**：
- 京瓷研发项目"百分之百成功率"——稻盛的信念
- 大企业研究员质疑："这是不可能的"
- 稻盛："在京瓷，研究开发一定要持续到成功为止。以失败告终的事例没有"
- 关键："已经不行了"的时候并不是终点，而是重新开始的起点
- 狩猎民族比喻：盯上目标后锲而不舍，绝不放弃

**机制——为什么将来进行时有效**：
1. **目标引导成长**：高目标倒逼能力提升
2. **承诺创造资源**：先承诺"能做"才会想办法
3. **能力适应性**：人的能力随任务需要扩展
4. **未来视野**：从未来回望现在——而非从现在推测未来
5. **心理解放**：拒绝"我现在不行"的自我设限

**与"成长型思维"的关系**：
- 德韦克成长型思维：能力可通过努力发展
- 稻盛将来进行时：把"未来能力"作为目标设定的前提
- 共通：都拒绝固定能力观
- 稻盛更激进：不是"可能发展"而是"一定提高"——把成长作为前提假设

**与"necessity vs preference"的对照**：
- 多贝里[[期望值越低幸福感越强-多贝里]]：把"必须"换成"想"——降低必要性压力
- 稻盛：把"现在做不到"换成"将来能做到"——提升必要性
- 张力：多贝里降期望增幸福；稻盛设高目标激发成长
- 整合：在能力圈内设高目标（稻盛）；对结果不执着（多贝里）——目标作为方向而非执念

**与"先承诺后兑现"的创业逻辑**：
- 京瓷早期："能做"的"大话""谎言"无论如何必须兑现
- 创业逻辑：先承诺客户，再倒逼内部能力建设
- 与硅谷"fake it till you make it"相似但更严苛——稻盛要求必须兑现

**"将不可能变为可能"的具体路径**：
1. 接下"不能做"的任务
2. 相信能做
3. 加紧努力
4. 不久将来做成
5. 实际上"能做"——从不可能中孕育出可能

**稻盛的"短期观点"配合**：
- 不痴迷"将来搞出什么研究成果""人生将会怎样"等不着边际远景
- 短期观点：今天的目标今天一定要完成
- 今天比昨天，哪怕一厘米也要向前推进
- 京瓷从不建立长期经营计划——只用一年年度计划
- 月度、每天具体目标——千方百计达成
- "今天一天努力干吧，以今天一天的勤奋就一定能看清明天"

**适用边界**：
- 适用于：目标设定阶段——倒逼成长
- 适用于：能力可塑性强的领域——知识工作、技能学习
- 不适用于：物理/生理硬限制——"将来进行时"不创造物理可能
- 不适用于：道德/诚信边界——不能以"将来进行时"承诺明知做不到的
- 与"诚实承诺"的张力：先承诺后兑现——需要诚信托底

**实践含义**：
- 设定比当前能力高20-30%的目标
- 从未来目标倒算现在能力提升路径
- 绝对不说"自己不行"——先相信自己
- 把"已经不行了"视为真正的开始
- 用短期观点配合长期目标——今天比昨天前进一步
- 把"将来进行时"用于能力评估——而非用于诚信承诺
