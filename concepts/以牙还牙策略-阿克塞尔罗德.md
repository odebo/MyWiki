# 以牙还牙策略

**定义**：**以牙还牙**（Tit for Tat, TFT）是阿克塞尔罗德计算机锦标赛两届冠军策略，由阿纳托尔·拉普波特提交。规则极简：第一步合作，之后模仿对方上一步的行为。看似简单，却在 62 个复杂策略中胜出，揭示了合作涌现的核心机制。

**策略规则**（仅 4 行代码）：
1. 第一步：合作
2. 之后：复制对方上一步
3. 对方合作 → 我合作
4. 对方背叛 → 我背叛（下次又合作则继续合作）

**为何能赢**：

### 1. 永远不首先背叛（友善性）
- 不会主动挑起冲突
- 不剥削他人
- 永远给合作机会

### 2. 立即报复（报复性）
- 对方背叛必受罚
- 不可欺
- 立刻回应，不含糊

### 3. 立即宽恕（宽恕性）
- 对方回归合作即宽恕
- 不记仇
- 不陷入相互背叛循环

### 4. 行为可预测（清晰性）
- 规则透明
- 对方学习后能理解
- 建立稳定预期

**失败模式**：

### 1. 噪声问题
- 误判对方意图导致连锁报复
- 解决：宽容版以牙还牙（一定概率不报复）

### 2. 同时背叛陷阱
- 双方都用 TFT，一次误判即循环
- 解决：CTFT（考虑对方意图）

### 3. 与"永远背叛"对峙
- 单次相遇会输
- 但群体中能扩散

**应用场景**：
- 国际关系（核威慑、贸易谈判）
- 商业合作（合同执行、信任建立）
- 生物学（互惠利他、共生）
- 日常生活（邻里、同事）

**经典案例——一战战壕**：
- 英德对峙战壕
- 双方达成"不攻击对方用餐时间"
- 实质 TFT：你不打我，我不打你
- 高层强攻命令打破合作
