# 半熟素材

**定义**：**半熟素材**（Intermediate Packets）是蒂亚戈·福特提出的概念——构建最终作品所必需的、个别的、具体的创作元素。任何一则笔记都可能在某个更高级别的项目或目标中扮演"半熟素材"角色。化整为零的理念让创作从"从零开始"变为"拼搭积木"。

**五种半熟素材类型**：

1. **干货笔记**：对书籍或文章通读提炼后形成的精要梗概（可用[[渐进式归纳法-蒂亚戈福特]]提炼）
2. **落选素材**：没被历史项目采用，但可能在日后发挥作用的材料或设想
3. **过程性文件**：历史项目中产生的文档、图片、日程、计划等
4. **最终成果**：历史项目中交付的工作成果，可能成为新项目的一部分
5. **他山之石**：可借鉴吸纳的、由团队成员/承包商/顾问/客户所创造的知识资产

**类比其他领域**：
- 软件开发的"模块"
- 创业公司的"试运营"
- 建筑工程的"草图"
- 电视连续剧的"试映集"
- 工程师的"原型"
- 汽车设计的"概念车型"
- 音乐作品的"小样"
- 文章的"大纲"

**四大益处**：

1. **专注力强化**：不必将庞大项目整个装入脑中，一次只关注一个小型资料库
2. **工作时间灵活**：利用碎片时间处理不同半熟素材，宏伟项目不再令人望而生畏
3. **工作质量提高**：从细微元素开始步步试错，广泛听取外部反馈
4. **颠覆生产力认知**：当半熟素材达到一定量级，拼凑即可构建大项目，"从零开始""白纸作画"从创作字典里消失

**四种检索方法**：
1. **搜索**：节省时间精力，对目标信息有所了解时使用
2. **浏览**：通过文件夹和文件名层层抽丝剥茧，调用适应物理环境的大脑功能
3. **标签**：用于难以预见和推测的情况
4. **随缘**：天马行空的创意融合，机缘巧合的隔空连线

**关键应用——压缩范围策略**：
- 砍掉次要功能及时发布（如软件开发团队"压缩范围"）
- 被删内容存为半熟素材，可能在另一项目中闪光
- 例：从演示剪去的页面→社交媒体帖子；从报道删除的观点→大会演讲亮点
