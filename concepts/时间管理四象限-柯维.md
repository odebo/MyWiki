# 时间管理四象限

柯维把所有活动按"紧迫性"和"重要性"两维度分成四类，构成时间管理矩阵：

| | **紧迫** | **不紧迫** |
|---|---|---|
| **重要** | **I** 危机/赶时限/急救 | **II** 长期规划/预防/能力建设/关系投资 |
| **不重要** | **III** 不速之客/部分电话会议（对别人重要） | **IV** 琐事/无聊娱乐/办公室闲聊 |

## 四象限详解

- **第一象限**：既紧迫又重要。需要投入时间，但很多是因延误或缺乏预防造成。性质上"管理/创造"象限。
- **第二象限**：重要但不紧迫。**质量象限**。长期规划、预防、赋予能力、阅读学习、关系投资、准备。投入越多第一象限越小。**个人领导象限**——不会逼迫我们，我们必须主动去做。
- **第三象限**：紧迫但不重要。**蒙蔽象限**——紧迫噪声造成重要假相，实际是对别人重要。多数人误以为自己在第一象限。
- **第四象限**：既不紧迫也不重要。**浪费象限**。但被一/三象限折腾后"逃避"到这里。

## 关键洞察

1. **紧迫性与重要性成反比**——越紧迫往往越不重要
2. **第二象限是关键**——绝大多数"如果做得特别出色会对生活产生重大积极影响"的事情都在第二象限
3. **第三象限是时间来源**——从第三象限挤出时间投入第二象限
4. **第一象限的"为什么"**——若因紧迫性占据主导，重要性减弱时滑到第三象限（嗜急成瘾）；若因重要性占据主导，紧迫性减弱时进入第二象限

## 七大第二象限活动

柯维向成千上万人调研"如果做得特别出色且坚持下去会对生活产生重大积极影响"的事情，归纳出七类，全部属于第二象限：
1. 加强与人沟通
2. 做好准备
3. 加强计划和组织
4. 更好地照顾好自己
5. 抓住新的机遇
6. 个人发展
7. 增强能力
