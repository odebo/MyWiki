# 决策卫生

**定义**：决策卫生（decision hygiene）是减少判断噪声的一套系统性预防策略。不同于"消除偏差"的靶向治疗思路，决策卫生借鉴医学卫生概念——像洗手预防感染一样，通过标准化流程预防噪声，而非事后纠正。

**决策卫生 vs 消除偏差**：
- 消除偏差 = 靶向治疗（针对特定偏差进行干预）
- 决策卫生 = 洗手式预防（通过改变流程设计防止多种错误）
- 决策卫生能同时减少噪声和一些偏差，因为噪声的根源往往也是偏差的根源

**核心策略**：
1. 信息排序：将关键信息与非关键信息分离，推迟接触可能产生偏差的信息（司法鉴定中信息排序是减少噪声最大杠杆）
2. 结构化判断：将复杂判断分解为多个独立维度分别评估（如招聘中结构化面试取代随意提问）
3. 多人独立判断后汇总：先独立判断再聚集解决分歧，避免群体讨论放大噪声
4. 使用相对判断和精确量表：用比较而非绝对判断，减少量表理解差异
5. 任命"决策观察者"：负责跟踪和指导互动中的判断过程

**案例效果**：
- 结构化面试比非结构化面试选中的应聘者工作绩效更好
- 诊断指南大幅减少医疗诊断中的噪声
- 中介评估法（MAP）将决策卫生各项实践整合为通用方法
