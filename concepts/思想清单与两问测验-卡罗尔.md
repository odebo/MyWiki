# 思想清单与两问测验

**定义**：子弹笔记的入门工具——用三栏清单清点当前所有"正在做的事"，再用两个问题逐一审问，剔除无价值事项。这是"意向性生活"的起点。

**第一部分：思想清单（Mental Inventory）**

三栏法，每栏列项（不分轻重）：

| 正在做 | 应该做 | 想要做 |
|--------|--------|--------|
| 已在进行的事项 | 自认为有义务但未做 | 想实现但未做 |
| 工作、日常任务、项目 | "应该减肥""应该学X" | 想旅行、想学画、想写书 |

**关键洞察**：
- "应该做"是最危险的——它常是社会期待的内化，不是真意愿
- "想要做"常被"应该做"挤压——所以一直没做
- 把所有事写下来——才能看见全貌

**第二部分：两问测验**

对清单上的每一项，问：

1. **这件事重要吗？**（Important?）
2. **这件事紧要吗？**（Urgent?）

四象限分类：

| 重要 | 紧要 | 处理 |
|------|------|------|
| ✓ | ✓ | 保留——立即做 |
| ✓ | ✗ | 保留——计划做 |
| ✗ | ✓ | 委托或快速做 |
| ✗ | ✗ | **划掉** |

**核心动作：划掉**
- 大多数人会惊讶——清单上 60%-80% 的事项落入"不重要且不紧要"
- 卡罗尔："不要被自己感动"——很多"应该做"根本不需要做
- 划掉不是失败——是承认它本不属于你的生活

**为什么有效**：
- 把模糊的焦虑——变成可视化的清单
- 把"我应该…"的内疚——变成"这件事不重要"的判断
- 决策一次——而非每天重复纠结

**与"决策疲劳"的关联**：
- 每一个未决事项——都在持续消耗决策资源
- 思想清单——批量处理决策
- 一次清理——长期受益
- 见 [[决策疲劳与精简选择-卡罗尔]]

**与巴菲特25/5法则的同构**：
- 巴菲特：列出25项目标→圈5项→剩下20项"应避免"
- 思想清单：列出所有事项→两问测验→划掉无价值项
- 共通：**减法比加法更重要**——避免分心
- 见 [[巴菲特25-5法则]]

**适用场景**：
- 开启子弹笔记时——做第一次清理
- 每月反思时——更新清单
- 感到生活失序时——做一次清点
- 决策疲劳时——清理"应该做"

**实践步骤**：
1. 拿出一张纸，画三栏：正在做 / 应该做 / 想要做
2. 把脑子里所有事项——倒出来（不要分类）
3. 对每一项做两问测验
4. 划掉不重要且不紧要的
5. 把剩下的——迁入子弹笔记的集子
