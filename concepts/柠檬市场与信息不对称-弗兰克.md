# 柠檬市场与信息不对称

**定义**：当买卖双方对产品质量存在信息不对称时，市场会出现逆向选择——优质产品被劣质产品逐出市场（阿克洛夫的"柠檬市场"理论）。

**二手车柠檬市场**：
- "几乎全新"的二手车比新车便宜得多
- 原因：卖家比买家更清楚车况，好车卖家不愿在均价下出售 → 退出市场 → 市场只剩"柠檬" → 买方给出更低均价 → 更多好车退出
- 这是信息不对称导致的市场失灵经典案例

**相关案例**：
- **股票分析师几乎从不推荐卖出**：分析师知道推荐卖出得罪客户（公司），而所有人推荐买进时即使错了也是"普遍失误"——个人的批评有限。99%以上推荐都是买进或持仓
- **回归平均的统计错觉**：棒球年度新秀次年表现通常下滑，不是因为变差，而是第一年的运气成分会向均值回归——批评或表扬可能只是对统计噪音的反应
- **管理者高估批评、低估称赞**：批评后表现变好可能是回归平均，而管理者错误归因为"批评有效"；称赞后表现变差也是回归平均，但管理者错误归因为"称赞让人松懈"

**为什么经济学有那么多数学公式**：数学的精确性和难于造假的特性，使经济学论文更容易通过同行评审——公式是经济学界的"难于造假信号"。人文教授写晦涩难懂的文章同理：如果写得清晰，读者发现内容浅薄的风险太大。
