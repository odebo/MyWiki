# 鳄鱼与沼泽-奥赞瓦罗尔

源自NASA一位不知名雇员的话："今天我到这儿来，是为了穿越沼泽，而不是为了痛扁所有鳄鱼。"

**核心隐喻**：
- **沼泽** = 真正重要的目标，但令人害怕、充满不确定性，到达对岸不知何年何月
- **鳄鱼** = 紧急但不重要的事务（邮件、会议、通知），以100分贝高音嘶吼引起注意

**为什么我们总在打鳄鱼**：回邮件、参加没完没了的会议让人感到高产。沼泽太吓人，鳄鱼就在眼前。"把不重要的事情干得再漂亮，也不能让它变得重要。"

**待办清单的陷阱**：把所有待办事项记在一起、给予同等对待，反而提供了拖延的理由——去收拾桌子而不是写新书大纲。

**解决方案**：
1. 想好哪些事情是重要的，孜孜不倦地优先做它们
2. 识别生活中的鳄鱼——那些肤浅的、并不能帮你穿越沼泽的事务
3. 不要问"眼下最紧急的事是什么"，问"我能做的最重要的事是什么？为什么我现在还没做？"
4. "紧急"意味着"不会持久"，但重要的事情会
