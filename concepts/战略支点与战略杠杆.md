# 战略支点与战略杠杆

借势增长的核心工具。跳出普通人循环的方法。

## 普通人的循环

《穷爸爸富爸爸》里的隐喻：
```
等待机会 → 获得低薪工作 → 等待加薪 → 等待机会 → …
```

富爸爸对 9 岁小男孩说：这个循环如果无限重复，就是绝大多数人的一生。

**跳出去的方法：选支点，用杠杆。**

## 三个核心概念

### 战略支点（初心/使命）

> 支点是你的初心，是企业真实的使命，是不变的东西。

- 它是你强烈希望看到改变的那个点
- **那个你每天看到它没有变、都会让你痛苦的点，才是你的支点**
- 不必宏大，必须真实

梁宁自述：旅人网的支点只是"希望实现自己见识与收入的提高"——当腾讯收购时，她一点没纠结，因为初心已实现。

**强大的支点案例**：
- 阿里："让天下没有难做的生意"→ 支撑 20 年持续探索
- 贝索斯："成为最以客户为中心的公司"

为什么很多人无法跳出普通人循环？**不是没杠杆，而是没支点**。没有强烈希望改变什么，所以也不会冒险拉杠杆。

### 战略杠杆（自由度 + 连锁反应）

> 在一个你可以自由动作的地方，做和竞争对手不一样的动作，形成资源的连锁反应。

杠杆无处不在，每个环节都有自由度：
- 目标市场、产品、价格、供应链、渠道、促销……
- 大多数公司把这些当惯性套路；少数公司把某个环节做成经营杠杆

**案例：明星经纪公司**
- 所有人把当红明星当"现金牛"→ 和明星产生分成矛盾
- 这位朋友把流量小生当"杠杆"→ 用来对接和撬动合作资源

> 乔家大院匾额："学吃亏"——吃亏有时候就是杠杆。

### 战略指北针（准星）

> 用来衡量每个动作战略价值的那粒准星。

- 施瓦辛格："你是来锻炼的，他是来参赛的，而我是来拿奖的"——同样是运动，指北针不同，管控每个环节的方式完全不同
- 贝索斯的指北针："有利于形成长期领导地位的战略选择"（不是利润，不是用户满意度）
  - 可以做的事无数，但能帮你形成长期领导地位的选项并不多 → 舍九取一

## 三者关系

```
支点（初心）→ 提供动力和方向
杠杆（自由度）→ 连锁反应，以小博大
指北针（准星）→ 让所有杠杆形成合力
```

没有支点 → 没有动力去拉杠杆
没有指北针 → 多个杠杆互相干扰，无法形成合力
没有杠杆 → 只能靠蛮力，陷入普通人的循环

## 普通人也能用杠杆

- 一个人什么都没有，至少还可以**吃亏**
- 满眼都是新空间（技术变化/政策变化/代际变化），每个新空间都有自由度
- 问题不是有没有自由度，而是你的支点在哪里
