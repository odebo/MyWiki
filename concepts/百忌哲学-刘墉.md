# 百忌哲学

**核心**：人生处世不只看"该做什么"，更要看"忌什么"。刘墉把毕生处世经验凝结为八大类禁忌，构成与"人生开店哲学"互补的消极智慧——开店论积极立，百忌论消极避。

**八大忌框架**：

| 类别 | 核心禁忌 | 对应章节 |
|------|----------|----------|
| 出门有忌 | 游而无方、不留后路、露白、街头看地图 | 旅行安全 |
| 开口有忌 | 得便宜还张扬、幸灾乐祸、谎话的说与不说 | 说话时机 |
| 职场有忌 | 自作主张、聪明外露、不懂职业伦理 | 职场伦理 |
| 社交有忌 | 马屁拍马腿上、败兴的时刻撞见尴尬 | 社交分寸 |
| 忌迷信 | 信风水不信自己、命越算越薄 | 理性边界 |
| 忌无原则 | 讨价还价没了价、没有特权才有民主 | 原则与公平 |
| 忌无退路 | 万事留一线、为自己留条退路 | 风险管理 |
| 忌溺爱 | 渔网比鱼更重要、第二次断奶 | 亲子边界 |
| 忌执拗 | 投鼠要忌器、认赔杀出 | 取舍智慧 |

**百忌的方法论**：
- **倒果为因识迷信**：所有风俗信仰都是"人造的"，根据需要造的——对你有利的就信，否则大可不在乎
- **讨价还价没了价**：原则一旦破例就再也立不起来，"情是情，理是理"
- **万事留一线**：江湖好相见，没有退路就没有谈判空间
- **渔网比鱼更重要**：给孩子能力比给孩子资源重要，溺爱是让孩子失去自主

**与相关概念的关系**：
- 与 [[人生开店哲学-刘墉]] 互补——开店是积极立，百忌是消极避，二者构成完整处世体系
- 与 [[离舍断-刘墉]] 同源——都是边界管理智慧
- 与 [[稳住不动-刘墉]] 互补——稳住是情绪管理，百忌是行为管理
- 与 [[孙子兵法]] 同向——"知己知彼"与"知所忌"都是预防性智慧
