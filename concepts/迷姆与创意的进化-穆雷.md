# 迷姆与创意的进化

> 理查德·道金斯在《自私的基因》中创造"迷姆"（meme）一词，描绘一种文字信息——习惯或想法——从一个人传递给另一个人，像基因一样通过有机物世代传承、复制。

## 核心命题

**想法和基因一样，在为生存而奋斗**。判断驱动了创意的进化——决定生存能力。

## 迷姆的定义

- 词源：希腊语 mimema，本意是"模仿行为举止"
- 本质：想法的基因
- 机制：迷姆与其他迷姆结合，形成新想法，就像基因与其他基因组合形成新基因

## 创意进化的逻辑

```
想法A + 想法B → 新想法
              ↓
         生存斗争（判断）
              ↓
       活下来 / 灭亡
              ↓
       与新事物结合继续进化
```

## 生存能力 = 解决重要问题的程度

> "解决一个微不足道的问题，你的想法也是微不足道并且很快就会死去。解决一个重要问题的速度不及另一个解决方案，你的解决方案也会死去。"

### 决定生存的两个因素
1. 问题的重要性
2. 相对于其他解决方案，多大程度上完美解决了问题

### iPod 案例
- **生存原因**：解决了重要问题（娱乐），比其他解决方案都高明（比索尼Walkman更好）
- **进化链**：古老公式留声机 → 索尼随身听 → iPod
- **取代逻辑**：不必购买和存储笨拙的CD，不管去哪都能随身携带音乐库
- **传播机制**：人们口口相传它有多酷，将iPod的迷姆传给数百万人——**口碑见证产品成功**

## 进化链案例

### 工具进化
- 石头 → 车轮 → 手推车 → 战车 → 马车 → 汽车
- 每一环节都是前一环节的混合体
- 后代有时与祖先几乎没有相似之处

### 物种进化的类比
- 鸟类是兽脚类恐龙的直接后裔
- iPod是古老留声机的后裔
- 汽车是马车的后裔

## 知识产权的悖论

> "现在，由于法律限制，思考者们被告知不许复制，可是复制却是创意过程的核心。"

- 文艺复兴时期：艺术家可以自由复制他人作品，但希望拿来主义者可以"改进"作品
- 自由市场成立后："原创"成为珍贵财产，具备巨大财务价值
- 知识产权概念入侵创意世界——模糊了创意过程的真实性质
- 这种谬误使创作仿佛是从天而降——其实不是

## 判断驱动进化

### 判断的三个动作
1. **找出弱点** → 消除弱点
2. **找出优点** → 提升优点
3. **描述完美解决方案** → 用描述回到第二步借用

### 判断的本质
> "直觉会告诉思维，下一步怎么走。"——乔纳斯·萨尔克

- 直觉 = 判断的结果
- 创新者通过反复判断发展出"创新直觉"
- 一眼就能判断这是不是好想法

### 判断不是决策
- 不要用判断来接受或拒绝想法（那是在做决策）
- 判断是**提升想法的手段**
- 判断是**驱动想法进化的机制**
- 判断是**管理想法过程的方式**

## 三种判断模式

### 1. 消极判断（怀疑论）
> "创新者是怀疑论者。创新史也可以很容易地被称为怀疑史。"

- 史蒂夫·乔布斯："这些产品太糟糕了！他们都没有差异。"
- "那就是狗屎"是他对新想法的典型回应
- 尼采："伟大的智者都是怀疑论者"
- 毕加索："每一个创造的行为起初都是毁灭的行为。"
- **消极判断是天然的**——人类是消极思想家的后裔，这是争取生存的重要特征

### 2. 积极判断
- 找出想法的优点，提升它们
- 保证不会在消除弱点时误伤优点

### 3. 情绪判断
- 情绪反应作为判断信号
- 与直觉配合使用
