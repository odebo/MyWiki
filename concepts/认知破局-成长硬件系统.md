# 认知破局——成长硬件系统

> 一个人永远都无法赚到认知以外的钱，更无法拥有自己认知不到的东西。

## 大脑惰性原理

**大脑的默认工作模式：**
1. 优先调用"长期记忆区"做决策（省能量，效率高，不费脑筋）
2. 只有当记忆库经验不够用时，才启动思考能力

**"自动驾驶"现象：**
复杂操作重复一段时间后，会不知不觉地使习惯成自然——行为与动作会熟练地连贯起来，自动保存为"程序性记忆"。日常通勤路线、驾车等都是典型案例。

**大脑惰性的认知意义：**
- 记忆是思考的残留物——深度思考的东西，才会被存入长期记忆区
- 让人感觉"不会思考"的真正原因：没有足够的背景知识，导致思维速度与认知力跟不上
- 查理·芒格："我这辈子遇到的聪明人，没有一个不是每天都读书的，一个也没有。"

**进化大脑功能10种方式：**

| 方式 | 说明 |
|------|------|
| 多与他人交谈 | 深入讨论让大脑运动起来 |
| 玩智力游戏 | 填字/拼图/数独等 |
| 刻意思考转化练习 | 归纳演绎，把知识转化为"存储记忆" |
| 学习新语言 | 刺激大脑中枢，提高认知能力 |
| 做有氧运动 | 强化大脑重塑力，减少焦虑 |
| 关掉电视/视频 | 防止大脑形成"惯性"，懒于思考 |
| 练习写作 | 写作驱使思考 |
| 冥想放松 | 增加流向大脑血液量，改善专注力和记忆 |
| 学习新技能 | 促进大脑功能活跃 |
| 多进行阅读 | 复杂丰富的内容让大脑得到更多锻炼 |

## 赫布定律与认知实现

**赫布定律（Hebb's Rule）：**
> 如果大脑里两个神经细胞总是被同时激发，那么它们之间的连接就会变得越来越强。过后，如果我们再激发其中一个细胞，那么另外一个细胞也会被同时激发。

**对学习的意义：** 认知实现能力 = 从微知著的抽象思考 + 大脑的逻辑演绎 + 有效知识储备。三者持续同时激活，连接越来越强。

**认知实现的过程：**
先找到有效的学习方法 → 积累不同的知识 → 在大脑里把这些知识深化 → 整合思维 → 认知能力得以提升

**消除自我意识障碍：** 影响能力发展的是"自我意识障碍"——不敢面对真实的自己，不敢承认不足。能打破意识障碍才能持续成长。

**四类有价值的知识：**
1. **原理性知识** — 如爱因斯坦相对论、牛顿万有引力、罗森塔尔效应——科学规律，颇有学习价值
2. **事实类知识** — 确切无误的事情或事件；可通过观察、感知或数据获取
3. **人际关系知识** — 看似简单，实则复杂；如何求助、如何销售、如何建立信任
4. **技能类知识** — 编程、美术设计、口才表达等；需要不断锻炼和做事的诀窍来掌握

## 写作是知识留存的最佳实践

**费曼原理：** 知识留存率达到90%以上的学习，才是真正高质量的学习。写作无疑是知识留存率最高的实践方法。

**为什么写作有效：**
- 写作时边思考、边输出、边记忆——知识经过思维加工才能转换为能力
- 写作 = 思维的传达、语言的表达
- 写作有一种无形监督的力量，可以使人不断地思考与完善自己
- 反思与回顾可以提高知识的留存率
- 写作还是一种身心的疗愈方式

**与[[门徒效应]]的关联：** 写作本质上是"教别人"的输出形式——把内容写清楚才能真正掌握。

## 高效阅读7种方法

| 方法 | 核心操作 |
|------|---------|
| **知人论世阅读法** | 了解作者的思维方式和时代背景，才能更好理解内容 |
| **查字典阅读法** | 把书当"字典"来学习，遇到问题直接查找相关思维模型 |
| **思维导图阅读法** | 读完一章做思维导图，锻炼逻辑思维能力 |
| **合书阅读法** | 看到启发性内容就合书停下来思考；20%读书+80%思考 |
| **输出阅读法** | 能向别人说清楚才算真正读懂；引用原文+自己的感悟体验为主 |
| **关键词阅读法** | 寻找核心问题相关的关键词汇及它们之间的关系和逻辑 |
| **五星笔记阅读法** | 把别人的知识放在自己的知识体系里，对内容进行二次深加工 |

**关键原则：**
- 序言（凝缩了整本书的核心思想）+ 目录（整书逻辑结构）+ 后记（总结要点）三者先读
- "不动笔不读书"——把书中触动自己的内容手写下来
- 读那些让自己感到"不舒服"的书，拔苗助长式阅读妨碍成长

## 知识筛选三标准

> 只有那些能够改变我们自己生活的知识，才是真正有用的知识。

在知识泛滥的时代，筛选能力比获取能力更重要：

1. **稀缺性知识** — 别人不知道的你知道，别人不会的你会，才能占到独特优势
2. **实用性知识** — 实用的就是最重要的；学了做不出一件成功的事，价值有限
3. **学会筛选有用的知识** — 从成功的案例中提炼，找出对自己有用的知识，提升在某一方面的独特优势
