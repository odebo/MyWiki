# 提问四类型法-冈本纯子

哈佛商学院将提问分为四种类型，擅于提问的人通过在对话中不断变换提问形式来保持对话流畅。

**四种提问类型**：
1. **导入提问**："你好吗？""你是哪里人？"——用于打开对话
2. **反问提问**：重复对方所提问题——让对方感到被倾听
3. **跟进提问**：与对方所说内容相关的提问——深入挖掘
4. **转换提问**：转换话题的提问——避免冷场，引导新方向

**核心模式**：问→答→问→答→适时插入自己想说的话

**开放式问题公式**：6W+1H（what/why/when/where/who/which + how）

**关键数据**：哈佛商学院研究表明，多向对方提问能更好地了解对方，也让对方有好感，再次邀约见面的可能性更大
