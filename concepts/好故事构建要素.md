# 好故事构建要素

## 好故事五因素（图附-4）

好故事能"直抵人心"，必须同时具备五个要素：

```
         简单
    意外     信任
       好故事
    具体     情感
```

### 1. 简单

一句话就能让人记住的故事才是好故事。

**如何做到简单**：
- **一个主题**：一个故事只讲一件事，不要把"表达父爱"和"表达友情"混在同一个故事里
- **信息分层**：把信息按重要性排序，主次分明；无论有多少个点，对方都能快速抓住核心

> 简单的故事模式：别人讲给你听时，你一下子就懂了；你讲给别人听时，一下子就讲明白了。

### 2. 意外

给故事留一点惊喜——人的大脑天生对变化敏感，意外元素能立刻激活注意力。

**制造意外的两种方法**：
1. **打破常规**：挑战对方的预期，让故事走向出人意料
2. **制造神秘（缺口）**：在本质上，意外元素就是制造一个"缺口"——有缺口才有好奇心，好奇心会让对方持续保持兴趣

### 3. 具体

讲故事时，尽量不要让听者启动抽象思维，只用联想和回忆就能理解。

**如何具体化**：
- 用比喻或类比：把新事物比作对方熟悉的旧事物
- 描述具体场景而非抽象感受（"她哭了"不如"她一言不发，转身走进了洗手间，把门关上"）
- 数字具体化："很多人"不如"3000万人"

### 4. 信任

不要把讲故事理解为吹嘘或夸大事实。失去可信度，故事就失去了说服力。

**增加故事可信度的两点**：
1. **借助视频、图片工具**：视觉证据是故事的"证据"；没有证据，再长的论证也只是单方面的"臆想"
2. **多叙述，少形容和理论**：人们更关注"到底发生了什么"，而非你的评价和总结

### 5. 情感

有情感的故事才能打动人心。

**制造情感代入的要点**：
- 场景要贴近日常生活（读者能在日常中找到自己的影子）
- 微观视角切入：用一个具体的人的具体经历，而非宏观叙事
- **理性分析是感情牌的天敌**：故事中不要提数据分析、实验报告、专家建议——这些会打断对方的情感体验

> 想办法把你的故事与别人的情感痛点挂上钩，就成功了。

## 故事选择四原则（附录图附-2）

| 原则 | 含义 |
|------|------|
| **相关原则** | 故事服务于主题，不只是活跃气氛；把握对方的性格、心理需求，选与之相关的故事 |
| **针对原则** | 面对不同的人选不同的故事（吉·吉拉德：见客户前先了解背景、性格、需求） |
| **向上原则** | 故事要有深度含义，让人听完后可以思考；不能太庸俗 |
| **新颖原则** | 避免人人都听过的故事；让对方有耳目一新的感觉 |

## 故事表达七要（附录图附-3）

讲故事时必须遵守的七个原则：

1. **角色定位**：讲故事前进行角色定位，把对方拉入故事中，制造情节增强"参与感"，让听众产生深刻印象
2. **绘声绘色**：投入情感，掌握声音、神色等方面细节的描绘，让故事更加生动逼真；可借助视频短片、PPT、音频等工具
3. **善于设疑**：悬疑激发好奇心，善于运用提问来层层深入、引人入胜
4. **导入观点**：联合故事情节，加入你想表达的观点，深化故事意义，让对方更容易接受
5. **描述细节**：细节决定成败；细节增强真实感，更能打动人；没有细节的故事容易显得夸张虚假
6. **总结升华**：讲完故事不能就结束了，还要总结和升华，让对方充分意识到你的目的和立场，并适当引导
7. **学会分享**：鼓励对方对故事做出表态，希望对方将故事分享给更多人

## 讲故事训练重点三条（附录）

1. **故事主题要鲜明突出**：确定中心思想；是讲关于客户的故事、产品的故事还是服务的故事，提前想清楚
2. **故事内容要制造冲突**：学会在故事中制造冲突，加入矛盾挣扎、误会冲突、意外等；让对方的注意力高度集中
3. **故事要有画面感**：在销售现场，给客户创造画面感，引导感官体验（"我们卖的不是牛排，我们卖的是牛排的嗞嗞声"——必胜客创始人弗兰克·卡尼）

## 讲好故事十小窍门（附录）

1. **即兴创作**：尝试在故事里加入新东西，根据对方反应随机应变；即兴成分让故事更有魅力
2. **个性化**：关键不是记忆词汇，而是记忆体验；让故事有你独特的标签和风格
3. **加入强烈意愿**：你的观点要鲜明突出；故事要有一条清晰的"意愿主线"（如同哈姆雷特的意愿贯穿全剧）
4. **充满戏剧化**：出乎意料的冲突 + 符合现实 = 更吸引人；戏剧化≠夸张
5. **开头要精彩**：第一印象最重要；"先入为主"——一旦第一印象被破坏，后期需加倍努力才能改变
6. **保持敏锐的心**：时刻观察对方反应，根据反应调整故事（乔布斯："每个伟大的演讲者都是敏锐的反应者"）
7. **故事多样化**：借助肢体语言、提问、停顿、设疑等方式，让故事更丰富
8. **加入冲突和冒险**：安排矛盾和挫折，甚至制造一些误会，让人物更加立体
9. **自然放松**：不要刻意"表现"，顺其自然地进行；放松才能引导对方进入故事
10. **回归到听者身上**：让对方参与到故事中，故事的目的是说服听者

## 品牌故事"五讲四美三热爱"（附录）

品牌通过故事吸引眼球的核心框架：

### 五讲

| 讲什么 | 说明 | 案例 |
|--------|------|------|
| 讲创始人 | 创始人的传奇人生本身就是品牌故事 | 万科王石"7+2"探险 / 维珍理查德·布兰森 |
| 讲情怀 | 用情感故事引发共鸣 | 陈欧"我为自己代言"广告词 |
| 讲历史 | 企业品牌的发展史和创业史 | 百达翡丽"没有人能真正拥有百达翡丽" / A.O.史密斯热水器"用了52年" |
| 讲消费者 | 让消费者成为主角，有"主角光环" | 自然堂"你本来就很美" |
| 讲文化 | 传递品牌的价值观和精神 | 华为"芭蕾脚"广告（狼性文化） |

### 四美

让消费者意识到品牌是"美"的：
- **产品美**：产品设计、质量、功能之美
- **服务美**：服务体验、细节、响应之美
- **风格美**：品牌调性、视觉、语言风格之美
- **行为美**：企业行为、社会责任、员工行为之美

### 三热爱

品牌故事的底层价值观：**真**（真实）/ **善**（善意）/ **美**（审美）

> 案例：李维斯/Zippo/LV各自为消费者构建了一个身份认同故事——品牌故事像一颗种子，植入消费者头脑后生根发芽，成为其情感生活的一部分。

## 讲故事语言三技巧（附录）

1. **通俗**（易懂性）：让对方不费力就能理解；拒绝文言文、古文等形式
2. **幽默风趣**（趣味性）：让对方觉得有意思，主动继续听；幽默但不流于低俗
3. **贴近生活**（生活化）：减少典故和生僻词汇，避免让对方感到"卖弄学问"

> 案例："六神磊磊读金庸"为平安银行白金卡所做的《王姑娘，表哥让你再等等》——语言完全生活化、通俗幽默，最后自然引出信用卡广告，超过10万+阅读量。

## 故事呈现工具三类（附录）

| 工具 | 特点 | 注意事项 |
|------|------|----------|
| **面对面演讲** | 最直接，可即兴发挥；同时也最复杂，需应对现场反馈 | 需要灵活应变能力 |
