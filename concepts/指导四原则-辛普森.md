# 指导四原则

迈克尔·辛普森提出的教练/指导者四大基本原则：**信任、潜能、承诺、执行**。这四个原则构成有效指导的因果链——信任是基础，挖掘潜能是核心，创造承诺是动力，实际执行是结果。任一原则缺失则整个指导过程失效。

## 四原则结构

```
信任 → 潜能 → 承诺 → 执行
 ↑_________________________|
       (反馈循环)
```

### 1. 信任（Trust）
- 一切有效指导的起点
- 信任得之难失之易——几周几月精心呵护获得，一次失信即毁
- 保密是信任的命脉：当人们允许自己在你面前表现出脆弱时，必须承诺绝对保密
- 不是来自权力或职位，而是来自可靠、正直、关心

### 2. 潜能（Potential）
- 每个人都有可提高的潜力，无论起点如何
- 指导必须**量身定制**——好的教练从不让客户"穿事先做好的衣服"
- 通过倾听客户的故事、背景、梦想、恐惧、希望来了解潜力
- 教练将自己的故事搁置一边，全身心倾听

### 3. 承诺（Commitment）
- 外在激励（鼓励/即时回报/威胁）短暂，无法持久
- 唯一持久的承诺是**内在的承诺**
- 创造承诺的主要技巧：提出有力的指导问题
- 三方面问题：结合目的→向承诺出发→获得承诺

### 4. 执行（Execution）
- 没有执行的承诺只是空谈
- 将目标转化为可操作的具体行动
- 通过反馈循环持续校准
- 执行结果反哺信任，形成正向循环

## 与教练七技巧的关系

[[教练七技巧-辛普森]] 是指导四原则的操作化工具——每个技巧服务于一个或多个原则：

| 技巧 | 服务原则 |
|------|----------|
| 建立信任 | 信任 |
| 挑战思维定式 | 潜能 |
| 寻求战略清晰 | 承诺 |
| 完美地执行 | 执行 |
| 进行有效反馈 | 执行（反馈循环） |
| 挖掘才能 | 潜能 |
| 提升"中层" | 全部 |

## 与其他教练框架的对比

- 与 [[团队有效性六条件-哈克曼]] 的关系：哈克曼关注团队设计，辛普森关注个人指导，互补
- 与 [[优秀经理四要诀-白金汉]] 的关系：白金汉的"选拔才干/界定结果/发挥优势/因才适用"与辛普森四原则结构相似但视角不同
- 与 GROW 模型（Goal/Reality/Options/Will）的关系：GROW 是会话框架，辛普森四原则是关系框架——前者管一次对话，后者管整个指导关系

## 核心定义

> "指导是释放另一个人的潜能。"

辛普森强调指导的三个否定定义：
- 指导不是因为你有权势或职位就能命令周围的人
- 指导不是"修理"一个人
- 指导不是创造依赖性

这三个否定划清了指导与命令/纠正/控制的边界。
