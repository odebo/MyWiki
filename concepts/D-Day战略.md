# D-Day战略

跨越鸿沟的核心战略：效仿1944年诺曼底登陆，集中所有资源攻打一个高度聚焦的滩头阵地（利基市场），以压倒性优势拿下该市场，再以此为基地扩展到相邻细分市场。

## 核心逻辑

进入主流市场是**侵略行为**——既存企业已与目标客户建立关系，不欢迎入侵者。因此：
- 必须像军事行动而非外交行动来规划
- 不能分散兵力，必须集中攻击单一目标
- 拿下滩头阵地后，才能向相邻市场扩展（保龄球效应）

## 为什么必须聚焦

**生火三要素**：
- 营销预算 = 报纸（引火材料）
- 重大市场机遇 = 木头
- 聚焦的利基市场 = **引火柴**（关键）

没有引火柴，报纸烧完木头仍然点不着。失败案例：Webvan、Solyndra、Better Place——各自烧光了数亿美元风险投资。

管理层不聚焦的真实原因：**销售驱动文化**（"任何时候都不能放弃任何销售机会"）。这是反鸿沟的致命逻辑。

## 滩头阵地三条件

1. 规模足够大，有市场影响力
2. 规模足够小，能够拿下
3. 非常适合颠覆性创新产品

## 保龄球效应：从滩头到整个球道

拿下第一个利基市场后，借助已建立的参照客户群和整体产品，自然渗透相邻细分市场：

- **Documentum**：制药注册法规 → 研发部门 → 生产车间 → 炼油行业 → 华尔街金融服务
- **Apple Macintosh**：《财富》500强图形艺术部门 → 市场营销 → 广告公司 → 出版机构

## 利基市场之外的规划

战术目标 = 诺曼底海滩；战略目标 = 解放西欧。
从第一个利基市场获得的收益，应计算为撬动整个保龄球道所有收益的总和，而不只是该细分市场的孤立收益。
