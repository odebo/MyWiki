# 批判性思维定义（保罗）

保罗与埃尔德给出的批判性思维定义分两层：**初始定义**与**扩展概念**。

## 初始定义

批判性思维是一门**思考思维的艺术**，它思考如何改进思维。包括三个相互交织的阶段：

1. **分析思维**——把思维拆解为各要件
2. **评价思维**——按高标准检验思维
3. **改进思维**——创造性地重构思维

要批判性思考，必须愿意审视自己的思维并严格检验，必须愿意拆解思维（把思维看成由各要件组成的事物），必须愿意找出弱点同时承认优点，必须有内在动机对抗思维僵化的自然倾向——这种僵化倾向寻求证明当前想法的正确性，而不愿意自我改进。

## 扩展概念

批判性思维是**理智地自律过程**，是个体信念与行动的指南。它积极且熟练地对信息进行概念化、应用、分析、综合以及评估等处理，这些信息来自观察、经历、反思、推理和与人交流。

其典范形式基于超越学科划分的**理智的标准**：清晰性、准确性、精确性、一致性、相关性、深度、广度、公正性和充分性。

它要求对所有推理中隐含的**思维结构**进行检查：目的、问题、假设、概念、信息、推论与结论、蕴含与后果、推理的角度。

它还包含一系列相互交叉的思维模式：科学思维、数学思维、历史思维、人类学思维、经济学思维、伦理思维、哲学思维等。

## 核心特征

- **自我引导、自我规范**——试图以最高质量进行公正、合理的思考
- **克服自我中心和社群中心倾向**——人类自然思维有缺陷，需主动对抗
- **终身事业**——没有完美的批判性思考者，所有人都有洞察力和盲点
- **理智美德**——理智的谦逊、勇气、自主、笃信理性、公正心
- **苏格拉底式省察**——践行"未经省察的人生不值得度过"

## 与其他思维定义的区分

| 维度 | 一般思维 | 批判性思维 |
|------|----------|------------|
| 目的 | 寻求证明当前想法正确 | 寻求改进思维本身 |
| 对自身 | 难以发现自身错误 | 以同样高标准质疑自己 |
| 标准 | 缺乏明确标准 | 跨学科理智标准 |
| 对立观点 | 逃避或攻击 | 公正考虑 |
| 状态 | 思维僵化 | 终身实践 |

## 与已有体系的关联

- 与 [[学会提问-尼尔布朗]] 同源——布朗的10个批判性问题即保罗式提问工具的实操
- 与 [[强势批判性思维要求对所有主张包括自己的提出批判性问题-布朗]] 直接对应——保罗的"强批判性思维"
- 与 [[一厢情愿是批判性思维最大的障碍-布朗]] 互补——保罗的"思维僵化倾向"从根因角度解释
- 与 [[思考快与慢-丹尼尔卡尼曼]] 互补——卡尼曼从认知偏差切入，保罗从思维结构切入
- 与 [[超越智商-斯坦诺维奇]] 互补——斯Stanovich区分算法心智与反省心智，保罗的分析/评价/改进三阶段对应反省心智
- 与 [[认知觉醒-保罗·斯隆]] 区分——斯隆的觉醒偏情绪洞察，保罗的觉醒偏结构省察
