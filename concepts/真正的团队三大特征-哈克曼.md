# 真正的团队三大特征（哈克曼）

哈克曼和罗杰·施瓦茨为真正的团队下的定义：**团队是由一群人组成的，他们拥有明确的角色且互相依赖，为产生某些结果（产品、服务或决定）而共同工作**。

区分真正的团队与"共事群体"的三大特征：

## 特征1：清晰的边界

团队成员需要清楚队友都有谁。如果团队边界过于模糊，必然会招致麻烦——团队成员和外部人士都无法区分哪些人为团队结果担责。

**两种极端的危险**：
- **约束不足**（奥尔德弗术语）——成员不确定、边界可渗透，不断有人进出，可能"完全陷入环境动荡之中，并失去一致的身份认同感和团队凝聚力"。一个约束不足的团队几乎不可能制定和实施一个清晰的绩效策略
- **过度约束**——边界密不可透，凝聚力过高，可能发展成群体思维（欧文·贾尼斯研究），过度要求成员间的一致性，忽视外部重大变化，阻碍团队学习及纠正错误

**凝聚力的双面性**：
- 凝聚力本身既不像群体思维认为的那样致命，也不像非专业人士认为的那样有利
- 关键在于凝聚力**基于什么**：
  - 基于维持团队和谐和建立良好人际关系的共同愿望 → 风险高
  - 基于对完成团队任务的共同承诺 → 释放活力和潜能，创造松散群体无法企及的协同效应

**管理者需在松与紧之间找到平衡**。

## 特征2：成员互相依赖

真正的团队能凝聚成员的精力和才华，实现某些共同目标。

**关键区别**：真正的团队 vs 共事群体，不在于团队成员是否相互依存以获得某种回报（如根据独立贡献的简单总和获得认可），而在于**任务本身要求成员互相依赖，从而共同产出集体产品、服务或决策**。

**实证证据**：哈克曼与奥康纳对美国6个情报组织的64个分析单位的研究：
- 工作团队（41%）的绩效有效性综合测评远超共事群体（59%）
- 工作团队表现更好的原因是成员参与的同侪教练（peer-coaching，相互教学）活动要多得多
- 与其他因素相比，同侪教练与绩效结果的关联性更强
- 任务互依性为团队成员相互学习创造了条件

## 特征3：团队构成稳定

传统观点（错误）：团队成员待在一起的时间越长，生存能力和绩效表现越差，最好有持续的成员流动以保持新鲜感和敏捷性。

**研究证据（颠覆传统）**：与那些需要时常处理新成员到来和老成员离开的团队相比，成员稳定的团队更有活力，表现也更好。

- **NTSB飞行记录**：73%的事故发生在机组人员一起飞行的第一天，其中44%恰好发生在机组人员休息后的第一次飞行时
- **实验模拟**：已经飞行了多天且疲惫不堪的机组人员发现和纠正的失误，比充分休息后再出发的机组人员更多
- **挖矿团队、施工团队**实地研究发现也在实验室控制实验中得到验证

**稳定团队表现更好的原因**：
- 团队成员彼此熟悉，对工作环境熟悉，能更好地适应并专注于工作
- 随着时间和经验的积累，团队形成了一种绩效情景下的共同思维模式
- 稳定让成员有时间和机会学习如何更好地共事

## 真正的团队 vs 共事群体

| 维度 | 共事群体 | 真正的团队 |
|------|----------|------------|
| 边界 | 模糊可渗透 | 清晰 |
| 任务 | 各自执行同步任务 | 任务本身要求互相依赖 |
| 担责 | 个人担责 | 集体担责 |
| 成员稳定性 | 流动性高 | 相对稳定 |
| 协同效应 | 个人贡献总和 | 超越个人总和 |
| 同侪教练 | 少 | 多 |
| 学习 | 有限 | 显著 |

## 经典案例对比

- **应对新兴威胁的团队**（共事群体）——副主管发邮件收集建议、主管召集资深专家开一次会，两者都没真正形成团队。客户满意度得分较高，但团队作为绩效单元并未变强，成员也没学到什么
- **析出团队**（真正的团队）——12名成员脱离日常工作6周专注任务、启动时互相采访了解专长、明确目标和期限、确立行为规范、虽经历动荡但最终完成任务。团队作为绩效单元变得更强，成员学到很多

## 与已有体系的关联

- 与 [[赫茨伯格双因素理论]] 互补——团队三大特征是工作内容本身的激励
- 与 [[首先打破一切常规-白金汉]] 互补——白金汉的"选拔才干"对应哈克曼的"合适的成员"
- 与 [[习得性无助]] 对比——共事群体的成员容易陷入无助，真正的团队通过互依重建掌控感
- 与 [[心流-米哈里]] 互补——稳定团队形成的共同思维模式类似心流的群体版
