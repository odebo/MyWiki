# 市场竞争分析框架

## 市场分析五问法

战略规划前必答的五个问题：

1. **市场容量**：市场有多大？用什么口径定义市场？（可口可乐重定义为"肚子份额"——与所有饮料竞争）
2. **市场成长性**：过去3年/未来3年的增长趋势？处于什么发展阶段？
3. **市场特征**：B2B/B2C？集中/碎片化？技术/品牌/渠道哪个关键？
4. **关键成功因素（KSF）**：在这个市场上，赢的关键是什么？
5. **行业趋势**：未来3-5年的主要变化方向？哪些趋势不可逆？

> 重定义市场口径本身就是战略动作：可口可乐将对手从"碳酸饮料"扩展到所有饮料，重新定义增长空间。

## 三曲线+721原则

**三曲线**：任何行业都存在S型生命周期：
- 第一曲线：当前主业（成熟期→衰退期）
- 第二曲线：在第一曲线高峰时布局的新业务
- 第三曲线：未来探索性业务

**721原则**（资源分配建议）：
- 70%资源投入第一曲线（守住当前业务）
- 20%资源投入第二曲线（培育接班业务）
- 10%资源投入第三曲线（探索未来）

> 战略制定者最常犯的错误：在第一曲线还在高峰时不布局第二曲线，等到下滑才开始，为时已晚。

## 竞争对手分析：三梯队格局

将竞争对手分为三层：
- **第一梯队**：行业领导者（1-3家）
- **第二梯队**：区域性/细分领域强者
- **第三梯队**：跟随者、长尾竞争者

分析要点：各梯队的战略取向、资源禀赋、KSF的差异化，以及本公司在格局中的定位。

结合波特五力：现有竞争者/潜在进入者/替代品/供应商议价/买家议价。

## 竞争优势四标准（VRIO框架）

一项资源/能力要成为真正的竞争优势，必须同时满足：

| 标准 | 问题 |
|------|------|
| **V（价值性）** | 能否帮助公司利用机会或规避威胁？ |
| **R（稀缺性）** | 只有少数竞争者拥有？ |
| **I（不可替代性）** | 没有等效替代品？ |
| **O（难以模仿性）** | 竞争者难以快速复制？ |

> **扬长比避短更重要**：与其修补劣势，不如将优势打到极致，形成别人无法追赶的差距。

**资源禀赋→组织能力→KSF路径**：
- 识别公司独特的资源禀赋（有形/无形资产、组织能力）
- 匹配市场KSF（关键成功因素）
- 形成差异化竞争优势

## 客户洞察三层次

（与[[痛点-痒点-爽点]]页面联动）

- **痛点**：客户真正的恐惧和未被满足的核心需求（刚需）
- **痒点**：让客户更便利/更喜欢，非必需但显著提升体验
- **爽点**：超出预期的惊喜体验，形成口碑与忠诚度

战略洞察要挖到痛点层。能解决痛点的产品才有竞争壁垒。

## 商业模式：交易结构定义

**商业模式 = 企业与利益相关者之间的交易结构**

关键问题：
- 谁是买单方？谁是用户？（可能不同）
- 价值如何创造和分配？
- 成本结构与收入来源如何设计？

**吉列刀片模式**：低价主品（刀架）+高频耗材（刀片），锁定用户生命周期价值。

**伪模式识别**：商业模式的设计必须最终能产生正现金流和利润，否则是伪模式。
三层竞争递进：产品竞争→商业模式竞争→生态系统竞争（每层都比上一层更难被模仿）。

## SWOT三维校验

在战略制定前，用SWOT做最终校验：
- 外部：Opportunities（机会）+ Threats（威胁）
- 内部：Strengths（优势）+ Weaknesses（劣势）

**三维校验**：分别从**行业/竞争对手/内部**三个视角检验战略选择的合理性，避免只从一个维度看问题。
