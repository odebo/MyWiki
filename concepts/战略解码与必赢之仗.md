# 战略解码与必赢之仗

## 四大执行障碍（柯维·麦切萨尼·哈灵顿）

1. **不知道**：战略没有被清晰传达，员工不知道战略是什么
2. **不认同**：知道但不认为这是正确的方向
3. **不会做**：认同但没有能力执行
4. **没人管**：有能力但缺乏跟踪与问责机制

战略解码的核心目的：消除前三个障碍；执行系统消除第四个。

## 解码漏斗（四层）

```
分析环境
    ↓
3年战略重点（3-5个，不超过5个）
    ↓
1年"必赢之仗"（年度关键战役，3-5场）
    ↓
关键指标 + 行动计划（具体到人、时间、衡量标准）
```

每一层都比上一层更具体、更可操作。

## 澄清研讨会（战略解码会议）操作

**典型设计：3天（可压缩为2天）**

- 第1天：市场与竞争分析（共同认知环境）
- 第2天：战略重点共识（达成3年重点排序）
- 第3天：必赢之仗制定 + 行动分解 + 责任人确认

**关键原则**：
- 不是CEO一言堂，是"共创共识"的过程
- 先建立共同的"外部视角"（市场/客户/竞争），再讨论内部行动
- 结束时每个必赢之仗的挂帅人签署"军令状"（个人绩效承诺书）

**仪式感的价值**：让战略不只是PPT，而是有情感投入的集体承诺。

## 必赢之仗：六个特征

1. **聚焦**：数量严格控制（年度3-5场）
2. **关键**：对战略实现至关重要，不完成则战略失败
3. **可衡量**：有明确的完成标准
4. **有时限**：明确完成时间节点
5. **跨部门**：往往需要多部门协同，不是某一个部门的事
6. **有挂帅人**：具体到人名，不是"XX部门"

## 必赢之仗的行动格式（四要素）

每个行动计划必须包含：

| 要素 | 格式 | 例子 |
|------|------|------|
| 动词+宾语 | 做什么 | "建立大客户服务体系" |
| 完成时间 | 精确到月/季度 | "2025年Q3完成" |
| 衡量标准 | 可量化或可判断 | "完成3家大客户签约，收入占比超15%" |
| 责任人 | 具体姓名，不是岗位名 | "张伟（销售总监）" |

> 行动里面没有"推动""研究""探索"这类动词——只有能完成的动作。

## 化学式 vs 物理式分解

- **物理式**：简单拆分，A+B+C=总目标（适合相对独立的业务线）
- **化学式**：目标分解产生新的"化合物"，各部分之间有协同反应（适合需要跨部门整合的战略）

化学式分解更难但更有价值，需要挂帅人懂整体战略逻辑。

## 战略术语的12种选项

（选定赛道时的常见路径）

聚焦 / 细分 / 紧缩 / 差异化 / 垂直一体化 / 横向一体化 / 创新 / 多元化 / 转型 / 升级 / 平台化 / 生态化

每种有不同的适用条件，不存在"最好的战略路径"，只有"当前阶段最合适的路径"。

## 与同类框架的对比

| 框架 | 相似点 | 差异 |
|------|--------|------|
| [[toyota-business-practice]] TBP | 层层分解到行动 | TBP更聚焦个人/流程，战略解码更聚焦组织共识 |
| [[five-step-process]] Dalio五步法 | 目标→识别问题→设计方案→执行 | Dalio个人决策，战略解码是组织集体过程 |
| OKR | 目标+关键结果+行动 | OKR自下而上，战略解码强调一致性与承诺 |
