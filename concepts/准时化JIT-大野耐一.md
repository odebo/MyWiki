# 准时化JIT

**定义**：准时化（Just-In-Time，JIT）是丰田生产方式的两大支柱之一（另一为自働化）。其核心思想是"在需要的时间，按需要的数量，把需要的零部件送到需要的工序"。通过逆向思考生产流程——后工序在需要时去前工序领取所需数量的零部件——替代传统的"前工序向后工序供应"模式，实现库存最小化与生产同步化。

**核心机制：后工序拉动**

| 维度 | 传统推动方式 | 丰田拉动方式 |
|------|------------|------------|
| 流向 | 前工序→后工序 | 后工序→前工序领取 |
| 计划 | 各工序独立执行生产计划 | 只对总装配线下达计划 |
| 信息流 | 前工序决定后工序产量 | 后工序通过看板向前传递需求 |
| 库存 | 各工序储备库存以防变动 | 库存被视为浪费，趋近于零 |
| 异常处理 | 前工序异常后工序停工 | 异常暴露在连锁同步中 |

**逆向思考的起源**：大野耐一观察生产流程本质是"物品移动的过程"，尝试逆向思考——如果"让后一道工序在需要的时候去前一道工序领取需要的零部件"，则"前一道工序只生产后一道工序所需数量就够了"。

**连锁同步效应**：以总装配线为起点下达生产计划（什么时间、生产什么车型、多少辆），从总装配线开始各道工序依次向前一道工序领取所需零部件；这种逆向领取方式逆着生产工序向上推进一直到原材料供应部门，产生连锁式同步效应。

**为何传统推动方式不可行**：
- 汽车由几千个零部件组成，生产工序极多
- 生产计划变动因素多——预测错误、业务管理失误、出次品、返工、设备故障、出勤变化
- 一旦前面工序发生问题，后面工序必然停工
- 若无视现状让各工序执行生产计划→前工序产出与后工序脱节→不需要的零部件堆积如山
- 更糟糕的是无法区分哪些生产线正常哪些异常→异常处理迟缓→产出过剩

**JIT 的本质**：不仅是"严丝合缝减少库存"，更是"预则立"的思想——把工作做在前面，通过逆向拉动设计消除变动因素，而非用库存缓冲变动。

**与已有体系的关联**：
- 与 [[自働化-大野耐一]] 互为支柱——JIT解决"量"的浪费，自働化解决"质"的浪费
- 与 [[看板-大野耐一]] 不可分——看板是JIT落地的信息工具
- 与 [[七大浪费-大野耐一]] 同源——JIT消除的最大浪费是"库存"和"产出过剩"
- 与 [[丰田4P模型-莱克]] 互补——莱克将JIT纳入4P模型的流程维度
- 与 [[七种浪费-莱克]] 同源——莱克继承大野耐一的浪费分类
