# 两段式问题解决法

丰田强大的真正秘诀。现实中的问题解决并非总是"先充分思考再行动"，而是在混沌的第一阶段实践中获得"意外的成功"，再在第二阶段将成功提炼为可复用的标准。

## 核心框架

```
第一阶段（事后合理）
  └─ 直接进入STEP6实践，边做边用What/Why/How深度思考
  └─ 在混沌中试错，"意外的成功"自然涌现

第二阶段（标准化）
  └─ STEP7：从事后合理的角度分析成功原因
  └─ STEP8：将正确步骤标准化，制成一页纸资料推广
```

## 事前合理 vs 事后合理

| | 事前合理式 | 事后合理式 |
|---|---|---|
| **定义** | 行动之前做充分深度思考（TBP前五步） | 直接进入实践，成功后才给行动找合理解释 |
| **比喻** | "先摸石头再过河" | "一边摸石头一边过河" |
| **典型场景** | 条件充分、时间充裕时 | 日常大多数工作 |
| **风险** | 过度分析导致工作停滞 | 缺乏深度思考，无法复制成功 |

**两者不是非此即彼，而是相辅相成。** 绝大多数工作处于"事后合理"状态，但即使如此，也可以在实践中同步开展深度思考。

## 只能事后合理的三种情况

**①自上而下型**：How?已被上级确定，"如何执行"从一开始就被锁定。深度思考只能从已定好的对策反推问题和原因，是一种典型的事后合理。

**②拿来主义型**：直接搬用其他部门/组织的成功对策（How?），跳过自身的What?和Why?分析。坚持标准化下的每日深度思考，才能培养出判断他人方案是否适用于自己的直觉。（天才=1%灵感+99%汗水，99%的汗水孕育了那1%的灵感。）

**③因地制宜型**：现实存在各种限制条件（人手不足/预算有限/时间紧迫），无法按事前合理完整规划。在这种情况下需要适可而止的灵活性：明确问题要立足现实；已锁定根本原因可以直接跳过；对策无法更改时，从事后合理的角度反推该工作的意义。

## 试错法与知行合一

试错法（偶然试行）：在不断尝试中解决问题，高度重视实践，不过分探讨为什么某种解法会成功。

- **软件领域类比**："敏捷"——在实践的同时保持深度思考
- **知行合一**：即使直接进入STEP6实践，也可以在解决问题的过程中思考What/Why/How——"知"与"行"本为一体

> 即使直接进入TBP第六步实践，也可以在解决问题的过程中思考"What?""Why?""How?"，即在实践的同时保持深度思考。

## 意外的成功（Unexpected Results）

德鲁克《创新与企业家精神》中的概念。办公室工作中，造就"意外的成功"的关键在于**人**——在意想不到的地方得到高人指点，一件毫无头绪的工作突然得到解决。

事后分析这些意外的成功，总结规律→STEP8标准化，这就是第二阶段的核心价值。

## 丰田两段式的历史成因

昭和时期（1926-1989年）的丰田，面对战后繁荣的汽车市场需求，资源严重不足，必须立刻采取行动扩大生产。"时间就是金钱"的环境下根本没有余地慢慢进行事前合理式的深度思考。

因此，"深度实践的同时，不忘深度思考"成为彼时的唯一选择。久而久之，这些事后合理的成功经验形成了标准，即TBP八大步骤的前五步。

## 实践要点

- **任务结束后，必须将最终成果总结成"一页纸"资料**——这才是工作真正完成的标志
- 过分执着于事前合理，在实践中生搬硬套TBP的人，就和"扭曲的Why?型员工"一样，在思考的泥潭里狂踩刹车，工作也毫无进展
- 重视"深度思考"而忽视"深度实践"，无异于本末倒置
