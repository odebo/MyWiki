# 品牌延伸陷阱

用已有品牌名做新产品，借势看似合理，实则在心智中稀释原有定位。跷跷板两端不能同时在高位——一个名字只能强代表一件事。

## 跷跷板法则

```
品牌X = 强定位A
品牌X 延伸到 B →
  A 位置 ↓（原有用户认知弱化）
  B 位置 ↓↓（新进入，竞争更弱）
结果：两端都输
```

**根本原因：** 消费者用名字组织记忆。一个名字=一个位置。延伸后名字代表两件事，消费者感到混乱，倾向放弃这个品牌。

## 三大测试法

**购物清单测试：** 把延伸品牌名写入清单，让陌生人去买，看是否买回预期产品

**调酒师测试：** 走进陌生酒吧说出品牌名，看调酒师给你什么

**帕卡德测试（高端品牌专用）：** 高端品牌是否在推低价产品？ → 高警戒

## 帕卡德陷阱

**最惨烈案例：** 帕卡德（Packard）是美国最尊贵豪华车品牌 → 推出低价版Clipper（为提高销量）→ 原有富裕买家离开 → 公司倒闭

**规律：** 高端品牌推低端产品=摧毁稀缺感/尊贵感=摧毁品牌核心价值

## 正确替代方案

创建独立品牌而非延伸：
- 宝洁：51个独立品牌，利润是高露洁（延伸策略）的3倍
- 丰田→雷克萨斯：豪华市场独立品牌
- 可口可乐→雪碧：柠檬碳酸独立命名

**什么时候延伸有效（5维评估）：**
1. 新品类预期销量是否覆盖原品牌损失？
2. 新品类竞争格局是否空旷？
3. 是否有足够广告预算独立建立认知？
4. 产品是否有真正差异化特征？
5. 能否触达目标细分用户？

短期有利（借势入市快），长期不利（稀释定位）——是否值得，取决于时间维度。

## 与其他框架的关系

- 品牌延伸陷阱 ↔ [[小米四字诀]] 中的"专注"：小米"一个品类只出1-2款"，本质上是在用专注策略防止品牌稀释
- 品牌延伸陷阱 ↔ [[从0到1-垄断哲学]]：蒂尔的"专注小市场垄断"与避免延伸是同一方向——聚焦是护城河的来源

## 典型案例

- **蛋白质21洗发水** — 13%份额→延伸护发素/摩丝→2%份额（各品类无法集中资源）
- **大众甲壳虫** — 成功于"小而可靠" → 推大型车 → 两端皆失
- **沃尔沃** — 坚守"安全"50年，一旦强调"豪华/运动"，定位弱化，销量随之下滑
