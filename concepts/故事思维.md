# 故事思维

故事思维不是天生的，是一种可习得的认知模式——把生活中发生的事件主动识别为"可用故事素材"，并具备将其转化为有效演讲内容的能力。

## 有效故事的定义

一个有效的演讲故事需满足：
1. **有明确的观点**：故事是用来论证某个论点的，不是为了讲故事而讲故事
2. **有情感张力**：包含冲突、转折或强烈情绪的时刻
3. **有代入感**：听众能在故事中找到自己或认识的人
4. **有画面感**：具体、感官化的细节，让听众"看到"而非"听到"

## 就近原则：发现故事的眼光

找不到故事？因为距离太远。从"最近"处找：

- **时间最近**：最近发生的事（一周内，记忆最鲜活）
- **关系最近**：身边人的故事（比名人故事更有代入感）
- **心理最近**：深刻影响过自己的经历（有真实情感的故事才能感染听众）

"无处不在的故事"不是比喻——生活中每天发生的事都是素材，差异只在于有没有"故事的眼光"。

## 故事思维五维度

| 维度 | 描述 |
|------|------|
| 观察力 | 注意日常中的冲突、转折、情感时刻 |
| 关联力 | 将具体事件与抽象观点连接 |
| 提炼力 | 从故事中提取可复用的洞见 |
| 想象力 | 用细节填充故事，让它活起来 |
| 表达力 | 找到最能打动听众的讲述角度和语言 |

## 编辑 vs 编造

故事可以"编辑"，但不能"编造"：
- **编辑**：选择哪些细节呈现、调整叙述顺序、强化情感节点——合理合法
- **编造**：捏造不存在的事件、把别人的经历说成自己的——失去信任基础

真实性是故事力量的根源。听众对虚假的感知比我们想象的灵敏。

## JX 故事思维矩阵

筛选和使用故事的二维框架：
- **J轴（价值判断）**：这个故事对听众有没有价值？能不能支撑我的观点？
- **X轴（情感强度）**：这个故事有没有足够的情感冲击力？

高价值 × 高情感 = 优先使用的故事
高价值 × 低情感 = 需要"包装"提升画面感后再用
低价值 × 高情感 = 慎用（感动但没论点支撑）
低价值 × 低情感 = 舍弃

> 洞见：会讲故事的人不是"故事多"，而是"故事选得准"。故事思维的核心是筛选力，不是搜集力。
