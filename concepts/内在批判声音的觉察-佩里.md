# 内在批判声音的觉察 — 佩里

**定义**：几乎每个人的心底都有一种持续不断的唠叨或评价的声音——**内在批判者**（Inner Critic）。这个声音往往不是天生的，而是从父母那里承袭的——我们如何与自己对话，会直接传给孩子。**佩里断言：你的自我批评可能是妨碍孩子幸福的最大绊脚石。**

**内在批判声音的特征**：
- 持续不断的负面自我评价
- 我们习以为常，甚至注意不到它在说什么
- 常见内容：
  - "这不是我这种应得的"
  - "我不能相信任何人"
  - "我没救了"
  - "我永远做得不够好，还是趁早放弃吧"
  - "我什么事情都做不好"
  - "我太胖了"
  - "我真是一无是处"

**承袭的机制**：
- 佩里最早的记忆之一：母亲照镜子时对自己吹毛求疵
- 多年后，她在十几岁女儿面前做了同样的事
- **女儿提醒她**：她不喜欢妈妈这样做
- 佩里想起自己以前也不喜欢母亲那样——但习惯还是传下来了
- **承袭不需要语言**——孩子通过观察父母如何对待自己来学习如何对待自己

**内在批判声音的来源**：
- 多数来自主要照顾者（通常是母亲）
- 不一定是直接批评——可能是父母自己的自我对话
- 例：伊莱恩的妈妈从不说"你不够好"——但她对自己也是吹毛求疵（"千层面做得不好，奶酪放太多"）
- 孩子内化的是父母**对待自己**的方式，而非对待孩子的方式

**内在批判声音的破坏力**：
1. **引导有害判断**：让孩子也学会"我不行"
2. **放大低落情绪**：抑郁时这个声音最响
3. **打击信心**：让人样样觉得不如人
4. **破坏行动力**：在尝试前就放弃
5. **代际传递**：传给下一代

**4步觉察法**（伊莱恩的实践）：

### 1. 找出那个声音
- 随身带纸笔，记下一天中冒出的所有自我批判
- 问自己：以前是否听过其他人说类似的话？是谁？

### 2. 别理会那个声音，不要争论
- 与声音争辩会消耗精力且每次都输
- 把它当成难相处的同事——"反正你有权发表意见"
- 不忽视也不内化——只是听而不评判

### 3. 走出舒适区
- 做内在批评者说你做不到的事情
- 失败也没关系——重点是证明声音不全对
- 用具体行动对抗抽象否定

### 4. 意识到代际传递的危险
- 知道自我批评会传给孩子，会有动力改变
- 不是为自己改变——也是为孩子改变
- 觉察本身就是改变的开端

**伊莱恩的故事**：
- 内在声音：批评失败、劝退尝试
- 来源：妈妈的悲观和吹毛求疵
- 改变：重拾画笔，不评判画得好坏，只注意为什么喜欢画画、最满意哪部分
- 意外收获：不仅对绘画更自信，对整体生活也更自信

**言传不如身教**：
- 父母对孩子说1000句"你很棒"——不如孩子看到妈妈自信地照镜子
- 父母要求孩子"别怕失败"——但自己从不尝试新事物
- 孩子学的是父母**怎么做**，不是父母**怎么说**

**练习：揭穿内在的批判声音**：
1. 随身带纸笔，记下自我批判
2. 识别来源——这是谁的声音？
3. 想一个目标，注意自己如何劝退自己
4. 那个劝退的声音像谁？

**与"好/坏父母"标签的关系**：
- 自我批评的家长常陷入"好/坏父母"评判
- 评判自己"是坏父母"无助于改善
- 替代：观察及欣赏做对的事情
- 例：不说"我做的面包很好吃"，改说"全心全意投入烘焙是值得的"
- 例：不说"我不擅长瑜伽"，改说"我开始练瑜伽了，比上周进步一些"

**与已有概念的关系**：
- 与[[亲子教养的传承-佩里]]：内在声音是传承的核心载体
- 与[[正念冥想-安德烈]]：觉察内在声音是正念练习
- 与[[成长型思维-德韦克]]：内在批评者=固定型思维，觉察它=向成长型转换
- 与[[内阻力-普莱斯菲尔德]]：内在批评是内阻力的声音之一
- 与[[不完美主义-格兰特]]：自我批评是完美主义的内在化
