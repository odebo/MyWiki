# 基础、文化与创始人（《从0到1》）

蒂尔关于公司内部建设的三个核心主张：基础决定命运（蒂尔定律）、文化是帮派而非顾问委员会、创始人的极端特质是公司的引擎。

---

## 蒂尔定律：基础决定命运

> "一个初创公司被错误的基础所损害，是永远无法修复的。"

创业初期最重要的决策：

1. **联合创始人的选择**：和陌生人创业就像闪婚——99%会出问题。理想联合创始人要有足够长的共同历史（了解对方的边界）。创始团队内部纠纷是初创公司死亡的主要原因之一

2. **股权分配**：越早明确越好。股权模糊是定时炸弹——等到公司有价值了，分歧会被利益放大到无法调解

3. **所有权/控制权/管理权的三权分立**：
   - **所有权**：股东（谁拥有股权）
   - **控制权**：董事会（谁做战略决策）
   - **管理权**：CEO（谁执行日常运营）
   三权合一会造成独裁危险；三权完全分离会造成执行瘫痪。平衡点：小董事会（3-5人），CEO保持日常控制权，重大决策有制衡

4. **CEO薪资是文化信号**：
   - 外部投资者的CEO薪资上限越低，越有利于公司发展
   - 高薪CEO失去了维护自身价值的动力，更关注保持职位而非创造价值
   - 低薪创始人表明："我不是来拿钱的，我是来创造价值的"——这为整个文化设置基调

## 帮派文化：比"家庭"更极端

**最好的初创公司文化不是"工作环境好"，而是高度认同的使命共同体——接近帮派，而非顾问委员会。**

蒂尔的"邪教←→顾问委员会"谱线：

```
邪教（过度）←————————————→ 顾问委员会（过淡）
  盲目追随，封闭排外          互不认同，各怀异志
         ↑
    理想创业文化
   （极度认同使命，
    但不封闭于外部现实）
```

**好文化的标志**：
- 员工认同公司使命高于一切（近乎信徒），但不排斥外部批评
- 每个人都有明确专属的职责范围（避免内部竞争）
- "为什么你要来这家公司而不是谷歌？"——答案必须是关于使命，不能只是薪资

**专注于一件事**：每个人只做一件最重要的事。这不只是时间管理，而是内部冲突管理——当职责重叠，内部冲突必然发生。蒂尔在PayPal的管理经验：告诉每个人他们是最擅长那件事的人，然后让他们去做那件事，不要越界。

## 创始人的悖论：极端特质的双面刃

**伟大创始人的特质分布是"倒钟形曲线"：正态人群集中在中间，创始人集中在两端。**

他们同时具有看似矛盾的特质：
- 既是局内人（成功/富裕/有影响力）又是局外人（格格不入/被嘲笑/被误解）
- 既被崇拜又被指责
- 既天才又疯狂

**极端特质的自我强化循环**：
```
真正不同 → 发展为极端特质 → 他人将其夸大 → 本人将其夸大 → 更加真正不同
```

**两个危险**：
1. **创始人的危险**：沉醉于自己的神话——过于相信自己的特殊性，忽视现实反馈，迷失方向
2. **公司的危险**：不再相信创始人的神话，把"理性地否定创始人"当作智慧——错把去中心化当进步，实则失去了真正的创造力来源

**乔布斯案例的教训**：
- 1985年苹果董事会赶走乔布斯：认为他"太难管理"
- 结果：苹果陷入长达12年的低迷
- 1997年乔布斯回归：iPod、iPhone、iPad接连而来
- 公司需要创始人，不是因为他们总是对的，而是因为**创造新价值这件事无法被公式化、无法被职业经理人照章执行**

> "企业离不开创始人。对于创始人看似极端怪异的行为，要有更大的容忍度，我们需要靠非同寻常的人来领导公司，取得大的飞跃，而非限于小的进步。"

## 与知识库的关联

- **[[meritocracy]]** — 达利欧的"创意择优"：让最好的想法赢，不是地位最高的人赢。蒂尔的创始人悖论是反向视角：有时候最好的想法就来自那个"地位不合理高"的创始人
- **[[组织产品化]]** — 李想：把组织当产品来运营。蒂尔的帮派文化和李想的七个习惯考核，都在强调组织文化不是结果，而是需要主动设计的产品
- **[[战略执行-组织人才文化]]** — 王钺：文化重塑两路径。蒂尔更激进——文化必须从创始人开始，不能外包
