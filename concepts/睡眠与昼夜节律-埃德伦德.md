# 睡眠与昼夜节律

埃德伦德作为生物钟专家与睡眠医生的核心论点：**睡眠是被动休息的基础，但仅靠睡眠不足以解决疲惫**——必须配合主动休息 + 顺应昼夜节律。生物钟是"生命的电枢"。

## 生物钟即生命电枢

> "人体内的生物钟就是生命的'电枢'。"——罗马俗语"时间控制着生活"

- 体内强大生物钟设定每个细胞的基本状态
- 24 小时周期运行，昼夜节律是地球生命的基本构成
- 体内 1/5 深度睡眠产生生长激素；65 岁健康男性可能完全失去深度睡眠

## 七天睡眠改造计划

| 天数 | 任务 |
|------|------|
| 第 1 天 | 在你喜欢的时间起床 |
| 第 2 天 | 坚持在喜欢的时间醒来 |
| 第 3 天 | 在感觉自然、喜欢的时间入睡 |
| 第 4 天 | 制定入睡仪式 |
| 第 5 天 | 学会别担心 |
| 第 6 天 | 睡前泡个热水澡 |
| 第 7 天 | 晚上散步 |

## 仅靠睡眠不够

> "数百万人都睡得很好，但他们在生活的大部分时间里，仍然感到身心疲惫、郁郁寡欢。"

这是埃德伦德转向"主动休息"理论的临床起点——也是这本书区别于一般睡眠书的核心命题。
