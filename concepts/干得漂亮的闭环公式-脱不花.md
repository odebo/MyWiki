# 干得漂亮的闭环公式

脱不花在《干得漂亮》中提出的职场做事核心公式——把"干得漂亮"从模糊感受变成可操作方法。核心是**闭环**：凡事有交代、件件有着落、事事有回音。

## 公式：干得漂亮 = 接 + 做 + 交

### 1. 接（接收任务）
- **复述确认**——用自己的话复述任务，确认理解无误
- **追问目标**——这个任务要解决什么问题？不是机械执行
- **明确边界**——时间、资源、交付标准
- **拒绝模糊**——上级说"尽快"要追问"周几几点"

### 2. 做（执行任务）
- **拆解为可交付物**——把抽象任务拆成具体产出
- **里程碑反馈**——不在最后才汇报，过程中分阶段反馈
- **遇到卡点立刻求助**——不闷头硬扛，卡点超过 2 小时就该问
- **保留方案 B**——主路径失败时有备份

### 3. 交（交付任务）
- **超出预期一点点**——不是 100% 达标，是 100%+10% 惊喜
- **总结方法论**——交付的不只是结果，还有可复用的方法
- **主动复盘**——哪里做得好、哪里可改进、下次怎么做
- **闭环告知**——告诉所有相关人结果，不只是发起人

## 闭环的三个检验标准

脱不花给出闭环是否完成的三个检验：
1. **有交代**——任务发起人知道结果
2. **有着落**——任务有明确产出，不是空中楼阁
3. **有回音**——任务结束后有反馈和复盘

三个都满足 = 真闭环；缺任何一个 = 假闭环。

## 闭环的反面：开环

职场最常见的失败模式是"开环"：
- 接任务不确认 → 做错方向
- 做任务不反馈 → 上级不知道进度
- 交任务不告知 → 任务结束无人知道
- 开环的人 = 不可靠的人 = 晋升困难

## 与"完成主义"的对话

主流职场观念：任务完成 = 100%。
脱不花论点：
- 完成只是 60 分
- 干得漂亮 = 完成方法 + 超预期 + 复盘
- 60 分的人随时可被替代
- 90+ 分的人才稀缺
- "完成"是底线，"漂亮"是价值

## 与"做事三境界"的对话

主流讲"做事三境界"：做完 → 做好 → 做透。
脱不花类似但不完全相同：
- 做完 = 接 + 做 + 交的最低版
- 做好 = 闭环 + 超预期
- 做透 = 闭环 + 复盘 + 方法论沉淀
- "干得漂亮"对应"做透"——把单次任务变成可复用能力
