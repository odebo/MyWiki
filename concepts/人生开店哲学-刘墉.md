# 人生开店哲学

**核心**：把人生比作开店——不怕关门，怕不再开门；不怕店老，只要东西新鲜。刘墉五十年的写作生涯就是这种"老字号又有新货"的实践。

**三层含义**：

1. **关门论**：店面关门不可怕，可怕的是不再开门。失败不可怕，可怕的是放弃重启
2. **新货论**：店再老，只要东西新鲜，就有活路。人再老，只要保持创造，就有价值
3. **梦想与现实差距**：梦想不等于理想，最重要的是别气馁，缓口气，再开一家。梦想继续，行动继续

**与"开店"对应的隐喻系统**：
- 装修中的店 = 怀抱生意兴隆梦想的人
- 关门大吉的店 = 当初没想到会关店的人
- 重新开业 = 缓口气再开一家

**作者实践**：刘墉二十三岁写成《萤窗小语》，到七十多岁写《人生便利店》，整整五十年。"老来的文字跟年轻时不同，因为'世事洞明'，所以多些辛辣和豁达，还可能带点反讽与幽默"。

**与相关概念的关系**：
- 与 [[韧性心理学-马斯滕]] 一致——关门再开是韧性的核心表现
- 与 [[成长型思维-德韦克]] 互补——失败不是终点而是再开的起点
- 与 [[反脆弱-塔勒布]] 形成对照——塔勒布论系统从冲击中获益，刘墉论个体从关店后重开
