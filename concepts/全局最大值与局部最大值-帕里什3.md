# 全局最大值与局部最大值

**定义**：沙恩·帕里什在《思考的框架3》第8章提出的数学思维模型——局部最大值（Local Maximum）是当前区域内的最优解，全局最大值（Global Maximum）是整个空间的最优解。两者可能不一致——困在局部最优是优化最常见的陷阱。穿越山谷（暂时下降）才能到达更高峰。

**核心命题**：
- 局部最优未必是全局最优
- 穿越山谷——为了到达更高峰需要先下降
- 优化——避免困在局部最优
- 利用新的伙伴关系进行优化——跳出局部需要外部输入

**数学直觉**：
- 想象一片山脉——你站在某个山峰（局部最大值）
- 但不一定是最高峰（全局最大值）
- 到达更高峰必须先下山——穿越山谷
- 优化算法（梯度下降）容易卡在局部最大值

**生活中的局部最大值陷阱**：

**1. 职业局部最优**：
- 当前工作可能是你能力圈内的最优——但不是人生全局最优
- 切换职业=下山——短期收入下降、地位下降
- 但只有穿越山谷才能到达更高峰
- 与[[能力圈与痴迷-多贝里]]呼应——能力圈内的最优vs圈外的可能

**2. 关系局部最优**：
- 当前关系可能比身边可选项都好——但不是可能的全局最优
- 但切换有风险——山谷可能没有更高峰
- 与[[复利效应与边际收益递减-帕里什3]]呼应——长期关系的复利vs切换的不确定性

**3. 产品/业务局部最优**：
- 当前产品在当前市场是最优——但不是可能的全局最优
- 颠覆式创新=穿越山谷——短期业绩下降
- 克里斯坦森"创新者的窘境"——好公司失败因为困在局部最优
- 与[[更迭-帕里什3]]呼应——主动更迭跳出局部

**4. 学习局部最优**：
- 当前学习方法对你有效——但可能有更优方法
- 切换=短期效率下降——但长期可能更高
- 与[[业余生产力科学家-阿布达尔]]呼应——实验思维探索新方法

**穿越山谷的两种策略**：

**1. 模拟退火（Simulated Annealing）**：
- 偶尔接受"差"的移动——以跳出局部最优
- 早期探索多，后期利用多
- 与[[业余生产力科学家-阿布达尔]]呼应——实验思维

**2. 引入外部输入**：
- 利用新的伙伴关系进行优化
- 外部视角帮助你看到全局
- 与[[反馈回路与系统行为-帕里什3]]呼应——5人圈子提供高质量反馈

**为什么人们困在局部最优**：

| 原因 | 机制 |
|------|------|
| 损失厌恶 | 下山的短期痛苦大于上山的长期收益 |
| 即时反馈偏好 | 局部最优的当前收益更显著 |
| 身份认同 | "我就是做X的人"——切换=身份危机 |
| 沉没成本 | 已投入的资源让切换感觉浪费 |
| 信息不足 | 看不到远处的山峰 |

**与第一性原理的整合**：
- 第一性原理[[第一性原理-马斯克]]：从根本重新思考——绕过现有结构
- 局部/全局最大值：识别当前是否困在局部最优
- 整合：第一性原理是穿越山谷的工具——重新定义问题空间

**与稻盛哲学的张力**：
- 稻盛[[极度认真工作能扭转人生-稻盛和夫]]：在当前位置极度认真——深耕局部最优
- 帕里什：识别何时该穿越山谷——切换到全局最优
- 整合：稻盛适用于已找到全局方向的人；帕里什适用于还在寻找的人
- 实践：先用第一性原理找到全局方向，再用稻盛哲学深耕

**与心流的对照**：
- 契克森米哈伊心流：能力与挑战匹配时的最佳体验
- 帕里什：心流可能是局部最优的标志——舒适但非全局最优
- 整合：心流是当下体验，全局最大值是长期视角

**适用边界**：
- 适用于：职业规划、产品战略、人生重大决策
- 适用于：识别"舒适但停滞"的状态
- 不适用于：紧急任务——山谷穿越需要时间
- 局限：识别全局最大值本身是难题——可能误判

**实践步骤**：
1. 问自己：我当前在局部最大值还是全局最大值？
2. 识别"舒适但停滞"的信号——长期没有突破
3. 寻找外部视角——5人圈子的反馈
4. 评估穿越山谷的成本和收益
5. 必要时主动下山——切换到新曲线
6. 用第一性原理重新定义问题空间
