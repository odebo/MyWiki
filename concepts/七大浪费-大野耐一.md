# 七大浪费

**定义**：七大浪费是大野耐一系统梳理的生产现场七类无效活动。丰田生产方式的基本思想是"彻底消除浪费"——现有能力=工作+浪费，作业=劳动+浪费。真正提高效率不是"做更多"，而是"把浪费的比例降到最低，把工作的比例提到接近100%"。

**七类浪费**：

| # | 浪费类型 | 内涵 |
|---|---------|------|
| 1 | 产出过剩 | 生产了超过所需数量的产品——大野耐一认为这是"最可怕的浪费" |
| 2 | 窝工 | 人在等待机器或前工序产出 |
| 3 | 运输 | 物品在不必要的位置间移动 |
| 4 | 加工 | 加工本身存在不必要的步骤或精度 |
| 5 | 库存 | 超过所需的原材料/在制品/成品 |
| 6 | 动作 | 人的动作存在不必要的部分 |
| 7 | 次品 | 生产不合格品造成的返工/报废 |

**最可怕的是产出过剩**：大野耐一明确指出"最可怕的浪费非产出过剩莫属"。原因：
- 产出过剩掩盖了其他所有问题——库存一多，瓶颈、质量缺陷、设备故障都被掩盖
- 产出过剩是其他浪费的"母浪费"——一旦过剩生产，必然带来库存、运输、动作的多余
- 库存型思维（"不维持相当水平的库存就感到不安"）是低增长时期"产出过剩、不良库存"罪魁祸首

**库存观念的颠覆**：
- 传统观念：库存是缓冲，越多越安全
- 丰田观念：库存是浪费，越多越危险——掩盖问题、占用资金、占用空间
- "石油危机以后的低增长时期，库存型思维成为最大经营损失的罪魁祸首"

**现有能力公式**：
```
现有能力 = 工作 + 浪费
（作业 = 劳动 + 浪费）
```
提高效率 = 削减浪费 → 把"工作"的比例提升到接近100%。

**龟兔赛跑隐喻**：大野耐一用龟兔赛跑说明——以"需求量"为大前提，相比白天睡大觉的敏捷兔子，锲而不舍按需求稳定生产的乌龟更优。"缺乏可持续性的速度没有任何意义"。这与追求产能峰值、鼓励超额完成的传统观念形成对比。

**消除浪费的连锁效应**：
- 消除产出过剩 → 库存下降 → 问题暴露 → 持续改善
- 消除窝工 → 多余人员出现 → 重新配置（而非解雇）→ 一人多机
- 消除次品 → 自働化自动停止 → 五个为什么追溯根因 → 系统改进

**与已有体系的关联**：
- 与 [[准时化JIT-大野耐一]] 互补——JIT消除"库存"和"产出过剩"两大浪费
- 与 [[自働化-大野耐一]] 互补——自働化消除"次品"浪费
- 与 [[看板-大野耐一]] 同源——看板是控制产出过剩的核心工具
- 与 [[七种浪费-莱克]] 同源——莱克的七种浪费直接继承大野耐一的分类
- 与 [[丰田4P模型-莱克]] 互补——莱克4P模型将"消除浪费"纳入流程维度
- 与 [[现场Gemba与改善Kaizen-莱克]] 同源——浪费必须在现场发现
