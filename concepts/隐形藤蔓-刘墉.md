# 隐形藤蔓

**核心隐喻**：每个人身上都挂着隐形的藤蔓——那些牵肠挂肚的烦恼、责任、人际负担。很多树不是老死或病死的，而是被藤蔓缠绕致死。人也一样，活得不好甚至短命，常因为藤蔓太多，把需要的阳光完全遮掩。

**藤蔓的特征**：
- **隐形**：自己看不见，但旁观者从高处俯瞰一目了然
- **夜里偷偷长**：每天醒来都要检查，否则一夜之间又多了许多
- **剪不断理还乱**：不能彻底清除，只能日常维护

**作者给的实践方法**：
> 每天起床时，用手在头上抓一抓，无论有多少烦恼缠绕着自己，都留一块地方，让阳光照下来。

**与心理学概念的呼应**：
- 与 [[认知带宽-穆来纳森]] 同构——贫困、焦虑、责任都会占据带宽，像藤蔓遮蔽阳光
- 与 [[蔡加尼克效应-蔡加尼克]] 相关——未完成的事会持续占用心理资源，像夜里悄悄生长的藤蔓
- 与 [[决策疲劳-鲍迈斯特]] 互补——决策本身是藤蔓的一种

**与"减法人生"的对照**：
- 减法人生主张彻底清空
- 藤蔓论承认藤蔓无法根除，只能每日修剪留出阳光区
