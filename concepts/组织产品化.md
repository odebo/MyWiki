# 组织产品化

李想《产品实战16讲》发刊词+第06讲核心观点：**用做产品的方法论来打造组织本身**——组织是产品人的第二件产品。

## 核心洞见

> 产品人不只是做面向用户的产品，也要把组织当作产品来做——用同样的标准、同样的方法打磨。

如果只关注外部产品，忽视内部组织，最终组织的惰性/惯性/无知会拖垮产品。

## 组织的三大敌人

1. **惰性**：团队不愿深入研究用户，用经验代替洞察
2. **惯性**：0→1的成功经验不经反思就用到1→10阶段（→[[增长节奏]]）
3. **无知**：不知道自己不知道——最危险，因为无法自我发现

## 统一度量衡：产品四步法

让所有产品人用同一套语言描述产品决策：
1. 用户是谁？（精确定义，不能有歧义）
2. 用户的处境是什么？（场景）
3. 我们要帮用户完成什么任务？（目标）
4. 用户是否感受到了我们的价值？（验证）

**作用**：团队讨论时不再各说各话，形成统一的判断框架。

## 嵌入流程：PEA评审

PEA（Product / Evaluation / Approval）是把产品标准嵌入日常工作流程的机制。

**六要素**（任何产品/功能上线前必须完成）：
1. 解决什么问题（必须有具体依据）
2. 目标要求（用户是谁 + 用户获得什么体验，必须是用户能说出口的话）
3. 方案描述
4. 风险与评估（含预案）
5. 资源评估（研发/费用/周期）
6. 运营指标（可量化 + 事先预期值）

**不能通过PEA的需求，直接被打回**——这是保证产品质量的关键防线。

PEA的另一个价值：**复盘的基础**（见[[复盘方法论]]）——有了事前约定，复盘才能有迹可循。

## 培养成年人：七个习惯 + 真实案例考核

不仅是工具和流程，李想更强调培养"成年人"的工作人格。

**七个习惯**（柯维）被理想汽车强制要求：
- 以真实工作案例考核（不是读后感）
- 考核通过才能晋升

核心信念：**优秀的产品人必须有主动负责的成年人人格**，而不是等待被管理的孩子。

理想汽车的执行方式：
- 所有管理层必须完成培训并通过考核
- 培训内容结合公司真实案例讨论

## 组织能力是可以打磨的

关键洞见：组织能力 ≠ 天赋，是可以通过持续学习和迭代提升的。

2022年问界M7危机后，理想汽车全面学习华为：
- 研发：IPD（集成产品开发）
- 销售：IPMS
- 供应链、财经、人才体系

→ 学习方向：向最强的公司学习，不固守自己的方式
