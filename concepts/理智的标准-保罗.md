# 理智的标准（保罗）

保罗指出，批判性思考者谨慎地将普遍的**理智的标准**运用到思维的要素上。这些标准是**跨学科**的——超越学科划分，适用于任何推理的评估。

## 九大理智标准

| 标准 | 含义 | 自检问题 |
|------|------|----------|
| **清晰性** | 可被理解、可详细阐释 | 你能详细阐释吗？能举例吗？ |
| **准确性** | 按事物原本情形呈现 | 怎样检查是否真实？怎么核实？ |
| **精确性** | 把握必要细节 | 能给我多一些细节吗？能更明确吗？ |
| **相关性** | 与当下任务切实相关 | 你所说的与问题如何关联？ |
| **深度** | 触及问题复杂性 | 这个问题是简单还是复杂？是什么让它复杂？ |
| **广度** | 考虑多个视角 | 哪些视角与这个问题相关？忽略了哪些角度？ |
| **逻辑性** | 推论与前提一致 | 推论是否从信息中合理推出？ |
| **重要性** | 聚焦核心而非次要 | 这是最重要的问题吗？ |
| **公正性** | 不带偏见地对待各方 | 我是否同样高标准地质疑自己的观点？ |
| **充分性** | 信息足以回答问题 | 是否遗漏了重要信息？ |
| **一致性** | 不自相矛盾 | 我的多个主张之间是否冲突？ |

## 标准与要素的交叉评估

保罗的核心方法是把**理智的标准**应用到**思维的要素**上。例如：

- 评估**目的**：目的是否公正、现实、合理？是否与其他目的相悖？
- 评估**问题**：问题是否清晰、相关、重要？能否解答？
- 评估**信息**：信息是否准确、相关、充分？
- 评估**概念**：概念是否清晰、相关、未歪曲？
- 评估**假设**：假设是否合理、一致？是否应被质疑？
- 评估**推论**：推论是否合乎逻辑？是否有其他可信结论？
- 评估**蕴含**：是否追踪了所有逻辑后果？
- 评估**角度**：是否狭隘？是否考虑了对立视角？

## 充分性：最常被违反的标准

保罗特别强调**充分性**——人们通常收集的信息是重要的、相关的、准确的，但**不一定能确保足够充分**来回答问题。

涉及自身利益时，人们通常无法达到充分性标准。一些人通过**省略一些相关和重要的信息，同时包含另一些相关和重要的信息**，营造诚实的表象，而实际上是虚假的——以维护自己的观点、为自己或群体谋取不应得的东西，或向世人呈现"令人满意的"虚假形象。

## 自检清单（保罗推荐的检测点）

1. 所有思考都有目标——花时间清晰陈述目标，选择重要、现实的目标
2. 所有思考都面对问题——清晰表述要解决的问题
3. 所有思考都需要信息——核查信息的准确性和相关性
4. 所有思考都使用概念——深入分析概念，评估是否歪曲
5. 所有思考都包含推论——确认推论、评估其逻辑性
6. 所有思考都基于假设——识别和有力表达假设
7. 所有思考都产生蕴含——追踪逻辑后果
8. 所有思考都从某个角度——审视视角是否狭隘
