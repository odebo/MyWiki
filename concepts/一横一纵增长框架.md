# 一横一纵增长框架

梁宁·增长思维30讲的总纲。

## 框架图

```
         一纵（纵向打透）
             ↑
        破局点（从0开始）
             ↓
        加杠杆（放大优势）
             ↓
        做分形（复制扩张）

一横（横向四维）：
  设计模式 + 优化组织 + 借助势能 + 跨越周期
```

## 一纵：纵向打透

### 破局点（→[[破局点]]）
- 广谱 + 高频 + 体验可控
- 从 0 开始，建立服务图景的第一个锚点
- 高频打低频，用破局点撬动整个业务

### 加杠杆（→[[战略支点与战略杠杆]]）
- 找到自己的自由度，制造资源连锁反应
- 支点（初心）+ 杠杆（自由度）+ 指北针（准星）

### 做分形
- 将成功的模式进行复制和扩张
- 参考[[三级火箭]]：高频流量→商业场景→变现

## 一横：横向四维

### 设计模式（→[[增强回路与调节回路]]）
- 设计增强回路，直视调节回路和滞后反馈
- 让核心资源（心理能量/现金流）持续得到补充
- 模式驱动，而非意志力驱动

### 优化组织（→[[组织成长五阶段]]）
- 家庭/部落/村庄/城市/国家，每个阶段管理要点不同
- 组织是人的组织，视人如人
- 随规模建立对应的基础设施和文化

### 借助势能（→[[战略支点与战略杠杆]], [[闪电式扩张]]）
- 共生/结盟：让渡部分利益，撬动更大资源
- 踩中风口时：闪电式扩张，速度第一
- 利益相关人地图：识别所有能借势的节点

### 跨越周期（→[[玩家地图与增长生态位]]）
- 顶级玩家的核心挑战
- 能力来源：信息环境 + 决策模型
- 小成靠机会，大成靠趋势和周期

## 与产品思维的衔接

| 阶段 | 产品思维 | 增长思维 |
|------|---------|---------|
| 用户洞察 | 同理心/情绪四象限 | 玩家地图/机会判断 |
| 切入点 | 痛点/痒点/爽点 | 破局点（广谱+高频+可控） |
| 体验 | 峰终定律/五层次 | 增强回路（激励场） |
| 商业模式 | 三级火箭 | 一横一纵（完整增长路径） |

> 产品思维 = 做什么，为谁做
> 增长思维 = 怎么从 0 长到 N，怎么跨越周期

## 增长的底牌

> 增长的底牌是你这个人。你是什么人，你就能建立什么样的组织，做出什么样的产品，走过什么样的增长路径。
