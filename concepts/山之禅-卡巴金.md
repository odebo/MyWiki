# 山之禅

**定义**：卡巴金在MBSR中使用的**形象化冥想**核心修习之一——通过想象山的特质（高大挺拔、雄伟庄严、岿然屹立）来加深定力和正念的培养。山的形象使我们联想到这些特质，**直接将这些特质带入到自己的坐姿和态度中**。

## 山的隐喻

| 山的特质 | 冥想中的对应 |
|---------|------------|
| 高大挺拔 | 坐姿端正 |
| 雄伟庄严 | 内心庄严 |
| 岿然屹立 | 不为情绪所动 |
| 季节变换不为所动 | 心境起伏的容器 |
| 承受风雪而不变 | 面对痛苦保持清明 |

## 修习方法

1. **就座**：抱着明确的就座意识走到坐垫或椅子旁
2. **庄严坐姿**：脊柱有力地挺直，面部放松，肩膀放松，脑袋、脖颈以及脊背形成一条舒适的直线
3. **观想山**：在心中唤起山的形象，让自己成为山
4. **保持稳定**：无论发生什么（思绪游走、情绪起伏、身体不适），都像山一样不为所动
5. **季节变换**：想象山经历春夏秋冬、风雪雨晴，始终如一

## 与"镜子"态度的对比

- **山**：稳定、不动、庄严——适合培养定力
- **镜子**：空无一物、虚怀若谷、反映一切——适合培养正念

两者互补：定力是正念的基础，没有一定程度的定力，就无法拥有强大的正念。

## 与坐禅的关系

> "在禅宗中，铃木俊隆禅师如此说道：'坐姿恰当时油然而生的那种心境本身就是一种觉悟……这些形式（静坐冥想）并不是为了获得正确心态，这种坐姿本身就是一种正确心态。'" ——卡巴金引用

**关键**：山的形象不是装饰，**坐姿体现态度**——采取的坐姿要使身体由内而外散发出一种气质，一种毫无保留地认可并接纳任何时刻浮现的任何事物的态度。

## 实践要点

- **反复练习**：在面对任何心境时都表现得庄严、宁静、泰然自若——尤其是在你尚未陷入痛苦和混乱境地之前
- **不要"临时抱佛脚"**：真正的大事一旦来临，其力道之强大足以在一瞬间将你摧垮
- **终生练习**：冥想练习是一项缓慢冗长、循序渐进的工作，就像挖沟渠、栽葡萄一样

## 其他形象化冥想

- **湖之禅**：湖面如镜，反映一切但不被扰动的内心
- **行禅**：每一步都像山一样稳定地落下
- **立禅**：站立如山
- **卧禅**：躺下如山倒映湖中
