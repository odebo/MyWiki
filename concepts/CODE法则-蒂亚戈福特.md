# CODE 法则

**定义**：**CODE 法则**（信管法则）是蒂亚戈·福特为构建第二大脑发明的四步法——抓取（Capture）、组织（Organize）、提炼（Distill）、表达（Express）。这是个人知识管理的核心流程，兼具灵活性和普适性，不受专业、角色、笔记应用种类影响。

**四大步骤**：

1. **抓取（Capture）—— 让笔记更"走心"**
   - 只抓取最有价值的想法和见解（如生物学家只带回最稀有的蝴蝶）
   - 标准：是否让你为之**共鸣**（不是是否"有用"）
   - 反例：将整篇文章一字不落地保存——超高质量信息也未必值得全存
   - 诺奖得主的信息抓取法：保持12个兴趣问题随时悬挂

2. **组织（Organize）—— 以行动为导向**
   - 不按主题（杜威十进分类法）而按**行动**组织
   - 核心问题不是"这属于什么主题"，而是"这条信息放在哪个项目里最管用"
   - 实现：[[PARA系统-蒂亚戈福特]]

3. **提炼（Distill）—— 萃取本质**
   - 每个想法都有其精髓——核心思想
   - 爱因斯坦 E=mc² 的范式：深奥理论也能用简明公式表达
   - 关键问题：如何记录才能更好地帮到今后的自己？
   - 实现：[[渐进式归纳法-蒂亚戈福特]]

4. **表达（Express）—— 成果展示**
   - 前三步都指向终极目标：将思想、经历、知识与他人分享
   - 既不具备价值也不生产价值的知识没有灵魂
   - 建议将精力和时间从信息摄取转向信息创造

**元模式——发散与聚合**：
- 抓取 + 组织 = **发散**（打开可能性，收集种子）
- 提炼 + 表达 = **聚合**（缩小范围，促成结果）
- 创作过程即在两者间往复交替

**三大创作策略**（聚合阶段）：
1. **思想群岛**：先收集足够素材形成"群岛"，再在岛屿间搭桥
2. **海明威之桥**：在思路明确时停下，为下次创作留桥（下一步想法/当前状态/易遗忘信息/下阶段目标）
3. **压缩范围**：砍掉次要功能及时发布，被删内容存为半熟素材备用

**与已有概念的关联**：
- 与[[5S与PDCA-丰田]]对话：CODE 是知识工作者的 PDCA 循环
- 与[[福格行为模型]]对话：四步法降低了知识管理的"启动门槛"
- 与[[A3报告与5Why-丰田]]对话：都是结构化思考方法，CODE 面向个人，A3 面向组织
- 与[[刻意练习]]对话：CODE 是可重复、可优化的"练习结构"
