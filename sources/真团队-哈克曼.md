# 真团队

**作者简介**：理查德·哈克曼（Richard Hackman，1940–2013），哈佛大学社会与组织心理学教授，团队有效性研究的世界级权威。毕生研究团队有效性的Input-Process-Output模型，对超过1000个团队进行研究。著有《真高管》《真团队》等。曾任美国中央情报局、情报机构顾问。

**出版信息**：英文原版 *Collaborative Intelligence: Using Teams to Solve Hard Problems*；机械工业出版社中文版；译者张海藏；约280千字。

## 核心论点链

1. **诊断**：情报机构等复杂组织的团队普遍功能失调，根源不在能力而在设计
2. **IPO模型**：团队有效性由Input(6条件)→Process(3过程)→Output(3标准)决定
3. **6条件次序**：必要3+赋能3，先后次序不可违背
4. **真正的团队**：与共事群体的区别在任务互依性而非简单共事
5. **目标设计**：明确终点+过程自治（右上角最优），避免放弃领导和命令两种倾向
6. **60-30-10法则**：前期准备决定60%，启动决定30%，过程指导仅10%
7. **领导者角色**：园丁而非超级英雄，创设条件而非亲力亲为

## 经典案例

- **PLG模拟演习**——红队（设计良好）vs蓝队（设计欠佳）的对比
- **应对新兴威胁的团队**（共事群体）——副主管发邮件收集建议、主管召集资深专家开一次会，未真正形成团队
- **析出团队**（真正的团队）——12名成员6周专注任务、互相采访了解专长、明确目标期限、确立规范
- **佛罗里达航空90号航班**（1982年）——机组人员在地面操作和起飞过程中未能正确使用防冰功能，过程损失导致事故
- **NTSB飞行记录**——73%的事故发生在机组人员一起飞行的第一天
- **6个情报组织64个分析单位研究**（哈克曼+奥康纳2004）——59%共事群体/41%工作团队
- **消防模拟实验**——只传达目标的团队比下达具体指令的团队表现更好
- **TDS团队诊断工具**——可预测80%的团队有效性
- **IC年度员工氛围调查**（2007）——90%肯定工作价值，但只有40%认为领导者能激发积极性

## 阅读建议

第3章是核心——定义了团队有效性的3项标准、3个关键过程、6个条件模型。第4-9章逐章展开6个条件。第10章的60-30-10法则把全书收束为领导者行动指南。译者序对全书框架的中文转述非常清晰，可作为速读入口。本书不适合略读——6个条件相互依存，缺一不可理解全貌。
