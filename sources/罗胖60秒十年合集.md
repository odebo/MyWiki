# 罗胖60秒：思维与判断

从全十年（2013-2022，2263条）中提炼。

## 好选择的本质

**"选择本身没那么重要，把选择变成好选择才重要。"**

两个选项难以取舍时，往往是因为两类选择混在一起：
- 看似有选，其实没选（考不上好学校，那就不是真选项）
- 看似很重要，其实选哪个差不多（配偶、工作——努力之前根本不知道哪个好）

→ 人最重要的变量不是做选择，而是在努力之后把选择变成一个好选择。（2019年#003）

## 高手看到的变量

高手和普通人的差别不是同一维度上更努力，而是**看到了更高维度的变量**。

例：西红柿炒鸡蛋——普通人调火候和咸淡，高手关注西红柿的汁液处理（决定味道的真正变量）。

→ 所谓高手，就是不断发现被忽略的、更高维度的变量。（2019年#005）

## 结构化思考

结构化思考 = 为同一对象提供更多维度，而不是堆砌更多信息。

**"三门模型"描述人的性格**（老喻）：
- 花园门：对外的热情程度
- 房门：是否允许深交
- 卧室门：是否愿意坦诚相见

比"外向/内向"的二分法更精准，能描述"表面热情但难深交"和"表面冷淡但一旦信任就掏心掏肺"的不同类型。

→ 有时候，我们不需要更多信息，只需要更多维度的框架，就能加深理解。（2019年#009）

## 因果的局限

**"原因的原因不是原因，结果的结果不是结果。"**（老喻）

- 疫情导致工厂停产（直接因果），但最终结果是订单反而回流中国（因为其他国家控制更差）
- 好医院的死亡率反而更高（因为重症患者才去好医院）

→ 显而易见的因果，往往不是最后的因果。用因果逻辑思考时保持谨慎。（2020年#003）

## 战略 = 具体的人的具体变化

战略这个"大词"变成可操作的方法：**三年后，你的用户/同事/合作伙伴各自会变成什么样子？**

战略不是虚的，落在具体的人和具体场景上才是真战略。同理：
- 情商不是"会说话/人脉广"（从自己角度看）
- 情商是"走到人面前，被人无限地、无条件地信任"（从对方角度看）

（李希贵校长 + 俞敏洪，2022年#016）

## 统计数字的两面

统计数字只有**反映**现实的意义，不能用来**指导**现实。

考核指标 → 人为指标 → 数字失真（医生为了提高手术成功率，拒绝给重症患者做手术）。

→ 所有数字都值得看两遍：一遍看它反映了什么，一遍看它可能扭曲了什么。（2021年#010）

## 理性 vs 感性（梁宁的框架）

> "理性的反面不是感性，而是本能；感性的反面不是理性，而是麻木。本能的人不会成功，麻木的人不会幸福。"——梁宁

- 自以为感性 = 追随本能（好吃懒做、喜怒无常）
- 自以为理性 = 对世界感受麻木

理性和感性是需要花时间修炼的品质，是向上提升的两个通道。（2022年#025）


## 早期经典洞见（2013-2018）

### 历史认知三重境界（2013）

读历史：看故事 → 评人物 → 体察处境无奈，最终产生悲悯。把人物放回原来的格局中，所谓是非已不重要。

> 判断一个人，要把他还原到他所处的格局和约束里，才是真正的理解。

### 决策的两个内向问题（2014）

不再向外计算是否靠谱，而是问自己：
1. 如果做了，会不会后悔？
2. 如果没做，将来会不会不甘心？

这是在无数条林间小道中的唯一坐标。

### 人品 vs 性格的本质区分（2014）

性格才能描述一个人的本质行为，人品是表象。细节推论容易大错特错——花心男孩的"善行"并不代表他在其他情境下的表现。

### 趋势胜过能力（2015）

知识不是让你懂得更多，而是让你比竞争对手处于更高维度。皮萨罗以160人征服印加帝国，靠的是知识维度的优势而非装备。

→ 创业者最好的朋友不是能力，而是趋势和眼光。

### 成功与失败的非对称性（2015）

做失败的企业都相似，但成功的企业各有各的成功——所以成功学没有用。学成功要学具体的人和具体的情境，而非抽象规律。

### 灰度认知，黑白决策（2017）

认知领域必须容纳模糊性和多元观点，但决策领域需要明确判断。真正的高手能在研究中包容多个角度，在行动时果断下单。

### 套路的底层逻辑是惯性（2018）

所有说服和套路的背后都遵循一个原理——人无法摆脱自己的惯性。有效说服不是靠道理和诚意，而是创造一个让对方自己说服自己的情势。

### 远见的真正标志（2018）

不是预测能力的准确性，而是既有生存下来的热情和能力，同时又有不被生存条件驯化的警觉性。远见在不断迭代中生长。

### 思考与行动的网络效应差异（2018）

- **思考时**：把好事打折（防止自我合理化），把坏事翻倍
- **行动时**：把好事翻倍（网络会强化），把坏事打折

大多数能干的人失败，不是因为胡来，而是在行动前就把好结果打了折。

### 权力转向提问者（2022）

权力的本质在变化。不再是"说了算"，而是"对什么说"。真正的权力不是在有限选项里决策，而是通过发现和定义问题来掌握主导权。

### 人生调参 > 单纯努力（2022）

改变人生有两种方式：踩油门（努力）和调参（改变默认值）。大多数人停留在自动模式，而调参才是转折性改变：
- 从"融资扩大规模"到"盈利自供血"
- 从"目标优先"到"同时关注代价"

### 用恐惧清单拆解恐惧（2022）

面对恐惧时，用七步把巨大的未知问题拆成具体小问题：
1. 定义这个恐惧
2. 恐惧程度（0-10）
3. 预防措施
4. 修复措施
5. 修复后的收益
6. 半年不作为的代价
7. 三年不作为的代价

把情绪化应激反应转化为理性问题解决。

# 罗胖60秒：学习与成长

从全十年（2013-2022，2263条）中提炼。

## 知识的外部性

知识不只是个人的事，有强烈的社会性（外部性）：
- 一个人驾照考试学交规，是为了所有上路的人的安全
- 国家义务教育、扫盲——个人学了知识，不仅利己，也利社会

→ 学习是义务，不只是权利。（2019年#050）

## 知识是"点灯"传递的

所谓"二手知识"的批评站不住脚：

所有知识都是一盏灯点燃另一盏灯——佛经第一句"如是我闻"（听说来的），剑桥中华民国史是西方史学家整理中国史料。

→ 知识从来都是传递的，每一盏灯能操心的，只是自己能不能把这个火种传好。（2019年#011）

## 人和人的矛盾从哪里来

**内心冲突 → 外化为人际冲突**（陈海贤）：

- 你在犹豫要不要帮老婆带孩子，老婆一叫，你反而光火
- 你在犹豫要不要结婚，老妈一催，反而更排斥

原因：内心冲突的痛苦 > 外在人际冲突的痛苦。
→ 把内心冲突转换成人际冲突，可以逃避自己的选择，"都是别人的错"。

本质上：我们不是和别人有矛盾，我们是在逃避自己的选择。（2019年#013）

## 工作能力 = 分清主次

在分工明确的时代，工作能力 = 职业技能（厨师会做菜）。

但现在大量工作是新的、没有现成技能的——**工作能力 = 能分清主次的能力**：
- 全局中分清主次：当下最重要的任务是什么
- 时间段内分清主次：今天上午最该做什么
- 一篇文档中分清主次：主要说清什么

现代职场的残酷性：事务主导权的争夺。你不能分清主次，别人就会把你的时间扯得稀烂。（2022年#008）

## 不远求：在近处找资源

2021 年跨年演讲核心词：**不远求**

九渡河小学案例：乡村小学引入周边村子的辅导老师，做成优秀课程体系。

→ 现在做成一件事，资源是全球化的，可以随时调用。但关键是：**把远处的资源嵌入近处的问题**。（2021年#002）

## 外行的优势

为什么外行反而能干出大成就（马云懂数学不好）？

- 在新兴快速发展领域，专家懂的是1%，普通人懂的是0.1%，差距在绝对值上很小
- 专家因为天天被请教、乐于输出，容易对新知识关闭大脑
- 外行知道自己什么都不懂，思想反而更开放

→ 所谓"乱拳打死老师傅"，原因在此。（2019年#070）

## 教育的使命变了

过去：把人类存量知识原封不动转交给下一代（一个动机：好好学习）

现在：无法预知下一代遭遇什么挑战 →  **教育的使命 = 动机分化**（薛涌）

帮每个人找到学习动机（天分和兴趣所在），分头突围，应对各自的人生挑战。（2019年#030）

## 成长的正反馈

> 人都是因为痛苦而改变，因为受益而坚持。

→ 参见[[组织成长五阶段]]中李想的"实战建立成长正反馈循环"。


## 早期经典洞见（2013-2018）

### 大学非做不可的两件事（2013）

1. 阅读基础经典（通史、哲学史——不是上课，是自己读）
2. 谈恋爱

"选无能往往因为爱无力"——没有爱的能力就找不到人生方向。

### 年轻人冒险的经济学（2013）

年轻人冒险比循规蹈矩更理智：
- 时间维度上耗得起
- 虽然资源少，但通过折腾获得人脉和经验

不冒险赢不了和"老家伙们"的战争。

### 应试教育扭曲知识本质（2015）

应试教育以拉开成绩差距为核心，导致语法比单词量被重视、素描比实践被重视。教育追求知识应用，应试教育却把知识应用变成了知识竞赛。

### 概念学习的威力（2016）

成人学习最重要的是掌握新概念。每个概念背后都有复杂的诞生和论证过程，一个新概念往往意味着某学科的突飞猛进。

学习要抓住新概念作为抓手，让它在脑子里发酵，和其他概念产生化学反应——这会让学习变得飞快。

### 学习是体验而非信息（2017）

过去，知识是信息和工具，关键在于记住和使用；现在，知识是体验和环境，关键是你和它之间能建立多么真切的关联。阅读经典的意义在于获得那些现实生活中无法提供的体验。

### 中美教育思维的根本差异（2017）

- 中国大学的考试是**准入**（着眼点是公平）
- 美国名校的招生是**招聘**（着眼点是未来成才）

一个看入门时的公平与否，一个看出门时的结果如何。

### 高手与工具的共生关系（2018）

高手不是抽象的个体能力者，而是看他和工具、周边资源共生的能力。专用工具对高手来说已经是身体的一部分。判断真正的高手，是看他能否排除工具带来的干扰。

### 可叠加的进步是稀缺资源（2020）

科学之所以强大，在于它的进步是可叠加的。区分努力中哪些可叠加、哪些只是消耗很关键——只有可叠加的努力才能产生复利效应。

### 学习有四个层次（2019）

听过 → 知道 → 理解 → **能讲**

能讲是最高境界，需要能将知识传递给他人。大多数人把听课当成学习本身，是对学习的误解。

### 文字能力反而更值钱（2021）

短视频普及反而提升了文字能力的稀缺性。当掌握者变少时，竞争力反而提高——就像白话文流行后，能读文言文的人竞争力更强。

### 师父的真正职责（2022）

传统理解"师父教技能"是错的。师父更重要的职责是：
1. 识别好苗子
2. 领入行业共同体
3. 获得社会认可

这是行业代代相传的真正机制。

### 创作是抵御消费主义的最佳手段（2021）

消费主义本质是用消费解决意义缺失——买手机证明自己怎样。反面是创作：一张白纸、小花小草就能点石成金，横空出世地创造意义。有创作能力的人不会被消费绑架。

# 罗胖60秒：商业与战略

从全十年（2013-2022，2263条）中提炼。

## 领导力 = 谁兼容谁

**"谁能兼容谁，谁就能领导谁。"**（脱不花）

场景一：有人得罪你，来道歉。
- "好吧，我原谅你了" → 他兼容了你，他赢了领导力
- "好吧，来，我请你吃饭" → 你兼容了他，你赢了领导力

场景二：下属惹了麻烦，提了补救方案。
- "事已至此，只能这么办了" → 他兼容了你
- "这个方案是权宜之计，你再站在我的角度替我想想，我该不该这么做？" → 你兼容了他

→ 领导力不是靠权力，而是靠谁先放大了对方的视角。（2019年#020）

## 战略 = 具体的人的具体变化

（同见[[罗胖60秒十年合集]]）

三年战略的简化方法：想三年后你的用户、同事、合作伙伴各自变成什么样子。

→ 战略不是虚的，落在人身上才是战略。（2022年#016）

## 好公司：忍住不干房地产

衡量一家有些年头的公司，看一个关键点：**这么多年，这么多机会，能不能忍住不干房地产**。

不只是定力问题，还说明：这家公司爱惜羽毛，非常在意向市场/内部/用户/员工释放什么信号。

→ 任何决策都有两个效应：决策本身的现实后果，和决策在周边人那里引起的观感。（2020年#050）

## 伙伴关系的两种模式

**找保姆 vs 找战友**：

- 保姆模式：对方对我好，满足我的需求。这种起点的关系/家庭，往往崩溃最快。
- 战友模式：除了两个人，还有第三者——目标。因为对方的存在，彼此变得更好。

战友模式难，难在"每个人都得有目标"。不是每个人都有清晰目标。（2020年#035）

## 印度与"未来工厂"

判断未来的一个角度：**未来从现在做的事情里长出来**。

印度没能承接中国制造业转移的订单（越南、孟加拉接住了）→ 说明印度在利用人口优势方面已经失败过了。

→ 过去没有做好的事，我们有什么理由相信未来就能做好？（2020年#015）

## 孝道是文明传承的基础设施

孝道的多层功能（超越家庭私德）：
- 约束日常行为（孝子不在家门口给父母丢人，不会打架偷盗）
- 熟人社会的行为约束机制
- 国家凝聚手段（忠臣必出于孝子之家）
- 个人安身立命、找到对世界的终极责任感

→ 孝道是中华文明把文化价值传递到个人行为层面的基础设施。（2021年#016）

AI爆发不是算法突破而是算力提升。人缘差是接触人太少。新媒体难做是功夫不足。"奇技淫巧"那套想法是在幻想不增加数量的前提下偷工减料。底子厚才有后劲。

## 充裕社会的新挑战（《倦怠社会》）

现代人面对的最重要挑战，不再是匮乏，而是**过于充裕**：

- 匮乏时代的行动原则：认出异己，消灭或同化它
- 充裕时代的挑战：在好东西中**选择和拒绝**

身体进化出"尽可能吸收一切食物"的功能，在充裕时代导致糖尿病。

→ 机会过量、信息过量、娱乐过量，几乎所有领域都出现了"糖尿病式难题"。

> 现在的企业，往往都不是饿死的，而是撑死的。

问题从"外敌入侵型"变成了"内部梗阻型"。（2022年#003）

## 最懂和最不懂的行为可能一样

**知识与行为的悖论**：

艺术家工作室被盗，小偷只偷走几万元家电，没碰几百万的名画。有人说"知识不足，错过发财"。

但可能的另一种解读：小偷挺懂行——
- 艺术品按市场价定罪，一幅画就可能判无期
- 著名艺术品销赃极难（圈子小，人人知道是谁的）
- 所以不碰可能是理性选择

→ 最懂的人和最不懂的人，外在行为可能完全一样，背后的理由不同。批评别人愚蠢时要谨慎。（2019年#060）

## 统计指标会扭曲现实

（同见[[罗胖60秒十年合集]]）

一旦形成考核指标，人们就会为指标而行动，数字不是反映而是扭曲真实世界。

→ 所有数字，看两遍：反映了什么，可能扭曲了什么。（2021年#010）

## 纸质书在数字时代

纸质书不只是信息载体：

- "被书的作者团团围住，由他们来保证你生活的广阔性"——无法电子化（索尔·贝娄）
- "享受占有的优越感才是我买书上瘾的动机"（汤姆·拉伯）

→ 纸质书的命运像现场演出：线上传播越发达，线下演出越热闹。（2021年#040）

2021 年跨年演讲关键词：**不远求**

2020 年提醒我们：经常不得不在一个城市、甚至社区内解决问题，而且往往能解决得更精彩。

→ 把自己想成变形金刚，在自己周围就找得到资源，更漂亮地解决问题。（2021年#001）

# 罗胖60秒：表达与沟通

从全十年（2013-2022，2263条）中提炼。

## 好作家的三个条件（曹雪芹模型）

冯唐分析曹雪芹具备的三个优秀小说家条件：

1. **生活在边缘**：不是社会底层，而是一种视角——别人的热闹我看得见，但稍微置身事外
2. **理解在高处**：超越时代，站到更高的精神传统的位置
3. **表达在当下**（最重要）：旺盛的、当下的表达欲

→ 太多聪明人能冷眼旁观、高处着眼，但没有当下表达欲，所以成不了曹雪芹。

掺和欲望低 + 表达欲望高，集中在一个人身上很难。

**结论**：想靠文章立身，做到三条——少掺和、勤思考、多写作。（2022年#002）

## 演讲的核心不是言辞

**最好用的演讲技术：讲得比预期时间短。**

林肯葛底斯堡演说：从站起来到坐下，不过两三分钟，却是人类最著名的演讲之一。

为什么短更好？

演讲效果的决定性因素，**不是言辞，而是在场的人对演讲者的信服程度**。

→ 讲得短，显得对自己说的话更有信心，这份信心传达给听众。

→ 演讲者要磨炼的，不是言辞，而是自己和观众之间的**信用关系**。（2021年#003）

## 用户思维在法律中

律师的责任：不是搞清楚真相或主持正义，而是**用合法手段维护当事人的合法权益**。

案例：被告在追小偷过程中小偷心脏病发死亡，律师的思路——"你是在跑步，你啥时候追他了？"

→ 这是彻底的用户思维：为用户的利益负责，找对用户来说最优的方案，而不是最接近真相的方案。（2020年#025）

## 沟通的层次

沟通的目标不是传递信息，而是**改变对方的状态**。

好的沟通：让对方从当前状态走到你希望他在的状态。

→ 参见[[同理心]]：意识即防御，让用户思考就是在推开用户。罗胖的角度从表达者出发，梁宁的角度从接收者出发，结论互补。

## 演讲者和听众的信用关系

演讲不是广播，是**在演讲者和听众之间建立信用**的过程：
- 言辞只是工具
- 真正的效果来自"我相信这个人说的是真的"
- 短，是信心的信号；精，是尊重的信号

→ 参见[[峰终定律]]：演讲的终点印象决定全场记忆，所以结尾往往比开场更重要。


## 早期经典洞见（2013-2018）

### 说话要看人（2014）

说话要看人，实话尤其要看人。"不可与言而与之言，谓之失言；可言而不言，谓之失人。"

实话都不能全说，更别说假话。

### 道德绑架的更高境界（2013）

"己所不欲勿施于人"还不够，更高的道德境界是**"己所欲也勿施于人"**。许多父母怀好心行混账事，这就是道德绑架。

### 道德绑架的两个机制（2017）

把具体情境抽象化，把小范围选择变成大范围选择。

正确做法：回到具体情景下的道德权衡，而不是上升到"原则问题"。

### 仪式的根本作用是建立边界（2017）

仪式不是为了尊重场合，而是让自己的行为举止有边界感。有边界感的人能释放确定性信息，表现出分寸、规矩和自控。

### 信任需要持续经营（2018）

谣言的力量不在于有多真实，而在于种下一颗种子，合作者的人性缺陷会浇灌它。任何信任都需要小心谨慎的长期经营。

### 拒绝的艺术（2021）

拒绝别人的完整行动模型：
1. 第一步：说对不起
2. 第二步：提出替代方案（"你可以请...""你可以用...""你可以换个时间..."）

这样的拒绝才能传递善意，不伤交情。

### 证明自己能做成事的五步法（2021）

向领导或客户请战的标准套路：
1. 相关经历
2. 取得的成绩
3. 特殊能力
4. 做事的决心
5. 现有的资源

无论简短发言还是长提案，都是这五件事。套路反复用会内化成习惯。

### 赞誉就像膨化食品（2022）

赞誉和毁谤一样都是别人的投射，一样不可信。赞誉还可能是施加控制的手段。真正考验我们的事都是孤独穿越的、没人看到的——既没批评也没赞誉，但这些最重要。心不要让赞誉留下痕迹。

# 罗胖60秒：组织与领导力

## 领导力 = 兼容

## 伴侣/合伙关系：战友模式

保姆模式（满足需求）→ 崩溃快
战友模式（共同目标 + 彼此成就）→ 更稳定，但难——需要每个人都有清晰的个人目标。

（见[[组织成长五阶段]]中李想的经验）

罗胖的角度：**一旦惩罚新错误，员工就会隐藏错误，减少创新。**

→ 只惩罚重复犯同一错误。新错误是成长的必要成本，"不能因为第8个包子吃饱了，就说前7个包子没价值"。

## 组织的知识外部性

（同[[罗胖60秒十年合集]]中的"知识的外部性"）

→ 组织培训/学习不只是个人收益，是整个协作系统效率的基础设施。

## 横向管理的本质

在复杂组织中，很多影响不来自权力，而来自**信息的流向**。

→ 参见[[玩家地图与增长生态位]]中阿里的决策结构：马云/曾鸣/彭蕾/张勇各控制一个维度的信息，而不是靠职级命令。

### CEO 的两种角色（2016）

好公司的CEO不是119式的天天救火，而是114式的资源查号台。公司是给人赋能的平台，而非管制。

### 管理的真正目的（2017）

管理的核心从来不应该是管住人，而是激发人、成就人。最残忍的教育是变相灭掉孩子人生的多姿多彩可能性。

### 进步的最好方式不是互相批评（2018）

有效的公司会在平时立即给反馈，而不是在集体会议上才批评。增量比存量重要，未来比过去重要，所以应该关注建设性的事情。

### 组织规模的未来趋势（2013）

互联网冲击下，大组织难以维持规模，小而美是未来。但判断趋势和做出选择是两回事，不要以为看准趋势就能做对决定。

### "少年感"是组织的反油腻（2021）

油腻 = 对人生有了完成感、确定感，可以仗势欺人或自我放弃。少年感 = 保持人生未完成状态，对目标执着、对未来好奇、对自己有期待。

这既是个人状态，也是组织文化的核心气质。
