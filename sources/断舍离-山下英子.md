# 《断舍离》— 山下英子

## 书籍信息

- **作者**：山下英子（Yamashita Hideko，日本）
- **出版社**：湖南文艺出版社·博集新媒
- **出版时间**：2019.1
- **ISBN**：9787540489304
- **字数**：73 千字
- **页数**：118 页

## 作者简介

山下英子，日本断舍离哲学倡导者。毕业于早稻田大学文学部，学生时代接触瑜伽哲学，从中提炼出"断行·舍行·离行"的断舍离思想。2001 年 9 月首次在自家客厅开课，8 名学员围长桌开始。截至本书写作时已坚持 17 年（前 23 年为独自试验），讲座遍及日本本土及亚洲、欧洲、美洲。"断舍离®"为其注册商标，由苏州华联盟企业管理咨询有限公司独占许可使用。

## 核心论点

通过物品代谢训练生命代谢。断舍离三字来自瑜伽：**断**（断绝不需要的东西进入）、**舍**（舍弃身边的废弃物）、**离**（脱离对物品的执念）。最终目的是让人在死亡到来前能坦然放手——断舍离即"终活"。

## 三大命题链

1. **物质轴是思维陷阱** → 需转向空间轴 → 获得[[俯瞰力-山下英子]]
2. **断舍离不是整理术** → 是生命代谢哲学 → 借物品训练放手
3. **占有是错觉** → 物品是地球借用品 → 缘尽痛快放手

## 章节结构

### 推荐序
- 陈数（演员）"做物质的减法，精神的加法"——停下两年主动拒绝影视剧，成为"时间暴发户"
- 孙志勇（志邦家居联合创始人）"断舍离帮我们实现对家的美好想象"

### 断舍离的奥义
不只是"扔东西"——核心是"出"字；进则出，出则进；新陈代谢；不是极简生活倡议书；撼动物品价值观。

### 第1章 你之所以无法放手的原因
- 被困在水槽淤泥口的鲇鱼（香鱼变鲇鱼隐喻）
- 生活在"事物随意渗入生活空间"的年代
- "不收拾"深层原因是顽固的"物质轴"思维
- 因过度焦虑而郁闷的我们
- 断舍离注重的不是物品而是空间
- "无法放手"的人有三类：逃避现实型/执着过往型/忧虑未来型——共通点"对时间意识淡薄"
- "舍"与"弃"的不同（舍=布施=二次循环；弃=废弃）
- 人有"获得的自由"也有"放手的自由"

### 第2章 这就是断舍离的工作机制
- 观念上的断舍离 3 步：认识现状 / 停止自我否定 / 描绘家的具体构想
- 杂物上的断舍离 5 步：拿出杂物俯瞰 / 扔掉垃圾废品 / 以自我·时间判断关联度 / 以必要合适愉快为标准 / 收纳在杂物最适化之后
- 收纳指南 5 法：三分法 / 7·5·1 法 / 1 out 1 in 法 / one touch 法 / 自立·自由·自在法
- 从切实能出成绩的小地方着手（加分法）
- 有心无力时先找"出口"（三种生命：肉体/社会/精神）
- 居所整体断舍离要点（衣柜/壁橱/厨房/餐具柜/冰箱/书架/厕所/玄关/客厅餐厅各自象征）

### 第3章 断舍离改变人生
- 一阵莫名的清爽感抚过心头（40 年前大学时代接触瑜伽）
- 摆脱过剩执念，减轻心灵负重
- 获得深刻的智慧（"为学日益，为道日损"——知识增加，智慧减少）
- 提高选择·决断的精度和行动速度（螺旋上升式人生路线：关联度→思维→行动→结果）
- 清除闭塞感，疏通人生路
- 引导现在的自己做出最恰当的选择与决断（高野山体验+俯瞰力）
- "身体、心灵、生命"机制的回归（局部即整体·分形）
- 沟通力显著提升（"间"意识）
- 比想象更怡然的人生就在不远处（人与空间力为伍）

### 第4章 断舍离，怡然生活
- 没有"出"，则难获自在（排泄盲点：东日本大地震避难所）
- 获得主体性的生活方式（歌德"人最大的罪就是不快活"）
- 抛开家庭关系的烦恼（认可欲求·势力范围·单方面期待过高）
- 遵守三大原则，收获怡然人生（活在当下/结果反馈到自身/给予——啐啄同机·机度间）
- 断舍离，让人生处处自在怡然（自在=在必要的时刻获得必需分量的必要东西）
  - 信息与自在人生（"不信、不疑、亲自确认"）
  - 时间与自在人生（宽松空间的"放满"vs塞满）
  - 烦恼与自在人生（烦恼=心灵废品；改善烦恼体质）
  - 节约与自在人生（金钱/精力/时间三天平；减法解决法）
  - 结婚与自在人生（精神性/动物性/社会性三层婚姻）
  - 家务与自在人生（家务=家庭内部新陈代谢）
  - 终活与自在人生（人生本就是活一天少一天的终活）
- "搬"家，遇见新的自己（清零式 vs 保养式断舍离；不搬家的"搬家"）
- 在必要的时刻，能获得必要的东西（"请试着先扔掉东西，再发愁吧"）
- 恢复"呼吸空间"，获得自在人生（先呼后吸；"吐"是自力行为）
- 用心珍惜当下的人·事·物（死亡率100%；占有是地球借用）
- 不断地追寻"出"之美学（熵增定律vs生命本能；从哲学升华成美学）

### 后记
8 年时光埋头宣传断舍离。从 2001 年客厅 8 名学员到全球百万实践者。断舍离从私人生活哲学→人生实践哲学→改变人生的断舍离→美学。本书回到原点，反复强调"会呼吸的断舍离"。
