# 《清晰思考：将平凡时刻转化为非凡成果》

- **作者**：沙恩·帕里什（Shane Parrish）
- **出版**：2023年
- **规模**：98页全览（中文版）
- **核心主题**：识别并对抗无意识默认值，在平凡时刻建立良好判断力

## 核心公式

**位置 → 选择 → 结果**

驾驭环境，而非被环境驾驭。
改变结果靠环境设计，不靠意志力。

## 顶级洞见

1. **默认值是平凡时刻的幕后推手**——大多数人生结果由无意识的自动反应决定，而非重大决策
2. **环境设计 > 意志力**——在最佳状态下设计系统，系统在最差状态下保护你
3. **有效决策 ≠ 好决策**——好决策需要先知道什么值得追求（实践智慧）
4. **过程原则**——评估决策质量看过程，不看结果；好过程+坏结果=运气不好，坚持
5. **Memento Mori**——"记得你终将死去"是已知最强的优先级清醒剂；小确幸胜大惊喜
6. **信息过多助长偏见**——斯洛维奇赛马研究：5条→40条信息，准确率不变，信心翻倍
