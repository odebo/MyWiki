## 核心框架速查

**三段式演讲地图**：序幕（钩子+明确主题）→ 大戏（三钉子论点）→ 余音（回顾+升华）

**BCAR**：背景（Background）→ 冲突（Conflict）→ 行动（Action）→ 结果（Result）

**思维收集四步**：入耳（命名）→ 进脑（记录关键情节）→ 化身（提炼三角度观点）→ 随心（预想使用场景）

**钉子三原则**：对称 / 分离 / 一致

**故事使用边界（6 NO）**：时间不够 / 听众有敌意 / 听众情绪不良 / 未经练习 / 反复给同一批人讲 / 演讲全是故事

## 最具原创性的三个洞见

1. **双重作用论**：每个故事既服务演讲主题（显性目标），又悄悄塑造讲者在听众心中的形象（隐藏目标）——这让讲故事从"沟通技能"升级为"品牌建设工具"

2. **"那一刻"优先于"完美故事"**：不追求完整精彩的故事框架，追求找到并放大故事中那个最打动人的瞬间——更务实、更可操作的质量提升路径

3. **转述他人故事用第三人称**：不把他人故事变成"我的故事"，既更安全（细节不清楚时不必编造），也更有公信力（听众中可能有人认识原版）
