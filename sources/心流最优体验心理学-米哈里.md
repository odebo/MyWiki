# 心流：最优体验心理学 — 米哈里·契克森米哈赖

米哈里·契克森米哈赖（Mihaly Csikszentmihalyi，1934-2021），积极心理学创始人之一，芝加哥大学心理学系前主任。1960年代开始研究艺术家、运动员、棋手等人士专注投入的状态，提出"心流"（Flow）概念，成为积极心理学的基石概念。

本书基于十万份心理体验抽样法（ESM）问卷数据，系统阐述了最优体验的理论框架。全书共10章：心流快乐的源泉 → 控制意识 → 心流的构成要素 → 如何在日常生活中寻找心流 → 感官之乐 → 思维之乐 → 工作之乐 → 人际之乐 → 挫折中自得其乐 → 追寻生命的意义。
