# 说话的技术

**原书名**：说话的技术

**作者**：冈本纯子（日），沟通术教练、原记者

**出版**：四川文艺出版社·果麦文化，2023年4月

**全书结构**：50条说话技术（技术1-50）+ 后记，按应用场景分类：闲聊 → 提问 → 夸奖/批评 → 说明（浓缩/汉堡/三条/解决问题）→ 共鸣/情感 → 讲故事 → 演讲（开场/声音/眼神/肢体）→ PPT → 综合

**顶级洞见**：
1. 交流的主角不是说话者，而是听众——从"我想说什么"切换到"对方想听什么"是交流的首要法则
2. 人是情感的奴隶，逻辑只在唤起情感后才有效——卡尼曼双系统理论在日常交流中的实战应用
3. 6:1的夸奖与批评比例——肯定性反馈与否定性反馈的最佳黄金比例
4. 自信不是交流的前提，而是交流的结果——假装自信就能变得自信
5. 汉堡说话术（总起→详情→总结）是美国从幼儿园就开始教的"铁板规则"
6. "最初→最终→启示"的三十秒故事公式让任何人都有故事可讲
7. 共鸣型管理者（库克、纳德拉、皮查伊）正在取代强权型管理者，这是全球趋势
