# 梁宁·增长思维30讲

得到 App 课程，梁宁（天使投资人）以「增长」为主轴，讲述企业从0到跨越周期的完整框架。

> 主动增长 = 面对变化，持续作出正确决定的能力。

## 核心框架：一横一纵

```
一纵（纵向打透）：
  破局点 → 加杠杆 → 做分形

一横（横向拓展）：
  设计模式 + 优化组织 + 借助势能 + 跨越周期
```

## 四种玩家的核心动作

| 玩家 | 核心动作 | 关键词 |
|------|---------|--------|
| 草莽 | 冲 | 看到机会先冲再说 |
| 腰部 | 扎 | 运营生态位，把根扎下去 |
| 头部 | 收 | 拿制高点，终结一场战争 |
| 顶级 | 决 | 跨越周期，持续作出正确决定 |

## 贯穿全课的关键洞见

- **增长来自模式，不来自意志力**：调节回路永远存在，靠模式而非靠自律
- **高频打低频**：破局点必须高频，才能带动整体业务
- **速度 vs 效率**：风口期优先速度，市场净空结束后才讲效率
- **组织是人的组织**：视人如人，不同规模有不同管理要点
- **信息优先**：作决定的能力来自信息环境 + 决策模型

## 与产品思维的关系

| 产品思维 | 增长思维 |
|---------|---------|
| 读懂用户（同理心/痛点） | 找到机会（发散收敛/破局点） |
| 设计体验（五层次/峰终） | 设计模式（增强回路/飞轮） |
| 商业模式（三级火箭） | 增长路径（一横一纵/闪电扩张） |

→ 产品思维解决"做什么/为谁做"，增长思维解决"怎么长大/如何持续"
