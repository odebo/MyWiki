# 《超级沟通者》— 查尔斯·都希格

查尔斯·都希格（Charles Duhigg），《纽约时报》记者，普利策奖得主。前作《习惯的力量》《更快》均为畅销书。本书基于神经科学、心理学、组织学十年研究，回答：为什么有些人能瞬间连接他人，而另一些人却屡屡失败？核心答案：匹配原则。
