# 战胜一切市场的人

- **作者**：爱德华·O. 索普（Edward O. Thorp）

## 作者简介

爱德华·O. 索普,1932年生于芝加哥大萧条时期。加州大学欧文分校数学教授,后成为对冲基金经理。被誉为"量化金融之父"和"击败庄家的人"。

主要成就:
- 1962年出版《击败庄家》(Beat the Dealer),证明21点可通过算牌击败,改变赌博业
- 1967年与希恩·卡索夫合著《击败市场》(Beat the Market),奠定对冲基金方法论
- 在布莱克和舒尔兹之前发现布莱克-舒尔兹期权公式（塔勒布称之为巴舍利耶-索普公式）
- 1969-1988年运营普林斯顿-新港合伙公司,年化收益率22.8%（有限合伙人18.2%）,远超标普500的11.5%
- 首次将凯利公式从理论变成可操作的下注系统
- 2008年揭露伯尼·麦道夫庞氏骗局

## 核心思想

1. **凯利公式**（[[凯利公式-索普]]）：概率优势决定下注比例,数学上保证不破产
2. **战胜21点策略**（[[战胜21点策略-索普]]）：将赌博变成工程问题
3. **对冲权证与股票**（[[对冲权证与股票-索普]]）：价格联动证券对的误估套利
4. **市场中性对冲**（[[市场中性对冲-索普]]）：剥离市场方向性风险,只承担愿意承担的风险
5. **复合增长**（[[复合增长世界第八大奇迹-索普]]）：时间+再投资>高利率
6. **用指数战胜大多数投资者**（[[用指数战胜大多数投资者-索普]]）：夏普原则+主动投资的三层成本

## 核心方法论

索普在序言中总结的四条原则:
1. 对于像"你无法战胜庄家"这类被广泛接受的观点,都要亲自检验
2. 通过发明新的实验来检验理论,养成采纳纯粹的思考结果的习惯
3. 当设定一个有价值的目标时,制订一个很现实的计划,坚定不移地加以执行直到成功
4. 努力保持一贯的理性,不仅在特定的某个科学领域中,也在做这个世界上的所有事情时；没有证据不轻易下结论

## 经典案例

- **3岁烫伤事件**：母亲告诫不要触碰热炉子,他还是按上去——养成了"不接受他人结论,直到亲自验证"的方法论
- **6岁背诵英格兰国王**：陌生人质疑他读不懂10年级水平的书,他按顺序背诵历任国王+执政年份,父亲眼神闪闪发亮
- **斯米梯叔叔的台球桌**：下棋超过叔叔后被禁止打台球——第一次体会"竞争会压低利润"
- **1962年《击败庄家》出版**：拉斯维加斯赌场一度改变21点规则,后又恢复
- **1987年黑色星期一**：普林斯顿-新港用统计套利在标普500和股指期货间套取超过10%利润
- **1968年与巴菲特共进晚餐**：巴菲特用非传递骰子考验索普——A击败B,B击败C,但C击败A,违反传递规则
- **1987年朱利安尼突袭**：50名武装警员搜查普林斯顿办公室,援引RICO法案（原用于起诉黑帮）首次用于证券业
- **2008年揭露麦道夫**：通过分析其收益结构判断是庞氏骗局
