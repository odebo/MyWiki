# 掌控习惯 — 詹姆斯·克利尔（2018）

**作者简介**：詹姆斯·克利尔（James Clear），美国作家、演讲者。曾是大学棒球运动员，因重伤后的康复经历开始研究习惯科学。网站 jamesclear.com 读者超过百万。《掌控习惯》是其代表作，英文原版《Atomic Habits》全球销量超2000万册。

**全书摘要**：习惯改变的核心不是目标设定，而是**系统建设**。书的核心框架是四步习惯回路（提示→渴求→反应→奖励）和四大定律（显而易见/有吸引力/简便易行/令人愉悦）。书中还强调习惯改变应从身份认同出发，而非结果驱动。

**章节结构**：

- 第1-4章（基础）：习惯的复利效应；四步回路；身份认同层次；反馈环路
- 第5-7章（第一定律）：环境设计；习惯记分卡；执行意图；习惯叠加
- 第8-10章（第二定律）：诱惑绑定；群体归属；渴求的重新框架
- 第11-14章（第三定律）：最省力法则；决定性时刻；两分钟规则；承诺机制与自动化
- 第15-17章（第四定律）：即时满足；习惯追踪；问责伙伴；习惯契约
- 第18-20章（高阶战术）：天赋与习惯匹配；金发女孩准则；习惯+刻意练习=精通
- 结语+附录：四定律教训的深层推论（意识先于欲望；幸福即无欲；满意=喜欢-想要）
