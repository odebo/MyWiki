# 重启吧！我的健康人生

## 基本信息

- **作者**：兰根·查特吉博士（Dr. Rangan Chatterjee）
- **摄影**：苏珊·贝尔
- **出版年**：2024.5（中文版）；英文原版2017
- **出版社**：中国科学技术出版社
- **译者**：王琳
- **ISBN**：9787523605486
- **字数**：108千字
- **英文原名**：The Four Pillar Plan

## 作者简介

兰根·查特吉，英国全科医生，BBC健康节目主持人，渐进型医疗（Progressive Medicine）倡导者。拥有20余年临床经验，主张通过生活方式调整而非药物治疗慢性病。其播客《Feel Better, Live More》是全球最受欢迎的健康播客之一。

## 内容结构

全书20章，按健康四步法组织：

**第一部分 休息**（5章）
- 每天15分钟"自我时间"
- 每周一天"网络戒断"
- 睡前写感恩日记
- 5分钟静息练习（3-4-5呼吸法）
- 每天全家人围坐进餐

**第二部分 饮食**（5章）
- "糖"连锁效应
- 吃5种颜色不同的蔬菜
- 12小时轻断食
- 水的神奇力量
- 不吃5种以上成分的高度加工食品

**第三部分 运动**（5章）
- 多走两步
- 每次收缩肌肉抗炎
- 高强度锻炼10分钟胜过低强度1小时
- 即兴运动
- 叫醒"昏昏欲睡"的臀部

**第四部分 睡眠**（5章）
- 夜间光线零容忍
- 沐浴晨光
- 遵循生物钟
- 睡前铁律：不争辩、不玩游戏、不查存款
- 咖啡虽好，但过了中午不能贪杯

## 核心思想

1. **渐进型医疗**（[[渐进型医疗-查特吉]]）：疾病非单一病因，治疗需考虑多重因素
2. **健康四步法**（[[健康四步法-查特吉]]）：休息/饮食/运动/睡眠四要素均衡
3. **均衡优于完美**（[[均衡优于完美在健康管理中成立-查特吉]]）：8分均衡>10分单点完美
4. **真实食物原则**（[[真实食物原则-查特吉]]）：吃看起来像本来样子的食物
5. **光照管理**（[[光照与生物钟-查特吉]]）：晨光沐浴+夜间零容忍+琥珀色眼镜

## 与其他健康类书籍的关系

- 与 [[休息休息-埃德伦德]] 的关系：两者都强调休息的主动性，但查特吉将休息纳入更广的健康四要素框架，埃德伦德专注于休息的内部细分
- 与 [[睡眠与昼夜节律-埃德伦德]] 的关系：查特吉直接采用昼夜节律理论，并提供更具体的光照管理操作
- 与 [[正念冥想-安德烈]] 的关系：查特吉将冥想简化为3-4-5呼吸法，作为正念的入门工具
- 与 [[皮质醇与大脑发育-格罗斯]] 的关系：两者都强调皮质醇管理的重要性，但查特吉面向成人健康，格罗斯面向儿童大脑发育

## 阅读建议

- 不必按顺序阅读，可从最薄弱的要素开始
- 每个要素至少采纳3种方法
- 重点读前言与结语，理解渐进型医疗的哲学基础
- 与韦伯《新教伦理》对读，可见现代健康观与早期资本主义健康观的延续与断裂
