# 《即兴演讲：掌握人生关键时刻》（朱迪思·汉弗莱）

**基本信息**：朱迪思·汉弗莱（Judith Humphrey），加拿大人，汉弗莱集团创始人，专注培训领导者演讲能力数十年。该书2018年出版，入选樊登读书会推荐书目。

**全书五部分结构**：
1. **即兴新时代**：组织扁平化、科技发展、时空观改变，逼使正式演讲让位于即兴对话
2. **即兴思维**：领导意愿（leader mentality）、倾听（三个层面）、保持真实（六个策略）、保持专注（反对信息倾泻）、保持尊重（对组织/管理者/同事/自己）
3. **领导者讲话脚本**：抓手（与听众建立联结的一句话）+ 要点（核心观点，一句话）+ 结构体（论据，如原因/方法/情况/时间顺序）+ 呼吁行动（要求对方做什么），用模板套用到各种场景
4. **各种场合脚本**：会议、求职面试、社交活动、电梯对话、敬酒词、问答
5. **即兴舞台**：排练、选词、即兴演员技巧、声音和肢体语言

**核心主张**：即兴演讲不是张开口就说，而是需要事先准备。领导者每天的即兴时刻多达20-30次，用错一次就可能损害声誉，用对一次就能赢得人心。
