# 《思考，快与慢》丹尼尔·卡尼曼

**原书名**：Thinking, Fast and Slow
**作者**：丹尼尔·卡尼曼（Daniel Kahneman，1934-2024），诺贝尔经济学奖得主（2002年），普林斯顿大学心理学教授。与阿莫斯·特沃斯基共同创立了前景理论和启发法与偏见研究范式，是行为经济学的奠基人。
**出版**：2011年（英文），2012年（中文），约326千字。

## 全书结构

全书5部分、38章：

1. **系统1，系统2**（第1-9章）：两个系统的架构——系统1（快速/自动/不费力）与系统2（缓慢/刻意/费力）；注意与努力；认知放松与联想记忆；常模与因果；确认偏差与光环效应；WYSIATI原则；系统1如何用简单问题替代困难问题
2. **启发法与偏见**（第10-18章）：小数定律；锚定效应；可得性启发；代表性启发与忽略基率；琳达问题与合取谬误；回归均值；直觉预测的校正
3. **过度自信与决策失误**（第19-24章）：理解幻觉与有效性幻觉；未来不可预测；直觉vs公式的竞争；专家直觉何时可信；外部视角与规划谬误；乐观主义与竞争忽略
4. **选择与风险**（第25-34章）：伯努利错误；前景理论三大特征（参照点依赖/损失厌恶/敏感性递减）；禀赋效应；公平与经济行为；四重模式；稀有事件与概率权重；风险政策；心理账户；偏好逆转；框架效应
5. **两个自我**（第35-38章）：体验自我与记忆自我；峰终定律与过程忽视；幸福感的测量；思考生活

## 顶级洞见

1. **系统1制造了大多数决策，系统2只负责签字**：人以为自己在理性思考，实际上直觉在主导，理性只是在事后合理化。WYSIATI是核心机制——系统1只用可见信息构建连贯故事，不标记信息缺口。
2. **损失约等于收益的两倍**：损失厌恶是人类决策中最稳健的不对称性，广泛存在于商业谈判、法律、体育、政治中。这是前景理论取代期望效用理论的关键。
3. **记忆不记录长度，只记录峰值和终值**：峰终定律和过程忽视颠覆了对"幸福"和"痛苦"的传统理解——体验自我的时间积分被记忆自我系统性扭曲。
4. **外部视角是唯一解药，且痛苦**：规划谬误不能用"更谨慎"来克服，必须制度化地收集基率数据。但即使知道了基率，人仍会坚持"我们不一样"——因为内部视角的连贯故事令人舒适。
5. **专家预测不如简单公式**：在可验证领域，公式的一致性好于专家的判断。专家的价值在于知道测什么变量，而非如何加权。
