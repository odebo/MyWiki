# 《思考致富》— 拿破仑·希尔

**原书名**：Think and Grow Rich

**作者**：拿破仑·希尔（Napoleon Hill，1883-1970），美国成功学作家。1908年受安德鲁·卡内基委托，采访500多位成功人士（包括爱迪生、福特等），历时29年提炼出十三条致富原则。1937年出版《思考致富》，全球销量超1亿册。

**出版**：1937年英文首版，2023年中国科学技术出版社精读本。33千字。

**全书结构**（引语+14章）：
- 引语：思想决定一切 — 思想是财富的起点，大脑是吸引思想和环境的"磁体"
- 第1-13章：对应十三条成功原则——欲望、信念、自我暗示、专业知识、想象力、精心计划、决心、毅力、智囊团的力量、性转换的奥秘、潜意识、大脑、第六感
- 第14章：战胜六个恐惧恶魔（贫穷/批评/病痛/缺爱/衰老/死亡）

**顶级洞见**：
1. 人的大脑所设想和相信的任何事，都可以变为现实——这是全书的核心公理
2. 知识只是潜在的力量，只有与明确的行动计划结合才能变成真正的力量
3. 成功者与失败者的区别不是能力，而是在遭遇失败后又向前迈了一步
4. 你是与你相处时间最多的五个人的平均值——智囊团的本质是借用他人的思想力量
5. 犹豫不决→怀疑→恐惧，三者相互关联逐步升级，是成功系统必须消灭的三个敌人
6. 性欲是最强大的人类情绪，通过"转换"将其引导到创造性输出上，庸才可变天才
