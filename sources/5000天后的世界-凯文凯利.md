# 《5000天后的世界》— 凯文·凯利

**原书名**：5000天後の世界（The World After 5000 Days）

**作者**：凯文·凯利（Kevin Kelly），《连线》杂志创始主编，著有《失控》《科技想要什么》《必然》。被称为"预言者"，成功预测了GAFA赢者通吃、免费经济等科技趋势。

**出版**：2021年日文版（大野和基 采访/编辑，服部桂 翻译），中文版由中信出版社出版。全书约58页（日文原版Page）。

**全书结构**：
- 序章：5000天后的世界概览
- 第一章：镜像世界（AR/VR/第三平台/区块链/NFT/数字资产）
- 第二章：AI时代（AI进化/GAFA替代/大数据/平台组织）
- 第三章：新生物学时代（人造肉/基因编辑/精准农业/自动驾驶/飞行汽车）
- 第四章：亚洲时代与科技地缘政治（中国印度/深圳/城市竞争）
- 第五章：倾听科技洞见未来（科技方法论/进托邦/阿米什人/乐观主义）
- 第六章：创新与成功的困境（成功陷阱/混沌边缘/失败分享会/学习方法/AI时代人的价值）
- 终章：5000天后的世界（精神领域的变化/科技拓宽选择）
- 原书序/后记

**顶级洞见**：
1. 科技不是中立的——带来的益处占51%，问题占49%，这2%的差额在时间复利下创造了人类文明的巨大进步
2. 镜像世界是继社交媒体的第三个巨型平台，物理世界的完全数字化将消除地理位置和语言的限制
3. 创新产生于秩序与混沌的边缘——越是追求效率最优的组织越无法创新
4. 成功是创新最大的障碍：成功让人与现实隔绝，能付费解决一切就不需要创造力
5. "倾听科技"是最务实的预知方法：看科技在底层被如何误用，而非听发明者说它应该怎么用
6. 解决科技引发的问题的唯一方法是创造更多更好的科技，而非减少科技
7. AI时代人类最有价值的行为是不断提问——可以马上得到答案的问题扔给机器
8. 乐观主义不是无视问题，而是相信更多更好的科技可以解决当前科技引发的问题
