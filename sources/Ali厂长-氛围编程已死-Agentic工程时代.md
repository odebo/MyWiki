# 阿里厂长《氛围编程已死，欢迎来到 Agent 工程时代》

抖音视频，约 8 分钟，Ali 厂长（阿里厂长）解读 Karpathy × 红杉 Stephanie Zhan 对话（《From Vibe Coding to Agentic Engineering》）。

## 基本信息

- 来源：Ali 厂长抖音（ID: 7641236470006631730）
- 发布时间：2025 年
- 核心话题：Karpathy 宣布氛围编程时代结束，进入 Agentic Engineering 时代

## 核心论点

1. **Software 3.0 框架**：LLM = 计算基底；自然语言 = 编程接口；Agent = Runtime。这不是预言，是现状描述。

2. **Vibe Coding vs Agentic Engineering**：前者靠感觉只配做原型；后者需要完整的工程纪律（Memory/Tools/测试/多 Agent 协作/Sandbox/监控/Code Review/Spec/安全边界）。

3. **老程序员焦虑**：经验越深，反而越觉得失控。Agent 吐 800 行代码，必须 Code Review 签字，却可能看不懂。"不是在编程，是在签字。"

4. **Root 权限金句**：给 Agent 放开所有权限听着像全能助理，但它一次幻觉就完了。"一个没有约束的 Coding Agent 是人质危机，不是劳动力策略。"

5. **判断力是唯一升值资产**：市场两极——认证体系（GH600）建立 + 大厂裁员（Cloudflare 1100+），AI 暴露了"在会议之间传话"的岗位，但没有替代真正的判断力。

## 关键数据 / 事件

- GitHub GH600 认证（Certified Agentic AI Developer）正式上线
- Cloudflare 一次裁员 1100+ 岗位，理由：适配 Agentic AI 时代
- Atlassian、Coinbase、Salesforce、Snap 同期裁员

## 最值得引用的句子

> "一个没有约束的 Coding Agent，不是同事，是一个拥有 Root 权限、精力无限、偶尔会幻觉的出击工程师。这不是劳动力策略，这是人质危机。"

> "Software 3.0 不是 Slogan。它是程序员从代码作者，变成计算劳动力操作者的那一刻。"
