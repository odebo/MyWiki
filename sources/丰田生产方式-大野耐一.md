# 丰田生产方式

**作者简介**：大野耐一（1912-1990），丰田生产方式（Toyota Production System, TPS）的创始人与总设计师。被誉为"日本复活之父""生产之神"。1932年加入丰田纺织，1943年转入丰田汽车，从工程师一路升任丰田汽车副社长。在长达35年的实践探索中，将"准时化""自働化""看板""五个为什么""七大浪费"等理念系统化为完整的丰田生产方式，对全球制造业产生深远影响。所著《丰田生产方式》是精益生产的奠基之作。

**出版信息**：日文原版初版于1978年；机械工业出版社中文版；约90千字。

## 全书结构

### 核心章节

- **前言** — 丰田生产方式的诞生背景
- **第一章 立足于需求** — 石油危机唤起觉醒；丰田生产方式的两大支柱；打破常规；让机器拥有人的智慧；目标在于降低成本
- **第二章 丰田生产方式详述** — 反复追问五个"为什么"；对浪费进行彻底分析；现场主义；标准作业表；看板；均衡化；微调；龟兔赛跑；忍术式经营
- **第三章 丰田生产方式的渊源** — 两位杰出人物；永不服输的精神；科学性与合理性相结合的丰田主义；追求日本特色；辩证式的发展
- **第四章 福特生产方式的真谛** — 福特生产方式；压缩批量迅速变换程序；亨利·福特一世的先见之明；必须自己制定"标准"

## 核心论点链

1. **诊断**：石油危机后的低增长时代，传统"库存型思维"成为最大经营损失
2. **基本思想**：彻底消除浪费是丰田生产方式的核心
3. **两大支柱**：准时化JIT（量）+ 自働化（质）
4. **运行手段**：看板（信息载体）+ 后工序拉动（流程方向）
5. **改进方法**：五个为什么追溯根因 + 现场主义获取真信息
6. **浪费清单**：七大浪费系统化，产出过剩为"最可怕的浪费"
7. **经营者角色**：现场主义 + 忍术式经营 + 发现多余人员并有效使用（而非解雇）

## 经典案例

- **大野耐一1937-1938年编制"纺织标准作业表"**——多次前往生产第一线反复修改；现场主义思维起点
- **丰田佐吉自働纺织机**（1867-1930）——经纱断了或纬纱用完时立即停止；自働化精神源头
- **机器停止工作五个为什么案例**——保险丝断→过载→润滑不充分→润滑泵磨损→无过滤器混入铁屑；最终方案加装过滤器
- **超市启发看板**——大野耐一从超市按需补货机制得到看板灵感
- **龟兔赛跑隐喻**——按需求稳定生产的乌龟优于追求短期速度的兔子
- **石油危机1973**——唤起日本企业对库存型思维危害的觉醒
- **"给发臭的东西盖上盖子"批判**——日本谚语；传统做法掩盖问题无法改进
- **0.1个人也是1个人**——多余人员的发现与有效使用
- **忍术式经营 vs 算术式经营**——灵活应对而非算术式扩产
- **大车间角落办公**——大野耐一作为副社长坐在生产现场角落而非办公室

## 阅读建议

第一章是核心——定义了丰田生产方式的两大支柱（准时化+自働化）和基本思想（彻底消除浪费）。第二章是全书精华——详细展开看板、五个为什么、均衡化、现场主义、龟兔赛跑、忍术式经营等核心概念。第三章是思想渊源——理解大野耐一受丰田佐吉、喜久治等前辈影响。第四章是与福特生产方式的对比——理解丰田方式相对于福特方式的进化。本书字数不多（90千字）但信息密度极高，每节都是实践浓缩，不适合略读——建议结合企业自身实践逐章对照反思。
