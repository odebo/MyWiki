# 罗胖60秒：学习与成长

从 2019-2022 年约 55 条相关内容中提炼。

## 知识的外部性

知识不只是个人的事，有强烈的社会性（外部性）：
- 一个人驾照考试学交规，是为了所有上路的人的安全
- 国家义务教育、扫盲——个人学了知识，不仅利己，也利社会

→ 学习是义务，不只是权利。（2019年#050）

## 知识是"点灯"传递的

所谓"二手知识"的批评站不住脚：

所有知识都是一盏灯点燃另一盏灯——佛经第一句"如是我闻"（听说来的），剑桥中华民国史是西方史学家整理中国史料。

→ 知识从来都是传递的，每一盏灯能操心的，只是自己能不能把这个火种传好。（2019年#011）

## 人和人的矛盾从哪里来

**内心冲突 → 外化为人际冲突**（陈海贤）：

- 你在犹豫要不要帮老婆带孩子，老婆一叫，你反而光火
- 你在犹豫要不要结婚，老妈一催，反而更排斥

原因：内心冲突的痛苦 > 外在人际冲突的痛苦。
→ 把内心冲突转换成人际冲突，可以逃避自己的选择，"都是别人的错"。

本质上：我们不是和别人有矛盾，我们是在逃避自己的选择。（2019年#013）

## 工作能力 = 分清主次

在分工明确的时代，工作能力 = 职业技能（厨师会做菜）。

但现在大量工作是新的、没有现成技能的——**工作能力 = 能分清主次的能力**：
- 全局中分清主次：当下最重要的任务是什么
- 时间段内分清主次：今天上午最该做什么
- 一篇文档中分清主次：主要说清什么

现代职场的残酷性：事务主导权的争夺。你不能分清主次，别人就会把你的时间扯得稀烂。（2022年#008）

## 不远求：在近处找资源

2021 年跨年演讲核心词：**不远求**

九渡河小学案例：乡村小学引入周边村子的辅导老师，做成优秀课程体系。

→ 现在做成一件事，资源是全球化的，可以随时调用。但关键是：**把远处的资源嵌入近处的问题**。（2021年#002）

## 外行的优势

为什么外行反而能干出大成就（马云懂数学不好）？

- 在新兴快速发展领域，专家懂的是1%，普通人懂的是0.1%，差距在绝对值上很小
- 专家因为天天被请教、乐于输出，容易对新知识关闭大脑
- 外行知道自己什么都不懂，思想反而更开放

→ 所谓"乱拳打死老师傅"，原因在此。（2019年#070）

## 教育的使命变了

过去：把人类存量知识原封不动转交给下一代（一个动机：好好学习）

现在：无法预知下一代遭遇什么挑战 →  **教育的使命 = 动机分化**（薛涌）

帮每个人找到学习动机（天分和兴趣所在），分头突围，应对各自的人生挑战。（2019年#030）

## 成长的正反馈

> 人都是因为痛苦而改变，因为受益而坚持。
