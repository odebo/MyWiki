# 罗胖60秒：商业与战略

从全十年（2013-2022，2263条）中提炼。

## 领导力 = 谁兼容谁

**"谁能兼容谁，谁就能领导谁。"**（脱不花）

场景一：有人得罪你，来道歉。
- "好吧，我原谅你了" → 他兼容了你，他赢了领导力
- "好吧，来，我请你吃饭" → 你兼容了他，你赢了领导力

场景二：下属惹了麻烦，提了补救方案。
- "事已至此，只能这么办了" → 他兼容了你
- "这个方案是权宜之计，你再站在我的角度替我想想，我该不该这么做？" → 你兼容了他

→ 领导力不是靠权力，而是靠谁先放大了对方的视角。（2019年#020）

## 战略 = 具体的人的具体变化

（同见[[罗胖60秒-思维与判断]]）

三年战略的简化方法：想三年后你的用户、同事、合作伙伴各自变成什么样子。

→ 战略不是虚的，落在人身上才是战略。（2022年#016）

## 好公司：忍住不干房地产

衡量一家有些年头的公司，看一个关键点：**这么多年，这么多机会，能不能忍住不干房地产**。

不只是定力问题，还说明：这家公司爱惜羽毛，非常在意向市场/内部/用户/员工释放什么信号。

→ 任何决策都有两个效应：决策本身的现实后果，和决策在周边人那里引起的观感。（2020年#050）

## 伙伴关系的两种模式

**找保姆 vs 找战友**：

- 保姆模式：对方对我好，满足我的需求。这种起点的关系/家庭，往往崩溃最快。
- 战友模式：除了两个人，还有第三者——目标。因为对方的存在，彼此变得更好。

战友模式难，难在"每个人都得有目标"。不是每个人都有清晰目标。（2020年#035）

## 印度与"未来工厂"

判断未来的一个角度：**未来从现在做的事情里长出来**。

印度没能承接中国制造业转移的订单（越南、孟加拉接住了）→ 说明印度在利用人口优势方面已经失败过了。

→ 过去没有做好的事，我们有什么理由相信未来就能做好？（2020年#015）

## 孝道是文明传承的基础设施

孝道的多层功能（超越家庭私德）：
- 约束日常行为（孝子不在家门口给父母丢人，不会打架偷盗）
- 熟人社会的行为约束机制
- 国家凝聚手段（忠臣必出于孝子之家）
- 个人安身立命、找到对世界的终极责任感

→ 孝道是中华文明把文化价值传递到个人行为层面的基础设施。（2021年#016）

## 早期经典洞见（2013-2018）

### 企业规模的本质定义（2013）

周其仁观点：小企业就是不会用他人钱财的企业，大企业就是会用的。不是融资难，而是不会融资。解决问题的方式决定企业规模。

### 系统会自我进化（2014）

微商虽起初售三无产品，但一旦挣到钱就想站着把钱挣，系统本身会自我进化升级。不要欺负年轻人，他们会进化。

### 被存量绑架的大公司陷阱（2015）

大公司边缘业务资源少、束缚多、反应慢。创业最大的时间差就在这里——打的不是差异化，而是时间差。

大公司的致命要害不是强大的敌人，而是被绑定在过去，不能踏入趋势之中。

### 时间是新的竞争战场（2017）

不同产业都在为体验而竞争，体验消耗用户时间，而时间只有那么多。手套销量因手机下降是产品特性排斥，口香糖销量因手机下降是时间竞争。**隔行也是冤家的时代正在到来。**

### 埃隆·马斯克的创业套路（2017）

发现人类大问题 → 展示技术解决它的前景 → 成立公司融资。

> 激发人对海洋的渴望比教人造船重要。

### 垄断性技术的真正含义（2018）

不是对手学不会，而是学会了对他们也没用。长城对游牧民族无用，不是因为保密，而是因为其优势基于定居生活方式，对手无法复制那个生活方式。

### 商业本质是合作而非对抗（2017）

所有对抗本质上都是思维被限定的结果，所有对抗都能转换为合作。市场经济是"人类合作的扩展秩序"。

### 消费者购买的是"事件"，不是商品（2022）

7-Eleven创始人的深洞见：消费者买的不是商品，而是事件。买咖啡不是因为好喝，而是"中午犯困"或"同事的好意"。能把商品还原为生活中的事件，才是真正理解消费者需求。

### 绩效主义限制创造力（2022）

绩效指标让人只会"跑"不会"舞"。跑步是加快速度的行走，舞蹈是全新的运动方式。**绩效只会让我们忙碌，而不产生新事物**——只会重复或加速已存在的东西。

### 质量问题本质上是数量问题（2021）

AI爆发不是算法突破而是算力提升。人缘差是接触人太少。新媒体难做是功夫不足。"奇技淫巧"那套想法是在幻想不增加数量的前提下偷工减料。底子厚才有后劲。
