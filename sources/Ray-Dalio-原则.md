# 《原则》— Ray Dalio

> 作者：Ray Dalio（瑞·达利欧）
> 出版：2017年，增订版
> 背景：桥水基金创始人40年经验结晶，覆盖"生活原则"与"工作原则"两大部分

---

## 核心命题

**原则是价值观与行动之间的桥梁。**
把遭遇的情境分类，针对每类情境形成原则，再把原则编码成算法，就能系统性地做出好决策。

---

## 生活原则（Life Principles）

### 拥抱现实，应对现实

- 现实运作有规律，理解规律才能与之合作
- 进化是宇宙最强大的力量，人和机构都必须持续进化
- **痛苦 + 反思 = 进步**（核心等式）→ 详见 [[pain-reflection-progress]]

### 极度求真 · 极度透明

- 这是桥水40年核心运营方式 → 详见 [[radical-transparency]]

### 5步流程

目标 → 识别问题 → 诊断根因 → 设计方案 → 执行
→ 详见 [[five-step-process]]

### 两个自我的战争

- **高层自我**（理性/前额叶皮层）vs **低层自我**（情绪/杏仁核）
- 关键修炼：把失败视为数据，把情绪当信号而非指令
- 每个人都有"盲点矩阵"——自己看不见自己的弱点

### 理解大脑差异

- 人格类型差异有神经基础（左脑/右脑、内向/外向）
- 不要期望别人像你一样思考；理解差异才能合理搭档

## 工作原则（Work Principles）

### 创意择优（Idea Meritocracy）

桥水最核心的组织原则 → 详见 [[meritocracy]]

### 可信度加权决策

投票不等于民主，要按可信度加权 → 详见 [[credibility-weighting]]

### 组织设计

| 层次 | 关键原则 |
|------|---------|
| 文化 | 极度求真/透明；严厉之爱；慷慨≠有权受惠 |
| 人员 | 招最适合的人，不招最好的人；塑造者模型 |
| 管理 | 机构=文化×人；自我强化螺旋 |
| 流程 | 原则→算法→工具；杠杆效应50:1 |
| 治理 | 制衡机制；三层治理结构；联合CEO机制 |

### 人员管理五要素

1. 招到合适的人（大任务不将就）
2. 管理好人（训练/测试/评估/晋升或淘汰）
3. 设计机器（岗位→流程→指标）
4. 知人善用（塑造者必须是创造者+推进者+改进者+贯彻者+变通者的集合体）
5. 解雇处理（缓慢诊断，快速决断）

### 经验法则

- **1.5 倍法则**：任何事情实际花费时间和金钱约为预期的 1.5 倍
- **100人临界点**：组织超过100人需要正式原则，否则靠文化维系会失败
- **80/20法则**：找到那20%关键变量，集中精力
- **5步流程第5步**：计划再好，不执行等于零（"按既定计划行事"）
