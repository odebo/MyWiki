# 《写作全技术》

**作者**：斋藤孝（Saito Takashi），日本明治大学文学部教授，教育学者，著述颇丰。这是其"全技术"系列的第三部，前有《超级阅读术》《大人的沟通全技术》。

**核心主张**：在信息化社会尤其是互联网高速发展下，商务人士的"写作能力"已可与交流能力、事务处理能力相提并论甚至更胜一筹。写作能力决定工作成败——写不好商务邮件的人会被评价为"工作能力低下"。

## 全书结构（5章+末章）

**第1章：商务人士需要掌握"写作能力"的理由**
- 文章关乎构建人际关系，第一句话决定对方对你的印象
- 商务文书需要有"温度"——人是感性的生物
- "说写两用力"：谈话时保持"写"的意识，以接近书面语的形式说话
- 写作是锻炼思考力的最佳手段——试着写才发现"原来没明白"

**第2章：改变写法就能改变活法**
- 写的本质：口语=混沌，文章=秩序=建筑物
- 文章三步骤：找到主题→创造三个关键概念→联结构建
- 电脑让写作能力飞跃：先大量收集素材再删除多余
- 文章必须含有"发现"和"新视角"——只有你知道的新信息
- 10页稿纸（4000字）是写作的门槛和分水岭

**第3章：写作能力决定工作的成败**
- 商务邮件术：热（热情）修（修饰）确（确认）
- 道歉信写法：正确道歉可化危机为机遇
- "透明度"是商务文章的核心要求
- 企划方案的价值由倾注的精力和热情决定
- 应答速度体现诚意

**第4章：成为作文高手**
- 词汇能力和"意义含有率"
- 独自辩证法——通过与自我对话深化思考
- 引用能带来"赚到了"的感觉
- 谈判文章：三个基本要点+重视换行和数据
- 确立文风以表明立场

**第5章：成为"读写说"高手**
- "读""写""说"三位一体，"写作能力"的根本在于"阅读能力"
- 先"说"再"写"更轻松
- 像呼吸般读书，掌握以写作为目的的阅读方法

**末章**：助作者练成"写作能力"的书籍推荐
