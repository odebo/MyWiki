# 正念禅修：在喧嚣的世界中获取安宁

## 作者简介

**马克·威廉姆斯（Mark Williams, 1957-）**：英国临床心理学家，牛津大学临床心理学荣誉教授。1980年代起研究抑郁的认知机制，与约翰·蒂斯代尔（John Teasdale）、津戴尔·赛戈尔（Zindel Segal）共同开发**正念认知疗法（MBCT, Mindfulness-Based Cognitive Therapy）**——在卡巴金MBSR基础上整合认知疗法，专门用于抑郁症复发预防。MBCT被英国NICE纳入官方治疗指南。

**丹尼·彭曼（Danny Penman）**：英国科普作家、记者，博士。把威廉姆斯的MBCT课程改写为面向大众的8周实操指南，使MBCT从临床走向日常。

## 全书结构

《正念禅修》分12篇 + 序言，围绕"通过8周正念禅修从行动模式换挡到存在模式"展开：

- **第1-2篇**：无意义的忙碌；为什么攻击自己——指出过度思考的恶性循环
- **第3篇**：认识你的生活；大脑"行动"与"存在"模式的7个特点；有意识地换挡
- **第4篇**：8周正念禅修简介；习惯破除训练；为禅修准备时间和空间
- **第5-12篇**：8周课程的具体内容（每周一篇）

## 经典案例与隐喻

- **公园一丝哀愁**——春季游览公园，开始"我希望自己更快乐"自我检讨，差距感强化心情低落
- **疲惫实验**——思考"我为什么疲惫"后感觉更糟，证明苦思冥想降低解决能力
- **山顶雨中俯瞰**——乌云消散太阳出来，城市焕然一新——视角转换改变感受
- **度假行李准备**——仓鼠转轮般疲惫，到沙滩上突然焕发——同一现实不同视角
- **与客服争吵**——当时怒不可遏，几周后几乎忘记——时间改变态度
- **7个特点对比表**——自动导航/分析/努力/想法即现实/躲避/时间旅行/消耗 vs 有意识/感知/接受/想法即想法/靠近/当下/滋养
- **沙漏形状**——3分钟呼吸空间的上端开口/狭窄脖颈/下端开口
- **高山制高点**——纯粹意识高于思维，看清一切不被裹挟
- **谣言工厂**——第4周揭示大脑如何制造谣言
- **迷宫中的老鼠**——第3周比喻陷入行动模式的徒劳
- **8周习惯破除**——电视评估/出去散步/看电影/播撒种子/再次舞蹈

## 循证基础

- **NICE官方认证**：英国国家健康和临床质量研究所推荐MBCT用于抑郁症复发预防
- **复发率显著降低**：研究显示MBCT显著降低抑郁症复发率，特别是3次以上发作患者
- **停药后保护**：停服抗抑郁剂患者进行8周MBCT后复发率显著降低
- **8周足以改变大脑**：研究显示8周训练足以改变大脑关键区域
- **威斯康星大学研究**：8周正念后大脑活跃区域从右转到左，快乐感和幸福感增强
- **加州大学洛杉矶分校**：给情感贴标签降低情感强度
- **麻省大学医疗中心卡巴金团队**：验证禅修对慢性疼痛/压力的效果
