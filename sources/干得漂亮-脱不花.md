# 干得漂亮

## 作者简介

**脱不花**：得到 App 联合创始人 & CEO,中国知识付费行业代表人物。17 岁辍学创业,先后做过广告、咨询,2015 年与罗振宇共同创办得到 App,开创中国知识服务模式。著有《沟通的方法》（2021）、《干得漂亮》（2024）。她的方法论来自得到内部 8+ 年管理实践,而非理论推演——这是本书的特殊价值。

## 全书摘要

《干得漂亮》是脱不花继《沟通的方法》后的第二部方法论著作,聚焦"职场做事"——如何把事情干得漂亮,而不只是做完。核心论点：职场价值不在"做得快",在"干得漂亮"——漂亮 = 闭环 + 超预期 + 方法论 + 影响。

全书围绕"接-做-交"三阶段展开,每阶段提供具体方法。本质是把"职场直觉"变成"可操作流程"。

## 关键洞见

### 1. 闭环是职场第一能力
能力再强不闭环 = 不可靠 = 不会被重用。组织选择晋升对象时,可靠 > 聪明 > 勤奋。闭环三要素：凡事有交代、件件有着落、事事有回音。

### 2. 干得漂亮比做得快更重要
做得快 = 60 分,干得漂亮 = 90+ 分。做得快可被 AI 替代,干得漂亮不可替代。漂亮 = 完成度 + 方法性 + 影响性 + 闭环性。

### 3. 向上管理不是讨好是省心
讨好是情绪价值,省心是工作价值。上级最稀缺的是注意力,不是情绪。被重用的人 = 让上级不用操心的人。

### 4. 行动建议代替意见反馈
意见指向过去,行动建议指向未来。意见让人防御,行动建议让人改进。把"批评"从职场词典删掉,只留"建设"。

### 5. 跨部门协作本质是 KPI 互换
不帮对方完成 KPI 的请求 = 道德绑架。帮对方完成 KPI 的请求 = 双赢合作。同理心 = 站在对方立场设计协作。

## 与"成功学"的对话

本书常被归为"职场成功学",但脱不花的方法论与成功学有本质区别：
- 成功学讲"心态",脱不花讲"方法"
- 成功学讲"努力",脱不花讲"闭环"
- 成功学讲"梦想",脱不花讲"具体动作"
- 成功学难验证,脱不花可立即验证
- 这是得到系方法论的一贯特征——可操作、可验证、可教学

## 局限性

- 方法论主要适用于知识工作者/白领,蓝领场景未必适用
- "干得漂亮"标准主观,容易被组织内卷利用
- 部分场景（紧急、危机）确实需要"做得快"
- 向上管理依赖上级质量——遇到糟糕上级,任何方法都难奏效
- 行动建议需要时间思考,紧急时只能用意见
