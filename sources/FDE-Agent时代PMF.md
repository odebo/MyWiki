## 文章核心主张

> **客户买的不是软件，而是一个"能干活的 agent"——PMF 发生在客户的真实业务现场，而不是产品团队的办公室。**

Agent 时代的到来使 FDE（Forward-Deployed Engineer）模式从 Palantir 专属发明，演变为 OpenAI、Anthropic、Stripe、Google Cloud 的共同选择。本文从第一视角（Bob McGrew 曾同时任职 Palantir + OpenAI）系统复盘了 FDE 模式的起源、运作逻辑、与 Agent 时代的关系。

## 顶级洞见

1. **FDE 不是服务，是产品探索过程**：Shyam Sankar 的核心洞见——把服务逻辑倒过来，让 FDE 充当产品探索
2. **碎石路 → 高速公路的产品杠杆**：FDE 在现场填补 gap，总部工程团队抽象泛化，服务下5-10个客户
3. **Echo = 反叛者**：最有价值的 FDE 不仅了解现有做法，还能看到它"不够好"的地方——看不到问题，永远想不出阶跃式改变
4. **Delta = 时间线优先于完美代码**：快速原型能力 > 工匠精神，核心是在约定时间线内交付可运行的软件
5. **咨询陷阱的识别标准**：如果"交付成果的单位价值成本"没有随时间下降，就已经变成了咨询
6. **AI 能力 ≫ AI 采用速度**：未来5年极可能是"技术飞速进步但现实感觉平庸"，FDE 填补这一 gap
7. **Palantir Mafia 孵化 350+ 公司不是巧合**：FDE 训练本质上就是创始人训练（Echo + Delta ≈ 一个创业团队）
