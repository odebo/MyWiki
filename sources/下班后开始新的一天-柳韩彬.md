# 《下班后开始新的一天》柳韩彬

**作者**：柳韩彬（韩国兽医兼多栖创作者），2022年中文版（浙江文艺出版社），63千字。

## 全书结构

- **PART 01 改变之前，问自己4个问题**：打破"工作日=上班"的认知框架；重新定义"工作与生活平衡"
- **PART 02 善用晚间时光，收获4份人生礼物**：自尊（找到证明自己价值的证据）、斜杠、自我、开源（收入翻倍）
- **PART 03 晚间计划第一步：确定大小目标**：曼陀罗计划表、目标设定4步骤、行动计划表、只为自己的目标
- **PART 04 晚间计划第二步：赢得时间自由**：时间轴计划表（事后记录为核心）、晚间日程设计、番茄工作法
- **PART 05 晚间计划第三步：打造固定日程**：把想做的事变成固定日程、节奏管理、避免过度热情爆发
- **PART 06 坚持不下去时怎么办：6种危机应对法**：计划被打乱/低落感/完美主义/意志力薄弱/想放弃时的应对

## 顶级洞见

1. **改变从重新定义"一天"开始**：把工作日拆分成上班前/上班中/下班后三段，就会发现每天至少3-4小时完全属于自己。"晚上不是'为了迎接明天做准备'的时间，而是属于'今天的我'的时间。"
2. **自尊不能靠自我暗示建立，需要实际行动的证据**：不断说"我很珍贵"无法真正建立自尊；真正有用的做法是"找到证明自己价值的证据"——通过晚间活动在其他领域取得实际成果，即使搞砸了工作也有其他来源的价值感
3. **事后记录比事前计划更重要**：不是待办清单，而是每小时记录实际上做了什么，才能发现浪费时间的模式，找到自己的高专注时间段。写一个月每日计划表比读一百本时间管理书更有用
4. **不用辞职就能实现梦想——背水一战多半赢不了**：辞职后失去收入会产生压力，反而不利于从容做事。保留"工作"这个安全装置，利用晚上的时间慢慢发展副业才是更稳的策略
5. **计划是为我们服务的，不是用来囚禁自己的**：战略性修正不是失败。时间表的目的是避免虚度时光，而非逼迫自己。做得下去的计划才有效，可持续比爆发力重要
6. **意义是无法被量化的终身动力**：目标可量化但会带来空虚循环，意义则提供持续动力。追问"这件事对我来说有意义吗"比设定目标本身更重要
