# 走出思维泥潭 — 罗伯塔·乃斯

**作者**：罗伯塔·乃斯（Roberta Ness），美国医学科学院院士，得克萨斯大学公共卫生学院教授，美国流行病学会主席。长期从事创新思维培训，开发的科学创新训练课程让研究生创造力测试成绩提高297%。

**出版**：2021年9月，浙江教育出版社（原版 *Innovation Generation*，2012年牛津大学出版社）

**核心问题**：创造力是天生的还是可训练的？如何系统性地培养科学创新思维？

**全书结构**（24章+大量练习，178千字）：

**第一部分：理解并克服创新的障碍**
- Ch.1 勿读此书 — 2009年H1N1流感案例，创新定义（有目的的创造力），美国创造力危机
- Ch.2 一切取决于你怎么看 — 认知框架的概念：无处不在、打破会激起情绪、具有约束性
- Ch.3 战胜认知框架 — 珍·古道尔研究黑猩猩打破"人类优越性"范式；脑筋急转弯揭示框架局限
- Ch.4 怎么想就怎么说 — 语言作为认知框架的载体
- Ch.5 征服隐喻 — 隐喻影响思维方向（"癌症是战争"vs"癌症是邻居"→完全不同的应对策略）
- Ch.6 查明问题 — 观察的局限性和系统性偏差
- Ch.7 做一个更敏锐的观察者 — IDEO设计公司五步创新流程；在范式中寻找异常
- Ch.8-9 偏见程度/克服偏见 — 情境偏见、锚定效应、确认偏见、后视偏见及各自的克服方法
- Ch.10-11 大脑和创造力 — 创造性思维的神经科学基础

**第二部分：驱动创新——提出并回答科学问题**
- Ch.12-24 PIG In MuD六步创新框架（Phrase→Identify→Generate→Incubate→Meld→Disseminate）的详细展开，每一步都有科学案例和练习支撑

**核心论点**：创造力不是神秘天赋，而是可训练的系统性技能。创新障碍来自认知框架（有局限、有情感色彩、根深蒂固），通过PIG In MuD六步框架可系统性地克服这些障碍。
