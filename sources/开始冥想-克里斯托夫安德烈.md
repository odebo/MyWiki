## 作者简介

克里斯托夫·安德烈（Christophe André，1956— ），法国精神科医生、心理治疗师，巴黎圣安娜医院心理治疗科主任，正念认知疗法在法国的主要推动者之一。著有《不害怕》《情绪的力量》《自尊的力量》《开始冥想》等。他将正念冥想引入法国主流心理治疗临床实践，是欧洲正念运动的核心人物。

## 核心论点

冥想不是"闭上眼睛安静地坐在角落里思考"，而是通过内在的激荡增强对世界的热忱、对连接的渴望、对万物的慈悲。正念冥想是觉醒、明辨与行动的序曲。

全书反复强调一个悖论：冥想无目的、无期待——像睡眠、幸福一样是"涌现"现象，越追逐越远离。它的"心灵姿势"是不期待、不强求、不批判、不挑拣——所做的努力不在控制，而在存在本身。

## 三条主张链

1. **注意力链**：呼吸锚定 → 集中注意力训练稳定性 → 开放注意力训练容纳度 → 注意力不被"捕获"而劫持 → 当下不被偷走
2. **解构链**：思想≠现实 → 念头/想法/反思三层次 → "我的头脑正在告诉我" → 回应而非反应 → 疼痛≠痛苦（第二支箭）
3. **连接链**：从"我执"中解脱 → 自我关怀 → 慈心冥想 → 合作而非竞争是物种法则 → 与世界连接而非分离 → 把死亡纳入生活

### 第八章 冥想与连接
