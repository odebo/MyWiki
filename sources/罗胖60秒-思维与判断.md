# 罗胖60秒：思维与判断

从 2019-2022 年约 41 条相关内容中提炼。

## 好选择的本质

**"选择本身没那么重要，把选择变成好选择才重要。"**

两个选项难以取舍时，往往是因为两类选择混在一起：
- 看似有选，其实没选（考不上好学校，那就不是真选项）
- 看似很重要，其实选哪个差不多（配偶、工作——努力之前根本不知道哪个好）

→ 人最重要的变量不是做选择，而是在努力之后把选择变成一个好选择。（2019年#003）

## 高手看到的变量

高手和普通人的差别不是同一维度上更努力，而是**看到了更高维度的变量**。

例：西红柿炒鸡蛋——普通人调火候和咸淡，高手关注西红柿的汁液处理（决定味道的真正变量）。

→ 所谓高手，就是不断发现被忽略的、更高维度的变量。（2019年#005）

## 结构化思考

结构化思考 = 为同一对象提供更多维度，而不是堆砌更多信息。

**"三门模型"描述人的性格**（老喻）：
- 花园门：对外的热情程度
- 房门：是否允许深交
- 卧室门：是否愿意坦诚相见

比"外向/内向"的二分法更精准，能描述"表面热情但难深交"和"表面冷淡但一旦信任就掏心掏肺"的不同类型。

→ 有时候，我们不需要更多信息，只需要更多维度的框架，就能加深理解。（2019年#009）

## 因果的局限

**"原因的原因不是原因，结果的结果不是结果。"**（老喻）

- 疫情导致工厂停产（直接因果），但最终结果是订单反而回流中国（因为其他国家控制更差）
- 好医院的死亡率反而更高（因为重症患者才去好医院）

→ 显而易见的因果，往往不是最后的因果。用因果逻辑思考时保持谨慎。（2020年#003）

## 战略 = 具体的人的具体变化

战略这个"大词"变成可操作的方法：**三年后，你的用户/同事/合作伙伴各自会变成什么样子？**

战略不是虚的，落在具体的人和具体场景上才是真战略。同理：
- 情商不是"会说话/人脉广"（从自己角度看）
- 情商是"走到人面前，被人无限地、无条件地信任"（从对方角度看）

（李希贵校长 + 俞敏洪，2022年#016）

## 统计数字的两面

统计数字只有**反映**现实的意义，不能用来**指导**现实。

考核指标 → 人为指标 → 数字失真（医生为了提高手术成功率，拒绝给重症患者做手术）。

→ 所有数字都值得看两遍：一遍看它反映了什么，一遍看它可能扭曲了什么。（2021年#010）

## 理性 vs 感性（梁宁的框架）

> "理性的反面不是感性，而是本能；感性的反面不是理性，而是麻木。本能的人不会成功，麻木的人不会幸福。"——梁宁

- 自以为感性 = 追随本能（好吃懒做、喜怒无常）
- 自以为理性 = 对世界感受麻木

理性和感性是需要花时间修炼的品质，是向上提升的两个通道。（2022年#025）
