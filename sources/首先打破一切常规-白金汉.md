# 首先，打破一切常规

**作者简介**：马库斯·白金汉（Marcus Buckingham），盖洛普公司高级副总裁，主导盖洛普针对优秀经理的研究。本书与柯夫曼合著，是盖洛普 25 年两项大规模调查（百万员工 + 8 万经理）的成果结晶。

**出版信息**：1999 年美国初版，2002 年 1 月中国青年出版社中文版；ISBN 9787500647508；152 千字；由得到 APP 授权电子版。

## 全书结构

### 核心章节

- **引言 打破一切常规** — 优秀经理是革命家，推翻"传统智慧"
- **第一章 测量的标尺** — 什么事情我们明知重要却无法测量、Q12 的诞生、与经营业绩的关联
- **第二章 优秀经理的智慧** — 优秀经理做什么、与传统智慧的根本对立
- **第三章 第一要诀：选拔才干** — 才干、技能、知识的区分；过滤器；神经科学基础
- **第四章 第二要诀：界定结果** — 阻力最小路径；规定结果 vs 规定步骤
- **第五章 第三要诀：发挥优势** — 优势理论；铁杵不要磨成针；非弱点管理
- **第六章 第四要诀：因才适用** — 横向发展 vs 爬梯子；明星与状元
- **第七章 优秀经理的实用工作指南** — 四要诀落地实践
- **结语 力量的汇合** — 知识经济时代的催化剂角色

## 核心论点链

1. **测量**：Q12 是基层工作环境的测量标尺，敬业度（非满意度）预测业绩
2. **诊断**：一线经理（非公司层）决定员工敬业度，N 个部门 = N 个文化
3. **人性**：每个人都有天赋才干（精神过滤器），定形后很难改变，无法培训
4. **优势**：优势 = 才干 + 技能 + 知识，应扬长避短而非补缺
5. **方法**：四要诀——选拔才干/界定结果/发挥优势/因才适用
6. **角色**：经理从"管卡压"转为"催化剂"，加速才干与目标反应
7. **目标**：每个岗位都有明星，让员工在适合才干的岗位出类拔萃

## 优秀经理的座右铭

> 人是不会改变的，
> 不要为弥补欠缺而枉费心机，
> 而应多多发挥现有优势，
> 做到这一点已经不容易了。

## 与传统智慧的四点对立

| 维度 | 传统智慧 | 优秀经理 |
|------|---------|---------|
| 选拔 | 选经验/智力/意志 | 选天赋才干 |
| 要求 | 规定正确步骤 | 界定正确结果 |
| 激励 | 弥补弱点 | 发挥优势 |
| 培养 | 往上爬 | 因才适用 |

## 经典案例

- **迈克尔与侍应生团队**：布拉德（预见性）、盖里（友好）、苏珊（得体）、埃玛（组织力）——区别对待，因人而异
- **水星行动六宇航员**：经验智力意志培训完全相同，表现分三等——才干差异决定
- **兰克福德-西斯科公司**：家庭企业被西斯科合并，员工流动率<10%、缺勤率最低、顾客满意度名列前茅
- **1707 锡利群岛海难**：克洛迪斯利·肖维尔海军上将算错经度，四舰二千人葬身海底——明知重要却无法测量的代价
- **运输公司司机**：平均 12.5 万英里 4 次事故 vs 最出色 400 万英里无事故
- **客服代表**：一般员工让客户多打 3 倍电话
- **活鱼厨师小陈**：选鱼关键是看眼睛，找"宁死不屈的眼神"——选才要挑剔
- **盖洛普公司**：1935 年乔治·盖洛普创立，70 多年测量分析人类态度意见行为

- 与 [[赫茨伯格双因素理论]] 互补——动力因素对应优势发挥

- 与 [[心流-米哈里]] 互补——心流是优势发挥的最优体验状态
- 与 [[习得性无助]] 对立——补缺文化制造无助，优势理论重建掌控
- 与 [[控制二分法-爱比克泰德]] 共鸣——专注可控优势，放下不可控欠缺
- 与 [[破维-张君归]] 的能力圈互证——优势圈即能力圈
- 与 [[神经可塑性终身视角-列维廷]] 部分冲突——白金汉强调才干定形难改，列维廷强调大脑终身可塑

## 适合读者

- 中大型组织的中层和一线经理
- 人力资源从业者，特别是人才选拔和绩效管理方向

## 阅读建议

第一章是测量标尺的论证，第二到六章是四要诀的核心，第七章是落地。建议边读边对照自己的团队——四要诀的每一诀都可以立刻用 Q12 诊断。本书与 [[赫茨伯格双因素理论]]、[[服务利润链]] 配套阅读效果更佳。
