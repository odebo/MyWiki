# 《丰田一页纸极简整理法》浅田卓

## 作者简介

浅田卓（Asada Suguru），日本沟通技巧培训师，"一页纸"工作法倡导者。曾任职于丰田汽车，在丰田期间月加班曾达 400 小时，后通过自己开发"一页纸"框架将加班降至 0。离开丰田后创立一页纸咨询公司，向企业传授 Excel 1 / Logic 3 等整理思维与传达技巧。

## 核心论点

丰田之所以能成为 No.1，与其内部的"一页纸"文化密不可分——所有文件都用 A3 横放的一页纸呈现。浅田卓从 3000+ 张丰田文件中提炼出三大共同特征（一览性/框架/主题），并将其简化为任何人都能掌握的 Excel 1 + Logic 3 框架。最终目标是"0 页纸状态"——大脑自然形成整理回路，无需纸笔也能瞬时整理信息、总结思维、传达给别人。

## 三条主张链

1. **方法链**：三特征（一览性/框架/主题）→ Excel 1（绿蓝红三色笔）→ Logic 3（1P+Q1Q2Q3）→ 0 页纸状态
2. **动机链**：从以自我为中心（"想整理自己的混乱"）到以对方为中心（"能否传达给对方"）——这是从"为自己"到"被选择"的跃迁
3. **时代链**：日新月异的时代，How 比 Why 更需重视——不要被 5 次 Why 的金标准绑架

## 章节结构

### 序言
- 20 多岁时一份文件被上司递给总经理，第二天就发展成大项目
- 一页纸能"独自前行，越做越大"
- 加班 400 小时 → 0 的经历

### 第 1 章 为什么丰田公司能成为 No.1？
- 丰田 A3 一页纸文化
- 三特征：一览性 / 框架 / 主题
- 丰田社长"3 秒决断"原则
- 丘吉尔"即使战略正确也未必能赢，因为执行更重要"
- 一页纸的"独自前行"
- 为什么"不爱车"的人选丰田——靠一页纸传递信息而非靠车迷热情

### 第 2 章 基本篇
- 整理→总结→传达 三步骤
- 动作化原则：动词需转化为可见动作
- **Excel 1**：三色笔（绿框架/蓝关键词/红整理）+ 时间限制（8 格 1 分钟/16 格 2 分钟/32 格 5 分钟）
- "不要企图追求 1 次完美"
- 手写 vs 电脑：TOPPAN FORMS 前额皮层实验 / 动作先于心情
- "原本"口头禅——"原本为何而做"
- 一句话概括（1P）
- Excel 1 活用三例

### 第 3 章 应用篇
- **Logic 3**：1P? + Q1?/Q2?/Q3?（What/Why/How，顺序可变）
- 工作五要素：目的(Why) / 现状 / 课题(What) / 对策(How) / 日程
- "3"的魔法数字：记忆容量 / 三级跳惊喜 / 超过 4 个就饱了
- 手写锻炼逻辑
- Logic 3 活用案例
- **工作停滞的本质**：信息混乱 + 缺乏下一步动作
- **5 次 How 优于 5 次 Why**：Why 陷阱 + How 是最短路径 + 平衡原则
- **0 页纸状态**：从以自我为中心到以对方为中心
- "不断被选择"由毫厘之差决定——求职简历/升职小论文/跳槽简历

### 后记
- "传达"的本质如同登山：
  - 登山（整理总结）：15 → 7 → 3 → 1 自下而上筛选
  - 下山（传达阶段）：1 → 3 → 7 → 15 从山顶展开
- Logic 3 / Excel 1 所做的都是登山——把想传达的限定为对方更易理解的内容
