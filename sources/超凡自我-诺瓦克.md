## 作者简介

**戴维·诺瓦克**：百胜餐饮集团（Yum! Brands，肯德基/必胜客/塔可贝尔母公司）前首席执行官、董事长。在任期间百胜从百事分离独立上市，全球门店数翻倍。著有《英语快乐学》《全力以赴》等。创立戴维·诺瓦克领导力（David Novak Leadership）非营利组织，致力于培养全球领导人才。曾获"霍雷肖·阿尔杰奖"、"商业执行官领导力奖"。

**杰森·戈德史密斯**：职业高尔夫绩效教练。患有阅读困难症，曾被视为缺陷，后重构为"超能力"。曾与多位 PGA 巡回赛冠军合作，包括戴伊、贾斯汀·罗斯（2016 奥运金牌）等。把绩效训练方法拓展到企业高管、飞行员、大学生等非运动员人群。

## 全书核心论点

本书是诺瓦克和戈德史密斯合著的"自我教练手册"。核心命题：**你要做自己的总教练**——不是单干，而是对自己负责，按需剖析自己，推动自己前进。全书围绕一个核心工具 SBT（Single Biggest Thing，唯一的最大事）展开，给出"对话→思维→计划→旅途→习惯"五阶段训练框架。

贯穿全书的三个核心论点：

1. **自我训练 ≠ 单干**——要对自我负责，但要善用他人帮助。"你是总教练，只有你可以拍板。"
2. **动力不是决心，是设计**——把动力嵌入环境和仪式，而不是依赖每天早上的决心。
3. **失败是桥梁，不是终点**——重构失败为学习，记住胜利，保持思维灵活。

## 五章结构

1. **自我训练对话** — 4 关键问题（不快乐根源/快乐基石/SBT/目的地）；"启发我们的不是答案，是问题"
2. **自我训练思维** — 怀有信念 / 学会中立 / 利用意识 / 建立自我认知；引入[[重构技术-诺瓦克]]、[[中立状态-诺瓦克]]
3. **自我训练计划** — 确保目的地有的放矢 / 坦然面对 / 学会寻求帮助 / 开启学习曲线 / 找到扫清障碍方式 / 听从 SBT 指引；引入谦逊（伍登教练"得分后指向队友"）和 40/70 决策规则（科林·鲍威尔）
4. **自我训练旅途** — 把见解转变为行动 / 认清现实 / 开启路线 / 留下进步足迹（杰瑞·宋飞红叉日历）/ 学会和自己对话 / 欣赏自己 / 逆转立场
5. **自我训练习惯** — 内置积极动力三策略（激励空间 / 想象未来 / 公开）/ 拖延症 / 接受失败 / 记住胜利 / 保持思维灵活 / 不断抬高标准
