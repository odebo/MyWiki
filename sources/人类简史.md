## 核心论证链

```
认知革命（虚构能力）
  → 陌生人大规模合作
  → 农业革命（复杂社会秩序需要维护）
  → 文字/记账/官僚制度/阶级
  → 帝国/金钱/宗教（三大统一力量）
  → 科学革命（承认无知 + 三角联盟）
  → 资本主义/工业革命/消费主义
  → 全球融合的单一文明
  → 智人末日（超人 or AI替代）
```

---

## 顶级洞见（跨章综合）

1. **虚构是智人的核武器**：国家/公司/法律/人权都是虚构故事；主体间性让数百万人共同相信同一个故事
2. **农业革命是最大骗局**：物种成功≠个体幸福；采集者比农民更健康更自由
3. **科学革命是无知的革命**：真正的起点是承认"我们不知道"——这本身就是革命性的
4. **三大统一力量**：金钱/帝国/宗教——都是虚构故事，都让陌生人扩大"我们"的边界
5. **幸福悖论**：物质财富指数增长，但快乐来自内心（血清素）而非外部条件；真正的快乐是生命有意义
6. **智人末日**：我们正在成为改变自身的"上帝"——结果要么是超人，要么是被AI替代
