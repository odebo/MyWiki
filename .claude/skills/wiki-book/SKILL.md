# Wiki Book — 长书分章节阅读 & Ingest

## 触发条件

用户说：
- `/wiki-book <pdf路径>`
- `/wiki-book`（无路径）
- "帮我逐章读这本书"
- "分章节阅读 <pdf>"
- `/wiki ingest <pdf>` 且 PDF 超过 30 页

---

## 核心流程

### 第 0 步：初始化

1. **确定 PDF 路径**：
   - 若用户提供了路径或消息中包含文件附件，直接使用
   - 若无路径：运行 `ls -t /Users/zhuqichen/Documents/WorkSpace/Asrocky01/.cc-connect/attachments/*.pdf | head -1` 取最新 PDF，**直接使用，不询问用户**
2. 读取 wiki CLAUDE.md（`~/wiki/CLAUDE.md` 或 `MyWiki/CLAUDE.md`）
3. 读 `hot.md` 获取近期上下文
4. 读 PDF 前 5 页，获取：书名、作者、出版信息
5. 读目录页（通常在第 2-10 页），提取章节列表和页码

输出章节列表，格式：
```
📚 《书名》 — 作者
共 N 章 / M 页

章节列表：
  第1章 章节名（第X-Y页）
  第2章 章节名（第Y-Z页）
  ...

准备开始逐章阅读。输入"继续"开始第1章，或指定"第N章"跳转。
```

---

### 第 1 步：逐章阅读

对每章执行以下循环：

#### 1a. 读取章节内容

- 每次调用 Read 工具最多读 20 页（硬限制）
- 若章节超过 20 页，分多次读取，拼接理解
- 读取时静默处理，不输出原文

#### 1b. 提炼章节洞见

阅读完本章后，输出：

```
---
## 第N章：《章节名》（第X-Y页）

**核心论点**
一句话总结本章最重要的主张。

**关键洞见**（2-4条）
• 洞见1：...
• 洞见2：...
• 洞见3：...

**金句 / 原话**（可选）
> "引用原文..."

**与前章的关联**（第2章起）
→ 本章如何发展/对比/印证前章的论点

---
[回复"继续"读下一章 | "跳到第N章" | "先停这里" | "开始写页面"]
```

#### 1c. 更新运行中的知识地图

在内存中维护一个 `knowledge_map`，结构：
```
{
  "主题A": ["洞见1（第2章）", "洞见2（第5章）"],
  "主题B": ["洞见3（第1章）"],
  ...
}
```
每读完一章，将新洞见归类到主题下。不输出给用户，仅内部使用。

---

### 第 2 步：阶段性总结（可选）

用户说"总结一下"或读完全书后，输出跨章综合：

```
## 全书知识地图

**贯穿全书的核心主题**
1. 主题A — 出现于第X/Y/Z章
2. 主题B — ...

**作者的核心论证链**
第1章 → 第2章 → ... （一句话描述逻辑链）

**最具原创性的3个洞见**
1. ...
2. ...
3. ...

**与已有知识的关联**（参考 wiki）
• 与[[已有页面A]]的关系：...
```

---

### 第 3 步：写入 Wiki

用户确认后（说"开始写"或"ingest"），执行：

#### 3a. 规划页面结构

根据知识地图，提议创建的页面：

```
建议创建以下页面：
concepts/
  • 主题A.md — 核心概念页
  • 主题B.md — ...
entities/
  • 作者名.md — 人物页（如有必要）
sources/
  • 书名-来源摘要.md — 来源摘要页

确认？（可调整）
```

#### 3b. 创建页面

按标准 wiki 格式创建每个页面：

```markdown
---
updated: YYYY-MM-DD
sources: [/绝对路径/book.pdf]
related: [[相关页面A]], [[相关页面B]]
---

# 页面标题

正文（综合全书相关章节的洞见，不是逐章摘要）...
```

**原则：**
- 按主题组织，不按章节顺序堆砌
- 跨章节的洞见合并为统一论述
- 来源页（sources/）才写章节结构摘要

#### 3c. 更新元文件

1. 更新 `index.md`（追加新页面）
2. 追加 `log.md` 一条记录
3. git commit & push

## 状态管理

### 中断恢复

用户下次说"继续读"时：
1. 询问书名和已读到哪章
2. 或让用户直接说"继续读《书名》第N章"

### 进度提示

每读完一章后显示进度条：
```
进度：█████░░░░░ 5/10章（第87页/共230页）
```

---

## 注意事项

- **自动逐章阅读**：读完一章后自动继续下一章，无需等用户确认（用户说"先停这里"才暂停）
- **不要跳过提炼**：每章必须输出洞见，不能只说"读完了"
- **保持知识地图**：跨章主题关联是这个 skill 的核心价值
- **PDF 20页硬限制**：单次 Read 调用不超过 20 页，超过的章节分多次调用
- **页面按主题不按章节**：写 wiki 时合并同主题洞见，不要按章节机械摘要
