# 雷军（Lei Jun）

**1969-** · 小米集团创始人/董事长/CEO · 金山集团董事长 · 天使投资人 · 《小米创业思考》作者

---

## 核心身份

- **小米**（2010年创办）：全球第四大智能手机制造商（2020年）→ 全球第二（2021年Q2）
- **金山集团**（1992年加入，2011年接任董事长）：WPS等核心产品，营收增长11倍
- **天使投资人**（2007-2010年）：投资凡客诚品、UC浏览器等数十家公司
- **小米汽车**（2021年宣布）：小米正式进军智能电动汽车，投入100亿美元

**里程碑**：
- 2021年：小米三次入榜《财富》世界500强（第338名）
- 2021年Q2：手机销量首次超越苹果，全球第二，市占16.9%
- 2021年：起诉美国国防部DOD清单，史无前例胜诉

## 主要思想贡献

| 框架 | 核心内容 |
|------|------------|
| 风口理论 | "站在风口上，猪都能飞"；时机/市场选择是创业第一要素 |
| 四字诀 | 专注·极致·口碑·快 |
| 铁人三项 | 硬件（近成本价）+ 软件/MIUI + 互联网服务 |
| 5%利润上限 | 硬件综合净利润率永不超过5%；多出部分返还用户 |
| 米粉文化 | 直连用户；MIUI每周更新；论坛是真正产品部门 |
| 生态链 | 投资+赋能100+企业，非自建；带动1000+品类 |
| 蜕变哲学 | 人生多次"刷ROM"，每次蜕变需重新归零 |
| 三十顾茅庐 | 找人要花80%时间；找不到人只有一个原因：没花够时间 |

## 个人四次蜕变（"刷ROM"）

1. **28岁**：热爱写程序 → 被迫成为金山总经理（同事误格式化硬盘，断了退路）
2. **38岁**：金山CEO → 专职天使投资人（主动选择，希望帮助创业者）
3. **40岁**：天使投资人 → 创办小米（互联网思维做硬件的"脑洞大开"）
4. **2016年**：互联网CEO → 硬件工程师（小米危机，亲自接管手机部）
5. **2021年**：手机CEO → 汽车制造商（"我人生最后一次重大创业项目"）

**蜕变体会**：
> "每一次进入新领域，过去的知识、经验、声望、荣誉，大部分清零了。你能依靠的，只有一颗一往无前的心。"

## 管理风格

- **用户第一**：所有决策以用户信任为锚点
- **工程师文化**：小米是一家"工程师文化主导的公司"
- **情义无价**：对金山的承诺（兼任董事长10年），对用户的承诺（3.7亿红包回馈首批用户）
- **直面风险**：每次关键决策都伴随极大风险，但果断决策，从不拖延
