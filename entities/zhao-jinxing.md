# 赵金星

上海轼事顾问公司创始人，"故事的力量"研究者与实践者，商业演讲领域培训师。

## 基本信息

- **职业**：培训师 / 演讲教练 / 作家
- **公司**：上海轼事顾问公司（创立于2016年），定位为全国知名的"故事的力量"研究公司
- **著作**：《故事演讲力：商业演讲中的故事策略》（北京大学出版社，2024）

## 创业故事（公司转折点）

2016年，赵金星与几位志同道合的朋友共同创立上海轼事顾问公司，专注于"故事的力量"的研究与培训。创业初期屡屡碰壁，公司发展举步维艰。

公司面临战略分歧时——一位合伙人认为应拓宽业务领域、不应只坚守"故事的力量"——赵金星在杭州一家企业进行培训时，一位女学员上台讲述了父亲突然去世时的遗憾故事（因工作繁忙未接父亲电话、未回家陪伴，直到在派出所注销父亲户口才真正意识到父亲离开……），打动全场所有人，学员们纷纷掏出手机给家人打电话。

回到上海，赵金星在合伙人会议上分享了这个故事。所有人沉默，那位提出异议的合伙人低着头许久后说："我觉得你是对的，我们有责任也有义务帮助更多人从故事中受益。"

这是公司发展的真正转折点，也是赵金星坚信"故事改变现实"的核心体验。

## 思想体系

赵金星的故事演讲理论体系以"神经科学 + 结构设计 + 场景应用"为框架：

- **神经科学层**：三激素模型（多巴胺/皮质醇/催产素）+ 双系统理论 + fMRI体验原理
- **工具层**：BCAR结构 + 黄金三角（代入感/画面感/节奏感）+ "那一刻"+ 思维收集四步法
- **系统层**：1G2W2H + 三段式演讲地图 + 钉子三原则 + 多场景应用
- **边界层**：故事非万能论 + 六条使用禁忌 + 真诚先于技巧
