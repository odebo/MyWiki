# 詹姆斯·克利尔（James Clear）

**身份**：美国作家、演讲者、习惯科学研究者

**背景**：大学棒球运动员，因被球棒击中头部重伤，颅骨骨折，经历长期康复。这段经历让他开始系统研究微小改变如何积累成重大变化。恢复后重返运动员生涯，后成为全职作家。

**代表作**：《掌控习惯》（Atomic Habits，2018），全球销量超2000万册，长期位居《纽约时报》畅销书榜。

**核心思想**：
- 习惯改变的关键是系统，而非目标（"你不会上升到目标的高度，你会下降到系统的层次"）
- 四步习惯回路（Cue→Craving→Response→Reward）
- 身份认同是持久改变的根基，每次习惯行为都是为身份投票
- 四大定律框架：显而易见 / 有吸引力 / 简便易行 / 令人愉悦
- 1%的微小改变复利积累：每天进步1%，一年后提升37倍
