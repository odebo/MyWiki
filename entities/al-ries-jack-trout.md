# 艾·里斯 & 杰克·特劳特（Al Ries & Jack Trout）

美国营销战略家，"定位"理论的共同创始人。两人合作的《定位》（1981）被认为是有史以来对美国营销影响最大的书籍，开创了以"心智占位"为核心的品牌战略思想体系。

## 核心贡献

| 框架 | 核心命题 |
|------|----------|
| 定位理论 | 竞争战场是消费者心智，不是货架 |
| 心智阶梯 | 第一入心智的品牌，份额≈第二名2倍（二元法则） |
| 空位策略 | 跟随者应找未被占据的心智位置，而非正面攻击 |
| 重新定位 | 改变对手在心智中的位置，为自己创造空间 |
| 跷跷板法则 | 一个名字只能强代表一件事，延伸是慢性自杀 |
| FWMTS陷阱 | 成功后品牌延伸=忘记成功之道=领导者死亡路径 |

## 影响

- 定位理论影响了宝洁多品牌策略（51个独立品牌）
- 七喜"非可乐"是定位理论最经典的实践案例
- 里斯后来单独著有《品牌的起源》，进一步发展品类创新理论

## 《什么是战略》（特劳特，独著）

特劳特晚年对战略本质的系统阐述，补充了《定位》之后的完整战略框架：

| 框架 | 核心命题 |
|------|---------|
| 战略≠目标 | 战略是企业一致性经营方针，目标是"我们想达成什么"（往往脱离现实） |
| 战略源自战术 | 自下而上而非自上而下；先找战术切入角度，再围绕它整合资源 |
| 四种战略方阵 | 防御战（领导者）/ 进攻战（第二位）/ 侧翼战（小企业）/ 游击战（极小企业） |
| 聚焦即字眼 | 伟大战略只有一个特征——简单；在心智中拥有一个字眼 |
| 心智战场终极法则 | 战略成败取决于是否将顾客心智视为战场 |

## 思想在当代的映射

- **AI时代**：Cursor/Claude/ChatGPT 的竞争本质也是心智占位——"最好的编程工具"/"最通用的AI助手"/"最快的聊天AI"
- **新能源汽车**：特斯拉占据"电动汽车"心智位置的方式，正是定位理论的完美实践
