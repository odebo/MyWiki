# 浮浅工作会自我扩张填满所有可用时间

**主张**：浮浅工作（email、会议、行政任务）有类似帕金森定律的扩张属性——如果不主动规划和限制，它会自然蔓延占满全部工作时间，挤出深度工作。

**反常识在哪**：人们通常把浮浅工作多视为"事情太多"的结果，认为解决办法是提高浮浅工作的处理速度。纽波特认为真正的解决办法是**预算**：主动决定浮浅工作占工作时间的比例上限（通常30-50%），而非试图处理得更快。

**核心证据/论据**：
- 时间块计划实验：要求每分钟都有明确分配的人，比"弹性安排"的人完成的高价值工作更多
- 固定截止时间（定时结束的生产力）：提前设定工作结束时间，倒逼在有限时间内优先处理高价值任务
- 发件人过滤策略：要求发件人提供更多背景信息才回复，减少低价值通信量

**可被挑战**：在高度协作的团队环境中，单方面减少响应频率可能损害协作关系；组织文化不支持时个人力量有限。
