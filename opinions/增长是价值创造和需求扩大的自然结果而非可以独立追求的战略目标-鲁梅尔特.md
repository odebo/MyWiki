# 增长是价值创造和需求扩大的自然结果而非可以独立追求的战略目标

**主张**：增长不能作为独立的战略目标来追求。增长是组织创造了有效价值且市场需求扩大的自然结果。把"增长"设为战略目标，相当于把"症状"当成"病因"来治疗。

**反常识在哪**：增长是几乎所有企业战略的第一关键词。鲁梅尔特认为这是因果倒置——追求增长本身会导致盲目扩张、收购和价值破坏。

**核心证据/论据**：
- S&P Global 案例：真正的增长来自对特定客户群体的价值深化，而非"增长目标"
- Boyd 循环（OODA）的启示：竞争优势来自比对手更快的决策循环，增长是这种优势的结果
- 简化→增长：简化运营模式释放出的资源才是增长的燃料，而非相反

**可被挑战**：在赢家通吃的网络效应市场中，速度本身就是战略——先增长再优化是理性选择（如 Uber、滴滴）。
