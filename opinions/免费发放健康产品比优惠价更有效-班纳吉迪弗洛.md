# 免费发放健康产品比优惠价更有效

**主张**：在健康领域（蚊帐、驱虫药、口服补液盐、疫苗等），免费发放比优惠价销售更有效——使用率最高、覆盖面最广、长期行为改变最显著。这推翻了"免费不被珍惜""优惠价培养责任感"的流行偏见。健康领域确实存在贫穷陷阱——小投入撬动大回报——而免费发放是把穷人推过临界点的最直接方式。

**反常识在哪**：常识被"施舍养懒汉"观念支配——莫约和埃斯特利认为免费发放蚊帐会让人不珍惜、不用、甚至让当地蚊帐供应商破产。班纳吉和迪弗洛援引RCT指出——**实证完全推翻这一论断**：免费得到蚊帐的人使用率与全价购买者相同甚至更高，且下次购买蚊帐的概率不降低。

**核心证据**：
1. **肯尼亚蚊帐实验（TNS）**：免费发放蚊帐的群体蚊帐使用率最高。疟疾传播严重地区睡在杀虫剂处理蚊帐中可将感染病例减少一半——半数人口睡蚊帐时另一半即使没睡感染概率也大大降低。
2. **使用率vs价格**：免费蚊帐的使用率与全价购买者相同甚至更高——推翻"免费不被珍惜"论点。优惠价蚊帐的使用率反而低于免费发放。
3. **驱虫药实验**：肯尼亚——免费驱虫药让学校出勤率大幅提升，效果持续多年。驱虫药成本极低（每人每年约0.5美元），但回报率极高。
4. **口服补液盐案例**：口服补液盐治疗腹泻脱水——成本几美分，但能挽救儿童生命。但普及率低，主要因为信息缺失和分发渠道不畅。
5. **疫苗接种实验**：免费接种+小激励（如一袋扁豆）大幅提升接种率。印度拉贾斯坦邦完成全部接种可领一袋扁豆——接种率从6%提升到38%。
6. **加纳驱虫+健康讲座对照**：单纯讲座效果差，免费驱虫药+讲座效果显著——免费产品本身是最强信号。

**机制——为什么免费比优惠价更有效**：
- **零价格效应**：行为经济学证实"零"是特殊价格——免费产品跨越心理门槛，优惠价仍需决策成本
- **临界点跨越**：健康产品有明显的S形回报曲线——免费发放让穷人立刻跨过临界点享受回报
- **网络效应**：蚊帐、疫苗等有正外部性——半数人使用让另半数人也受益，免费发放加速网络效应
- **行为惯性**：使用习惯需要先有使用——免费发放降低首次使用门槛，建立习惯后下次愿意付费

**推翻"优惠价培养责任感"的论点**：
- 实证显示：优惠价购买蚊帐的人与免费得到的人在使用上没有差异
- 优惠价反而筛选掉了最穷的人——他们买不起优惠价蚊帐
- "责任感"是中产阶级的投射——穷人不用蚊帐不是因为不珍惜，而是因为买不起或不知道
- 莫约的"蚊帐供应商破产"故事是个案——RCT大规模研究显示免费发放不损害当地长期供应链

**适用边界**：
- 适用于：高回报/低成本的公共卫生产品（蚊帐/驱虫/疫苗/口服补液盐/避孕套）
- 不适用于：需要持续投入的产品（如长期药物）
- 不适用于：需主动配合的产品（如完整疗程抗生素——免费发放反而增加抗生素滥用风险）
- 不适用于：高单价产品（如清洁炉灶——免费发放成本太高）
- 边界条件：免费发放需配套分发渠道和信息教育——单纯发放不够

**实践含义**：
- **国际援助**：优先免费发放高回报公共卫生产品——比大笔基础设施建设回报更高
- **政府卫生政策**：基础疫苗/驱虫/口服补液盐应完全免费——覆盖率达到群体免疫水平
- **NGO策略**：放弃"收点钱让人珍惜"的中产阶级偏见——直接免费发放更有效
- **企业CSR**：免费发放比"优惠价"模式更具成本效益

**可被挑战**：
- "免费不被珍惜"在某些非健康产品上可能成立——书籍/农具/小额信贷等场景实证显示优惠价更有效
- 免费发放的财政可持续性——长期依赖外援不可持续
- 政治经济学挑战：免费发放可能挤压本地企业，长期损害本地供应链
- 部分RCT显示优惠价蚊帐的使用率与免费蚊帐无差异——零价格效应可能被夸大
- 文化差异：在某些文化中免费产品被视为低质量——使用率反而更低
