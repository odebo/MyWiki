# 创始人首要任务是融资非产品

**主张**：早期创始人的首要任务是"保证现金流不断"——不是做产品、不是写代码、不是带团队——产品可以外包,团队可以慢慢建,现金断了公司立刻死。

**反常识在哪**：创业文化偏爱"产品导向"——乔布斯式的产品天才叙事让创始人以为"做好产品就能赢"。本书反转:99% 的创业失败不是产品失败,是现金耗尽——创始人的第一身份是"资本筹集者",产品是第二位。

**核心证据/论据**：
- **创业失败统计**：38% 的创业失败原因是"现金耗尽"——比"无市场需求"（35%）更高
- **现金断 = 立即死**：产品不好可以迭代,团队不行可以换,现金断绝无任何缓冲
- **融资周期长**：3-6 个月,必须提前准备——拖到现金 < 6 个月就来不及
- **奈特案例**：耐克 18 年间多次濒临破产,核心是奈特融资能力（日商岩井合作）救了公司,不是产品能力

## 反"产品天才"叙事

主流创业叙事偏爱乔布斯/马斯克式的"产品天才"——把创始人等同于产品经理。本书反驳:
- 乔布斯/马斯克是少数——他们的产品能力稀缺
- 多数创业公司不是产品失败,是现金失败
- 把创始人等同产品经理 = 把多数创业引向错误方向

## 融资能力的具体内涵

"融资"不是狭义的"找 VC",包括:
1. **VC 融资**——股权融资
2. **客户融资**——预付款、回款加速
3. **供应商融资**——账期延长
4. **银行融资**——信贷额度
5. **政府融资**——补贴、低息贷款

优秀的创始人能从五个渠道同时融资,而非只靠 VC。

## 与"产品驱动"文化的对话

当代创业文化鼓励"产品驱动"——做让用户爱的产品。本书论点:
- 产品驱动 ≠ 创始人亲自做产品
- 创始人可以招产品负责人
- 创始人不可委托的是融资
- 因为融资能力=个人关系,不可转移

## 局限性

**可被挑战**：
- 不同阶段不同——种子轮产品为王,B 轮融资为王
- 不同行业不同——硬科技产品为王,互联网融资为王
- "融资优先"可能让创始人忽视产品,导致"融资到位但产品烂"
- 早期创始人能力有限,要求"全能"不现实
- 乔布斯式反例确实存在——产品天才也能赢
