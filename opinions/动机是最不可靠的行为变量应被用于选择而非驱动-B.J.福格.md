# 动机是最不可靠的行为变量应被用于选择而非驱动

**主张**：动机呈波浪式涨落，无法可靠地维持行为；应该把动机用于"发现愿望和选择要做什么"，而不是依靠它驱动日常行为执行。

**反常识在哪**：主流自我提升文化把"提升动机"作为改变的核心——看励志视频、找使命感、逼自己感受紧迫性。福格认为这是错误的方向：动机高的时候你根本不需要靠它，动机低的时候靠它必然失败。

**核心证据/论据**：B=MAP方程中，动机是最难控制的变量，能力和提示才是设计可以稳定干预的变量。高动机时可以做困难的事（"动机高位时做大行为"），但日常习惯不能依赖这种状态。

**可被挑战**：对于某些人，外在使命感确实能产生持续的高动机状态（如马斯克式人物）。但这属于特殊情况，对普通人不适用。
