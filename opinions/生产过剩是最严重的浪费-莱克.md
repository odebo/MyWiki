# 生产过剩是最严重的浪费

**主张**：在丰田识别的八类未能创造价值的浪费中，**生产过剩是最严重的浪费**，因为其他浪费大多由其导致；批量生产方法最常导致生产过剩。

**反常识在哪**：传统制造业直觉认为"机器停止运转是浪费"、"员工与设备持续生产就是效率"。大野耐一指出这是根本错误——生产出尚未有订单的项目比让机器停下来更浪费，因为生产过剩会连锁引发存货、运输、瑕疵、过度处理等其他浪费。

**核心证据/论据**：
- **连锁反应**：任何作业步骤若生产超过顾客所需数量，必然导致下游存货增加——材料只是堆放在那儿等候进入下一个作业阶段
- **降低改善动机**：大批量缓冲存在时，"既然停工不会立即影响最后组装线，何必对机器进行预防性维修？"
- **隐藏瑕疵**：大批量生产出来的东西中可能隐藏着问题，堆放在那儿数周而未被发现；"既然可以丢弃瑕疵品，何必过度忧虑少数质量问题？"
- **悖论性见解**：
  - 许多情况下，最佳做法是让机器停下来，暂停生产
  - 最好建立最终成品某一存货水平，维持均衡生产进度
  - 让员工忙碌于尽可能快速地生产物料并不一定是最佳做法
- **拉动式生产是解药**：由下游顾客需求拉动上游生产，避免生产过剩——见 [[丰田模式14项原则-莱克|原则 3]]
- **加油站类比**：当车发出需要更多油料的信息时（下游工序），才会到加油站（上游工序）补货；当油箱还有足够汽油时根本不会去加油——但批量生产中这种"愚笨的做法"经常发生

**可被挑战**：
- 规模经济在某些行业（如化工、钢铁）仍然有效，批量生产不完全过时
- 生产过剩在某些场景（如预期涨价的投机性生产）可能是理性选择
- "拉动式生产"对供应链协调要求高，小企业难以实现
- 数字化时代可通过实时需求预测减少生产过剩，不必完全依赖拉动式
- 3D 打印等新技术使单件流成本接近批量生产，改变了浪费的定义
