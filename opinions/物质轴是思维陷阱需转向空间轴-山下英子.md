# 物质轴是思维陷阱，需转向空间轴

**主张**：人不收拾的深层原因不是懒，而是被困在"物质轴"思维里——以"物品有效性"判断去留，导致空间被物品反向殖民。断舍离的根本是认知重构：从物质轴迁移到空间轴。

**反常识在哪**：流行整理术都问"这东西还要不要"——这本身就是物质轴问题。山下英子把问题翻转为"这个空间想要什么状态"。前者把人当物品管理员，后者把人当空间创造者。

**核心证据/论据**：
1. **30 兆吨物质**：现代消费型社会物量洪水，居住空间却被设计为"考量不足"的次要项
2. **500 万年人类史**：人类卷入物质变化洪流，"有效性"vs"必要性"的判断被本能驱动
3. **"太可惜了"陷阱**：上个时代的节约价值观在物质过剩时代变成思维枷锁
4. **香鱼变鲇鱼隐喻**：水槽进水阀（断）松动、出水阀（舍）堵塞，储水槽变污水池——居所同样会因只进不出而腐败
5. **高野山体验**：山顶寺院寝房只有草席被褥，没有任何多余杂物——证明空间的力量来自"留白"而非"装备"
6. **物质带"黏着剂"**：物品进入空间后会附着看不见的情感和执念，反向塑造居者心理
7. **犯罪者居所**：警界人士观察——罪犯的家大多乱七八糟颓废不堪——居所"相"反映内心"相"

**可被挑战**：
- 物质轴并非纯然陷阱——在物质匮乏时代/贫困人群中，"有效性"判断是生存必需
- "空间轴"是中产以上阶层的审美特权——租屋/拥挤住宅中难有留白空间
- 因果方向不明确：是乱导致人颓废，还是人颓废导致乱？山下英子倾向于"乱导致颓废"但缺乏严谨证据
- "分形自相似"是隐喻而非科学机制——居所映射内心是诗意说法，不是因果
- 极简主义本身就是另一种物质轴——把"少"当作物质量目标，仍困在物质轴里

**与已有观点的对话**：
- 与[[出之美学-山下英子]]互为表里：空间轴是认知视角，"出"是实践动作
- 与[[反时间管理-诺顿]]对话：诺顿反对"时间管理=效率"的物质轴时间观，山下英子反对"整理=塞东西"的物质轴空间观——都是认知重构
- 与[[棱镜生产力-诺顿]]对话：诺顿的多面折射是空间轴式的工作观
- 与[[绿灯-麦康纳]]对话：麦康纳"自编剧本"是空间轴式的人生观——不被现成剧本塞满
