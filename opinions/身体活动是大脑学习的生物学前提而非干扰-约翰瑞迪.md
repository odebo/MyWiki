# 身体活动是大脑学习的生物学前提而非干扰

**主张**：运动不是学习的敌人，而是学习的前提条件。身体活动触发BDNF释放和神经新生，为大脑创建学习所需的分子环境。把体育课从学校砍掉，等于砍掉学生最佳的学习准备机制。

**反常识在哪**：传统观念认为体育课和文化课是零和竞争关系——多上一节体育课=少上一节数学课。但内珀维尔的实验证明，增加高强度体育锻炼反而显著提升学业成绩。

**核心证据/论据**：内珀维尔零点体育课学生阅读理解能力提高17%（vs对照组10.7%）。TIMSS科学测试世界第一、数学第六。BDNF机制的实验室证据。

**可被挑战**：内珀维尔的富裕人口结构可能是一个混淆变量。没有严格的随机对照实验证明因果关系。
