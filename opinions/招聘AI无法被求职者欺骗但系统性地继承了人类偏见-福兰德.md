# 招聘AI无法被求职者欺骗但系统性地继承了人类偏见

**主张**：AI视频招聘系统通过分析微表情、语音自然度和行为模式来评估候选人，无法通过改变说话内容来欺骗，但它系统性地继承了企业历史人事数据中的偏见（如偏爱年轻白人男性）。

**反常识在哪**：求职者以为可以通过精心准备的内容和假装的人格来"糊弄"AI，但实际上系统依赖于人无法有意识控制的微小肌肉运动和语音特征。同时，AI被宣传为比人类招聘员更公平——但亚马逊的测试中AI直接排除了女性候选人。

**核心证据/论据**：
- 作者亲自测试：录制了两个版本的视频（自然友善版vs高傲版），AI对性格特征的分析几乎一模一样，只有"外向"维度产生约10%的差距
- 制造商解释：软件通过分析面部微表情、语音自然度和正常流利程度来评估"可感知的性格特征"，准确率超过92%
- AI不能判断候选人在想什么或他是谁，只能判断他给人的感觉如何
- 亚马逊的测试失败：AI将表现最好的员工判定为30-40岁白人男性，系统性地排除了女性候选人——因为这是公司历史晋升数据中占优势的人群
- 德国70%的顶级企业认为未来将越来越频繁地使用自动化筛选系统

**可被挑战**：如果训练数据足够多元且经过去偏处理，AI评估可以消除人类招聘员不自觉的偏见（如偏爱与自己有同样性别、肤色或相似经历的候选人）。AI确实可以实现比单个招聘员更客观的评价。
