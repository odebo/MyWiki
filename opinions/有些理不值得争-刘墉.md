# 有些理不值得争

**主张**：投鼠要忌器。当你是小虾米碰上大鲸鱼，当你没实力却要争理，当打官司的成本远超过争回的利益——有些理不值得争。认赔杀出、息事宁人不是软弱，是看清楚成本和代价后的清醒。当先驱还是先烈，需要算账。

**反常识在哪**：常识认为"有理走天下"，理直就该气壮到底。刘墉反转——这世界有财阀、法匠、讼棍、白道养的黑道和黑道养的白道，只有理没实力的人难免吃亏。最有理和最有实力的人最有发言权，只有理却没实力的人难免吃亏。

**核心证据/论据**：
- 华人医生朋友：自认理直官司打到底，50万能和解的案子赔了91万
- 律师费每小时300美元，上一次庭3000美元——"和解算了吧！别争下去了"
- 刘墉自己打版权官司：赢了5万赔款，旅费+律师费远超，受寒重感冒躺了一个月
- 墓园修理纠纷：律师建议"找议员打电话"而不是告上法庭——"墓园给你点小动作，你防不胜防"
- "开车时闪躲路上每个小洞的人，出事率特别高"
- "白道养黑道，黑道养白道"
- "不是不报，时候未到"——只有忍一时之气，谋长远之计的人才会是最后的赢家

**计算成本的四个维度**：
1. **金钱成本**：律师费、旅费、误工费 vs 争回的利益
2. **时间成本**：官司三五年的拖累 vs 用这些时间创造的价值
3. **精神成本**：焦虑、失眠、家庭关系受损
4. **机会成本**：错过其他机会的代价

**与相关论点的关系**：
- 与 [[沉没成本-斯特曼]] 互补——已经投入的不该影响未来决策，但未来投入的也要算
- 与 [[斯多葛主义]] 同向——关注可控的，接受不可控的
- 与 [[阿喀琉斯之踵-刘墉]] 互补——阿喀琉斯之踵是被攻击的弱点，"有些理不值得争"是不主动暴露弱点
- 与 [[稳住不动-刘墉]] 一致——都是反冲动的智慧

**可被挑战**：
- 系统性不公（歧视、剥削）不应让个体承担"认赔"的责任——这种情况下"争理"是制度改进的起点
- "认赔杀出"的过度推广可能纵容作恶者——坏人就靠好人息事宁人
- 公益诉讼、集体诉讼的价值不能仅用金钱衡量—— precedents 的社会价值远超个案成本
- "实力"的判定本身有主观性——历史上很多"看似无实力"的一方最终赢了（民权运动、劳工运动）
