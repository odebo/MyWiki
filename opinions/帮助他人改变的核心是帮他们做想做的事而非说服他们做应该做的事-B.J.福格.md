# 帮助他人改变的核心是帮他们做想做的事而非说服他们做应该做的事

**主张**：有效帮助他人改变行为，只有两条原则：①帮人做他们已经想做的事；②帮人感受成功。试图说服他人做他们不想做的事，几乎必然失败。

**反常识在哪**：大多数"帮助"行为（父母帮孩子/管理者帮员工）本质上是"说服对方做我认为他们应该做的事"。福格认为这条路效率极低。正确的起点是：先找到对方**真正想要的愿望**，再设计行为去服务那个愿望。

**核心证据/论据**：埃米帮助女儿瑞秋案例——瑞秋多动症、不愿完成作业。埃米没有强迫，而是发现瑞秋真正的愿望是"和同学保持步调一致"，再围绕这个愿望设计了完成作业的微习惯。最终瑞秋六年级不再需要特殊教育，以优异成绩毕业。

**可被挑战**：在紧急/安全场景（如孩子危险行为），不能仅等待对方愿意，有时需要直接干预。另外，识别他人"真正想要的愿望"本身就很困难，容易投射自己的判断。
