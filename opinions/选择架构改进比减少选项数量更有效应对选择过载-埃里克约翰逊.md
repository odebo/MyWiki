# 选择架构改进比减少选项数量更有效应对选择过载

**主张**：面对选项过多的问题，解决方案不是减少选项，而是改进选择架构——好的选择架构可以让更多选项同时变得流畅和正确，其影响力是选项数量的3倍以上。

**反常识在哪**：流行的"选择过载"理论认为选项越少越好（"选择的暴政"），但元分析表明选择架构的积极调整可以完全消除选项增多带来的负面影响——显示计算结果（如年度总费用）可以让8选项的正确率和4选项一样高。

**核心证据/论据**：医疗保险实验中，加一列"年度总费用"使8选项的选择正确率不再低于4选项，平均每个家庭节省533美元。元分析（切尔内夫等人）：选择架构对决策的影响是选项数量影响的3倍多。德国汽车公司配置器中改变默认选项导致发动机均价差近800欧元。

**可被挑战**：选择架构改进在设计者有意误导选择者时（黑暗模式）可能被反向利用——更多选项配合恶意默认选项会加剧伤害。
