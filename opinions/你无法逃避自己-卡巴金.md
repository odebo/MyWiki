# 你无法逃避自己

**主张**：我们其实无法避开任何事情——你不想应对、努力逃避或掩耳盗铃的事情早晚会找上门来，特别是如果它们与你以往的行为模式、与你的恐惧相关的话。**不切实际的想法是，如果这儿不好，我就去那儿，然后一切都会不同**。但你没法逃避自己，再怎么努力也没用——你去哪儿，你的头脑和心灵也会跟着去哪儿。

**反常识在哪**：现代生活的默认模式就是"逃避"——换工作、换城市、换伴侣、换老师、换门派。卡巴金指出：**这是再常见不过的陷阱**。从长远来看，服药也好，冥想也好，酗酒也好，旅游也好，离婚也好，辞职也好——**你都不可能成功逃避自己**。你只能转变。

**核心证据/论据**：
- "身不在心在"——你以为换个地方一切就会好起来，但你的"气场"会如影随形
- 问题很大程度上起因于个人看待问题的方式、思考模式和行为举止——所以无论你躲到哪儿，同样的问题早晚还会出现
- 静修冥想的危险：可能演变成逃避现实生活，"转变"最终也可能仅是皮毛般肤浅
- "自光明"——释迦牟尼临终对信徒的点化，觉醒终究只能靠自己
- 与 [[至强则弱-卡巴金]] 内嵌——强者无须向自己或他人宣扬，逃避脆弱本身是逃避自己
- 与 [[当下即是-卡巴金]] 同源——逃避就是从当下逃向过去/未来/他处

**可被挑战**：
- 环境确实重要——有毒的关系/工作/城市改变后确实能让人重获新生
- 卡巴金不是反对改变环境，而是反对"以为换环境就能解决内在问题"的幻想
- 严重创伤（PTSD）确实需要先离开刺激源才能开始疗愈
- 卡巴金的回应：转变 ≠ 不改变外在，而是先接纳现状；逃避和转变的区别在于"是否直面"
- 反向论证：心理学"地理疗法"（geographical cure）的失败案例支持这一观点
