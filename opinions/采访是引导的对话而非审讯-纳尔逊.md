# 采访是引导的对话而非审讯

**主张**：采访是一次被引导的对话，不是填写问卷调查，也不是审讯；采访者像河流向导——有大致把握但不强行控制漂流路径，知道最佳出发地点、有信心应对意外、知道如何让船只平安靠岸。

**反常识在哪**：大众印象中"好的采访=尖锐问题+施压"或"好的采访=严格按大纲执行"。纳尔逊主张两者都错——前者把采访变审讯，后者扼杀即兴。真正好的采访是"确保你握有把控权，随时准备好迎接出乎意料的结果"。

**核心证据/论据**：
- **核心定义**："采访并不只是向一群随机的人提出一堆随机的问题。采访是一次被引导的对话。"
- **河流向导比喻**：
  - 每条河流有曲折的转弯、隐藏的石头、湍急的河水和倒塌的树干
  - 有经验的向导对此有大致的把握
  - 但漂流不一定会平稳又简单
  - 好的向导知道怎么让漂流者做好准备
  - 知道哪里是最佳的出发地点
  - 有信心应对意外状况
  - 知道如何让船只平安靠岸
- **东尼·坎波楼案例**：纳尔逊原本任务是采访海地眼镜项目，但坎波楼主动提起被踢出宗教大会的事——纳尔逊即兴调整："我们先用于海地项目，然后回到大会相关的疯狂事件上"——结果是更深的故事
- **伊拉·格拉斯论亲密**：采访目标是"拥有这样一个特殊的时刻"——"我会真的开始爱上他们"——这只有通过对话而非审讯才能达到
- **完整指引**："问开放式的问题，准备好绕一些弯路，拥抱沉默，不要去支配对话——但要确保你握有把控权"

**可被挑战**：
- 调查性报道（如水门事件）需要更接近审讯的方式
- 法律庭审中的"采访"本质就是审讯
- "被引导的对话"对采访者的判断力要求极高，新手难以把握
- 时间紧迫的短采访无法承担"绕弯路"的成本
- 与 [[尖锐与陷阱的边界-纳尔逊|尖锐问题]] 之间存在张力：何时引导、何时挑战需要经验判断
