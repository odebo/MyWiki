# 智商不是科学成功的关键

**主张**：尼斯贝特提出——**智商不是科学成功的关键**。智商160的科学家获得诺贝尔奖的可能性并不比智商130的科学家高。沃伦·巴菲特法则同样适用于科学家——成功是智力×教育×抱负×好奇心×努力工作×与人相处的能力的乘法函数，任何单一维度（包括智商）都不必太高，但任何维度太低都会"化为乌有"。

**反常识在哪**：常识认为"高智商=高成就"——智商测试预测科学能力。尼斯贝特反指——**智商超过一定阈值后，不再是成功的决定因素**。麦奎尔（智商超高）只小有成就；沙赫特（智商不如麦奎尔）工作更具成就。智商只是多维乘法的一项——其他维度（教育、抱负、好奇心、努力、合作）同等重要。

**核心证据**：
1. **智商与诺奖相关性**：尼斯贝特读到——智商160的科学家获得诺贝尔奖的可能性并不比智商130的科学家高。
2. **巴菲特法则**："你不需要成为火箭科学家。投资不是一场智商160的人打败智商130的人的游戏。"——尼斯贝特深信同样适用于科学家。
3. **巴菲特的极端说法**："如果你的智商是160，你还不如卖掉其中的30个智商点，因为你用不上它们。"
4. **麦奎尔vs沙赫特对照**：
   - 麦奎尔：超高智商，每周工作70-80小时——只得到不多的赞誉
   - 沙赫特：智商不如麦奎尔，每周工作40小时，暑假在阿马甘塞特工作半天——更具成就（1969年获美国心理学会杰出科学贡献奖）
   - 麦奎尔最著名的贡献是"接种"概念——但影响力远不及沙赫特的六项不同研究成果
5. **超智商低成就的普遍现象**："我知道一些智商测试超过160的科学家，但他们取得的成绩远远低于同领域中那些智商无疑比他们低得多的科学家。"

**汉斯·谢耶的乘法公式**：
- 科学上的成功 = 智力 × 教育 × 抱负 × 好奇心 × 努力工作 × 与人相处的能力
- 这些维度中的任何一个都不必太高
- 但如果其中任何一个维度太低，那么这一切都会化为乌有
- 启示：成功是多维乘法——单维优势不能单独决定结果，但单维短板可以毁掉一切

**麦奎尔vs沙赫特的深度对比**：

| 维度 | 麦奎尔 | 沙赫特 |
|------|--------|--------|
| 智商 | 超高 | 较高（不如麦奎尔） |
| 工作时间 | 每周70-80小时 | 每周40小时 |
| 工作风格 | 沉迷复杂性 | "至简是美" |
| 假设风格 | 椒盐卷饼形状 | 直线开始，按需修正 |
| 主要贡献 | "接种"概念 | 六项不同研究成果 |
| 影响力 | 不多的赞誉 | 1969年美国心理学会杰出科学贡献奖 |
| 学生评价 | 令人不悦 | 对学生有启发性 |

**"至简是美"vs"沉迷复杂性"**：
- 沙赫特："当我听到'三阶交互作用'这个词时，我就不想听了"
- 麦奎尔："如果宇宙是椒盐卷饼形状的，你就必须有椒盐卷饼形状的假设"
- 尼斯贝特反思："如果你的假设是椒盐卷饼形状的，那么宇宙最好也是椒盐卷饼形状的，否则你永远不会发现它是什么形状"
- 启示：简洁假设更易验证——复杂性可能是思维的奢侈

**"工作狂"的反思**：
- 麦奎尔（工作狂）vs 沙赫特（适度工作）
- "即使是智商极高的人，玩命干也不能保证一定能完成出色的工作"
- "那些仅仅是比较聪明的人，尽管工作时间适中，也能做得很好"
- "这一认识使我免于成为一个工作狂"
- 启示：努力时间不与业绩成正比——质量>数量

**阿莫斯·特沃斯基的工作风格**：
- "做好研究的秘诀是始终保持一点不务正业"
- 不务正业=好奇心驱动的探索——而非KPI驱动
- 启示：科学成功需要"不务正业"的空间——而非紧盯产出

**与稻盛"人生方程式"的呼应**：
- 稻盛[[人生方程式-稻盛和夫]]：思维方式×热情×能力
- 谢耶：智力×教育×抱负×好奇心×努力工作×与人相处的能力
- 共通：都是乘法公式——单维不能决定
- 区别：稻盛强调思维方式（可为负）；谢耶强调多维乘积
- 整合：思维方式（稻盛）+ 多维乘积（谢耶）= 完整成功模型

**与"卵巢彩票"的张力**：
- 多贝里[[成功不是你应得的卵巢彩票-多贝里]]：成功largely是运气（包括基因智商）
- 尼斯贝特：智商不是关键——其他维度同等重要
- 共通：都降低智商的绝对地位
- 张力：多贝里更强调运气；尼斯贝特更强调可习得维度
- 整合：智商是运气（多贝里对）；但智商不决定成功（尼斯贝特对）

**与"能力圈与痴迷"的呼应**：
- 多贝里[[能力圈与痴迷-多贝里]]：圈内1小时>圈外1000小时；痴迷是引擎
- 尼斯贝特：好奇心+抱负比智商更重要
- 共通：都强调专注与痴迷
- 整合：智商×痴迷×能力圈=真正的高效

**与"品格技能"的呼应**：
- 格兰特[[品格技能-格兰特]]：proactivity、fit-for-role、sacrificing for mission
- 谢耶公式中的"与人相处的能力"——属于品格技能
- 共通：都把非智商因素作为关键
- 整合：品格技能是科学成功的隐藏维度

**适用边界**：
- 适用于：科学事业、长期研究、创新工作
- 适用于：智商达到一定阈值后——边际效益递减
- 不适用于：智商极低的情况——基础认知能力必要
- 不适用于：纯数学等高度依赖抽象能力的领域
- 与"天赋领域"的张力：数学、物理等可能更依赖智商

**实践含义**：
- 不要追求智商最大化——超过阈值后回报递减
- 重视多维发展——教育、抱负、好奇心、努力、合作
- 警惕任何单一维度太低——短板毁掉一切
- 选择"至简是美"——而非沉迷复杂性
- 工作时间适中——而非玩命干
- 留出"不务正业"空间——好奇心驱动探索
- 寻找合作者——"与人相处的能力"是关键维度

**可被挑战**：
- **领域差异**：纯数学、理论物理等可能更依赖智商——尼斯贝特可能低估
- **阈值的位置**：智商阈值在哪？130？150？——尼斯贝特未明确
- **时代差异**：当今科学越来越依赖大规模合作——可能改变智商的重要性
- **方法论局限**：尼斯贝特的证据多为个案——大规模研究需要更严格
- **与卵巢彩票的真实张力**：智商本身是卵巢彩票——尼斯贝特需要承认运气
- **个体差异**：不是所有高智商者都会"玩命干"——个体风格差异大
- **诺奖不是唯一成功标准**：尼斯贝特用诺奖作为成功——但成功有多维定义
