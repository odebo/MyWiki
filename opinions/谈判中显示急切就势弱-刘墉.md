# 谈判中显示急切就势弱

**主张**：你太想要、太急、太见猎心喜，都会让你在谈判中势弱。古董大佬明明捡了漏还要还价，明明一眼看上小瓷瓶却顾左右而言他——隐藏真实意图是谈判的核心功夫。侵前是为了退让，说大人则藐之，谈判像跳探戈。

**反常识在哪**：常识认为"诚意"是谈判的基础，坦率表达需求能促进合作。刘墉反转——在谈判中显示急切就暴露底牌，让对方掌握主动。真正的高手是"见猎不心喜"，把想要藏在不想要里。

**核心证据/论据**：
- 古董大佬捡漏还价——"我不这么说，会对不起他啊"，避免对方后悔
- 声东击西——先问旁边的烂东西，一样样问，最后才"不经意"问到目标
- 商业订单：客户说20万箱立刻答应，对方隔天反悔；说"最少25万箱否则提单价"，胜券八成在你手中
- 张五常卖橘子树——故意安排另一摊在旁边，有比较才放心
- 美国野心政客——皮鞋不能太新也不能太旧，包装公司专门"磨"得恰到好处
- 接电话不能秒接——等响两声再装从容说"喂"
- "说大人，则藐之"——愈是跟自以为了不起的人说话，愈要表现得自信

**势弱的常见信号**：
- 接电话秒接
- 急着答应对方第一次报价
- 主动打电话次数过多
- 皮鞋太新、衣服太正式（应征时显得太想得到）
- 眼睛发亮一把抓起目标

**与相关论点的关系**：
- 与 [[锚定效应-特沃斯基]] 一致——先开高价锚定谈判区间
- 与 [[稀缺-西奥迪尼]] 同源——稀缺感需要隐藏急切
- 与 [[WYSIATI使人在信息越少时反而越自信-卡尼曼]] 形成对照——见猎心喜是系统1冲动
- 与 [[势弱与谈判心理学-刘墉]] 同源——势弱是症状，谈判心理学是机制

**可被挑战**：
- "诚意"在某些文化（如东亚）是建立长期信任的基础，过度隐藏反而损害关系
- 透明谈判（如哈佛谈判项目的"原则谈判"）主张把利益分开、聚焦共同点，与"隐藏意图"相反
- "势弱"模型适用于一次性交易，不适用于长期合作关系
- 信息不对称下的"势强"可能涉及欺诈——商业伦理边界
