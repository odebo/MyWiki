# 仅靠睡眠不足以解决疲惫

**主张**：数百万人睡得很好，但生活大部分时间仍然身心疲惫——睡眠是被动休息的基础，但**仅靠睡眠不足以让人重获活力**，必须配合四种主动休息。

**反常识在哪**：与"睡够就好"的大众直觉和睡眠书主流叙事对立。埃德伦德作为睡眠医生，自己承认曾以为问题只是睡眠不足，临床经验颠覆了这一假设。

**核心证据/论据**：
- 临床观察：成千上万病人睡得好但仍疲惫
- 睡眠只覆盖生理重建的夜间部分，白天 16 小时的疲劳累积无法被睡眠完全清理
- 主动休息可 30-60 秒即时生效，睡眠做不到
- 凯莉案例：改善睡眠后仍疲惫，引入主动休息才真正恢复
- 深度睡眠随年龄递减，65 岁健康男性可能完全失去深度睡眠——更需主动休息补足

**可被挑战**：许多慢性疲劳其实是未被诊断的睡眠障碍（睡眠呼吸暂停等），"睡得好"的主观判断不可靠；该命题可能低估了睡眠质量评估的复杂性。
