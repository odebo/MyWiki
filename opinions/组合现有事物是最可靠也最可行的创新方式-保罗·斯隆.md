# 组合现有事物是最可靠也最可行的创新方式

**主张**：许多伟大创意并非无中生有，而是现有事物的组合。古腾堡将铸币模具和酒榨机组合创造了印刷术，铁和锡组合创造了青铜——组合思维是提升创造力最可靠的方式之一。

**反常识在哪**：人们崇尚"从0到1"的原创，但历史上绝大多数突破性创新是"从1+1到10"的组合：带轮子的行李箱、发条收音机、便利贴（弱黏胶+书签）、闹钟（钟+铃）。

**核心证据/论据**：
- 古腾堡印刷术 = 铸币模具灵活性 + 酒榨机动力
- 斯玛特汽车 = 奔驰汽车工程 + 斯沃琪设计思维
- 帕瓦罗蒂与U2合作 = 古典+摇滚两种音乐的交叉听众
- Trunki儿童行李箱 = 带轮行李箱 + 儿童骑乘玩具

**可被挑战**：纯组合思维可能催生无意义的加法（feature creep）；真正改变世界的创新有时来自全新范式而非组合。
