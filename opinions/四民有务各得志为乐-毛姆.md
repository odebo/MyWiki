# 四民有务各得志为乐

**主张**：没有一种"正确的"生活方式适合所有人。每个人应该找到与自己的本性相符的生活——有人适合精神求索，有人适合物质享受，有人适合社交活动，有人适合平凡劳作。重要的不是"哪种生活最好"，而是"每个人是否在自己的位置上"。

**反常识在哪**：常人倾向于认为某种生活方式是"最好的"——成功人士、幸福家庭、精神导师——所有人都应该追求同一种理想。毛姆借嵇康《与山巨源绝交书》中的"四民有务，各得志为乐"颠覆这种统一标准——**不同的人有不同的"志"，各得其所才是乐**。

**核心证据/论据**：
- 毛姆借作者之口引用嵇康：
  > "四民有务，各得志为乐。"
  出自嵇康《与山巨源绝交书》——四民（士农工商）各有各的事务，各自能实现自己的志向就是快乐。
- 《刀锋》人物画廊正是这种多元幸福观的展示：
  | 角色 | 选择的生活 | 是否"得志" |
  |------|-----------|-----------|
  | 拉里 | 精神求索 | 是——最后得到解脱 |
  | 伊莎贝儿 | 物质享受 | 是——得到财富地位 |
  | 格雷 | 事业家庭 | 是——回归家庭得安慰 |
  | 艾略特 | 社交虚荣 | 部分——临终被遗忘 |
  | 索菲 | 自我毁灭 | 否——堕落被杀 |
  | 苏姗·鲁维埃 | 务实生存 | 是——成为画家夫人 |
- 毛姆的非评判立场：他不否定伊莎贝儿的物质选择，不否定格雷的平凡选择，甚至对艾略特的虚荣也有理解。他只是如实记录，让每个角色在自己的逻辑中"得志"。
- 与拉里对照的深意：拉里的精神求索不是"高于"伊莎贝儿的物质享受，只是"不同于"。如果伊莎贝儿强行追求精神生活，她不会得到解脱，只会得到痛苦——因为她不是拉里。
- 嵇康原文的语境：嵇康拒绝山涛的推荐出仕，理由是自己本性不适合官场。"各得志为乐"不是相对主义，而是**承认人的差异性**。

**可被挑战**：
- "各得志为乐"可能沦为相对主义——如果所有选择都一样好，何必追求卓越？
- 索菲的堕落被杀显然不是"得志"——毛姆的多元幸福观是否隐藏了价值判断？
- 现代社会的"个性选择"往往受制于经济条件——伊莎贝儿能选择物质享受，因为她有遗产；穷人可能没有"得志"的自由
- 与 [[不存在万能记忆法须因任务选择-弗莱]] 类比——弗莱论记忆法因任务选择，毛姆论生活方式因人选择，但这种类比是否掩盖了"生活方式"与"记忆法"的本质差异（前者涉及价值，后者只涉及效率）？
- 与 [[精神生活比物质生活更令人兴奋-毛姆]] 形成张力——如果精神生活更令人兴奋，为何又承认物质生活可以"得志"？毛姆是否在两种立场间摇摆？
  - 一种调和：精神生活的兴奋性是客观的（更高），但不是所有人都能企及；对于不能企及者，在自己能企及的位置上"得志"也是合理的。
