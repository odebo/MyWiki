# 减少决策比增加决策更重要

**主张**：决策是有限资源——决策疲劳下人会退化到拖延或轻率。最佳策略不是"做更多决策"，而是"减少决策数量"——把决策力集中在真正重要的事上。

**反常识在哪**：现代生产力工具都在卖"更多选择"——更多标签、更多视图、更多自定义选项。卡罗尔（借鲍迈斯特研究）指出——这些"选择"本身就是消耗。一个本子一支笔，反而胜过功能丰富的App——因为决策点最少。

**核心证据/论据**：
- **鲍迈斯特意志力研究**：决策与意志力共享资源池——用一点少一点
- **奥巴马/乔布斯/扎克伯格**：固定穿衣——不把决策力浪费在低重要事项
- **巴菲特25/5法则**：列25目标→圈5→剩20"应避免"——分心比无关更危险
- **卡罗尔对照**：App/电子日历分散在不同工具→决策点多→零乱；子弹笔记一个本子→决策点最少→专注
- **工具复杂本身是消耗**："你花了大把时间思索什么时段要干什么事"

**机制**：
1. 每个未决事项→持续消耗决策资源
2. 每个工具选项→决策点→消耗
3. 累积→决策疲劳
4. 疲劳→决策规避（拖延）或轻率决定
5. 关键时刻无资源可用→错误决策

**减决策的三层策略**：
1. **自动化**：高频低重要决策固定化（穿衣、饮食、记录位置）
2. **结构化**：用固定模板减少每次决策（集子、快速记录法）
3. **清理**：定期用思想清单+两问测验——批量删除无价值事项

**与"多选项=自由"的对照**：
- 现代误信：选项越多越自由
- 实际：选项越多越焦虑——"选择困难症"
- 子弹笔记哲学：**约束带来自由**——结构化限制决策，反而能在重要事上投入

**可被挑战**：
- 对创意工作者——过多的约束可能扼杀灵感
- 不同人格差异：高开放性者可能享受选择——而非被消耗
- 决策疲劳的强度因人而异——不能一刀切
- 某些领域（产品、设计）——多选项是创意的来源
