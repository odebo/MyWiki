# 天才之为责任是一种伦理姿态

**主张**：维特根斯坦的"天才"不是天赋才华，而是一种**伦理责任**——把自己的能力推到极限、不留情面地诚实、与自己本性战斗的强制倾向。罗素认可他的天才之后他才停止自杀念头，说明"是天才"对他是救赎性的伦理判断。

**反常识在哪**：与浪漫主义把天才视为恩赐的叙事对立。蒙克笔下的维特根斯坦，天才是负担、是任务、是必须自我证明才能确立的伦理事实——"仿佛他的一生是一场与他自己的本性进行的战斗"。

**核心证据/论据**：
- "撒谎对自己有利的时候，为什么要说实话？"——八九岁的两难预示了一生
- "称我为真之寻求者，我就满意了"——拒绝"大哲学家"标签
- 罗素认可其天才之前，维特根斯坦长期被自杀念头困扰
- 一生以一系列危机转变为界标，每次转变根源都归向自己
- 凯恩斯宣告"维特根斯坦有天才"后事情才定下来

**可被挑战**：把天才伦理化可能掩盖了真实的精神痛苦（维特根斯坦很可能有抑郁/孤独症谱系特质）；"战斗本性"的叙事是蒙克的解释框架，不一定是维特根斯坦本人的体验。
