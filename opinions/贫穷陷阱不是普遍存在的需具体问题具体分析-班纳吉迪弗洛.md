# 贫穷陷阱不是普遍存在的需具体问题具体分析

**主张**：贫穷陷阱并不是存在于每个领域——判断陷阱是否存在，关键不是理论立场（萨克斯大推论 vs 埃斯特利/莫约自由市场），而是曲线的形状；而形状只能通过具体领域的实证研究确定。找不到一个普遍适用的答案。政策制定者想弄明白的不是穷人陷入困境的100万种方式，而是"贫穷陷阱"形成的几个重要因素——通过缓解特定问题使穷人脱贫。

**反常识在哪**：常识被两极化立场支配——左派（萨克斯/联合国）认为穷人处处陷入陷阱需要大规模援助；右派（埃斯特利/莫约）认为穷人只是缺乏自由市场，无需援助。班纳吉和迪弗洛援引RCT研究指出——**两个立场都错了**，陷阱在某些领域确实存在（健康、教育、营养），在某些领域不存在（许多一次性补贴）。

**核心证据**：
1. **S形曲线 vs 反向L形曲线**：S形曲线代表陷阱存在——曲线低于对角线的区域穷人会越来越穷；反向L形曲线代表陷阱不存在——最穷的人也能挣到比原来更多的钱。仅靠理论不够，要回答"贫穷陷阱是否存在"必须了解现实世界能否由图表体现。
2. **蚊帐实验**：肯尼亚和马达加斯加——免费发放蚊帐的群体使用率最高，且下次购买蚊帐的概率不降低。这反驳了莫约"免费发放让人不珍惜"的论点。健康领域确实存在陷阱。
3. **驱虫实验**：肯尼亚——驱虫药让学校出勤率大幅提升，比免费餐更有效。健康陷阱在儿童发展领域特别明显。
4. **化肥实验**：肯尼亚西部肯尼迪案例——农民知道化肥的好处，但季节间无法储蓄所以买不起化肥。这是储蓄陷阱而非信息陷阱。
5. **现金转移实验**：马拉维——有条件（要求送孩子上学）和无条件现金转移对入学率效果相同。这表明在入学领域陷阱不存在——家长不需要被强迫。
6. **食品补贴的错配**：印度一半的小麦和三分之一的大米在运输途中"不知所踪"，但政府仍坚持原有政策，因为他们认为饥饿与贫穷紧密联系。但实证显示当今绝大多数穷人并非处于饥饿陷阱中。

**机制——为什么陷阱是局部的**：
- **临界点逻辑**：陷阱存在的领域有临界点——低于临界点的人会向下螺旋，高于临界点的人会向上累积
- **回报曲线形状**：陷阱存在领域的回报曲线呈S形——低收入时回报极低，跨过临界点后回报陡升
- **市场失灵**：陷阱常源于市场失灵——保险市场缺失、信息不对称、协调失败
- **门槛效应**：教育、健康、营养等领域有明显的门槛效应——一年教育vs三年教育的回报差异非线性

**陷阱存在 vs 不存在的领域对照**：

| 领域 | 陷阱是否存在 | 政策含义 |
|------|--------------|----------|
| 极端饥饿 | 在历史情境存在（埃塞俄比亚1984），当今多数地区不存在 | 食品补贴错配 |
| 疟疾预防 | 存在 | 免费发放蚊帐 |
| 驱虫 | 存在 | 免费驱虫药 |
| 疫苗接种 | 存在 | 免费接种+小激励 |
| 基础教育 | 部分存在 | 减少入学障碍（校服/课本） |
| 高等教育 | 不明显 | 一次性补贴够 |
| 小额信贷 | 不存在 | 单靠信贷无法脱贫 |
| 微型企业投资 | 边际存在 | 需配套培训/保险 |

**适用边界**：
- 班纳吉迪弗洛主要研究发展中国家绝对贫困——结论不能直接迁移到发达国家的相对贫困
- RCT的外部有效性有限——肯尼亚的结果未必自动适用于印度
- 陷阱存在与否可能随时间变化——经济发展可能让某些领域的陷阱消失

**实践含义**：
- **政策设计**：先RCT诊断陷阱是否存在，再决定是大规模补贴还是消除小障碍
- **国际援助**：放弃"大推论"或"自由市场"的两极立场，转向具体领域具体干预
- **慈善资源分配**：优先投入陷阱存在的领域（健康/教育/营养）——回报率最高
- **政策评估**：所有扶贫项目应嵌入RCT评估机制，避免资源浪费

**可被挑战**：
- RCT的伦理争议——随机分配意味着部分人得不到援助
- RCT的外部有效性——小规模实验成功的项目放大到全国层面常效果减弱
- 陷阱/无陷阱的二元划分过于简化——现实常是连续光谱
- 阿马蒂亚·森的"能力方法"批评：贫困不仅是收入低，更是能力被剥夺——RCT的视野过于狭窄
- 全球结构性因素（贸易不平等、气候殖民等）被班纳吉迪弗洛忽视——RCT擅长微观但不擅长宏观
