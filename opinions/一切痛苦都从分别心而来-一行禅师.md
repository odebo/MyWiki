# 一切痛苦都从分别心而来

**主张**：一切痛苦都从分别心而来。我们天然地认为跟孩子在一起比跟客户在一起有意思，陪孩子叫生活，讲课叫工作——这种"分别心"创造了痛苦。任何事本身没有自性（法无自性），是我们的分别心赋予了它们"快乐"或"痛苦"的概念。

**反常识在哪**：常识认为某些事本身就是快乐的（度假/陪孩子），某些事本身就是痛苦的（上班/洗碗）。一行禅师指出这是错觉——事物没有自性，是分别心制造了痛苦。同一个事件可以是别人的笑话也可以是你的痛苦（如500万炒成200万），区别不在事件，在你是否认为"我不应该承受"。

**核心证据/论据**：
- 樊登讲课 vs 陪儿子嘟嘟——认为陪孩子更好玩，则讲课时焦虑；焦虑来自分别心而非讲课本身
- 节日的悖论——期待完美旅行结果与男友吵架；陪孩子半个月快疯掉——分别心让"应该是快乐"成为痛苦
- 王阳明学生"我没时间修炼"——分别心把"判案"和"修炼"分开；王阳明回应：拒绝贪心/保持耐心/明辨之心都是修炼
- 樊登与柳传志对话——"求不得苦"vs"你认为不应该有痛苦的痛苦"——后者是更深的痛苦，源于分别心
- 苏格拉底面对死亡——"我去死而你们将活着；究竟谁更不幸，只有天知道"——无分别心
- 与 [[痛苦等于疼痛乘以抵抗疼痛不可避免但痛苦是可以选择的-梅格索尔特]] 同源——抵抗=分别心
- 与 [[放弃修正-情绪的空间而非解决方案-索科洛夫]] 互补——放弃修正即放弃分别心

**可被挑战**：
- 痛苦是真实生理反应——分别心不能消除疼痛
- 部分痛苦来自客观境遇（如丧亲/疾病）——不是"分别心"造成
- "无分别心"可能导致消极接受——对不公不义不再反抗
- 一行禅师的回应：觉知痛苦不是接受不公，是不被情绪劫持；分别心减弱后反而能更有效行动
- 王阳明"知行合一"=正念=无分别心——但王阳明同样积极入世
