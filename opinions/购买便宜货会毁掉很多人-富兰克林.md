# 购买便宜货会毁掉很多人

**主张**："购买便宜货,会毁掉很多人"（A cheap bargain ruins many）——便宜不是节省，而是隐性毁灭的开始。便宜货的隐性成本（维护、替换、效能损失、注意力分散）往往超过正品价格，反直觉地毁掉购买者。

**反常识在哪**：常识将"便宜"等同于"节省"——同样功能花更少的钱是理性的。富兰克林指出这是单价思维的盲区：单价低不等于总成本 低，便宜货的总成本（购买+维护+替换+机会成本）常常超过正品。

**核心证据/论据**：
- 穷理查原文："你不需要的东西,再便宜也是贵的"
- "花钱买你不需要的东西,不久就会被迫卖掉你需要的东西"
- 便宜货常伴随质量妥协——更早损坏、更频繁替换、累计支出超过一次购买正品
- 便宜货占用空间、注意力、维护时间,形成隐性占用
- Father Abraham演讲中,听众正是被拍卖场的"便宜"吸引而至——而富兰克林警告他们正是这种吸引力本身具有毁灭性

**可被挑战**：
- 现代大规模生产使许多便宜货质量不逊于昂贵品（如宜家家具、丰田汽车）
- 价格歧视与品牌溢价使许多"正品"价格虚高,便宜货并非总是低质
- 对低收入群体而言,便宜货是必要选择,而非可避免的错误——命题隐含中产阶级视角
- "便宜"与"贵"的判断需要信息成本,完美决策的成本可能超过便宜货的损失
