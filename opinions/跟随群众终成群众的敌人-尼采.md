# 跟随群众终成群众的敌人

**主张**：一直跟随着群众的人，有一天会成为群众的敌人。因为跟随群众是为懒惰得好，但群众比他更懒惰——群众一直向前不允许任何人站着不动，而他想站在原地不动。

**反常识在哪**：常识认为从众是安全的、合群的。尼采揭示从众者与群众的根本矛盾——从众者要的是懒惰的安逸，群众要的是不停向前。当从众者想停下时，他成为群众必须抛弃的累赘。

**核心证据/论据**：
- 从众者跟随群众是相信懒惰会得到好处
- 群众还不至于像他那么懒惰——群众一直向前
- 群众不允许任何人站着不动
- 从众者喜欢站在原地不动——这本身就违背群众逻辑
- "所有人都说话，但无物奏效"——群众吞没表达
- "所有人都说话，但无人愿意去理解"——群众拒绝理解

> 一直跟随着群众的人，当然也是群众的赞颂者，但是，有一天他会成为群众的敌人！因为他跟随群众，相信他的懒惰会得到好处；但他没有想到，群众还不至于像他那么懒惰！群众一直向前，不允许任何人站着不动！而他喜欢站在原地不动！

**可被挑战**：合作性、社会性是人类进化的优势，完全离群索居在生物学意义上不可行。尼采的论断适用于精神创造领域，不适用于日常社会协作。
