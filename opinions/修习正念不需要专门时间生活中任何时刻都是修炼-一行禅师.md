# 修习正念不需要专门时间生活中任何时刻都是修炼

**主张**：正念不是要在专门时间专门地点做的事情——洗碗/吃饭/走路/陪孩子/工作/会朋友/扫地/喝茶，生活中的任何时刻都是修炼机会。把生活、工作和修行分开是很难实现的。越南谚语：修行最难的地方是在家里，其次是工作中，再其次是寺庙里。

**反常识在哪**：现代"冥想"文化鼓励找专门时间——30分钟早晨冥想、周末禅修营、静修中心。一行禅师反其道而行：寺庙反而最容易（无干扰），家里最难（美剧/孩子/各种牵扯）——所以应该在日常生活里修习，而不是逃避到寺庙。

**核心证据/论据**：
- 艾伦的发现——把陪孩子时间当作自己的时间，结果"有了无限时间给自己"；分割时间制造痛苦
- 王阳明学生"我没时间修炼"——王阳明回应：判案时拒绝贿赂=修炼控制贪心，对说不清楚的当事人不烦躁=修炼耐心，复杂案情理出头绪=修炼明辨之心
- "砍柴是禅，担水也是禅"——禅宗传统
- 《正念经》："行走时，修行者应当觉知到他正在行走；坐下时...躺下时..."——任何姿势都是修炼
- 读体见月律师《毗尼日用切要》——穿衣/洗碗/如厕/叠被/担水/刷牙都有偈语
- 与 [[边角料时间-格拉宁]] 互补——柳比歇夫利用碎片时间，一行禅师把碎片时间变成修炼
- 与 [[时间统计法是向时间要时间的唯一方法-格拉宁]] 对话——柳比歇夫统计时间，一行禅师觉知时间
- 与 [[第二象限是质量象限必须在其中投入时间-柯维]] 共鸣——正念本身是第二象限活动，但能渗透所有象限

**可被挑战**：
- 专门时间确实有助于深度修炼——早起30分钟冥想有科学证据
- 完全否定专门时间可能让人放弃结构化练习
- 初学者需要安静环境才能开始
- 一行禅师的回应：32个练习中有"平躺全身放松"等专门练习——不是否定专门时间，是不让它成为唯一时间
- 与 [[正念注意力最低有效剂量-阿米希杰哈]] 对话——杰哈证明12分钟专门练习有效，但与日常嵌入不矛盾
