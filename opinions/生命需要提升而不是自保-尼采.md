# 生命需要提升而不是自保

**主张**：生命的基本天性旨在延展生命原本的活力，而非自保。**仅仅寻求自卫、自保之本能的人，只能说明他很苦恼，而且狠狠地拘禁了真实的生命**。过分注重自我保护，说明你只把自己当成一个弱者来看待。

**反常识在哪**：现代安全文化把"自保"视为理性，把"冒险"视为冲动。尼采颠覆——自保本能是生命力衰弱的征兆，生命应当追求提升而非苟安。

**核心证据/论据**：
- 生命力最弱的人最需要温和、平静、亲切的言辞和思想
- 弱者需要"排除恐惧的狭小禁锢空间"——逻辑学就是这种空间的产物
- 强者想陶冶别人，弱者走进大自然为沉迷自然、忘掉自身
- 谦虚、勤奋、和善、中庸——这些"善良"美德实为奴隶道德
- "你应"（服从）→ "我要"（英雄）→ "我是"（古希腊诸神）的精神层级

> 生命的基本天性，旨在延展生命原本的活力；过分注重自我保护，说明你只把自己当成一个弱者来看待。

**可被挑战**：在生存威胁真实的情境下（战争、饥荒、重病），自保是必要的前置条件，谈生命提升是奢侈。尼采的论断预设了基本生存已解决。
