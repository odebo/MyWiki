# 行为改变失败是设计失败而非意志力薄弱

**主张**：当人们无法建立好习惯或戒除坏习惯时，根本原因是行为设计出了问题，而不是本人性格软弱或缺乏意志力。

**反常识在哪**：主流文化把习惯失败归因于个人，用"缺乏自律""不够努力"等描述来定性。福格认为这是根本性的误解——如果依靠意志力，就说明设计失败了。

**核心证据/论据**：B=MAP方程（动机×能力×提示）解释了所有行为发生的条件。习惯失败通常是因为：缺少可靠提示、行为门槛太高超出当前能力、或依赖波动性极大的动机。这些都是设计变量，不是性格变量。

**可被挑战**：在极端情况（如成瘾、强迫症）下，行为改变确实需要医疗介入，单纯设计调整可能不够。另外，某些人的认知/情绪特质会使设计策略的效果存在差异。
