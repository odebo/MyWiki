# 坏战略不是没有战略而是积极采用了错误形式

**主张**：坏战略不等于"没有战略"，而是组织主动采用了具有明确特征的错误战略形式。空话连篇、无视挑战、目标代替战略、错误战略目标——这四个特征可以精确诊断坏战略。

**反常识在哪**：大多数人认为战略失败是因为"战略不够好"，但鲁梅尔特指出，绝大多数失败案例里，组织是有战略的——只是那个战略是坏的。识别坏战略的能力比制定好战略的能力更容易习得，且同样关键。

**核心证据/论据**：
- 硅谷图形公司案例：麦克拉肖提出"实现50%增长率"——有目标，有计划，但那是坏战略。结果：并购多家公司，工作站战略无法应对PC游戏技术变革，2006年宣告破产
- 目标代替战略的识别检验：把战略文件里的所有"实现X增长"类句子替换为"我们是如何克服X障碍的"——如果无法回答，就是目标，不是战略
- 空话检验：把行话替换成普通词，看剩下什么

**可被挑战**：有时候，高层次的愿景和目标在特定历史时刻（如公司危机、重大转型）能够凝聚人心、提供方向感，其价值超过精确的战略规划。坏战略四特征的批判更适用于相对稳定的竞争环境。
