# 改变观点应该让人感到喜悦而非羞耻因为这意味着学到了新东西

**主张**：被别人说服比说服别人更应该令人高兴——前者证明你学到了新东西，后者只是赢了一场辩论。

**反常识在哪**：文化中普遍认为改变立场 = 软弱、不坚定、墙头草。领导者被期待"有立场"，改变想法会被批评为"意志不坚定"。

**核心证据/论据**：
- 科学家 Changeux 和 Crick 争辩10小时后，被说服的那方走出去**更快乐**——他的身份是"追求真理的科学家"，被说服意味着更接近真理
- 超级预测者研究：最准确的预言者平均更新预测4次，普通分析师只更新2次；频繁更新不是立场不稳，是认知能力的体现
- 科学哲学：马克斯·普朗克说"一个新的科学真理并不是通过说服反对者获胜的，而是他们的反对者最终都会死亡"——代际更替比个人改变观点更快，说明文化阻力是真实的

**可被挑战**：
- 某些情境下，立场稳定确实有价值（如谈判、公众信任场景）——但格兰特区分的是"基于新证据的更新"vs"为保颜面的坚持"，前者任何情境都有价值
- 新纽约州长 Roosevelt 案例：他公开承认不确定性反而赢得了信任（大萧条时期的支持率），说明至少某些情境下表现出认知灵活性是政治优势
