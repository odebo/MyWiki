# 新媒体文案最小单位是3秒

**主张**：新媒体文案的最小结构单位不是句子而是 3 秒——因为用户的注意力切换周期就是 3 秒，任何超过 3 秒没有刺激的内容都会被滑走。

**反常识在哪**：传统文案训练把"句子"作为最小单位——好文案 = 好句子 + 好段落 + 好结构。这一默认认知在新媒体平台彻底失效——一段精心雕琢的 30 秒长句在抖音上等于 10 个流失窗口。文案训练的"修辞学"传统被算法打碎。

**核心证据/论据**：
- 抖音/快手算法的 3 秒完播率权重——前 3 秒未留住用户，视频直接不进推荐池
- 直播间用户停留数据——3 秒内无刺激点则滑走率超过 60%
- 短视频脚本结构分析——爆款视频 90% 在第 3 秒有钩子，第 6/9/12 秒有连续刺激点

**可被挑战**：
- 3 秒原则是平台算法的产物，若算法调整（如增加长视频权重），原则可能失效
- 知识类/深度类内容在 B站/小红书等平台仍以"段落级"为主，3 秒原则并非普适
- 长视频（10分钟+）的中腰部内容正在崛起，可能挑战"3 秒为最小单位"的极端判断
