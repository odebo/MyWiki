# 行动应先于反思

**主张**：收到反馈后应**先尝试应用再讨论反思**，而非相反。多数人的习惯是"练习-反馈-反思讨论-也许重练"，正确顺序是"练习-反馈-利用反馈重练（可能多次）-反思"。

**反常识在哪**：挑战"想清楚再做"的常识。多数人以为反思能让下次行动更明智，于是收到反馈后先讨论、辩驳、消化。莱莫夫指出反思可能成为**回避行动的工具**——讨论让人觉得在进步，其实只是把反馈丢进"耳旁风"档案。

**核心证据/论据**：
- **大卫和劳拉的会谈准备**：劳拉给反馈后，大卫没有先辩论"开门见山会不会让苏珊情绪激动"，而是立即从头排练。讨论建立在执行之后的反思上，而非执行之前的犹豫上
- **培训教室观察**：练习者被分成 8 人一组时，常陷于"我们刚才还在说，如果碰到这种情况你们会怎么做"的热烈讨论。讨论有价值，但必须在尝试反馈之后
- **"+Δ 模式"**：教师接受反馈后必须立即回到起点应用反馈——一分钟内重练。无法回避，因为六个同行同时听到反馈
- **反馈与接受者思路不合**：若反馈与接受者想法合拍，根本不需要反馈——所以反馈必然让人意外，"尝试后的结果才会让回顾和反思变得有意义"

**核心顺序对比**：
```
正确：练习 → 反馈 → 利用反馈重新练习（多次）→ 反思
错误：练习 → 反馈 → 反思并讨论 → 也许重新练习
```

**可被挑战**：
- 高风险情境（外科手术、战略决策）中，先反思再行动可能更安全
- 当反馈本身存在道德或方向性问题时，盲目尝试可能强化错误
- "行动先于反思"在技能训练中成立，在概念理解或价值观讨论中未必
- 某些人格类型（高反思型）需要先内部消化才能有效行动

**与已有知识的关联**：
- 与[[拖延靠习惯而非意志力-威林厄姆]]形成对话：威林厄姆指出"思考任务的不适感"导致拖延——大脑用"准备"和"计划"回避真正的执行。莱莫夫的"反思陷阱"是同一机制在反馈环节的体现——用"讨论"和"消化"回避"重练"的不适
- 两人共同启示：学习的敌人不是没有方法，而是大脑用看起来像学习的行为（重读/讨论/反思）替代真正学习（测验/重练/行动）
