# 语音助手默认女性声音强化了服务型性别刻板印象

**主张**：全球主流语音助手（Alexa、Siri、Cortana、中国百度和小米助手）全部默认使用女性声音，这在无形中向儿童和社会传递了"服务性工作属于女性"的错误信号。

**反常识在哪**：人们通常将女性语音助手视为中性技术选择，但实际上它反映了根深蒂固的性别偏见——研究显示人们偏好女性声音提供帮助、男性声音发表权威声明，这一区分将"服从"编码进了技术产品。

**核心证据/论据**：
- 联合国研究结论：助手系统因其服务属性使用女性声音，"在表达中展现出来的从属感清楚地表明了被编码进技术产品中的性别偏见"
- 20世纪90年代宝马在车载导航中首次使用女性声音，遭到男性司机的强烈抗议（"男人绝不会愿意让一个女人来告诉他们路要怎么走"），宝马被迫召回更换为男性声音
- 科幻电影的性别固化：专制和威胁性机器是男声（《2001太空漫游》HAL9000），服务型机器是女声（《星际迷航》机载计算机）
- 分析师认为，如果不是企业害怕用户联想到负面、邪恶的科幻计算机，会有更多男声
- 进展：已出现首个无性别声音"Q"，可以在男性和女性之间的细微差别中实现性别中立

**可被挑战**：制造商声称研究显示用户群体更喜欢女性声音，且女性声带在更高音调时振动更快，客观上更容易被理解。这是一个需求驱动的选择而非纯偏见。
