# 一个今天值两个明天

**主张**："一个今天值两个明天"（One today is worth two tomorrows）——同样单位的行动，今天执行的价值是明天执行的两倍。这不仅是反拖延的劝诫，而是对时间价值结构的本体论判断。

**反常识在哪**：常识将时间视为均质容器——明天的一小时与今天的一小时等价，差别只在内容。富兰克林指出时间是**带折现的**：明天的行动产生后天的结果，今天的行动产生明天的结果，因果链的提前一天使价值翻倍。

**核心证据/论据**：
- 今天行动者明天享受结果,明天行动者后天享受结果——时间优势累积
- 明天的不确定性使承诺价值打折（"明天再说"常变成"永不"）
- 行动产生反馈,反馈修正下一步行动——越早行动,反馈循环越多
- 复利效应：今天的行动进入复利累积,明天的行动少一天累积
- Father Abraham:"今天该做的事绝不要拖到明天"

**可被挑战**：
- 并非所有任务都适合立即执行——某些任务需要信息、资源、心智状态的成熟
- 过度强调今天可能导致冲动决策,忽视深思熟虑的价值
- "两个明天"的折现率因任务类型而异——战略决策与日常事务的折现率不同
- 凯恩斯"长期看我们都死了"的反命题：过度关注今天可能牺牲长期价值
