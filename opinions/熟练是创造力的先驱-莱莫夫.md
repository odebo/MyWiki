# 熟练是创造力的先驱

**主张**：创造力不来自天赋或灵感，而来自基础技能自动化后释放的认知空间。淋浴、开车、刷牙时脑洞大开，是因为身体在做习惯动作，大脑腾出空间产生创意。

**反常识在哪**：挑战"模仿压制创造力"的流行观念。许多人觉得一板一眼模仿示范是"剥夺自由、压制创意"，应该一开始就加入个人风格。莱莫夫指出这是本末倒置——只有先准确无误地复制示范、把技能练成习惯，才能为创造力腾出空间。

**核心证据/论据**：
- **约翰·克鲁伊夫**（荷兰足球教父）：创造力来自自动化技能——基础动作无需思考后，球员才能在比赛中即兴创造
- **失忆症患者电子游戏实验**（大卫·伊戈尔曼《隐藏的自我》）：失忆症患者无法记住游戏规则，但游戏技能却稳步提升——技能可以脱离显性记忆独立自动化
- **棒球击球案例**：球从投手到本垒只需 0.4 秒，而意识启动需 0.5 秒——击球者根本来不及"想"，全靠自动化反应
- **职业运动员的"不要去想"**：高水平表现反而要求停止显性思考
- **教师感悟**：练习让"怀着乐观心态教书育人"成为可能——课堂管理自动化后，教师才能关注学生的真实需求

**可被挑战**：
- 部分领域（纯艺术、概念创新）中，过早自动化可能固化思维模式，反而阻碍突破性创造
- "熟练生创造"在程序性技能（运动、演奏、教学）中最显著，在 declarative 领域（写作、研究）证据较弱
- 克鲁伊夫本人的创造力也可能部分来自天赋而非纯训练

**与已有知识的关联**：
- 与[[记忆三原则-威林厄姆]]的"记忆是思想的残渣"形成对话：威林厄姆指出思考的深度决定记忆强度，莱莫夫指出技能的自动化决定创造空间——两人都关注"什么被外包给习惯，什么保留给意识"
- 与[[练习成就恒定而非完美-莱莫夫]]互证：正因为练习使行动恒定，所以必须练正确的——错误自动化后释放的不是创造力，而是混乱
