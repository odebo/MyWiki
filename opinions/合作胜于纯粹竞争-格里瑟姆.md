# 合作胜于纯粹竞争

**主张**：在重复博弈中，合作策略（以牙还针：友好+强硬+宽容+明确）系统性地胜过纯粹的竞争或背叛策略；纯粹追求个人利益最大化反而导致次优结果。

**反常识在哪**：传统博弈论和流行文化都推崇"竞争理性"——强者通吃，先发制人，永远不要先合作。格里瑟姆借用阿克塞尔罗德的囚徒困境计算机锦标赛颠覆这个信念：在重复博弈中，**最自私的策略不是最聪明的策略**。以牙还针既不首先背叛（友好），又立即报复（强硬），还愿意原谅（宽容），且策略透明可识别（明确）——这种"合作的强硬派"在两轮锦标赛中均胜出。

**核心证据/论据**：
1. **囚徒困境的悖论**：双方背叛是单次博弈的纳什均衡，但双方都得到次优结果——纯粹理性导致集体非理性
2. **阿克塞尔罗德锦标赛**：两轮计算机锦标赛，以牙还针策略均胜出——击败所有"更狡猾"的策略
3. **以牙还针四特征**：友好（不首先背叛）+强硬（被背叛立即报复）+宽容（对方回归合作立即恢复）+明确（策略可被对手识别）——四个特征缺一不可
4. **未来阴影**：合作的可能性取决于双方预期未来还会相遇——未来阴影越长，合作越可能。商业长期合作、邻里关系、国际外交都符合此规律
5. **集群效应**：合作者即使在群体中是少数，只要彼此相遇概率足够高，就能在群体中扎根并扩散——合作可以自我维持
6. **伯南克火灾类比2008金融危机**：各家银行"理性"自保（不合作）导致流动性枯竭，全行业受损——纯粹竞争的系统性失败

**可被挑战**：
- 单次博弈中背叛仍是理性选择——合作优势仅在重复博弈中成立
- 当一方拥有压倒性力量时，合作未必是最优（不对称博弈）
- 以牙还针对"噪音"敏感——一次误判可能引发无限报复循环（需加入"宽容概率"修正）
- 阿克塞尔罗德锦标赛是简化的理论模型，真实世界的不确定性远超模型
