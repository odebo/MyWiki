# 冲突无法消除但可以建设性地处理

**主张**：幸福婚姻和不幸福婚姻都存在冲突，区别不在于有无冲突，而在于处理方式。不幸福的伴侣关注保护自己而非解决问题，使用"你"语言、缺少同理心、不仔细倾听。幸福的伴侣承认意见不一致是正常的，使用知觉检核理解对方视角，愿意承认错误。

**反常识在哪**：流行观念认为"好的关系没有冲突"或"沟通好的人不吵架"。但实际上朋友之间平均每天有1-2次分歧，冲突在所有关系中必然存在。冲突本身不是问题，处理方式才是。

**核心证据/论据**：
- 几十年研究表明，幸福和不幸福婚姻都会存在冲突，处理方式截然不同
- 不幸福伴侣用"破坏性"吵架：保护自己、很少或没有同理心、"你"语言、忽视关系向度信息、不仔细倾听
- 幸福伴侣：尽管可能激烈争论，但使用知觉检核找出对方想法、让对方知道自己理解对方角度、愿意承认错误
- 破坏性冲突模式导致各方身心健康状况不佳
- 冲突定义的五个特征：表达出来的斗争、相互依赖、感知到互不相容的目标、感知到资源短缺、必然性

**可被挑战**：在高情境/集体主义文化中（如许多亚洲国家），回避和迁就被视为保留面子和处理冲突的高尚方法，而非破坏性应对。冲突处理风格的文化差异不应被病理化。
