# 一页纸的本质是"让工作不停滞"而非格式美观

**主张**：一页纸的真正价值不是"做得漂亮"，而是"让停滞的工作动起来"——只要不停笔地把混乱写进 16 格，下一步线索会自己浮现。

**反常识在哪**：多数人把一页纸当成"成果物的美观标准"，先在脑中想好完美结构再下笔；浅田卓认为这恰是工作停滞的根源。一页纸是"启动器"而非"装饰品"。

**核心证据/论据**：
- 浅田卓在丰田月加班 400 小时——用 Logic 3 把每个停滞的工作写出来后，加班降至 0
- "不停笔就能看出下一步该做什么"——蓝笔填关键词时不必思考优劣，红笔圈出 3 个重要项后路径自然显现
- 丰田社长"3 秒决断"——一页纸的存在是为了让上司能在 3 秒内拍板，而非让下属展示排版技巧
- "现地现物"理念——"无论如何先填写"训练观察事物本身的能力，避免在脑内空转

**可被挑战**：
- 对外展示场景（提案书/融资 BP）格式美观确实重要，一页纸的"启动"功能不替代"打磨"
- 创意类工作（设计/写作）的停滞可能源于灵感缺失而非信息混乱，此时一页纸未必能撬动
