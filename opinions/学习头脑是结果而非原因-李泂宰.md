# 学习头脑是结果而非原因

**主张**："学习头脑是天生的"是世俗谬误——学习头脑是被成绩反向定义的标签，而非先天天赋。成绩好就被称赞有学习头脑，成绩差就被说成没有学习头脑，这是循环论证，不是因果分析。

**反常识在哪**：主流观念将"聪明""学习头脑"视为先天特质，决定学习成就。李泂宰指出这是归因颠倒——人们是在看到成绩后反向赋予"学习头脑"标签，但误将标签当作原因。这一颠倒使失败者放弃努力（"我没学习头脑"），成功者忽视努力价值（"我天生聪明"）。

**核心证据/论据**：
- 李泂宰亲身经历：高中前从未被夸聪明，考上知名大学后被赞叹"头脑聪明"——同一人，标签随成绩变化
- 哥哥五次复读考医大：前四次失败时无人期待，第五次成功后被认为"聪明"——"聪明"源于无数次血汗努力
- 世俗观念的循环论证：成绩好→有学习头脑→努力就能考好；成绩差→没学习头脑→不努力
- 韩国公务员九级考试41:1竞争率——按平均投入时间备考，希望甚微，需超额努力
- "聪明"的医生们实际付出无数血汗努力——"聪明"是努力的可见结果

**可被挑战**：
- 认知科学显示工作记忆/智商存在先天差异（如IQ测试的遗传度约0.5）
- 完全否认先天差异可能使部分学习者（如有学习障碍者）无法获得适当支持
- 哥哥案例可反向解读——五次复读才考上，恰恰说明天赋不足需要超常努力
- "学习头脑"作为激励工具：相信天赋可使人更早投入努力（自我实现的积极面）
