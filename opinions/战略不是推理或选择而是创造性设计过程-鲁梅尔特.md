# 战略不是推理或选择而是创造性设计过程

**主张**：战略制定不是从备选方案中挑最优的那个，也不是从框架中演绎出答案。战略是一种创造性的设计行为——你需要先诊断挑战，然后设计出应对方案。

**反常识在哪**：MBA教育和咨询行业把战略变成了一套标准化分析工具（SWOT/五力/BCG矩阵），但鲁梅尔特认为这些工具只能描述现状，不能产出战略。真正的战略来自"设计"——创造性地构造出原本不存在的应对方案。

**核心证据/论据**：
- 邓小平的改革开放：不是从"社会主义vs资本主义"中二选一，而是设计了第三条路
- Marvel 转型：不是接受"漫画行业衰退"，而是诊断出"IP资产被困在错误商业模式中"并设计了电影宇宙方案
- 所有伟大战略（SpaceX可回收火箭、iPhone触控界面）都不是分析框架的产物，而是设计思维的产物

**可被挑战**：设计思维的不可复制性意味着战略质量高度依赖个人天赋，难以组织化和规模化。
