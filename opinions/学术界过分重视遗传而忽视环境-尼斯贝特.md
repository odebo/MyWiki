# 学术界过分重视遗传而忽视环境

**主张**：尼斯贝特提出——20世纪末关于智力的学术共识在很大程度上是错误的：**学术界过于看重遗传因素而忽视环境因素**，没有认识到基因与环境交互作用的重要性。强调智商类型的才能而忽略宝贵的认知技能和知识也是错误的。关于"白人和黑人在智商方面存在差异，基因扮演重要角色"的结论是**绝对错误的**。智力不是先天彩票，而是基因与环境持续交互的可塑产物。

**反常识在哪**：常识（也是当时学术共识）认为"智力largely由基因决定"——智商测试测量先天能力。尼斯贝特反指——**这是错误的共识**。基因提供倾向，环境决定表达；基因×环境交互才是智力的真实图景。强调智商型才能而忽略认知技能和知识是双重错误。

**核心证据**：
1. **学术共识的检讨**：尼斯贝特自陈"我开始相信，20世纪末关于智力的共识在很大程度上是错误的"——这是内部人的反思。
2. **干预措施的有效性**：致力于在学生与学术环境之间建立联系的干预措施，能有效提高少数族裔和工薪阶层家庭学生的学习成绩——反证"智力=先天"。
3. **密歇根大学的非评判性环境**：合作环境本身放大个体能力——证明环境对智力表达的塑造。
4. **大鱼小池塘效应**：环境塑造智力自我认知，进而影响实际表现——环境不只是一个舞台。
5. **白人黑人智商差异的基因解释被推翻**：尼斯贝特明确说"绝对错误"——这是科学共识的转变。

**机制——为什么学术界过度重视遗传**：
1. **方法学偏差**：双胞胎研究、家谱研究易于测量遗传度，环境因素难以量化
2. **意识形态便利**：遗传解释为不平等提供"自然"理由——支持现状
3. **简化偏好**：单因解释比交互解释更易传播
4. **历史惯性**：20世纪初智商测试运动的影响持续
5. **出版偏差**：遗传研究易于发表；交互研究难做、难发表

**基因×环境交互的真实图景**：
- 基因不决定——只提供倾向
- 环境激活——决定哪些基因表达、如何表达
- 反馈循环——基因影响环境选择，环境影响基因表达
- 时机敏感——环境作用有窗口期
- 非线性——环境微小差异在某些基因背景下放大

**与"卵巢彩票"的张力**：
- 多贝里[[成功不是你应得的卵巢彩票-多贝里]]：成功largely是运气（出生国家、时代、基因）
- 尼斯贝特：基因重要但环境×努力可塑——智力不是固定彩票
- 共通：都承认起点不平等
- 张力：多贝里更强调运气决定上限；尼斯贝特更强调可塑性
- 整合：基因是起点（多贝里对）；但起点不决定终点（尼斯贝特对）——基因×环境×努力

**与稻盛"将来进行时"的呼应**：
- 稻盛[[能力要用将来进行时-稻盛和夫]]：能力在未来一定会提高
- 尼斯贝特：智力可塑，环境+努力可改变
- 共通：都拒绝能力固定观
- 区别：稻盛从工作哲学角度；尼斯贝特从科学证据角度

**与格兰特"品格技能"的呼应**：
- 格兰特[[品格技能-格兰特]]：品格技能可学
- 格兰特[[隐藏的潜能-格兰特]]：潜能隐藏待开发
- 尼斯贝特：认知技能和知识宝贵——不仅智商型才能
- 共通：都强调非智商因素的可习得性

**对教育的启示**：
- 早期干预杠杆率高——窗口期投资
- 环境设计能放大或压缩基因潜能
- 不应用单次智商测试定义学生
- 重视非智商认知技能的培养

**对政策的启示**：
- 起点不平等需要补偿——而非"自然"接受
- 教育投资是智力发展杠杆——不是慈善
- 警惕"基因决定论"被用作不平等的正当化
- 支持弱势群体不是"恩赐"——是补偿结构性不平等

**适用边界**：
- 适用于：教育政策、人才培养、个人成长
- 适用于：早期干预——窗口期杠杆率高
- 不适用于：否认个体基因差异——基因确实影响倾向
- 不适用于：极端环境决定论——环境也有边界
- 与"成长型思维"配合：相信能力可发展+提供支持环境

**实践含义**：
- 不要用单次智商测试定义一个人
- 重视环境设计——非评判性、合作性、跨学科
- 早期干预杠杆率高——投资儿童教育
- 警惕"基因决定论"——它是放弃努力的借口
- 政策上支持弱势群体——补偿起点不平等
- 重视非智商认知技能——好奇心、合作、坚持

**可被挑战**：
- **行为遗传学证据**：双胞胎研究显示智商遗传度较高（约50-80%）——尼斯贝特可能低估
- **基因-环境交互的复杂性**：交互作用难以实证——尼斯贝特的强主张需要更强证据
- **跨群体差异的解释**：尼斯贝特否定基因解释——但环境解释也需要严格证据
- **文化差异**：不同文化对"环境"定义不同——尼斯贝特基于西方教育环境
- **被滥用为"努力万能"**：环境可塑性不等于"努力就能改变一切"
- **与卵巢彩票的真实张力**：多贝里有道理——尼斯贝特需要承认运气的边界
- **个体差异**：可塑性在不同个体间差异巨大——不是所有人都同等可塑
