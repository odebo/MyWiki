# 空袋站不直：诚实需要物质基础

**主张**："空袋站不直"（An empty bag cannot stand upright）——让一个穷人总是诚实不是容易的事，诚实不仅是意志问题，更是物质条件问题。贫穷本身就剥夺了人维持诚实的能力。

**反常识在哪**：主流道德观将诚实视为意志品质——只要想诚实就能诚实，无论贫富。富兰克林指出这是中产阶级偏见：当物质匮乏到一定程度，诚实所需的心理资源（安全感、未来预期、可承受的损失）被系统性剥夺，意志无法补偿。

**核心证据/论据**：
- 历书原文："让一个穷人总是诚实可不是一件容易的事"
- 贫穷创造持续性焦虑，焦虑侵蚀决策带宽（参见森德希尔·穆来纳森《稀缺》）
- 负债者更可能撒谎以延缓催讨（见 [[债务即奴役-富兰克林]] 中"谎言骑在债务的背上"）
- 极端贫困下,诚实可能意味着家人挨饿或失去住所——道德成本超出可承受范围

**可被挑战**：
- 存在大量反例——赤贫者保持诚实的案例（如托尔斯泰《穷人》中的渔夫夫妇）
- 倒推逻辑危险：若诚实需要物质基础，则富人应更诚实,但事实并非如此（金融诈骗多出自富人）
- 真正的诚实或许正在物质压力下仍坚持——否则"诚实"只是舒适环境的副产品,不构成美德
- 道德责任不应被经济条件免除，否则等于否定穷人的道德主体性
