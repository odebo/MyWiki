# 战略不是管理质量战略不是财务结果三者各自独立

**主张**：战略、管理和财务结果是三个独立的东西，混淆它们是战略失败的主要原因。好管理不能替代好战略，财务表现好不等于战略正确。

**反常识在哪**：企业界习惯用"提升管理"或"改善财务指标"来替代战略思考。鲁梅尔特系统论证了这三者之间的独立性——你可以管理得很好但战略错误（诺基亚），也可以财务漂亮但战略空洞（靠成本削减撑利润）。

**核心证据/论据**：
- 麦克纳马拉在福特和国防部的管理革命——卓越的管理系统，但越南战争的战略失败无法用管理弥补
- "90天赛马"：许多公司用短期财务竞赛替代战略思考，导致长期竞争力丧失
- DelKha 案例：管理层把战略问题当成管理问题来处理——优化流程而非解决根本挑战

**可被挑战**：在成熟行业中，管理效率本身可能就是唯一的竞争优势来源，此时管理=战略。
