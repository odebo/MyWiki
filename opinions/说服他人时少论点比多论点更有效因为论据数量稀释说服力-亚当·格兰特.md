# 说服他人时少论点比多论点更有效因为论据数量稀释说服力

**主张**：在试图改变他人想法时，列出更多论点会降低说服效果。只使用最强的2-3个论点，放弃其余所有的。

**反常识在哪**：直觉认为"论据越多越有说服力"——更多证据 = 更强支持。辩论培训通常也强调多找论据。

**核心证据/论据**：
- 论据稀释效应（Argument Dilution Effect）：加入一个弱论点会拉低强论点的平均说服力
- 听众注意力有限：多论点给对方提供了更多反驳入口，他们会抓住最弱的那个来否定整体论证
- IBM Project Debater 研究：最有说服力的辩手使用的独立论据数量最少，但每个论据的质量最高
- 实验数据：向潜在捐款人列出多个慈善原因，比只列最强一个原因的捐款率更低

**可被挑战**：
- 某些场景需要提供完整证据（学术论文、法庭辩护）——稀释效应主要发生在**说服性对话**中，而非系统性证据陈述
- 与专家沟通 vs 与普通人沟通可能有差异——专家能筛选论据质量，普通人更容易被平均质量影响
- 群体决策场景中，多论点可能更好，因为不同成员被不同论点打动
