# 内阻力是普世存在的破坏力而非懒惰

**主张**：拖延、逃避、自我破坏不是个人品德的缺陷（懒惰/缺乏意志力），而是一种普世的、近乎形而上的破坏性力量——内阻力（Resistance）——的体现。每个想从低领域向高领域运动的人都会遭遇它，与品德无关。

**反常识在哪**：常识说"做不到=懒/没毅力/不够努力"，所以解决方案是更努力、更自律、更鞭策自己。但普莱斯菲尔德断言——内阻力是普世的、非个人的、形而上的力量，把它当作品德问题是误诊，更努力鞭策自己只会让内阻力更强大（因为你越在乎，它反扑越猛）。

**核心证据/论据**：
- **单向设障现象**：没人想戒酒会感觉内阻力阻拦，没人想放弃写作去打游戏会感觉内阻力阻拦——内阻力只阻挡向上运动，从不阻挡向下堕落。如果它是懒惰，应该双向均匀分布。
- **终点线前最猛**：项目越接近完成，反扑越疯狂——作家最后三章会突然想打扫车库。这不符合"懒"的模式，懒应该在开头，不会在快成功时。
- **希特勒案例**：希特勒曾想成为艺术家，但内阻力击败了他——"面对空白画布比发动二战还难"。如果内阻力是品德问题，难以解释这种极端案例。
- **普莱斯菲尔德本人**：27年才出版第一本小说，期间在11个州打过21份工作——这不是懒，是被强力阻挡。
- **恐惧作为指南针**：你越害怕的项目对你的成长越重要——这种"恐惧与重要性正相关"的模式，无法用懒惰解释。

**可被挑战**：
- "内阻力"作为形而上的力量无法被实证——可能是把复杂的心理现象神秘化了
- 心理学可以用"损失厌恶""未来折扣""任务回避"等机制解释同样的现象，无需引入新概念
- 把内阻力普世化可能削弱个人责任——"不是我懒是内阻力"——但普莱斯菲尔德明确反对：内阻力存在并不意味着你不该工作，反而要求职业态度
- "内阻力"可能是对抑郁/ADHD/焦虑等临床问题的浪漫化描述

**实践含义**：
- 不再道德化地鞭策自己
- 把内阻力当成可观测的信号——它越强，说明项目越重要
- 用职业姿态（每天出现）对抗，而不是用意志力对抗
- 不与内阻力对话，直接行动
