# 穷人与我们几乎一样只是资源更少

**主张**：穷人几乎在所有方面都和我们一样——他们做选择时非常谨慎，为了生存都需要成为精打细算的经济学家。贫困不是道德缺陷、不是文化落后、不是认知不足——贫困是资源约束的结果。把穷人贬低为固定形象（懒惰/愚昧/短视）是扶贫政策失败的根源。理解穷人的最好方式是承认他们与我们一样，只是每天只有99美分可以支配。

**反常识在哪**：常识被"穷人特殊论"支配——穷人被描述得有时懒惰、有时上进、有时高尚、有时鬼祟、有时愤怒、有时顺从、有时无助、有时自强。班纳吉和迪弗洛指出——**这些矛盾形象本身就是问题**：穷人的出场通常只是作为某种励志剧或悲剧的主人公，而不是某种知识的传播者，人们不会向他们咨询其想法或计划。

**核心证据**：
1. **99美分生活约束**：在全球穷人最多的50个国家，平均贫穷线为每人每天99美分（购买力平价）。要在迈阿密或莫德斯托每天只靠99美分生活——这点钱在印度只能买15根小香蕉或3磅劣质大米。
2. **穷人是精打细算的经济学家**：穷人在作选择时会非常谨慎——为了生存，他们都需要成为精打细算的经济学家。多个机构不是为你这样的人而建的——大多数穷人都没有收入来源，更不用说基于自动缴纳的福利。
3. **网络互借的复杂金融**：每个普通家庭与平均2.5个其他家庭存在借贷关系——穷人构建了复杂非正规金融网络应对风险。
4. **多职业对冲策略**：穷人家庭常同时从事农业、非农业、零工多种工作以分散风险——这是金融理论中的对冲策略，穷人自发实践。
5. **信息约束而非认知缺陷**：每天99美分的生活意味着接收信息渠道受限——报纸、电视和书籍都要花钱来买。穷人不知道蚊帐/疫苗的好处不是认知不足，而是信息渠道缺失。
6. **摩洛哥希达案例**：拒绝贷款多买牛的希达并非甘于贫穷——他骄傲于一个儿子在接受护士培训。希达的选择与中产阶级对孩子的教育投资逻辑完全相同。
7. **徐爱华案例**：浙江绍兴的徐爱华从借扩音器招生做起——8年固定资产增长100多倍。她的企业家精神与硅谷创业者无异，只是起点不同。

**机制——为什么"几乎一样"**：
- **同样的决策模式**：穷人在不确定条件下的决策与普通人无异——都权衡成本收益、考虑风险、为未来投资
- **同样的偏好结构**：穷人也希望孩子过得更好、希望有稳定工作、希望被尊重——这是普世价值
- **同样的认知偏差**：穷人也有时间不一致、乐观偏差、过度自信——但容错空间小让偏差后果更严重
- **同样的社会性**：穷人也会举办奢侈婚礼葬礼以维持社会地位——南非葬礼花费让家庭陷入财务困境，但这是社会资本投资

**资源约束如何放大问题**：
- **小花费变大问题**：被我们忽略的小花费、小障碍、小错误，在穷人的生活中却成了尤为突出的问题
- **零容错空间**：中产阶级一次感冒不工作一周无伤大雅，穷人一周不工作可能让孩子辍学
- **认知带宽税**：贫穷占据大量心理资源——穆莱纳桑和沙菲尔研究显示贫穷等效降低13点智商
- **风险叠加**：穷人面对多重风险（收入/健康/气候/政治）叠加，单一冲击可能引发崩溃

**与"穷人特殊论"的对照**：
- **文化论**：穷人有"贫困文化"——班纳吉迪弗洛实证反驳：穷人的决策模式与中产阶级相同
- **基因论**：穷人是"劣等基因"——徐爱华等案例反驳：给机会穷人能成为卓越企业家
- **道德论**：穷人懒惰/短视——希达等案例反驳：穷人的"短视"是资源约束下的理性选择
- **认知论**：穷人不会做长期规划——反驳：穷人做长期规划的难度比中产大几个数量级

**实践含义**：
- **扶贫设计**：把穷人当作理性的决策者——理解他们的约束和偏好，而非说教他们"应该"怎样
- **政策评估**：政策失败时不要归咎于穷人不配合——而要检查政策是否适配穷人的真实约束
- **国际援助**：放弃"我们懂他们不懂"的傲慢——穷人最了解自己的生活
- **个人认知**：警惕对穷人的浪漫化或贬低化投射——他们既非天生圣人亦非天生愚人

**可被挑战**：
- 穷人在某些决策上确实表现不同——如时间偏好更短、风险厌恶更强，这是长期贫穷塑造的
- "几乎一样"可能掩盖结构性差异——穷人缺乏的不仅是资源，还有制度性赋权
- 穆莱纳桑和沙菲尔的"认知带宽税"研究暗示贫穷确实改变认知模式——不只是资源约束
- 文化因素确实存在——某些社会的种姓制度、性别规范塑造了穷人独特的决策框架
- 班纳吉迪弗洛的方法论偏好（RCT、个体层面）让他们倾向于发现共性而非差异
