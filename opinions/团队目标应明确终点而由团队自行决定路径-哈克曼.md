# 团队目标应明确终点而由团队自行决定路径

**主张**：团队目标的最佳表述是明确规定团队要取得的最终结果，但让团队自行决定取得结果的具体方式（哈克曼四象限模型右上角）。团队领导者在行使权威确认最终结果时应坚定不移、不卑不亢，同时要确保不对所有执行细节进行过多限制或干预。这种"目标明确+过程自治"的组合是最优团队设计。

**反常识在哪**：大众印象和传统管理思维默认"目标越具体越好""指令越详细越安全"。哈克曼指出这两种倾向都会偏离最佳设计：领导者常因"放弃领导"（既不指定目标也不明确过程，"团队将搞定一切"）或"命令"（同时指定目标和具体行动）而破坏团队效能。讽刺的是，"命令"倾向最常出现在团队目标紧急或重要之时（如危机管理），传统观念认为危机需要集中控制——但出色的危机管理反而要求现场团队有实时应对急剧变化的回旋余地。

**核心证据/论据**：
- **四象限模型右上角最优**——明确规定最终结果+让团队自行决定具体方式；其他三格都有严重问题
- **左下角最糟**——明确手段而非目标，是那些完全不知道团队该做什么但感到有必要对团队行为进行个人控制的领导者的最后手段；他们写了一份又一份备忘录，发布了一项又一项指令，结果都以团队再一次表现欠佳而遗憾收场
- **消防模拟实验**——扑灭森林大火的消防模拟中，与团队领导者下达具体行动指令的团队相比，只传达应该完成目标的团队表现得更好
- **动态环境创造性任务研究**——注重结果的团队比注重过程的团队在问题识别和调整工作流程以适应环境变化上表现出更强能力
- **关注目标而非过程的好处**——体现对团队能力的尊重；平衡团队领导者和成员之间的认知负荷；允许团队更好地运用其成员的专业知识；当成员尝试以其他方式继续工作时，往往会加深对团队任务的理解
- **偏离目标的两大原因**——放弃领导（向左移动）和命令（向下移动）；前者常见于领导者团队/专家团队（"我们是经验丰富的专家，不必把我们当新手"），后者常见于危机时刻（误以为危机需要集中控制）
- **领导者/专家团队的特殊挑战**——他们假定大家对应该做什么有共识，但并没有相互确认，当这一假设不成立时（通常情况下都是如此），就会出现分歧，让所做的工作都白费

**可被挑战**：在团队成员经验不足、任务标准化程度高、合规要求严格的场景中（如飞行驾驶舱、医疗急救、金融合规），过程必须明确指定——哈克曼自己也强调飞行机组事故的研究。哈克曼可以回应：这些场景中目标已由飞行手册/医疗规程明确，所谓"过程"实际上是"目标"的具体化，并非真正的过程干预；右上角模型适用于有判断空间的知识工作和复杂任务。此外，对初入职缺乏经验的员工，步骤指导仍是必要起点。
