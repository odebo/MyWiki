# 好战略的核心是聚焦于关键且可解决的挑战而非面面俱到的待办清单

**主张**：战略天然是关于"重要事项"的，但大多数组织的战略文件变成了罗列所有应该做的事情的长清单。好战略的核心纪律是敢于说"这个挑战我们现在不处理"。

**反常识在哪**：全面性被误认为严谨性。鲁梅尔特指出"优先事项超过三个就无所谓优先了"——政治正确的"什么都重要"恰恰是战略的对立面。

**核心证据/论据**：
- 政府机构案例：团队列出26个"关键"挑战。鲁梅尔特强制要求缩减到5个 → 讨论一个后竟分化出4个新的 → 再强制回到5个。每次缩减都让讨论更深入
- FarmKor 案例：从20个挑战聚焦到3个 → "高价值作物"战略自然浮现
- 公共机构的"战略"往往是愿望清单——每个部门都必须被照顾到，结果是没有部门被真正照顾到

**可被挑战**：在高度监管或政治化的环境中，"面面俱到"可能是组织生存的必要代价，纯聚焦战略在现实中不可行。
