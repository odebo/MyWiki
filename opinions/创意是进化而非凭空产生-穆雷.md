# 创意是进化而非凭空产生

**主张**：想法和有机物种一样随着时间进化——有祖先也有后代；判断驱动了创意的进化，就像生存斗争推动有机进化；产品是产品的后裔（iPod是随身听的孙辈，汽车是马车的后裔），创意不会从天而降，它们通过组合、试错、选择逐步演化。

**反常识在哪**：大众文化把创新浪漫化为"灵光一现"的天才时刻——牛顿被苹果砸、阿基米德浴缸呼喊"尤里卡"。穆雷反转——这些"灵光一现"是潜意识长期工作的产出，是进化过程的最后一步而非第一步；专利、版权等"所有权"概念延续了"创意从天而降"的谬误，模糊了创意过程的真实性质。

**核心证据/论据**：
- **道金斯的迷姆理论**：想法的进化如同基因进化——迷姆与其他迷姆结合形成新想法，"任何想法，不管它是理论、故事，还是一段旋律，一个产品。想法和基因一样，在为生存而奋斗"
- **生存能力的两个维度**：
  1. 问题的重要性——解决微不足道的问题，想法很快死去
  2. 相对于其他解决方案，多大程度上完美解决问题——解决速度不及竞争者也会死去
- **iPod 进化链**：古老留声机 → 索尼随身听 → iPod——"iPod是随身听的孙辈"
- **工具进化链**：石头 → 车轮 → 手推车 → 战车 → 马车 → 汽车
- **物种进化类比**：鸟类是兽脚类恐龙的直接后裔——"产品和想法都是之前没出现过的东西的后代"
- **判断=生存斗争**：判断驱动了创意的进化——"没有测试，就会有灾难，没有判断，想法只会灭绝，变成纸上谈兵"
- **三种判断驱动进化**：消极判断（找出弱点并消除）+ 积极判断（找出优点并提升）+ 情绪判断（直觉反应）
- **乔布斯作为怀疑论者案例**："这些产品太糟糕了！他们都没有差异"——创新者是怀疑论者，"创新史也可以很容易地被称为怀疑史"
- **毕加索**："每一个创造的行为起初都是毁灭的行为。"——消极判断是创造的必要环节

**可被挑战**：
- "进化论"应用到创意领域可能存在范畴错误——生物进化是无目的的，创意进化有目的性
- 迷姆理论本身在学界有争议——道金斯的迷姆概念被批评为"无法证伪"
- 创意的"祖先"追溯往往是事后重构——可能存在"路径依赖"的叙事偏差
- 跨领域组合的"进化"需要解释为什么某些组合被选中——单纯"判断选择"可能不够，还需考虑社会、经济、文化因素
- 与 [[合作的进化-阿克塞尔罗德|阿克塞尔罗德论合作进化]] 共享同一可被挑战点：进化机制是否能完全解释人类文化现象
- "判断驱动进化"的论断可能过度理性化——许多创意的存亡由市场运气、时机等非理性因素决定
- 实践层面：判断本身需要经验和专业知识，新手可能"判断错误"导致好想法被淘汰
