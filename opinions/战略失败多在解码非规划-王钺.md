# 战略失败多在解码非规划

**主张**：多数公司战略失败,不是因为没想清楚（规划问题）,而是没解码到执行（解码问题）——战略规划能力普遍被高估,解码能力普遍被低估,这才是组织能力的真正分水岭。

**反常识在哪**：主流战略咨询偏重规划——花百万请麦肯锡做战略,产出 200 页 PPT,然后放抽屉。王钺反转这一论述:多数公司不缺战略思考,缺的是战略翻译能力——把战略意图翻译为组织-部门-个人可执行的目标体系。

**核心证据/论据**：
- **咨询行业观察**：多数公司有战略规划部门或外部顾问,但极少有战略解码部门——解码能力无组织归属
- **PPT 战略现象**：CEO 在战略会上讲得激情澎湃,中层在执行层做得稀里糊涂——中间翻译层缺失
- **华为案例**：华为战略成功的核心不在 BLM（IBM 也有 BLM）,而在 BEM 和解码体系——这是华为的差异化能力
- **管理逻辑**：战略是抽象的,执行是具体的——抽象到具体必须经过解码,无解码则战略悬空

## 规划被高估的原因

1. **咨询商业模式**——咨询公司卖规划,不卖解码,所以放大规划价值
2. **CEO 偏好**——CEO 喜欢定战略的"高瞻远瞩感",不喜欢解码的"繁琐细节"
3. **媒体叙事**——商业媒体爱讲战略故事,不讲解码流程
4. **培训市场**——战略培训多,解码培训少

## 解码被低估的原因

1. **解码枯燥**——没有战略故事性感,无人愿意做
2. **解码跨部门**——需要 HR、流程、财务协同,难度高
3. **解码难量化**——规划有方法论,解码靠经验
4. **解码无英雄**——规划是 CEO 工程,解码是中后台工程,无聚光灯

## 解码缺失的典型症状

- 战略会上人人激动,会后无人行动
- 部门 KPI 与公司战略无关
- 个人 PBC 写得漂亮,与战略脱节
- 战略年年定,执行年年差

## 解码能力是组织真正护城河

王钺论点延伸：
- 战略可以被复制,解码能力不能
- 战略意图容易模仿,执行体系难模仿
- 华为的护城河不是"做什么",而是"如何把战略做到组织每一层"

**可被挑战**：
- 规划仍是基础——没有正确的战略,解码再好也南辕北辙
- 部分行业战略正确性确实更重要——如生物医药、芯片,选错赛道解码无用
- 解码能力依赖组织基础——小公司没体系,谈解码是奢望
- "解码"概念模糊——王钺未给出操作性清单,实操仍靠经验
