# 过度储蓄反而会有损失

**主张**：过度集中于储蓄而不投资会产生三种损失——低收益损失、通胀损失、机会损失。储蓄不是"安全"的，表面本金不变，实际购买力在缩水。但投资要知情，不能盲目——不投资是可以接受的选择，前提是知情地接受这三种损失。

**反常识在哪**：常人认为"储蓄=安全，投资=风险"——存银行最稳妥，投资可能赔本。黑田颠覆这种认知——**储蓄也有风险，而且是确定的风险**。通胀在悄悄侵蚀购买力，机会损失是必然的。真正"安全"的选择是了解两种风险后做出知情决策。

**核心证据/论据**：
- 黑田的核心论断（第21节标题）：
  > "过度集中于储蓄，会有意外的损失"
- 不投资的三种损失（详见 [[不投资的三种损失-黑田尚子]]）：
  - **第一种损失：低收益**
    - 大型银行活期存款利率：0.001%
    - 网上银行定期存款利率：0.1%
    - 每月10000日元×20年=利息仅24000日元
    - 对比年利率1%：利息256000日元（10倍以上）
  - **第二种损失：通胀风险**
    - 1970-2020年CPI上涨3.32倍
    - 1970年的100日元，2020年需要332日元
    - 储蓄本金不变，实际购买力降低
  - **第三种损失：机会损失**（必然）
    > "并不是指实际投资产⽣的损失，⽽是因为没有做出最好的决策，⽽错过了获得更多利益的机会。"
- 退休后的后悔调查：
  - 500名60-65岁退休后再雇用男性
  - "如果退休前做这件事就好了"
  - **回答最多的是"理财"（38.4%）**
  - 约40%的人工资降到退休前一半以下
- 黑田的 nuanced 立场：
  > "作为理财规划师，对于'是否应该投资？'这个问题，我会回答'如果不想投资的话，就不必勉强去投资'。"
  > "我并不认为投资是改善家庭经济状况的'救世主'。和节俭不同，投资并不⼀定会有成果。"
- 投资的前提条件：
  - 有3-6个月生活费"以防万一的钱"
  - 手头资金没有确定用途
  - 有基本投资知识
  - 不在投资热潮中入场
- 百岁人生时代的考量：
  > "如何在延长健康寿命的同时延长资产寿命也是重要的课题。尤其是对于时间充裕的年青一代，'还是进⾏投资更好'。"
- 黑田的个人印证：
  > "因为跳槽、结婚、⽣孩⼦、育⼉、移居、⽣病、照顾⽗母等各种各样的⽣活杂事⽽导致收⼊减少，有好多次都是投资的收益帮助了我。"

**可被挑战**：
- 投资确实有风险——2008年金融危机、2022年股市暴跌都是例证
- 日本"失去的30年"——股市长期低迷，储蓄反而更安全
- 黑田主要基于日本经验，日本长期通缩，"通胀损失"论点可能不适用
- 投资需要知识——不学习就投资更危险
- 与 [[投资热潮]] 警告形成内部张力——既然投资好，为何投资热潮时不要入场？
  - 调和：长期投资 vs 短期投机
- 与巴菲特等价值投资理论一致——但巴菲特也强调"不要亏钱"
- 行为经济学研究显示，多数散户投资者跑输市场——投资并不容易
- 与 [[会攒钱的人都会整理房间-黑田尚子]] 形成内部张力——既然整理=攒钱，为何又说储蓄不够？
  - 调和：攒钱（储蓄+控制支出）是基础，投资是进阶
- 与 [[不存在的幸福配方须因人选择-铃木祐]] 强呼应——铃木祐论"因人选择"，黑田论"知情选择"
