# 好文章是改出来的

**主张**：好文章不是一次写出来的，而是反复改出来的——初稿必然粗糙，修改才是写作的真正环节。写完放一放，再读再改，是写作训练的必修课。

**反常识在哪**：写作新手的默认期待是"一次写好"——下笔如有神，落纸即成章。这一期待导致两种结果：要么因初稿不理想而放弃写作，要么把初稿当终稿不再修改。叶圣陶指出这一期待违反写作规律——任何初稿都是粗糙的，好文章必须经过反复修改。

**核心证据/论据**：
- 名家手稿研究：托尔斯泰《战争与和平》改了8遍，曹雪芹《红楼梦》"披阅十载，增删五次"——证明好文章都是改出来的
- 初稿的必然缺陷：思路未理清、用词不准、逻辑不顺、段落失衡——这些只有通过修改才能发现
- "写"和"改"是两种不同的思维模式：写是"产出"，改是"评估"——同时进行会互相干扰
- 时间间隔能切换视角：写完立即改，作者仍处在"产出模式"看不见问题；放一放再改，能以"读者视角"审视

**修改的方法论**

叶圣陶建议的修改流程：
1. **放一放**：写完后隔几小时甚至几天再改
2. **朗读**：读出声，不通顺的地方会"卡"住
3. **删减**：先删多余的字词句段——"删"比"增"更重要
4. **重排**：调整段落顺序，使逻辑更顺
5. **换词**：把不准的词换成准的词
6. **复读**：改完再通读一遍

## 与现代写作研究的对应

- 海明威："所有初稿都是垃圾"——同构判断
- 安佳《互联网文案写作》："好的文案不是写出来的，是改出来的"——直接继承
- 斋藤孝《写作全技术》："热修确"方法论——把修改作为商务邮件的核心方法

这一观点已成为写作学的共识——叶圣陶是较早系统阐述的现代学者。

**可被挑战**：
- 部分文体（如即兴诗、即兴演讲）确实可以一次成稿——不是所有文章都需要反复改
- 时间压力下的职场写作（紧急邮件/危机公关稿）没有"放一放"的余地——必须一次写好
- 修改可能过度——超过某个阈值后边际效益递减，甚至改坏
- 修改依赖外部反馈（编辑/读者），自我修改有上限——叶圣陶的方法对孤立写作者未必适用
