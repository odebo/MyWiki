# 不要将未来外包出去

**主张**：把"现在看似不重要的能力"外包给第三方，短期省成本，长期丧失"未来能做什么"的能力。未来不是规划出来的，是当下"应用流程"积累出来的——一旦外包，未来就被一并外包。

**反常识在哪**：主流管理学推崇"专注核心竞争力、非核心外包"。克里斯坦森承认这条规则的方向对，但警告：**外包的边界很难划清**。外包"资源"看似安全，但代工厂在执行过程中会形成"应用流程"，逐步具备向上攀爬的能力，最终变成新的竞争者。

**核心证据/论据**：

1. **戴尔-华硕悲剧**：戴尔从主板开始，逐步把整机外包给华硕。每一步都"理性"——华硕更便宜更专业。最终华硕推出自有品牌，戴尔沦为空壳。戴尔的"未来"（设计制造能力）被一步步外包出去。
2. **半导体行业**：fabless 模式短期高效，长期导致品牌方丧失工艺理解，代工厂（台积电）占据产业链核心。
3. **家庭"外包式悲剧"**：足球妈妈把孩子的活动、作业、冲突解决全部外包给机构、家教、家长自己——孩子资源丰富但"应用流程"空白，长大后缺乏独立解决问题的能力。
4. **忒修斯之船隐喻**：每一块木板外包替换看似无伤，最终整艘船已非原船。能力丧失是渐进的、不可见的，直到某天突然暴露。
5. **"未来"的定义**：未来不是某天突然出现的项目，而是今天看似边缘的应用流程。今天的边缘，是明天的核心。

**可被挑战**：

- 真正非核心的能力（如公司食堂、IT 运维）外包确实安全，关键在区分"资源型外包"与"流程型外包"；
- 资源极有限的小公司不外包无法生存，"不外包"是奢侈品；
- 部分场景下，代工厂爬升需要漫长时间，原品牌方有充足窗口期反应——并非所有外包都必然导致悲剧。
