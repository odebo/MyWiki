# 招运是执念，开运非目的

**主张**：执着于"招运"本身就说明认定自己没运气；"开运"是手段而非目的，把它当目的就会走向奇怪方向。超越"幸与不幸"的秘诀是怀抱纯粹的"信念"与"梦想"。

**反常识在哪**：开运产业（吉祥物/风水/幸运色/积分卡）默认"招运=好事"。山下英子作为断舍离创始人也曾走过这条弯路，反思后指出——所有招运行为都在反向证明"觉得自己运气不好"。

**核心证据/论据**：
- **自我证伪的逻辑**：正因为食不果腹，才满脑子都是美食。一心想招运 = 认定自己没运气
- **打折商品的心理陷阱**：买打折商品是用"划算感"证明自己走运 → 反向证明自己其实没什么运气
- **积分卡的障眼法**：商家返还是营销策略而非感谢，"幸运"是障眼法。"下次不带就亏了"的不安 = 持有积分卡的真正原因
- **森信三的智慧**："人的一生中，一定会遇见应该遇见的人，而且还是在刚刚好的时候，一刻也不会早，一刻也不会晚。"——缘不求则不生，但强求招运反而远离缘分
- **"准备周全"≠"运气好"**：背折叠伞没淋雨不叫运气好，是准备周全。但长期背沉重包包带来的压力才是更严重损耗
- **愿望 vs 梦想**：山下英子母亲一辈子想吃大间金枪鱼却从不去——这"愿望"对她太过奢侈，她没允许自己去实现。怀揣信念向梦想进发（铃木一郎、浅田真央）的态度超越了"幸与不幸"

**可被挑战**：
- 心理学"自证预言"角度，积极期待确实能改善结果——招运不一定全然负面
- 信徒众多的事物（风水/吉祥物）不能完全用"执念"否定，可能有文化心理价值
- "信念与梦想"的纯粹境界难以实践，普通人难免在"幸与不幸"中起伏
