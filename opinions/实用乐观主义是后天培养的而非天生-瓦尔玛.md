# 实用乐观主义是后天培养的而非天生

**主张**：乐观主义者可能是天生的，但实用乐观主义者是后天培养的。乐观不仅是一个"感觉良好"的概念，它在大脑中有神经基础——通过有意识的实践可以重塑神经回路，无论天性如何都可以学习。

**反常识在哪**：大众常把乐观视为性格特质——"他天生开朗"或"我就是悲观的人"。瓦尔玛反驳：乐观的"实用"部分是可以学习和实践的技能，与学习乐器、工作技能、语言或运动没有不同。即使是悲观倾向的人也能通过八大支柱的实践增强左脑活动（与乐观、冷静、能动性相关），抑制右脑过度活动（与悲观、抑郁、逃避相关）。

**核心证据/论据**：
- "乐观主义者可能是天生的，但实用乐观主义者却是后天培养的"
- 神经科学研究：增强大脑左半球活动与促进乐观、冷静、能动性及积极思考和行为有关；右脑过度活动与悲观、抑郁、被动、逃避有关
- 八大支柱的每一根以及相关应用练习都能在神经生理层面增强乐观情绪
- 瓦尔玛本人经历：从医学教育的精神药理学/精神分析训练，转向认知行为疗法（CBT）后感到"比以往任何时候都更有力量"
- "9·11"后担任世贸中心心理健康项目医疗总监的临床观察：同样遭遇巨创，一些人从未达到心理障碍标准——这推动了框架研发
- 父亲在印度贫困童年却活出"生机勃勃的童年"——乐观是"专注的、有意识的、经过时间考验的"实践
- "悲观主义者抱怨风向，乐观主义者期待风向改变，现实主义者（实用乐观主义者）调整风帆"——威廉·亚瑟·沃德

**可被挑战**：
- 部分人确实有先天气质倾向——神经生理差异不是完全可塑的
- 与德韦克[[成长型思维-德韦克]]形成支持：都主张可塑性
- 严重抑郁症患者可能无法仅靠自我实践——需要药物和专业治疗配合
- "可以学习"不等于"容易学习"——长期悲观者改变需要大量重复实践
- 与汉森[[单纯拥有积极体验意义不大必须主动内化-汉森]]呼应：两者都强调主动实践
- 整合：先天倾向+后天实践——基因给底色，实践改变强度
