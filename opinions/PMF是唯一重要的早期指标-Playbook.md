# PMF 是唯一重要的早期指标

**主张**：创业早期（0 到 A 轮）,唯一重要的指标是 PMF——其他指标（用户数/收入/增长/融资额）在 PMF 之前都是噪音,关注它们会误导决策。

**反常识在哪**：当代创业文化偏爱"增长指标"——DAU/MAU/收入/获客成本都被当作核心指标。本书反转:这些指标在 PMF 之前都是"虚假繁荣"——无 PMF 的增长是烧钱换来的,验证不了商业模式。

**核心证据/论据**：
- **逻辑链**：无 PMF → 投放获客 → 用户不留存 → 持续烧钱 → 现金耗尽
- **历史案例**：WeWork/共享单车/ofo 都是无 PMF 大规模扩张的失败案例
- **Sean Ellis 测试**：40% 用户"非常失望"是 PMF 的客观标准——多数早期公司远未达到
- **马克·安德森论点**：PMF 是"市场拉着你跑"的感觉,无 PMF 是"推着市场走"

## 虚假繁荣的指标

### 1. 用户数
- 靠补贴拉来的用户 ≠ 真用户
- 补贴停了用户流失 = 无 PMF

### 2. 收入
- 靠关系/朋友/早期用户的收入 ≠ 可持续
- 单位经济模型未跑通的收入 = 烧钱

### 3. 增长率
- 增长率不区分"自然增长"和"投放增长"
- 投放增长率随投放停止而消失

### 4. 融资额
- 融资额反映投资人预期,不反映市场需求
- 高融资 ≠ PMF（如 WeWork）

## PMF 之前的"小而精"

本书论点:PMF 之前要"小而精":
- 团队小（< 10 人）
- 功能少（聚焦核心）
- 用户少但深（< 1000 深度用户）
- 烧钱慢（> 18 个月现金）

"小而精"是 PMF 验证的最佳环境——大团队/多功能/广撒网反而模糊 PMF 信号。

## 与"增长黑客"的对话

当代互联网讲"增长黑客"——快速实验、A/B 测试、规模化增长。本书论点:
- 增长黑客在 PMF 后有效
- 在 PMF 前用增长黑客 = 烧钱加速错误
- 增长黑客优化的是"已有 PMF 的产品",不是"找 PMF 的产品"

## 与"精益创业"的对话

精益创业讲"持续验证假设"——PMF 是最大的"假设"。本书论点:
- 精益创业提供方法（如何验证）
- PMF 提供目标（验证什么）
- 互补:精益创业 + PMF = 完整的早期创业框架

## "唯一重要"的边界

本书论点有时间边界:
- **0 到 A 轮**：PMF 唯一重要
- **A 到 B 轮**：PMF + 单位经济
- **B 到 C 轮**：增长率 + 市场份额
- **C+ 轮**：盈利能力 + 市场地位

"PMF 唯一重要"是早期论点——成熟期不能套用。

## 局限性

**可被挑战**：
- "PMF"概念本身模糊——40% "非常失望"是否科学？
- 不同行业 PMF 信号不同——B2B vs B2C vs SaaS 差异巨大
- "PMF 之前小而精"可能错过窗口期——某些市场先发优势关键
- PMF 不是静态——市场变化后 PMF 可能消失
- 关注 PMF 不等于忽视其他——团队/融资同样基础
