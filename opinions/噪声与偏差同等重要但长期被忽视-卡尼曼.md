# 噪声与偏差同等重要但长期被忽视

**主张**：噪声（判断中不必要的变异）对总体误差的贡献与偏差（系统性误差）完全相同——MSE = 偏差² + 噪声²——但噪声几乎从未被公开讨论。偏差是台上的主角，噪声是幕后不起眼的参与者。

**反常识在哪**：打破"错误=偏差"的默认认知。大多数组织和个人只关注判断是否"有偏差"，从不测量判断是否"不一致"。事实上，即使整个判断系统平均正确，个体判断间的巨大噪声依然会造成严重的不公平和经济损失。

**核心证据/论据**：误差方程（MSE = 偏差² + 噪声²）是一个数学事实，不依赖任何心理学假设。GoodSell市场预测案例：噪声和偏差数值相同，对总体误差贡献等同。208名法官判决研究：系统噪声标准差3.4年（均值7年），任意两位法官对同一案件平均差3.8年。

**可被挑战**：在某些情境中，噪声可能反映的是合理的观点多样性而非错误——人们有权对复杂问题有不同看法。作者回应：问题不在于多样性本身，而在于人们没有意识到判断中的噪声有多⼤，且在很多场景中（如司法判决），噪声造成的是不公正。
