# 入口浪费甚于出口浪费

**主张**：真正的浪费不在"出口"（扔东西），而在"入口"（过量生产）——比起批评断舍离"从早到晚扔东西多浪费"，更应该追问为什么生产了大量不得不废弃、没有用武之地的东西。

**反常识在哪**：常识把"扔东西"视为浪费，把"生产/购买"视为理所当然。山下英子反转这个判断——扔掉至少是诚实地承认物品已无用，过量生产才是真正的浪费源头。

**核心证据/论据**：
- **俯瞰视角的产物**：从飞机上俯瞰日本，仅数百公里范围内有 50 多个高尔夫球场——泡沫经济时代大兴土木，砍山引发泥石流、农药污染水源，萧条后任其荒废
- **物品生命周期**：物品从被生产出来那一刻起，就已经走在变成垃圾的路上。用俯瞰视角看物品从生产到沦为无用之物的全过程，心中自然有答案
- **身体类比**：错误理解"浪费"就像说"来来来，多吃点，但可千万别排泄啊"。将多余物质排出体外，身体才会健康
- **断舍离的批评者反转**："什么断舍离，不就是从早到晚扔东西嘛，多浪费啊！"——批评者把焦点放在出口，忽视了入口处更大的浪费

**可被挑战**：
- 个人层面"入口浪费"难以追责——消费者无法直接控制生产端
- 对物资匮乏地区"出口浪费"仍是真问题（食物扔掉=他人饥饿）
- 资本主义市场逻辑下，过量生产是供需机制的产物，非单方面可破
