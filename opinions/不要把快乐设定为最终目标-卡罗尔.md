# 不要把快乐设定为最终目标

**主张**：追求快乐本身是徒劳的——享乐适应让快乐快速衰减，影响偏差让人误判快乐的来源。应追求意义——快乐是意义的副产品，不是直接目标。

**反常识在哪**：整个消费文化都在告诉你"要快乐"——广告、影视、社交媒体都在贩卖快乐。卡罗尔（借弗兰克尔之口）指出——这条路径注定失败。越追求快乐——快乐躲得越远；放下对快乐的执念——快乐反而不期而至。

**核心证据/论据**：
- **享乐适应**：中大奖者一年后幸福感与未中奖者无异；丧偶者两年后回归基线
- **影响偏差**（吉尔伯特）：人高估未来事件对情感的影响——以为升职买房结婚会长期快乐，实际效应短暂
- **弗兰克尔**："快乐不可追，只可待——它只能是意义的副产品"
- **Ikigai**：日本"生之意义"概念——四圆交集（热爱/擅长/需要/能赚），目标是意义不是快乐
- **塞利格曼PERMA模型**[[持续的幸福-塞利格曼]]：幸福=P+E+R+M+A，"快乐"仅是P一项
- **卡罗尔的好奇心指南针**："好奇心是指南针，不是地图"——意义由好奇导航，不由快乐驱动

**机制（为什么追求快乐会失败）**：
1. 追求→预期快乐
2. 得到→短暂快乐
3. 享乐适应→回归基线
4. 失望→加码追求
5. 永无止境——"享乐跑步机"

**机制（为什么追求意义会带来快乐）**：
1. 投入→心流（不计较感受）
2. 长期累积→看到进展
3. 进展→意义感
4. 意义感→稳定的满足
5. 满足中包含快乐——作为副产品

**可被挑战**：
- 快乐本身有内在价值——不是所有人都愿意为"意义"放弃当下愉悦
- 享乐适应的样本多来自西方中产——可能不普适
- 对抑郁症等临床群体——"快乐"确实需要主动干预，不是意义的副产品
- 弗兰克尔的"意义疗法"在集中营极端情境下产生——日常生活的推广需谨慎
