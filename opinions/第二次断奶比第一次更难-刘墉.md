# 第二次断奶比第一次更难

**主张**：人类有两次断奶期。第一次（婴儿期）妈妈们容易做到——为了自由、为了工作、奶水渐稀。第二次（16-17岁）父母反而做不到——年纪较大、冲力较弱、跟孩子相依十几年、舍不得放手。当孩子成长的时候，做父母的也得成长；不能成长的父母，千万别认为孩子离不开你们，要知道是你们离不开孩子。

**反常识在哪**：常识认为是孩子黏父母，青春期孩子叛逆想离开家。刘墉反转——很多家庭是父母黏孩子，妈妈"溺爱"换来孩子"逆爱"，孩子的叛逆本质是父母不愿第二次断奶的反弹。

**核心证据/论据**：
- 知更鸟幼鸟翅膀硬了自己飞走，鸟爸鸟妈发愣
- 麻雀父母强迫断奶——起先喂几口，渐渐躲开，最后用啄赶走
- 第一次断奶妈妈容易做到：年轻、要工作、要自由、奶水渐稀
- 第二次断奶做不到：父母年纪较大、冲力较弱、跟孩子相依十几年
- 台湾名医案例：大学科系爸爸指定，太太妈妈选定，子女数太太决定，想出家爸爸说"我来给你盖座庙"
- 老夫妇带未嫁大女儿：老先生看见水龙头全是锈水，意识到该给女儿自由
- 拖孩子走半辈子的父母，被孩子拖累一辈子，误了彼此一生

**与相关论点的关系**：
- 与 [[自驱型成长-斯蒂克斯鲁德]] 同源——斯蒂克斯鲁德论"顾问型家长"优于"经理型家长"
- 与 [[直升机父母-莱文]] 一致——直升机父母是第二次断奶失败的极端形态
- 与 [[由内而外的教养-西格尔]] 互补——父母先成长才能让孩子成长
- 与 [[放手心理学-拉瑟]] 同向——接受孩子是独立个体

**可被挑战**：
- 第二次断奶的文化差异——东亚家庭的代际紧密不一定是"溺爱"，也可能是健康的家族支持
- 16-17岁并非普世断奶期——经济独立年龄在不同社会差异很大
- "父母离不开孩子"的论断可能忽视双向情感需求——成年子女与父母的亲密关系不必然是病态
- 单亲家庭、独生子女家庭的特殊情境下，"断奶"模型过于简化
