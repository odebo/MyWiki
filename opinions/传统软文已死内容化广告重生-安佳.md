# 传统软文已死内容化广告重生

**主张**：传统软文（伪装成内容的广告）在算法分发时代已失效——平台算法会识别并降权。新形态是"内容化广告"——内容本身有独立价值（知识/娱乐/情绪），广告信息嵌入而非伪装。

**反常识在哪**：传统广告业的默认假设是"用户讨厌广告，所以要伪装成内容"。这一假设在算法时代失效——平台算法用机器学习识别"伪装模式"（高密度广告词+低信息密度+强 CTA），降权处理。伪装策略反而成为流量陷阱。

**核心证据/论据**：
- 抖音/小红书的算法对"硬广特征词"（"立即购买"、"限时优惠"、"加微信"）敏感，触发降权
- 公众号"软文"阅读量逐年下滑——用户已建立"软文抗体"，识别后立即跳出
- 内容化广告（如小红书种草笔记、B站测评视频）的完播率和转化率显著高于软文
- 用户行为数据：用户主动搜索的内容转化率是被动推送的 5-10 倍——内容化广告必须能被"搜索到"才有价值

**可被挑战**：
- 内容化广告生产成本是软文的 5-10 倍，中小品牌难以承担
- 部分垂直领域（如医美/保健品）软文仍有效——用户决策路径短，伪装策略仍有 ROI
- "传统软文已死"的判断过于绝对——朋友圈信息流广告本质仍是软文，仍在大量投放
- 算法迭代速度低于软文"变种"速度——软文写手在不断进化伪装策略
