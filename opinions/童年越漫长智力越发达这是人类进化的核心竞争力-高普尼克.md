# 童年越漫长智力越发达这是⼈类在进化上的核心竞争力

**主张**：人类之所以成为地球上最聪明的物种，核心原因是我们在所有动物中拥有最漫长的童年。漫长的受保护的不成熟期，让人类大脑有足够时间在探索中发育，而不是在生存压力下被迫快速"上线"。

**反常识在哪**：常识认为童年短暂、早早独立是进化的优势。但高普尼克用跨物种的证据证明恰恰相反：越聪明的动物（乌鸦vs鸡），童年越长。

**核心证据/论据**：
- 新喀里多尼亚乌鸦依赖父母喂食长达两年（鸟类中极长），但它们能制造和使用工具
- 人类童年至少是黑猩猩的1.5倍，人类大脑消耗66%的热量（4岁时）——整个身体发育为此减速
- 早熟性鸟类（鸡/火鸡）vs 晚成性鸟类（乌鸦/鹦鹉）：晚成 = 更聪明、更擅学习新技能

**可被挑战**：现代社会的"延长青春期"（大学、研究生院、经济依赖父母到30岁）是否仍然是童年/探索期？还是只是劳动力市场的病态延伸？
