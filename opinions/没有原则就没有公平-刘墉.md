# 没有原则就没有公平

**主张**：原则一旦破例就再也立不起来。"讨价还价没了价"——你给一个人破例，就要给所有人破例；你给一个人特权，就让所有其他人受委屈。民主的第一要义是公平，公平的第一要义是没有特权。

**反常识在哪**：常识认为讲情面、留余地是成熟的处世之道，特殊情况特殊处理是智慧。刘墉反转——情是情，理是理，原则一旦松动就再也立不起来。看似"通融"的破例，本质是公平的崩塌。

**核心证据/论据**：
- 签售规定只签名、规定本数——给一个人多签就引发"为什么他可以"的连锁抗议
- 教国画改作业：为前两个学生各添一朵花，给第三个画两朵，前两个回头抗议偏心
- 美国大学加分：原意鼓励，结果学生先问"会不会加分"——价值被搞混
- 女儿中文课：周末拖到周日，下午拖到晚上——一拖再拖等于停课；改为严格规定后，连父母忘了孩子都自己等
- 美国朋友家规：儿子负责洗碗，今天没回来——"情是情，理是理，你不是才说你很有原则吗？"
- "不患寡而患不均，不患贫而患不安"——孔子早说了

**原则缺失的连锁后果**：
- 孩子跟父母讨价还价——既要美式自由，又要中式宠爱，没美国孩子的自动，也没中国传统的孝道
- 进入社会后——既要美式公司福利，又要中式铁饭碗，没美国员工的自修，也没中国传统的忠诚
- 该讲情时讲理，该讲理时说情——原则错位

**与相关论点的关系**：
- 与 [[公平感-海特]] 一致——海特论公平是道德基础之一，刘墉论公平需要原则保障
- 与 [[百忌哲学-刘墉]] 同源——"忌无原则"是百忌之一
- 与 [[猪八戒照镜子-刘墉]] 互补——猪八戒化是原则缺失的表现
- 与 [[习惯回路-都希格]] 相关——原则是通过习惯回路巩固的

**可被挑战**：
- 原则的刚性可能忽视具体情境——医疗、教育、司法中"原则+裁量"的二元结构是现代治理基础
- "没有特权"的极端解读可能否定合理差异化（如残障照顾、家庭紧急）
- 文化差异——东方"情理并重"传统不必然劣于西方"原则优先"
- "原则没有例外"在组织管理中可能僵化——敏捷管理、情境领导都强调弹性
