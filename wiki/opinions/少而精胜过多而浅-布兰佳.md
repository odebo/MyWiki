# 少而精胜过多而浅

**主张**：在知识学习和个人发展中，少而精地深入少数核心理念，比多而浅地涉猎大量内容更有效——"你需要掌握多少食谱才能真正减轻体重？只要一个，就是你能真正坚持下来的那一个"。

**反常识在哪**：信息时代的常识是"多即好"——读更多书、上更多课、收藏更多文章。布兰佳主张相反：信息过载让人毫无积极性，多而浅的学习不如少而精的深入。

**核心证据/论据**：
- 减肥食谱隐喻：能持之以恒的那一个食谱才有效，而非"最好的食谱"
- 公司不停传达新管理理念 → 员工无法掌握任何一个
- 某公司总裁邀请布兰佳"强化我们一直在重复的东西，而不是指出新方向"——成功案例
- 间隔性重复少数理念 → 理念融入思考和行为方式
- 信息过载下，知识在 1 个月内遗忘 95%

**操作方法**：
1. 选定少数核心理念（3-5 个）
2. 通过间隔性重复不断强化
3. 投入 10 倍时间在跟进上，而非追求新内容
4. 每年集中学会 1-2 件新东西，而非盲目接触许多新事物

**可被挑战**：
- "少而精"需要先知道什么是"精"——选错核心浪费时间
- 快速变化的领域（如 AI 技术）需要持续吸收新信息
- 个人兴趣探索阶段需要广度，专精阶段才需要深度
- 信息时代的竞争优势部分来自信息差——少而精可能错失机会
- 与 [[无限可能-奎克]] 等"广博学习"的主张存在张力

**与相关观点的对比**：
- 与 [[本质主义-麦基翁]] 一致：聚焦少数重要的事
- 与 [[80/20法则-科克]] 一致：80% 价值来自 20% 核心理念
- 与 [[深度工作-纽波特]] 互补：深度工作对抗注意力过载，少而精对抗信息过载
- 与 [[无限可能-奎克]] 中"主动遗忘"主张一致——主动过滤不必要的信息
- 与 [[好心情练习手册-西多昌规]] 中"信息节食"主张呼应

**实践含义**：个人学习选少数核心书反复读；培训设计少而精 + 充分跟进；管理沟通坚持传达少数核心理念；知识管理建立"反复重读"机制。
