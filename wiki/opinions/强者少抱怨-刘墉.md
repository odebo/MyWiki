# 强者少抱怨

**主张**：被骗了别只怪骗子，要怪自己不够警觉；跌倒了别只怪路，要怪自己不小心；堵车迟到了别只怪堵车，要怪自己没预留时间。既成事实抱怨没用，反而让人笑话。强者很少抱怨，他们用抱怨的时间做检讨，暗自计划站起来之后的下一步。

**反常识在哪**：常识认为抱怨是情绪宣泄，有助于释放压力。刘墉指出抱怨的三重成本——一是既成事实无法改变，二是抱怨得罪人让你更孤独无助，三是抱怨让你看不清环境更难解决问题。抱怨不仅无用，还会延长困境。

**核心证据/论据**：
- 受骗、跌倒、迟到都是既成事实，抱怨无法逆转
- 抱怨会得罪周围的人，失去潜在援手
- 抱怨占用认知带宽，让人看不清真正的出路
- "倒了的树先要砍掉枝叶，才好扶起"——失意的人先要放下包袱才好站立
- "受苦者没有悲观的权利，战斗者没有流泪的权利，开拓者没有思乡的权利"

**与相关概念的关系**：
- 与 [[内控型人格-罗特]] 一致——内控者把结果归因于自己的选择，自然少抱怨
- 与 [[斯多葛主义]] 同向——关注可控的，接受不可控的
- 与 [[稳住不动-刘墉]] 互补——稳住是当下的情绪控制，少抱怨是事后的归因习惯
- 与 [[WYSIATI使人在信息越少时反而越自信-卡尼曼]] 形成对照——抱怨者用简单归因（怪外部）替代真实检讨

**可被挑战**：
- 完全不抱怨可能压抑真实情绪，长期累积导致心理问题
- 系统性不公（歧视、剥削）不应让个体承担全部归因——这种情况下"抱怨"是识别问题的起点
- 区分"建设性抱怨"（指向改进）和"情绪性抱怨"（指向宣泄）更有意义，而非一刀切否定
- "强者少抱怨"可能被滥用为对弱势群体的二次压迫——"你过得不好是因为你抱怨太多"
