# 真正的学习一定会改变行为

**主张**：真正的学习必然带来行为改变——如果知识没有转化为行动，就等于没学。学习本身就是一段从"知道"到"做到"的旅程。

**反常识在哪**：常识将"学习"理解为获取知识、了解概念——读完一本书、听完一门课就算学过。布兰佳主张相反：**没有行为改变的学习不是学习**，只是信息接收。

**核心证据/论据**：
- 记忆衰减数据：研讨班后 30 小时仅靠听的人记得不到 50%，1 个月后不到 5%
- 大多数人读过布兰佳的书，但无法说出这些理念对自己的行为产生了哪些具体影响
- 培训行业投入大量时间组织培训，却几乎不投入跟进时间——证明行业默认"培训 = 学习"
- 与 [[知行合一-王阳明]] 一脉相承："知而不行，只是未知"

**三层转变验证**：
- 知识层（最简单）：读新书/听音频
- 态度层（较难）：形成情感色彩的态度
- 行为层（最困难）：真正改变行动
- 只有走到第三层，才是真正的学习

**可被挑战**：
- 部分学习是延迟转化的——知识先积累，未来某时刻才应用
- 不是所有知识都需要行为转化（如艺术鉴赏、历史知识）
- 行为改变的原因复杂，不能全部归因于学习
- "知识就是力量"（培根）的传统主张与布兰佳立场存在张力

**与相关观点的对比**：
- 与 [[知行合一-王阳明]] 一致：知而不行只是未知
- 与 [[知道做到-彼得·圣吉引述]] 一致
- 与 [[刻意练习-艾利克森]] 一致：练习即学习
- 与传统"读书即学习"的观念对立

**实践含义**：评估学习效果时问"我的行为发生了哪些具体变化"；读完一本书后明确写下"我要改变什么"；培训设计以行为改变为评估标准，而非"满意度"。
