# 问题越严重成就几率反而越大

**主张**：问题越严重，往往你取得巨大成就的几率反而越大。大问题对应大机会——问题暴露需求、创造议价空间、驱动创新。

**反常识在哪**：常人假设"问题阻碍成功"——问题越大越该回避。特朗普反其道：问题越大越该进入，因为问题越大被吓退的人越多，留下的机会越大。这与"危机=危险+机会"的中文古语同源，但特朗普把它商业化为操作策略。

**核心证据/论据**：
- 1990 年代纽约房地产萧条——大问题，特朗普反向收购核心资产
- 9·11 事件后纽约地产市场崩溃——特朗普团队通过应急和重组保住核心资产
- 行业危机时其他公司倒闭——留下客户/资产/人才可被吸收
- 财务危机逼迫创新融资结构——合资/品牌授权等新模式在顺境不会出现

**可被挑战**：
- 不是所有大问题都有大机会——某些问题是真终结（行业消失/法律禁令）
- "问题即机会"需要资源支撑——赤手空拳时机会难找
- 大问题中的"幸存者"被记录，"阵亡者"不被记录——幸存者偏差
- 大问题中的成功需要运气——特朗普的案例不能简单复制
- 大问题可能导致心理崩溃——保持冷静的能力本身就是稀缺资源

**判别标准**：
- 问题是否可解（有路径）——可解则进，无解则退
- 自己是否有相对优势（资源/信息/能力）——有则进，无则换
- 时间窗口是否允许——允许则进，紧急则换
- 心理承受力是否足够——足够则进，不足则保命

- 与 [[考验是显化过程的一部分不是显化失败-纳福西]] 互补——都视障碍为过程
- 与 [[40定律-戈金斯]] 同源——通过痛苦磨砺证明潜能
- 与 [[大多数人反对的事业往往能成功-铃木敏文]] 同源——共识=平庸机会
