# 能力圈边界比能力圈大小更重要

**主张**：投资者不需要懂很多行业，但必须精确知道自己懂什么、不懂什么——能力圈的边界比其大小更关键。在边界外的"机会"不是机会而是陷阱。

**反常识在哪**：大众默认"机会越多越好"，应该尽量扩展能力圈覆盖更多领域。巴菲特反其道而行：能力圈大小不重要，知道边界才重要。不投科技股不是因为保守，而是承认边界——这个边界是诚实的，而非策略性的。

**核心证据/论据**：
- 巴菲特数十年不投科技股，错过微软、谷歌、亚马逊的早期机会，但避免了2000年互联网泡沫破裂
- 芒格："你必须将自己的天性和天分融入自己的投资策略中"——不可越界
- 巴菲特的能力圈随时间缓慢扩展（从纺织到消费品到金融到科技），每次扩展都基于深度学习而非冲动
- 在能力圈外的决策平均回报更低——缺乏判断质量的根基

**可被挑战**：
- 与 [[破局者思维-克里斯滕森]] 张力：克里斯滕森要求企业主动破坏自己以创新，巴菲特要求投资者守住边界——投资与经营逻辑不同
- 与 [[学会如何学习-吉姆奎克]] 张力：奎克主张学习能力可无限扩展，巴菲特承认能力圈有上限
- 在快速变化的时代，能力圈可能很快过时——不扩展就是慢性自杀
