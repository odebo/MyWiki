# 学会的标准是独立写成一本书

**主张**：判断是否「学会」的标准不是「教会别人」，而是「不看任何书、用自己的话独立写成一本书」；写书（不等于出书）是对学习者理解深度、谋篇布局、语言组织的终极考验。

**反常识在哪**：挑战流行说法「教会别人才算学会」。作者指出「教会别人」隐含循环论证——要确认「别人」学会了，又得靠别人再教更远的别人，无穷套娃；且找到愿意跟你学的人本身门槛很高。相比之下，写书是可直接自我验证的硬标准。

**核心证据/论据**：写作由易到难分「句子 → 段落 → 篇章 → 长文 → 报告 → 专著」，写书要求先在脑中构建立体图景、把知识按章拆分排布，还要对抗自我批判的情绪。他提出「输入驱动输出，输出倒逼输入」的完整表述（2014 年他首提，后流行只剩后半句），并以自己连续写三本书检验学习为例。他同时反驳两种偏见：「写书太难我不配」是完美主义，「写书就是导流变现」是糟蹋图书。

**可被挑战**：「写书」作为标准门槛过高、周期过长，对多数技能型学习（如游泳、开车、乐器）不适用——这些领域的「学会」更应看实战表现而非文字输出；且「用自己的话写出来」仍可能只是自我感觉良好，缺乏外部校准，未必比「在真实场景中教别人并获反馈」更可靠。
