# 股权设计决定公司命运

**主张**：创始团队的股权设计是公司命运的"基因"——第一天就决定,后期难以纠正。错误的股权设计必然导致公司危机或失败,无论产品/市场/团队多优秀。

**反常识在哪**：早期创业者普遍轻视股权设计——"先做事,股权以后再说"。本书反转:股权是公司最基础的"宪法",不写清楚 = 公司无宪法 = 任何分歧都致命。

**核心证据/论据**：
- **股权僵局案例**：50/50 股权 + 决策分歧 = 公司瘫痪（如 Snapchat 早期、Twitter 早期）
- **Vesting 缺失案例**：联合创始人 6 个月离职持股 → 后续融资受阻（如无数早期公司）
- **期权池缺失案例**：招 CTO 无股权可给 → 关键岗位招不到（如初创公司常见）
- **股权结构难调整**：股权变更需要所有股东同意——后期调整几乎不可能

## 错误股权的不可逆性

股权设计的特殊性:
1. **第一天决定**——公司成立时确定
2. **后期难改**——任何变更需要股东一致同意
3. **错配随时间放大**——贡献变化但股权不变 → 矛盾累积
4. **外部投资者关注**——错误的股权结构让 VC 望而却步

## 三大致命错误

### 1. 平均分配
- 50/50 或 33/33/33
- 失败原因：决策僵局 + 贡献不均引发矛盾
- 历史案例：无数早期公司因此瘫痪

### 2. 不签 Vesting
- 一开始全部归属
- 失败原因：联合创始人离职仍持股
- 后果：后续招聘困难 + 投资人拒绝

### 3. 不留期权池
- 100% 分给创始人
- 失败原因：招关键人时无股权可给
- 后果：核心岗位长期空缺

## 与"婚姻"的类比

联合创始人关系 = 商业婚姻:
- 婚姻有婚前协议 → 联合创业要股权协议
- 婚姻有离婚机制 → 联合创业要退出机制
- 婚姻有财产分配 → 联合创业要股权分配

不签协议的联合创业 = 不签婚前协议的闪婚——风险极高,纠纷必然。

## 与"团队即家庭"的对话

奈特讲"早期团队像家庭"——本书论点:
- 家庭是文化,股权是制度
- 文化可模糊,制度必须清晰
- 不清晰的股权 = 不清晰的家庭 = 早期崩盘
- 家庭与制度不矛盾——感情归感情,股权归股权

## 与"先做事再说"文化的对话

中国创业文化常讲"先做事,股权以后再说"——本书强烈反对:
- "以后再说"= 永远不说
- 股权不书面化 = 任何分歧都是法律战
- 早期股权成本低,后期调整成本高
- 一天没协议,一天公司在悬崖边

## 局限性

**可被挑战**：
- 股权不是公司命运唯一决定——产品/市场/团队同样关键
- 早期股权可以重新协商——虽然难但非不可能
- 不同阶段股权不同——早期错误可以通过增发/回购调整
- "股权决定命运"过于绝对——文化/战略同样影响
- 部分公司股权混乱仍成功——例外存在
