# 政府与金融资本是合作博弈关系

**主张**：摩根财团与历届美国政府的关系不是简单的"政府监管 vs 资本"——而是**复杂的合作博弈**：双方既合作又博弈，金融资本需要政府信用背书，政府需要金融资本执行政策。两者权力此消彼长，但从未完全脱离合作。

**反常识在哪**：左翼叙事强调政府对抗资本，右翼叙事强调政府干预资本。彻诺的历史叙事揭示：政府与金融资本从来是共生关系——摩根救市是合作，佩科拉调查是博弈，新政监管是博弈后的新合作框架。

**核心证据/论据**：
1. **1895 黄金危机**：摩根救金本位——政府求助于资本
2. **1907 恐慌**：摩根组织救市——政府默许资本权力
3. **一战融资**：摩根为英法融资——政府通过资本执行外交
4. **佩科拉调查**：政府揭露资本内幕——博弈高峰
5. **格拉斯-斯蒂格尔法案**：政府重塑资本结构——博弈后新合作
6. **2008 金融危机**：政府救银行——合作再现
7. **占领华尔街**：公众对合作的愤怒——博弈再起

## 合作博弈的动态

```
危机 → 政府需要资本救市 → 合作
稳定 → 公众质疑资本权力 → 博弈
监管 → 资本适应新规则 → 新合作
新危机 → 合作重启
```

## 现代启示

- 金融监管不是一次性，而是动态调整
- 政府与资本都不能单独解决系统性问题
- 监管过度会扼杀创新，监管不足会引发危机
- 关键是平衡，而非"击败资本"或"放任资本"

**可被挑战**：
- 合作博弈论掩盖了阶级利益冲突
- 政府常被资本"俘获"，合作不平等
- 2008 后的"大而不倒"显示博弈失衡
- 国际金融监管协调难度极大
