# 群体智慧只在独立性成立时存在

**主张**：群体到底是聪明还是愚蠢取决于条件——群体智慧只在成员能独立决策时成立，一旦互动讨论，偏见会像滚雪球式扩大。

**反常识在哪**：常识在两个极端——要么"三个臭皮匠顶个诸葛亮"（群体智慧），要么"乌合之众"（群体愚蠢）。莎罗特主张关键变量是**独立性**：独立决策则智慧，互动讨论则愚蠢。

**核心证据/论据**：
- 肥牛重量竞猜：800 人独立估算中位数误差仅 1%；先讨论再估算则偏差巨大；加入权威引导更是离题万里。
- 滚雪球式偏见：兄弟姐妹共有错误记忆、商业伙伴过度乐观彼此强化、文化群体认为本族群更优越。
- 平等偏见：人们给所有意见同等权重，即使有些明显更专业。
- 网络群体极化：社交媒体放大偏见，形成信息茧房。

**群体智慧成立的条件**：
1. 独立性：成员单独决策，不受他人影响
2. 多样性：成员有不同视角和信息
3. 去中心化：没有权威引导
4. 聚合机制：能有效汇总个体判断

**可被挑战**：
- 完全独立性难以实现——成员总受共同文化、媒体影响。
- 互动讨论有时能纠正个体错误（如德尔菲法）。
- 多样性比独立性更关键——同质群体即使独立也可能集体出错。
- 紧急决策无法等待独立收集所有意见。

**与相关观点的对比**：
- 与 [[乌合之众-勒庞]] 形成对话：勒庞主张群体是愚蠢的叠加，莎罗特提供更细致的条件论——群体可智慧也可愚蠢，关键在独立性。
- 与 [[沉默的螺旋]] 相关：少数派在群体压力下沉默，破坏独立性。
- 与 [[助推-桑斯坦]] 互补：选择架构可以保护群体决策的独立性。

**实践含义**：群体决策前先让成员独立写下观点；警惕"先讨论后表决"；警惕权威引导；在朋友、家庭、团队中保持独立性；评估他人意见时问"这是他独立思考的结果还是受他人影响？"
