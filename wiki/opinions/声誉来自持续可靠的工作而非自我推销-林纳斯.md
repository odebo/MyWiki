# 声誉来自持续可靠的工作而非自我推销

**主张**：在协作网络中，领导者的声誉只来自一个来源——持续可靠的工作，而非人格魅力、自我推销或神话化。Linux 项目没有"官方"版本，只有林纳斯的版本和其他人的版本；人们把他的版本当作官方版本，只因为他九年来一直信得过。

**反常识在哪**：主流领导力学强调人格魅力、愿景传达、媒体经营。林纳斯反转：领导者应该主动将作品与自我切割，让作品独立于自己的人格缺陷而运行——"哪怕我是地狱来的最黑暗的魔鬼，人们也可以选择不理睬我这个个人，因为他们在 Linux 上的事情完全可以自己处理"。

**核心证据/论据**：
- 林纳斯拒绝给记者回电话、拒绝媒体经营、拒绝"圣人"形象
- 信任基础是"到目前为止，我一直都是信得过的"——不是道德完美
- "我开放的是源代码，又不是我自己"
- 林纳斯自承有时候是浑蛋，但这不影响 Linux 运行
- 媒体塑造的"清心寡欲修道士"形象"又沉闷又无趣，而且还不是真的"
- 反例：当别人太把你当回事，那是温柔陷阱——神话化会反过来塑造你
- 声誉不能转移给继任者，但持续可靠的工作可以传递

**可被挑战**：
- 林纳斯的特殊性在于他是 Linux 内核的"独裁者"——这种结构在其他场景未必适用
- 媒体经营在现代商业中确实有效，林纳斯的反媒体策略可能只适用于已经成名的项目
- 人格魅力在早期招募 collaborators 时确实重要，林纳斯的论述忽略了冷启动问题
- "持续可靠的工作"需要客观可衡量的产出，软性贡献难以建立声誉
- 林纳斯本人 2018 年因行为不当公开道歉并暂离 Linux 项目，部分证伪了"人格不重要"
