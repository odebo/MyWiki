# 比起价廉物美更重要

**主张**：在物质充裕的日本市场，消费者追求的是"品质"而非"低价"——比"价廉"更重要的是"物美"。7-Eleven 通过自有品牌（7-Premium）、团队研发产品、从"家常味道"转向"家中难以实现的味道"等策略，证明品质竞争优于价格竞争。

**反常识在哪**：零售业常识默认"低价获胜"——打折、促销、价格战是常规武器。铃木敏文观察日本消费市场后反其道：物质充裕后消费者愿意为品质支付溢价，价格战反而伤害品质和品牌。这与稻盛和夫"销售最大化费用最小化"看似矛盾，实则统一——铃木敏文强调"销售最大化"靠的是品质溢价。

**核心证据/论据**：
- 7-Eleven 推出 200 日元"特色饭团"，比竞争对手的 100 日元饭团贵一倍，但销量更好
- 7-Premium 自有品牌的成功——品质 + 合理价格，而非最低价
- "越美味的东西越容易腻"——产品要持续迭代，靠品质维持新鲜感
- 物质充裕时代的消费心理：消费者愿为"小奢侈"和"高品质"付费
- 铃木敏文的判断："消费者所追求的是品质"

**可被挑战**：
- 不同消费群体对价格敏感度不同——低价策略仍有市场
- 经济衰退期消费者回归低价——平价商品反周期
- "品质"难以量化，需要消费者认可才能转化为溢价
- 7-Eleven 在日本的品质溢价未必能复制到其他市场

**操作含义**：
- 不打价格战——价格战伤害品质和品牌
- 用"假设-执行-验证"测试消费者对品质的支付意愿
- 产品研发从"家常味道"转向"家中难以实现的味道"——品质差异化
- 持续迭代——美味的东西容易腻，要及时更新

**与其他观点的关系**：
- 印证 [[物质充裕反而推动意义追求-平克]]——物质充裕让品质/意义成为新竞争维度
- 与 [[制造出来的满足-米尔本]] 互补——消费主义追求低价是制造出来的需求
- 与 [[作为人何谓正确-稻盛和夫]] 同源——以"对客户正确"为判断依据
