# 信息搜集能力决定谈判成败

**主张**：谈判的成败主要取决于信息搜集能力——而非说服力、关系、或强硬态度。知道对方的真实利益、限制、BATNA、内部利益分歧，就能设计让对方满意的方案；不知道就只能盲目让步或固执己见。

**反常识在哪**：流行文化把谈判等同于"说服"——好口才/好关系/会压人。马哈拉反其道：谈判的本质是研究而非说服。研究型谈判（见 [[研究型谈判-马哈拉]]）的方法是问"为什么"而非"接受"——拒绝背后是信息缺口。

**核心证据/论据**：
- 案例反复证明：谈判天才扭转乾坤的关键几乎都是发现了对方未表达的需求/限制
- 信息不对称理论：知道得多的一方在谈判中占优——这是经济学基本规律
- 价值创造的来源：偏好差异是价值创造的基础，而偏好差异需要信息搜集才能识别
- 应对谎言：信息充分才能识别对方谎言——谎言利用的就是你的信息缺口

**可被挑战**：
- 信息搜集成本高——某些谈判时间紧迫
- 完美信息不可能——总有不确定性
- 某些情境下信息过载反而妨碍决策
- 说服力和关系仍然重要——尤其在长期合作中

**操作含义**：
- 谈判前投入大量时间搜集信息——这是高 ROI 准备
- 谈判中持续问问题——每个拒绝都暴露信息
- 不要假设对方动机——直接问
- 建立信息网络——行业人脉/历史案例/可比交易
- 信息搜集是持续过程——谈判后也要复盘

**与其他观点的关系**：
- 与 [[一次只做一件事-拉塞尔]] 的"深挖真正的问题"同源
- 印证 [[初始假设-拉塞尔]]——假设驱动的研究方法
- 与 [[假设-执行-验证-铃木敏文]] 同构——都用循环迭代获取信息
