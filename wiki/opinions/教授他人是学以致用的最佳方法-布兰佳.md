# 教授他人是学以致用的最佳方法

**主张**：把学到的知识教授给他人，是将知识转化为行动的最佳方法——传授是内化的最强工具。

**反常识在哪**：常识认为"先完全掌握再分享"。布兰佳主张：教授本身就是掌握的过程——不需要等到完全学会才教，而是在教中学会。

**核心证据/论据**：
- 布兰佳的研讨班建议：结束后一周内邀请伙伴分享，把"啊哈"内容传达给别人
- 教授需要主动回忆（检索练习）→ 强化记忆
- 教授需要重新组织信息 → 加深理解
- 教授需要回答提问 → 暴露自己理解的盲区
- "开始应用新知识的途径之一就是把它传授给别人"
- 与 [[无限可能-奎克]] 的 FASTER 学习法中 Teach 一致
- 费曼学习法的核心：能用简单语言教会别人才算真正理解

**教授的三重作用**：
1. **强化记忆**：检索练习机制
2. **加深理解**：重组信息机制
3. **触发行动**：教授他人时被迫思考"如何应用" → 自己先应用

**可被挑战**：
- 教授需要先有基本理解——过早教授可能传播错误信息
- 无人可教时如何应用？（可写文章、做笔记、录视频替代）
- 教授的"教学相长"效应在不同领域强度不同（技能类 vs 知识类）
- 部分知识高度专业化，难以教授外行

**与相关观点的对比**：
- 与 [[无限可能-奎克]] 的 FASTER 学习法（含 Teach）一致
- 与 [[费曼学习法-费曼引述]] 一致：教授即学习
- 与 [[刻意练习-艾利克森]] 互补：刻意练习提升技能，教授他人强化理解
- 与 [[学习金字塔-戴尔引述]] 一致：教授他人留存率最高（90%）

**实践含义**：读完一本书后写文章/做分享；参加培训后回团队分享；学习新技能时主动教同事/朋友；建立"学—做—教"的循环；不需要等"完全掌握"才开始教——教中学会。
