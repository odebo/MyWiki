# 大多数人反对的事业往往能成功

**主张**：真正有突破性的新事业往往最初被大多数人反对——因为它是反常识的。如果所有人都看好，机会已被充分认知，没有差异化空间。能否在反对中坚持，是新事业成败的分水岭。

**反常识在哪**：决策文化默认"民主共识"——大多数人同意才执行。铃木敏文反其道：共识意味着平庸机会，反共识才意味着突破机会。这与商业的"少数人对，多数人错"现实一致。

**核心证据/论据**：
- 1970 年代引入便利店——内部强烈反对，结果成功
- 7-Eleven 开银行（IY BANK）——金融业和零售业都反对，三年盈利
- 自有品牌 7-Premium——内部认为会冲击品牌合作，结果大卖
- 共同配送——厂商强烈反对，结果物流效率大幅提升
- 这些案例共同特征：内部反对→坚持执行→验证成功

**可被挑战**：
- "大多数人反对的事业往往能成功"是幸存者偏差——失败的反共识案例不被记录
- 反共识本身不构成成功——还需要正确判断、执行能力
- 某些反共识是真的错——比如某些颠覆式创新被证伪
- 共识型机会也能成功（虽然收益不高）

**判别标准**：
- 反共识基于客户真实需求 → 值得坚持
- 反共识只是为反共识而反共识 → 危险
- 反共识有可验证的假设 → 可执行
- 反共识只有信念无验证 → 信仰

**操作含义**：
- 决策不是看支持人数，而是看逻辑和证据
- 内部反对时要回到客户需求验证
- "大多数人反对"不是必胜信号，而是值得深查的信号
- 决策者需要勇气承担反共识的失败

**与其他观点的关系**：
- 印证 [[打破常识才能开创新事业-铃木敏文]]——两者同源
- 与 [[塔勒布反脆弱]] 的"反共识押注"同向
- 与 [[横向思维四特征-斯隆]] 的"质疑默认假设"印证
