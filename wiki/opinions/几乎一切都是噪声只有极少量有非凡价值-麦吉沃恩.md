# 几乎一切都是噪声只有极少量有非凡价值

**主张**：在世界提供的无数选项中，只有极少量（前 10%）具有非凡价值，其余几乎一切都是噪声——把精力从噪声收回集中到信号上，是精要主义的第一原则。

**反常识在哪**：常人默认"所有机会价值相当"，因此倾向于"都接住"。麦吉沃恩引用约翰·麦克斯韦尔的话："几乎所有事物的次要性，再怎么高估都不过分"——价值分布是极端长尾，不是均匀的。

**核心证据/论据**：
- 帕累托法则（二八法则）的极端化——10/90 分布比 20/80 更接近现实
- 硅谷公司案例：员工胜任多种工作但最终"一星半点进步"——分散导致平庸
- 沉没成本研究：人对已拥有事物的评价高于实际价值，因此"已经投入"不是保留理由
- 反证：甘地用极端精要（穿着家纺/三年不读报/简餐缩食35年/每周一日沉默）做出全球性贡献——他没做很多事，但做的事价值非凡

**可被挑战**：
- 长尾理论显示，在某些领域（电商/内容）长尾部分的累计价值也很大
- "噪声"判断本身需要先有筛选能力，新手难以判断何为前 10%
- 过度精要可能导致错过意外机会（探索性收益）

**与其他观点的关系**：
- 印证 [[关键驱动因素-拉塞尔]]（麦肯锡方法）——关键驱动因素只是少数
- 与 [[一次只做一件事-拉塞尔]] 高度共振
- 与 [[入口浪费甚于出口浪费-山下英子]] 同源——少而精
