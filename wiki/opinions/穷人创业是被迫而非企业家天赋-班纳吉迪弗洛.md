# 穷人创业是被迫而非企业家天赋

**主张**：穆罕默德·尤努斯称穷人是"天生的企业家"，普拉哈拉德呼吁关注"金字塔底"，但班纳吉和迪弗洛通过RCT发现——穷人在18国50%从事非农业生意看似充满企业家精神，但这种"企业家精神"绝大多数是被迫的：穷人因为找不到稳定工作才做小生意，而非出于天赋或机会。"放手"策略在大多数情况下无效——穷人需要的是制度性支持（教育、医疗、保险），不仅是贷款。

**反常识在哪**：常识被小额信贷运动的浪漫叙事支配——"给贫穷社区一些机会，然后就放手"（约翰·凯奇）。班纳吉和迪弗洛指出——**实证完全相反**：摩洛哥AL Amana小额信贷两年后客户不到六分之一，希达案例显示穷人主动拒绝贷款。绝大多数穷人的"小生意"是生存策略而非机会捕捉。

**核心证据**：
1. **孟买4妇女捡海沙案例**：黎明前收集湿海沙→平铺路面→车轮回散热气烘干→几天后卖干沙→用废报纸做小口袋装好→拿到市场卖。叔叔称之为"真正的企业家精神：如果你所拥有的不多，那么就用你的聪明才智，做到从无到有"。班纳吉迪弗洛评注：这是生存智慧而非企业家精神。
2. **18国调查显示的高创业比例**：城市50%极度贫穷者从事非农业生意，乡村从7%（乌代布尔）到50%（厄瓜多尔）。但经合组织发达国家平均仅12%在职人员是个体经营——贫穷国家的"企业家"绝大多数是因为没有别的选择。
3. **摩洛哥希达案例**：有4头牛、1匹毛驴、8棵橄榄树——拒绝贷款多买牛。福阿德（AL Amana CEO）为他设计可行计划：贷款建牛棚+4头小牛+8个月后卖牛得利。希达仍拒绝——"什么都不用买，我们拥有的东西已经足够了"。但希达骄傲于一个儿子在接受护士培训——希望孩子通过教育而非做生意脱贫。
4. **斯里兰卡赠款实验**：给小企业主250-500美元商业赠款——普通生意者第一笔回报每年60%以上。墨西哥回报率更高每月10-15%。但穷人企业无法规模化——市场饱和、缺乏技能、资金链脆弱。高边际回报不等于高收入。
5. **徐爱华案例（浙江绍兴）**：1982年村里送她去时装设计学院→失业后借扩音器招生100名学做衣服→用学费买二手缝纫机和布料→留下8名优秀学生开服装店→1991年买60台缝纫机，8年固定资产增长100多倍→2008年首次投资房地产2000万元→客户包括梅西、贝纳通、杰西潘尼。**班纳吉迪弗洛评注**：徐爱华不是典型例子——穷人创业故事不在少数，但能达到这种规模的极少。
6. **孟加拉农村发展委员会"超穷计划"**：给予最穷者资产（一对奶牛、几只山羊、一台缝纫机）+几个月小额经济补助+定期开会、扫盲班、鼓励每周存款。6国RCT结果：参与家庭每月总支出上涨10%——但仍很穷。

**机制——为什么"被迫"而非"天赋"**：
- **没有选择**：穷人缺乏稳定就业机会——做小生意是唯一生存方式
- **风险偏好差异**：真正的企业家（如徐爱华）愿意承担规模化风险——穷人企业主只求生存
- **机会识别差异**：真正的企业家看到市场缺口——穷人企业主复制邻居的小生意（饱和市场）
- **资本约束**：穷人无法规模化——即使边际回报高，绝对收入低
- **教育差异**：真正的企业家常具备专业技能（徐爱华有时装设计培训）——穷人企业主往往辍学

**"放手"策略失败的逻辑**：
- 假设：穷人天生企业家+给点启动资金=脱贫
- 现实：穷人不愿贷款（希达）→即使贷款也不愿扩大（市场饱和）→即使扩大也无法规模化（资本/技能约束）→即使规模化也面临风险（无保险）
- 真正需要：教育（让下一代有选择）+保险（抵御风险）+市场接入（让产品有买家）+基础设施（让生产可行）

**真正企业家的特征对照**：

| 特征 | 真正企业家（徐爱华） | 穷人企业主（希达） |
|------|---------------------|---------------------|
| 起点 | 专业技能（时装设计） | 无技能 |
| 机会识别 | 看到出口市场缺口 | 复制邻居 |
| 风险偏好 | 愿意规模化投资 | 保守避险 |
| 资本积累 | 持续再投资 | 消费平滑 |
| 长期目标 | 企业扩张 | 孩子上学 |
| 规模化能力 | 8年100倍 | 维持生存 |

**适用边界**：
- 不是说穷人中没有真正的企业家——徐爱华是反例
- 不是说小额信贷完全无用——它是消费平滑工具
- 不是说穷人创业都不该支持——而是说支持方式应该是配套的（培训+保险+市场接入），不是单纯贷款

**实践含义**：
- **扶贫设计**：放弃"放手"幻想——穷人需要制度性支持
- **小额信贷**：定位为消费平滑工具而非脱贫工具
- **教育投资**：让穷人孩子有选择权——这是脱贫的根本路径
- **政策评估**：评估扶贫项目时关注规模化能力而非短期收入

**可被挑战**：
- 部分穷人确实具备企业家天赋——徐爱华案例显示天赋与约束可以共存
- 小额信贷运动在某些情境（孟加拉格莱珉银行早期）确实推动了一批穷人企业规模化
- "被迫"vs"天赋"的二元划分过于简化——大多数穷人企业主处于连续光谱
- 班纳吉迪弗洛的RCT方法论可能让他们的结论偏向保守——RCT擅长测量短期可观察变量，难以捕捉企业家精神的长期动态
- 把穷人的"小生意"贬为"被迫"可能本身就是中产阶级偏见——希达拒绝扩大可能反映他对"足够"的不同理解
