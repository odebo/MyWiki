# 生活所有事的动机都遵循生存-社会秩序-娱乐三阶段

**主张**：所有生命体做事的动机按顺序经历三个阶段——生存、社会秩序、娱乐。一旦达到娱乐阶段，事情才算完成。金钱在生存阶段是最强动机，到了娱乐阶段作用大幅下降。所有事务都在按这个方向走，虽然不同事务进度不同，局部倒退也常见，但整体方向不变。

**反常识在哪**：主流把娱乐看作生存的奖励或副产品，把工作伦理神圣化。林纳斯反转：娱乐是事务的终点和目的，生存和社会秩序都是为娱乐服务的中间阶段。改变世界的人往往没有改变世界的意图——Linux 诞生于"just for fun"，不是宏大愿景。

**核心证据/论据**：
- 繁衍活动：从延续生命手段 → 婚姻社会行为 → 娱乐
- 战争：从抢水源生存 → 建立社会秩序 → CNN直播、电子游戏
- 技术：从打水风车生存 → 电话电视社会秩序 → 移动设备的娱乐化
- Linux：极客不愁生存 → 全球极客社区社会秩序 → 编程本身的娱乐
- 林纳斯拒绝将 Linux 商业化，因为金钱动机在娱乐阶段失效

**可被挑战**：
- 三阶段论缺乏严格的演化心理学证据，更像是轶事观察
- "所有事务都走向娱乐"可能忽略了一些反向案例（如医疗、丧葬）
- "金钱在娱乐阶段无效"过于绝对——金钱可以买到很多娱乐
- 马斯洛需求层次可能更细致，林纳斯的简化丢失了自我实现等中间层级
- "改变世界的人没有改变世界的意图"是幸存者偏差——很多有意图的人也成功了，只是没被记住
