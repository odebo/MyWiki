# 好的研究从问题开始而非从题目开始

**主张**：研究失败的最常见根源是从"题目"开始（"我研究 X"）而非从"问题"开始（"我想知道 X 是否 Y"）。题目导向的研究堆砌资料、缺乏焦点；问题导向的研究聚焦追问、产生洞见。

**反常识在哪**：常识认为研究从"找题目"开始，学生常花大量时间选题目。布斯反转——题目只是起点，真正的研究从问题开始；很多研究失败不是题目不好，而是没把题目转为问题。

**核心证据/论据**：
1. **题目 vs 问题**：题目是名词短语，问题是疑问句——后者迫使研究者明确"想知道什么"
2. **资料堆砌症**：从题目出发的研究常陷入"什么都查"的低效
3. **聚焦原则**：问题聚焦研究范围，剔除无关资料
4. **学术评审标准**：评审首先问"研究问题是什么"
5. **从问题到难题**：只有先有问题，才能追问"那又怎样"得到难题

## 题目→问题→难题的递进

```
题目：宽泛兴趣
   ↓ 转化
问题：具体疑问
   ↓ 那又怎样
难题：值得解决的困境
```

## 实践工具

- **5W1H 设问**：把题目转为疑问句
- **对比设问**：X 与 Y 有何不同？
- **机制设问**：X 如何影响 Y？
- **条件设问**：什么条件下 X 成立？

**可被挑战**：
- 题目与问题的界限模糊：好的题目已隐含问题
- 有些研究领域（基础研究）确实从兴趣开始
- "问题导向"可能让研究功利化
- 初学者难以立即形成好问题，需要题目探索期
