# 边读边记是错的

**主张**：阅读和做笔记是两种不同的行为，切莫一心二用。正确做法是阅读时只圈页码、在重点处做记号，避免因记笔记而打断阅读的连续性与动力；读完一本书后再立刻把主要收获集中整理到笔记本。

**反常识在哪**：它直接违背「边读边记 = 高效学习」的普遍直觉。大多数人（尤其是被「不动笔墨不读书」训练出来的学生）默认应该一边读一边摘抄，而哈奇森把这称为破坏阅读流畅性的任务切换，主张把「读」和「记」在时间上彻底分开。

**核心证据/论据**：作者的论据是功能性的——边读边记会「破坏阅读的连续性和动力」，而阅读一旦被打断，进入心流和抓住作者论证链的能力就下降。他的替代方案有完整闭环：阅读时在页码和重点上做记号 → 读完后立即记录主要收获、并在心得旁标注页码以便日后查询重读 → 依赖「间隔性重复」（艾宾浩斯遗忘曲线）强化记忆，而不是依赖一次性详记 → 再把最重要的 5–10 个心得录入 Evernote，按「需实施事项/需深入研究/需深入阅读/一般事项/引用/杂项」分类。他还举了自己的反面教训：第一次读《思考致富》做了 100 多条笔记，「这个数量有点夸张」，根本不可能每天落实这么多心得。

**可被挑战**：认知科学对这个命题并没有一致结论——主动回忆和即时批注（marginalia）被许多研究证明能加深理解，边读边写恰恰是一种生成式加工。对信息密度大、术语晦涩的材料，「读完再记」可能因为边读边忘而遗漏关键点，反而需要即时的批注来锚定理解。此外，「读完再记」严重依赖页码回找的二次阅读，成本未必低于边读边记；电子书的高亮+导出功能更是天然支持边读边标。这个命题本质上是作者基于个人心流偏好的经验主张，未必能推广到所有读者和所有类型的文本。
