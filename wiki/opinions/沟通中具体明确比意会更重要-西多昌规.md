# 沟通中具体明确比意会更重要

**主张**：东亚文化推崇"心照不宣""应该懂我"——但**擅自期待他人猜中自己心思**是自恋情结，是沟通摩擦的最大根源。**具体明确地传达事项**比依赖意会更有效，也更能避免情绪影响。

**反常识在哪**：浪漫主义文化推崇"懂我无需多言"——情侣、上司下属、朋友之间都默认"应该懂我"。西多昌规反其道：**"你应该明白我"是自恋情结**——希望得到肯定却不愿花时间明确表达，是沟通失败的根源。

**核心证据/论据**：
- **"稍微"的陷阱**：上司说"这个你稍微处理一下"——定义模糊，靠意会完成让上司满意的工作
- **期待落空的后遗症**：上司期待落空大吼"这是在搞什么鬼？"，下属自尊心受伤
- **下属侧的擅自期待**："部长大概是这样想的吧""他应该对我有所期待"——一旦落空受伤
- **越自恋越受伤**：自恋情结越强，被影响的程度越严重，拖得越久

**擅自期待 vs 具体明确**：

### 上司侧
| 擅自期待 | 具体明确 |
|---------|---------|
| "你应该明白我" | "我说清楚" |
| "稍微处理一下" | "周三前完成 X，格式 Y" |
| 期待落空大吼 | 共同检查进度 |
| 失败归咎对方 | 共同责任 |

### 下属侧
| 擅自期待 | 具体明确 |
|---------|---------|
| "他应该会体谅" | "我确认一下预期" |
| "大概是这样想" | "您的意思是 X 吗？" |
| 期待落空自怜 | 主动澄清 |

**实践方法**：

### 给上司
1. 下指示时**尽量具体、明确**
2. 不要擅自期待对方会"积极主动"
3. 共享工作和作业的愿景
4. 用 [[校准型问题-沃斯]] 引导对方思考

### 给下属
1. 不要自己认定"老板应该会体谅"
2. **主动确认预期**——"您希望什么时候完成？"
3. 把模糊指示问清楚——"具体来说您需要什么？"
4. 共享进度，避免最后才发现期待落空

### 通用原则
- **传达具体的事项**，不依赖意会
- **接受"对方可能不完全懂我"**——灰色思考
- **使用校准型问题**——"这该如何做到？""什么是最重要的？"
- **战术同理心**（[[战术同理心-沃斯]]）——理解对方视角

**可被挑战**：
- 某些情境下意会确实高效（长期合作团队）
- 过度明确可能显得啰嗦或缺乏信任
- 文化差异——某些文化推崇高语境沟通
- "心照不宣"在亲密关系中有浪漫价值
