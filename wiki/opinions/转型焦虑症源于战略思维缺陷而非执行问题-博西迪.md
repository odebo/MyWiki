# 转型焦虑症源于战略思维缺陷而非执行问题

**主张**：当代企业普遍的"转型焦虑症"根源不在执行不力，而在战略思维方式的根本缺陷——目标脱离现实、商业模式模糊、外部环境分析缺失。仅靠提升执行力无法解决，必须从战略思维层面重构。

**反常识在哪**：博西迪和查兰发现执行问题已不是主要瓶颈（他们的前作《执行》已部分解决），但企业绩效仍不理想——根源在战略思维本身。常人假设"战略→执行"是割裂的两步，博西迪指出两者必须统一——好的战略本就包含可执行性，差的战略再好的执行也无法挽救。

**核心证据/论据**：
- 译者序描述的"转型焦虑症"——2003-2004 年中国企业家普遍焦虑，过去成功法宝失灵
- 评估商业银行价值的指标反转——10 年前网点数是关键优势，今天变成"消灭网点"
- 案例对比：EMC 与思科同期面对同一危机，选择不同——根源在战略思维不同
- "从前屡试不爽的制胜法宝突然失灵"——不是执行问题，是环境变了战略没变

**可被挑战**：
- 执行问题确实存在——不能完全归因于战略
- "战略思维缺陷"听起来宏大但难以操作——具体改什么？
- 某些行业（如稳定制造业）的战略思维缺陷影响较小
- 转型焦虑也有非理性成分——不是所有焦虑都源于真实问题

**操作含义**：
- 转型焦虑时先查战略而非执行
- 用 [[商业模式思维方法-博西迪]] 重新审视三要素
- 用 [[面对现实的客观分析-博西迪]] 检验战略是否脱离现实
- 战略和执行不可分——战略团队和执行团队必须紧密协作

**与其他观点的关系**：
- 印证 [[以事实为基础-拉塞尔]]——战略思维缺陷常源于脱离事实
- 与 [[初始假设-拉塞尔]] 同源——战略思维缺陷就是初始假设错误
- 与 [[成功悖论：成功带来机会稀释专注最终导致失败-麦吉沃恩]] 同源——成功后的战略思维僵化是焦虑根源
- 印证 [[打破常识才能开创新事业-铃木敏文]]——转型需要打破现状的常识
