# 消除偏见比填补知识空白更重要

**主张**：**全球卫生教育的核心使命不是填补知识空白，而是消除先入为主的偏见**——尤其是"西方总是比世界其他地方更发达"的观念。学生答错问题不是没学过，而是心里有错误假设。教育者面对的不是一张白纸，而是一张写满30年前老皇历的纸。

**反常识在哪**：
教育行业的默认假设是"学生不知道，所以教他"。但罗斯林的研究生罗宾·布里坦-朗的测试证明：卡罗琳医学院的学生在5组国家儿童死亡率选择题中，正确率只有36%——**比纯瞎蒙的50%还差**。比无知更差，意味着学生不是没学过，而是**主动持有错误信念**。这彻底改变了教育的任务定义。

**核心证据/论据**：
1. **36% < 50%的瞎蒙基线**：证明存在系统性偏见而非随机无知
2. **错误模式可预测**：学生总是选欧洲国家儿童死亡率低于亚洲国家（实际韩国优于波兰、斯里兰卡优于土耳其、马来西亚优于俄罗斯）
3. **达沃斯精英同样糟糕**：麻疹疫苗接种率问题只有23%正确（实际80%），比黑猩猩的33%还差
4. **感兴趣不等于了解**：选修全球卫生课的学生对世界事实的了解，与选修重症监护课的学生一样多——兴趣不带来知识
5. **25年的时间盲区**：罗斯林1970年代在东南亚看到的进步，到1990年代末瑞典学生仍未察觉

**为什么"填补知识空白"框架失效**：
- 学生会拒绝接受数据：声称"发展中国家的数据肯定错了"
- 情绪化对抗："你对那些动物就像希特勒一样！"
- 道德优越感：学生认为"穷人安于现状不需要发展"
- 二元世界观：根深蒂固的"我们vs他们"使任何数据都被重新解释

**正确的教育任务**：
1. **先呈现不可辩驳的事实**：动态气泡图
2. **让偏见可见**：黑猩猩测试——让学生看到自己比随机还差
3. **重写底层假设**：从"二元世界"转为"连续光谱"
4. **用历史对比打破"永远如此"**：1952年瑞典=今天的中国

**可被挑战**：
- 偏见和知识空白可能同时存在，消除偏见不等于不需要新知识
- "偏见"概念易被滥用——任何不同意见都可以被贴上"偏见"标签
- 部分议题（如气候变化）确实需要新知识输入，不是单纯消除偏见
- 消除偏见的工具（气泡图）本身可能引入新的视觉偏见
- 罗斯林的方法对"事实可被验证"的领域有效，对价值观议题（如移民政策）效果有限
