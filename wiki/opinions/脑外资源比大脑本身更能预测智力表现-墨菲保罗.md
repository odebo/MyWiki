# 脑外资源比大脑本身更能预测智力表现

**主张**：延展思维能力——使用外部物体、道具和辅助工具解决复杂问题的能力——是传统 IQ 测验无法测量的智力的一个额外方面。延展版智力测验比标准版更能预测现实世界的表现。

**反常识在哪**：默认认知是"IQ 测验测量智力，IQ 高就是聪明"。墨菲保罗反转：标准 IQ 测验故意去除思维延展（不允许用计算器/互联网、不允许移动身体、不允许布置环境、不允许与邻居交谈）——这种"剥离延展"的测验测量的是大脑本身的孤立的、不真实的能力。真实的智力是延展的智力。

**核心证据/论据**：

2019 年克拉克与荷兰心理学家在《自然与人类行为》发表的研究：
- 标准瑞文高级推理测验——测验者在头脑中运行所需操作，不允许借助脑外资源
- 延展版——测验者能在计算机屏幕上移动图片，形成新布局
- 495 名学生随机分组实验
- 充分利用新交互功能后，测验者往往能识别出移动小图片前识别不出的拼图
- 测验者与图片互动次数与问题解决能力正相关
- 测验者互动→反思新布局→重新评估策略→再次互动——这种循环让他们能有效解决问题

**关键发现**：
- 延展版瑞文测验比标准版更能预测学生在大学课程中所得的成绩
- 这可能是传统 IQ 测验无法测量到的智力的一个额外方面
- 人们正在运用大量未被重视的策略来解决问题
- 这些策略未被重视的部分原因是人们不善于描述自己的思维过程

**含义**：
- "智力天生的"被打破——智力至少部分是延展能力
- 教育应该教如何延展思维，而不仅是训练脑内推理
- 工作场所应该提供延展资源（大屏幕、合作空间、社交机会），而非仅靠员工脑力
- 个人成长方向不是"更努力地思考"，而是"更聪明地借助脑外资源"

**可被挑战**：
- 延展能力本身可能依赖基础认知能力——基础差的人用不好工具
- IQ 测验仍有预测力，延展能力是补充而非替代
- 延展能力受环境资源制约——富裕环境延展能力强，但这不是智力本身
- 研究样本主要是大学生，对其他人群的适用性待验证
