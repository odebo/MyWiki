# ADD是猎人特质

**主张**：注意力缺乏障碍（ADD）不是纯粹的疾病或缺陷，而是一种「猎人」式的生物适应特质，只是与「农夫」式环境（传统教室、办公室格子间）错配。

**反常识在哪**：打破「ADD=需要矫正的大脑疾病」的病理化默认。作者主张换个视角：问题不在猎人，而在「强迫猎人去当农夫」的环境；ADD 患者并非缺乏注意力，而是难以控制注意力的方向——他们有时会过度专注到忽略一切。

**核心证据/论据**：
- 作者引用汤姆·哈特曼（Thom Hartmann）1993 年的「农夫世界里的猎人」框架——ADD 者像最好的猎人：不断监测环境、能迅速投入追赶、线索快断时能持续追踪；而教师、图书管理员更像稳定耕作的农夫。
- 基因证据：加州大学欧文分校遗传学家 2002 年发现与 ADD 相关的 DRD4 基因 7R 等位基因可追溯到 1 万–4 万年前，且获得「正向选择」，说明它曾带来进化优势；该基因是「感受性基因」，与环境互动才决定是否成障碍。
- 现实案例：企业家、飞行员、急救人员、赛车手、交易员都是「成功猎人」的代表；捷蓝航空创始人戴维·尼勒曼、金考快印创始人保罗·奥法里都把 ADD 当优势经营（奥法里甚至把它改称「加速注意力障碍」AAD）。

**可被挑战**：把 ADD 浪漫化为「猎人优势」可能低估它给患者带来的真实痛苦与功能损害——正向选择的基因不等同于「人人都是潜在的天才创业者」，多数 ADD 者确实在学业、职业与人际中挣扎；且「环境错配论」容易滑向「是学校/社会的错」，削弱患者改变行为的动力。作者自己也承认：优势一旦过度使用就会变成劣势，ADD 者在被打扰后需极费力才能重新集中，其倒U形曲线是「峭壁」而非缓坡。
