# 投资热潮时买股票等于自找赔钱

**主张**：投资热潮是最坏的投资时机——它通常发生在股价最高的上升局面，新手在"再不买就吃亏了"的心理下入场，等于在最高点买入。正确的态度是静观其变，等股价下跌后再开始。

**反常识在哪**：常人认为"大家都在买=机会来了"，看到周围人赚钱就怕赶不上。黑田颠覆这种认知——**投资热潮是反向信号**，是人人都该警惕而非追逐的信号。"低价时买入，高价时卖出"是常识，但投资热潮时人们做的恰恰相反。

**核心证据/论据**：
- 黑田的核心论断（第28节标题）：
  > "投资热潮时买股票等于⾃找赔钱"
- 投资热潮的本质：
  > "投资热潮通常发⽣在股价最⾼的上升局⾯，这本来就是开始投资最坏的时机，像⾃找损失⼀样。"
- 投资的基本原则：
  > "低价时买⼊，⾼价时卖出。"
  > "投资热潮时应静观其变，等股价下跌后再开始。"
- 新手的心理陷阱：
  - "怕赶不上投资热潮"
  - "自己也试着开始投资吧"
  - "再不买就吃亏了"
  - 这些心理让人在最高点买入
- 与"不投资的三种损失"形成内部张力——既然不投资有损失，为何热潮时不要入场？
  - 黑田的调和：长期投资 vs 短期投机
  - 知情地等待 vs 盲目地跟随
- 与 [[不投资的三种损失-黑田尚子]] 中"不投资也有风险"的论点互补——
  - 不投资有损失，但**投资热潮时入场损失更大**
  - 真正的安全是"知情"——既知不投资的损失，也知投资热潮的危险
- 黑田的逆向智慧：
  - 当所有人都说"赶紧投资"时，要警惕
  - 当所有人都说"股市危险"时，可能是机会
  - 这与巴菲特"别人贪婪时恐惧，别人恐惧时贪婪"一致

**可被挑战**：
- 投资热潮可能持续很长时间——等待可能错过部分收益
- 日本"失去的30年"——股市长期低迷，任何时点入场都可能亏损
- 与 [[过度储蓄反而会有损失-黑田尚子]] 形成张力——既然储蓄有损失，等待是否也是损失？
  - 调和：等待不是储蓄，是准备——学习知识、积累资金、观察市场
- 如何判断"热潮"vs"正常上涨"——黑田没有给出明确标准
- 定投策略（DCA）的支持者认为时机不重要——黑田反对这一观点
- 与 [[WYSIATI使人在信息越少时反而越自信-卡尼曼]] 相关——新手在热潮中过度自信
- 与 [[系统1与系统2-卡尼曼]] 相关——投资热潮是系统1的从众反应
- 与 [[间断强化-斯特里普]] 相关——热潮中的人受到间歇性强化的刺激
