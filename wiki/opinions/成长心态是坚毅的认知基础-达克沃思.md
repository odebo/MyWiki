# 成长心态是坚毅的认知基础

**主张**：相信能力可以改变（成长心态）是坚毅的前提——不相信努力有用的人，再怎么训练也无法坚毅。

**反常识在哪**：直觉认为"先有坚毅再有信念"——先坚持才能看到改变。达克沃思指出因果反过来：**不相信可以改变的人，不会真正投入努力**——"很多人不是输在努力，而是输在不相信努力"。

**核心证据/论据**：
- **德韦克实验**：固定心态的孩子面对难题放弃，成长心态的孩子说"我还没有做到"
- **西点军校**：成长心态的学员更可能熬过野兽营
- **教育研究**：被表扬"聪明"的孩子更回避挑战，被表扬"用心"的孩子更迎难
- **成就公式**：天赋×努力=技能——相信这个公式本身就是成长心态
- **"做不到"vs"还没做到"**：一字之差，行为天壤之别

**逻辑链**：
1. 相信可以改变 → 愿意投入努力
2. 投入努力 → 技能提升（验证信念）
3. 技能提升 → 更相信努力
4. 正反馈循环 → 形成坚毅

**固定心态的死循环**：
1. 不相信可以改变 → 不投入努力
2. 不投入 → 没有进步（验证信念）
3. 没有进步 → 更不相信
4. 负反馈循环 → 放弃

**可被挑战**：
- 心态可以改变吗？德韦克的研究显示可以，但需要持续干预
- 不是"相信就能成"——天赋、机遇也是因素
- "成长心态"可能被滥用为"你不够努力"的指责
- 某些能力（如身高、绝对音高）确实有固定成分
