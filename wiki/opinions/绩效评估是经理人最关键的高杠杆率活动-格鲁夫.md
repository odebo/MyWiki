# 绩效评估是经理人最关键的高杠杆率活动

**主张**：绩效评估不是形式主义——而是经理人"再难也得做"的核心高杠杆率活动——一次评估影响下属全年绩效，进而影响整个团队产出。

**反常识在哪**：大多数经理人和下属都讨厌绩效评估——觉得繁琐、形式主义、令人不快。格鲁夫指出这是危险的回避——**绩效评估是高杠杆率活动**，一次评估影响下属全年，跳过评估等于放弃管理。

**核心证据/论据**：
- **杠杆率思维**：一次评估影响下属全年产出——高杠杆率
- **反馈缺失的代价**：下属不知道自己表现如何——按错误方向努力
- **期望对齐**：评估是对齐期望的关键时机——错位全年浪费
- **教练机会**：评估是教练对话——比日常指导更深入
- **格鲁夫的强调**："再难也得做"——再难也要做

**为什么绩效评估难**：
1. **诚实反馈难**——批评让人不快
2. **情绪管理难**——下属可能反应激烈
3. **时间投入大**——准备充分才能有效
4. **归因复杂**——绩效好坏多因素
5. **文化阻力**——东亚文化避免正面冲突

**有效的绩效评估**：
1. **基于事实**——具体事件、具体行为
2. **双向沟通**——听下属怎么说
3. **关注未来**——不只评过去，更规划提升
4. **持续反馈**——评估是"总结"，不是"惊喜"

**与"形式主义评估"的对照**：
| 维度 | 形式主义评估 | 格鲁夫式评估 |
|------|------------|------------|
| 目的 | 打分、分钱 | 提升绩效 |
| 准备 | 应付了事 | 充分准备 |
| 对话 | 单向宣告 | 双向沟通 |
| 反馈 | 一年一次 | 持续反馈 |
| 效果 | 大家都讨厌 | 真正提升 |

**与教练技术的关系**：
- 格鲁夫的评估本质是教练
- 与[[GROW模型-惠特默]]共鸣
- 评估是高杠杆率的教练对话

**可被挑战**：
- 大公司评估流程确实形式化——格鲁夫的理想难以实现
- 评估质量取决于经理水平——不是评估本身的问题
- 某些工作难以量化评估（创意、研究）
- 360度评估可能更全面
