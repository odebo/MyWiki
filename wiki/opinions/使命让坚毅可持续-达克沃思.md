# 使命让坚毅可持续

**主张**：坚毅的可持续性来自使命感——当工作不只是为自己，而是对他人有价值时，刻意练习的痛苦才能长期承受。

**反常识在哪**：直觉认为"为自己奋斗最有力"——名利驱动最现实。达克沃思的研究显示：纯功利的"事业"动机无法支撑10年以上的刻意练习，只有把工作视为"使命"——连接到超越自我的价值——才能持续。

**核心证据/论据**：
- **使命 vs 工作 vs 事业**：只有使命型工作者能10年如一日
- **"为什么"的层级**：表层动机（赚钱）→ 中层（成就）→ 深层（他人价值）
- **坚毅者的共同点**：几乎都把工作连接到他人/社会价值
- **心理学家汪冰观察**："当你知道自己做的事情对其他人也有价值时，你就更容易克服困难"
- **使命感的人更幸福**：坚毅与积极情绪正相关——使命提供意义感

**使命的力量**：
1. 让痛苦有意义 → 可承受
2. 让进步有方向 → 不迷茫
3. 让挫折是反馈 → 不崩溃
4. 让时间是朋友 → 不焦虑

**可被挑战**：
- 不是所有工作都能找到使命感——某些重复性劳动难有"意义"
- 使命感也可能被利用——某些组织用"使命"压榨员工
- 个人 vs 集体的张力——某些使命是危险的（极端主义）
- 使命感不是"想有就有"——也需要培养
