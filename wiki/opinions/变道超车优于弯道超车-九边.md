# 变道超车优于弯道超车

**主张**：张萌在《加速》（本系列第六册）中提出，弯道超车不是实现人生迭代的唯一方式，还有一种更厉害、更炫酷的方式——变道超车。当赛道太普通时，对手也不会太优秀，你始终在自己狭隘的小圈子里努力，一生不可能拥有太多次高水平的跃迁；只有主动更换赛道、升级赛道，才能遇到更厉害的战友，离人生目标越来越近。

**反常识在哪**：「弯道超车」默认你还在同一条赛道上、靠加倍努力在弯道处反超。张萌反转了前提：在一条烂赛道上，再努力也是在低水平里内卷，真正的跃迁来自「换赛道」本身。这与九边「小镇做题家破局先破圈」「从黄土路跳上高速路」的洞见同构。

**核心证据/论据**：她主张「只有同等能量的人，才能相互识别、相互欣赏」，你越优秀才能吸引越优秀的战友；并通过「自我输入」完成「自我版本的迭代升级」（决定性瞬间 → 自发性改变 → 自我输入 → 迭代）。书末「张萌拆解报告」把她的成长公式概括为：千天坚持 + 严格自律 = 成功基石；瞄准目标 + 变道超车 = 果断决策；社会资本 + 跨界思维 = 野蛮成长。书中目标管理、刻意练习、精力管理等 49 个方法，都是「升级自我」以支撑变道的工具。

**可被挑战**：换赛道本身有巨大风险与沉没成本，盲目追逐「更好的赛道」可能变成频繁跳槽、浅尝辄止，反而错过在原赛道积累复利的机会（九边自己就因「稳定倾向」选择大公司而错过小公司上市，却仍表示再选一次还会选大公司）。此外，一个人能否「识别并进入更好的赛道」，往往已经依赖其认知与资源，这对弱者构成「先有鸡还是先有蛋」的悖论。
