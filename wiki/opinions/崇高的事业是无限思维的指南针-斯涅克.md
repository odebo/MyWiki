# 崇高的事业是无限思维的指南针

**主张**：组织要玩无限游戏，必须有一个超越利润、长期不变、令人向往的"崇高的事业"——它是组织在变局中保持方向的指南针。

**反常识在哪**：商业教育强调"使命宣言"——大多数公司的使命宣言模糊空洞（"成为行业领导者""提供卓越服务"）。斯涅克指出这些不是崇高的事业——崇高的事业必须具体、理想、令人向往、服务导向、长期有效。

**核心证据/论据**：
- **苹果的"Think Different"**——不只是卖电脑，而是赋能有创造力的人改变世界
- **西南航空的"民主化飞行"**——让人人都能飞，不只服务精英
- **巴塔哥尼亚的"用商业拯救星球"**——环保优先于利润
- **SpaceX的"让人类成为多星球物种"**——超越具体产品
- **缺乏事业的组织的命运**：被短期数字驱动，最终失去方向

**崇高的事业的五个特征**：
1. **为某事而战**——不是反对什么，而是拥护什么
2. **具有理想性**——比现状好得多
3. **具有号召力**——员工、客户、社会都能认同
4. **服务导向**——对他人有益，不只是自我利益
5. **弹性适应**——不随短期目标变化

**崇高的事业如何驱动组织**：
1. **吸引对的人**——志同道合者聚集，不仅是为钱工作
2. **决策指南**——选择时回到"为什么"，避免短期诱惑
3. **韧性来源**——挫折时不放弃，"为什么"重要就坚持
4. **守护者文化**——员工成为事业的守护者，不只是执行者

**与"使命宣言"的区别**：
| 维度 | 传统使命宣言 | 崇高的事业 |
|------|------------|----------|
| 具体 | 模糊 | 具体 |
| 理想 | 现状描述 | 未来愿景 |
| 号召 | 自我中心 | 服务导向 |
| 持久 | 随CEO变化 | 跨越领导层 |
| 激励 | 弱 | 强 |

**可被挑战**：
- 不是所有公司都需要崇高的事业——纯粹商业也可以成功
- "崇高的事业"可能被滥用——成为压榨员工的口号
- 短期生存压力大的企业难以追求"崇高"
- 某些行业（如金融、贸易）难以定义"崇高"
