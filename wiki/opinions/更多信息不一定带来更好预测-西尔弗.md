# 更多信息不一定带来更好预测

**主张**：**大数据时代的信息爆炸没有带来预测质量的相应提升**——因为信息增长中噪声增长比信号增长更快。印刷机引发信息革命后人类花了几个世纪学会分辨信号；互联网时代同样面临"信号比例在缩小"的困境。预测质量取决于从噪声中分辨信号的能力，而非信息量的多寡。

**反常识在哪**：
主流观念认为"信息越多越好"——大数据、数据驱动决策、信息透明。但西尔弗通过跨13个领域的考察论证这是根本性误解——**关键瓶颈是分辨能力，不是信息量**。

更反常识的是：**对刺猬型专家而言，信息越多预测越差**。泰洛克研究发现刺猬型专家"掌握的事实越多，他们以自己的方式改变且操纵事实的机会就越多"。给忧郁症患者更多上网时间，他会把普通感冒误认为腺鼠疫。

**核心证据/论据**：

### 1. 信号比例下降规律
- 古腾堡印刷机后信息爆炸——但花了几个世纪才学会从中分辨信号（科学方法）
- 互联网时代同样：信息成倍增加，但有用的信息非常有限
- "信号的比例正在缩小，我们需要找到更好的方法对信号和噪声进行区分"
- 大数据公司（如谷歌）不花时间建模——每年上千次实验验证

### 2. 9·11前的信号淹没
- 9·11前已有大量信号：
  - 1994年阿尔及利亚恐怖分子企图劫持飞机撞埃菲尔铁塔
  - 1998年基地组织企图用飞机撞世贸中心
  - 1993年世贸中心曾遭爆炸袭击
  - 2001年7月赖斯收到基地组织频繁活动警报
  - 2001年8月穆萨维因飞行培训可疑被捕
- 但被数万条其他警告淹没——"从数万条甚至数十万条潜在的警告信息中披沙拣金"
- "信号无处不在"但被噪声掩盖

### 3. 珍珠港前的信号淹没
- 美军已破译日本外交密电码"紫色"（97%可读）
- 但聚焦于"日裔搞破坏"这一错误假设
- 日本航母无线电静默——这一真实信号被忽视
- "事后发现，驻扎在珍珠港的美军事先准备好要应对的事，结果都没有发生"

### 4. 经济预测的失败
- 2008年危机前经济学家拥有前所未有的数据
- 但没有预测到危机——"经济学家们过于自信了，计算概率的能力也很差"
- 蓝筹经济指标70名专家的群体预测：任何一名专家都不如群体预测准确
- 信息丰富不等于预测准确

### 5. 股票市场的反例
- 共同基金经理拥有大量数据和研究
- 但2002-2006年表现优异的基金在2007-2011年表现平平
- "过去的表现不代表未来的结果"
- 指数基金（最少信息）长期胜过80%主动基金

### 6. 刺猬型专家的信息诅咒
- 泰洛克：刺猬型专家获得的信息越多，表现越糟糕
- "你给他的时间越多，他要处理的信息越多，他最后得出的自我诊断也就越荒谬"
- 刺猬型专家用新信息"强化他们的个人偏见"
- "他们经常会陷入信息荆棘之中，无法自拔"

### 7. 狐狸型专家的应对
- 乌尔加利斯：关注球员微博这种"琐碎"信息
- 但知道哪些是信号——里基·戴维斯为了提升统计数据的自私表现
- 库克团队：面谈得到大量定性信息，但"瓦瑟曼通常会保持同样的评价"
- "他能从面谈中得到足量但不过量的信息"

### 8. 评级机构的灾难
- S&P和穆迪拥有大量抵押贷款历史数据
- 用复杂模型计算CDO违约率——预测0.12%
- 但被"违约独立"这一错误假设误导
- 实际违约率28%——偏差200倍
- 大量数据+错误模型=更大灾难

### 9. 气候预测的复杂模型批判
- 阿姆斯特朗：IPCC未遵循89条预测原则中的72条
- "模型越复杂，预测越不准确"
- "历史上从未出现拥有大量变量和不确定性的复杂事件最后是靠计量经济模型或其他复杂的模型解决的"

### 10. 股价图的人眼难辨
- 6幅股价走势图，4幅电脑随机生成，2幅真实
- 人眼几乎无法区分
- "投资者观察的股价走势也是如此，常常都将噪声误认为信号"
- 信息量大反而更容易产生虚假模式识别

**核心洞见**：
- 信号比例随信息增长而下降——这是大数据时代的根本困境
- 关键瓶颈是分辨能力，不是信息量
- 刺猬型专家的信息越多预测越差——因为用新信息强化偏见
- 狐狸型专家的"足量但不过量"原则
- 信息增长需要预测方法同步进化（贝叶斯思维）
- 没有环境的信号=噪声
- 印刷机革命后花了几个世纪才学会分辨信号——互联网时代同样需要时间
- **大数据不是预测的福音，而是噪声的放大器**

**可被挑战**：
- 某些领域确实从大数据中受益——如棒球统计、天气预报
- 信息不是预测失败的根本原因——模型和方法才是
- 大数据公司（谷歌）的成功表明信息有用——但关键是实验方法
- 9·11前信号淹没不是信息量问题——是分析能力问题
- 气候模型的复杂性问题——可能只是模型不够好，不是信息太多
- 信息越少可能预测更差——缺乏数据的基础预测无法做
- 与 [[信号与噪声的区分-西尔弗]] **核心概念**——本观点是该概念的命题化
- 与 [[预测失败的共同模式-西尔弗]] **同源**——信息过载是失败模式之一
- 与 [[谷歌效应-庞德斯通]] **互补**——大脑自动遗忘"可查到"的信息
- 与 [[二阶预测-庞德斯通]] **互补**——二阶预测避免噪声干扰
- 与 [[系统1与系统2-卡尼曼]] **互补**——系统1易被噪声误导
- 与 [[狐狸式预测优于刺猬式-西尔弗]] **协同**——狐狸式方法应对信息过载
- 与 [[黑天鹅-预测失败]] **张力**——塔勒布更悲观，认为信息无法解决黑天鹅问题
