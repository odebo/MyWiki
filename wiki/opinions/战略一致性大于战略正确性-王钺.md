# 战略一致性大于战略正确性

**主张**：一致地执行次优战略 > 不一致地执行最优战略——战略一致性（战略/组织/流程/人四层对齐）比战略本身的正确性更决定成败。

**反常识在哪**：主流战略论述偏重"找到正确战略"——波特五力、蓝海战略都在讲"如何选对战略"。王钺反转:战略正确性难以事前判断,一致性可以事前设计——一致性是组织真正可控的变量。

**核心证据/论据**：
- **战略不可事前验证**——战略正确性只能事后看,一致性可以事前设计
- **不一致必然失败**——四层任一脱节,执行必然走样
- **一致性提升战略成功率**——一致执行次优战略有概率成功,不一致执行最优战略必然失败
- **战略可迭代,一致性不能瞬间补**——战略错了可以调,一致性差了要数年重建

## 一致性的可设计性

战略正确性依赖外部判断（市场/竞争/技术）——不可完全控制；一致性依赖内部对齐（组织/流程/人）——可以完全控制。把精力放在可控变量上是理性的。

## 不一致的典型场景

1. **战略要创新,组织是控制型**——战略喊创新,KPI 考合规
2. **战略要客户导向,流程是产品导向**——流程不支撑客户场景
3. **战略要数字化,人没有数据能力**——人和战略脱节
4. **战略要敏捷,文化是审批型**——文化不支撑敏捷

每个场景都是"战略正确,一致性失败"——结果都是战略失败。

## 战略正确性的局限

- **未来不可预测**——所谓"正确战略"只是假设,可能错
- **正确性依赖执行**——再正确的战略,执行不到位也失败
- **正确性有运气成分**——成功战略常因运气,失败战略常因执行
- **正确性可被模仿**——战略被复制后,差异在执行一致性

## 与"战略定力"的关系

霍华德·舒尔茨讲"战略定力"——坚持战略不轻易动摇。王钺讲"战略一致性"——四层对齐支撑战略。两人互补：
- 定力讲"不要乱改战略"
- 一致性讲"要持续对齐组织"
- 两者结合 = 战略稳定 + 组织对齐 = 高成功率

## 与"演化理论"的对话

演化经济学讲"惯例决定组织能力"——惯例即一致性。王钺讲"四层对齐"——四层即惯例。两者本质同构：
- 战略是显性的,一致性是隐性的
- 显性易改,隐性难变
- 隐性一致性决定显性战略能否落地

**可被挑战**：
- 战略错了一致性也无用——南辕北辙的极致一致性比混乱更糟
- 极端情况战略正确性压倒一致性——如生死关头的转型,需要不一致地探索
- "次优"vs"最优"难以事前判断——王钺的"次优战略"实际是事后追溯
- 一致性可能成为变革阻力——太一致的组织难以转型
