# Harness 做的是基建，不是产品

**主张**：DeepSeek 这次发布的不应被理解为一个 Agent 产品，而是一套以 Cordis 内核为底座、把一切能力插件化的研究基建（Harness 系统）；"开发者预览版"的命名和"探索未至之境"的 slogan 都印证了这一定位。

**反常识在哪**：大众默认大厂发布的是面向终端用户的产品（像 Codex、Cursor 那样开箱即用），但 DeepSeek 反其道而行——它邀请全世界开发者进来一起插拔、共建插件生态，普通用户的体验反而被放在次要位置。

**核心证据/论据**：① Cordis 内核极度克制，只管插件装卸与依赖，其余皆插件；② 连 UI 都是可替换插件（社区已有人做皮肤插件）；③ 创造模式让 Agent 直接改造自己、自造插件挂到运行流程上——这是平台/生态玩法，不是成品软件玩法；④ 官方命名用 Harness 而非 Code/Build，版本叫"开发者预览版"。

**可被挑战**：基建定位若不能吸引足够开发者共建生态，插件数量起不来，平台就会沦为"理念先进但无人使用"的空壳；且 DeepSeek V4 Pro 大幅涨价（缓存命中价涨 12 倍、高峰输出 27 元/百万 token）后，单从 API 性价比看已难与 GLM、Qwen 拉开差距，可能削弱开发者涌入的动力。
