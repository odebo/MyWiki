# 没有利他主义者就没有搭便车者

**主张**：在公共品博弈中，搭便车者（free-rider）看似是独立的"理性策略"——别人付钱我白用。诺瓦克揭示其深层依赖关系：**搭便车者必须依赖利他主义者的超额付出来填补亏空，否则集体目标破产，搭便车者自己也一无所获**。因此利他主义者不是搭便车者的受害者，而是其前提条件——**没有圣徒，就没有罪人**。

**反常识在哪**：常识认为利他与自私是两类人的对立策略，自私者剥削利他者。诺瓦克说这种对立是寄生性的——**搭便车者是利他主义者的寄生体**，没有宿主，寄生体也无法存活。在气候博弈中：若所有人都搭便车，气候账户归零，所有人都失去一切；只有当部分人愿意做"利他"4 欧元投资时，搭便车者投 0 欧元才有意义。

**核心证据/论据**：
- 米林斯基气候博弈：若一位玩家投 0（搭便车），必须有另一位玩家投 4（利他）才能保证总额达标 120 欧元
- "如果一位玩家在博弈过程中搭便车，投资为 0，那么必须要有另一位玩家采取'利他'策略，投资为 4，才能保证投资总额达到目标"
- "没有利他主义者，就没有搭便车的动机。没有圣徒，也就没有罪人。"
- 在 90% 灾难版博弈中，半数小组失败——常常是搭便车者过度依赖少数利他者，最后利他者力竭
- 典型案例：第 9 轮 6 位玩家中 4 位投 4 欧元，2 位搭便车；最后一轮搭便车者依然投 0，利他者贡献不足，账户仅 114 欧元，全员空手而归

**核心推论**：
1. **搭便车是衍生策略**：利他主义在进化上先于搭便车——没有合作者就没有可剥削的合作
2. **搭便车者数量有上限**：当利他者被消耗殆尽，搭便车者也会崩溃——这是一场自我限制的寄生
3. **合作系统的脆弱性**：少数搭便车者可以拖垮整个合作生态，因为利他者的"补充"能力是有限的
4. **政策含义**：不必直接惩罚搭便车者，只需**切断其对利他者的依赖通道**——如让搭便车行为公开可见，使利他者能识别并拒绝补充
5. **进化视角**：若搭便车是衍生策略，则利他主义的进化起源需要独立解释（这正是诺瓦克五大合作机制要解决的问题）

**与既有框架的关系**：
- 与 [[气候博弈-诺瓦克]] 直接同源：博弈中的核心动态
- 与 [[公开个人行为是避免公地悲剧的关键-诺瓦克]] 互补：公开化让利他者能识别搭便车者，切断寄生通道
- 与 [[真正的赢家无须惩罚-诺瓦克]] 同源：不靠惩罚搭便车者，而靠奖励利他者和切断搭便车的依赖
- 与 [[五大合作机制-诺瓦克]] 元层关系：五大机制正是利他主义得以进化的独立解释
- 与 [[付出者获取者互利者-格兰特]] 张力：格兰特关注付出者的个体命运，诺瓦克关注利他作为系统稳态的前提
- 与 [[公地悲剧与个体群体利益冲突-弗兰克]] 互补：弗兰克描述困境，诺瓦克揭示困境内部的依赖结构

**可被挑战**：
- "没有利他就没有搭便车"在逻辑上同义反复——任何寄生体都需要宿主，这并非诺瓦克的独特发现
- 现实中的搭便车者可能并不"理性"——许多搭便车行为源于无知或惰性，而非对利他者依赖的计算
- 进化上"利他先于搭便车"的论断难以实证——化石记录不能区分两者出现的先后
- 在某些博弈结构中（如零和博弈），搭便车并不需要利他者存在
- "切断依赖通道"的政策建议可能伤及无辜——公开化机制可能让真正的利他者也被误判
