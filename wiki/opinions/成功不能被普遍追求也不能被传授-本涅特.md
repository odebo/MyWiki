# 成功不能被普遍追求也不能被传授

**主张**：成功意味着从普通人中脱颖而出——这是少数人的特质，不可能成为大多数人的目标。成功人士往往不理解自己为何成功，向广大人群传授"如何脱颖而出"简直荒唐。成功学是"一场少数人达成默契、欺骗多数人的巨大阴谋"。

**反常识在哪**：现代成功学产业（自助书、付费课程、TED演讲、领英网红）都在贩卖"任何人都能成功"的乐观叙事。本涅特在1908年就尖锐指出——这是虚伪的。成功人士分享经验时往往编造荒唐故事，把真相藏起来。成功很少来自勤奋/节俭/智慧——这些美德在普通人身上比在成功者身上更常见。

**核心证据/论据**：
- **成功的定义本身**：成功的核心理念在于从普通人中脱颖而出——向广大人群发表讲话，告诉他们如何脱颖而出，简直荒唐
- **大多数人并不渴望成功**：普通人渴望金钱（达到结婚"社会条件"即止），但不渴望政治权力或科学艺术成就
- **小镇观察**：注定要脱颖而出的极少数人做的第一件事就是离开小镇——留下的人并没有失败，他们低调地实现了自己的目标
- **成功人士往往更懒惰**："我曾近距离研究过成功人士，他们最常见的特征之一就是懒惰，这些人浪费时间的能力极强"
- **成功人士往往更不节俭**：金融家尤其如此
- **成功人士往往更缺乏智慧**："我一次又一次地为成功人士缺乏智慧而感到震惊——他们有时会犯下毁掉一个普通职员的愚蠢行为"
- **成功人士最不讲究条理**：但他们一旦取得成功，就会开始自娱自乐，给大多数人留下"从一开始就专注于目标"的印象
- **富兰克林自传批评**："本杰明·富兰克林的自传是一本令人厌恶的书，也是一本误人子弟的书"——"正是他那可怕的美德和智慧阻碍了他的成功"

**成功三类**：
1. **偶然的成功**：归功于机会——连续押中18次红色，名字会出现在欧洲的所有报纸上，但依然是偶然事件
2. **具有成功才能的人取得的成功**：这类人的特征是
   - 对成功持续不断、永不满⾜的渴望
   - 始终保持警觉（不等同于勤奋）
   - 不按常理出牌——会迷恋疯狂且没有出路的事业
   - 性格灵活，很少做违背道德之事
3. **纯粹高尚品德的成功**：占成功总数的10%（已经很宽容）——因为纯粹的⾼尚品德实在太少

**关键洞察**：
- "成功人士很少能够引导他人取得成功，因为他们往往不理解自己为何成功"
- "用美好、愉快、符合传统定义的方式来讲述成功，是最容易的事情"
- "成功不过是一场少数人达成默契，欺骗多数人的巨大阴谋"
- "伟大的成功从不取决于谦卑的美德，有时甚至可能依赖于傲慢的恶习"
- "我完全相信，从一般情况来看，不成功的大多数人比成功的少数人拥有更多的美德"

**机制**：
1. 成功是少数人特质 → 大多数人不可能"成功"
2. 成功者不理解自己为何成功 → 分享经验时编造故事
3. 用美德叙事包装 → 掩盖真实原因（运气、警觉、不择手段）
4. 大多数人模仿美德叙事 → 失败后责怪自己
5. 美德叙事成为社会共识 → 阴谋持续

**可被挑战**：
- 现代社会流动性比1908年高——教育、制度让更多普通人成功
- "成功不可传授"过于悲观——许多技能确实可学
- 本涅特自己也是成功作家——他的"反成功学"也是成功学的一种
- "美德无用论"可能被滥用为道德虚无主义
- 三类成功的分类缺乏严格实证——基于个人观察
