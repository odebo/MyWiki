# 稀缺陷阱源于借用未来资源

**主张**：稀缺陷阱的核心机制是**借用**——为缓解当下稀缺而挪用未来资源。借高利贷、熬夜赶工、延迟维护、跳过锻炼——所有形式的借用都在用未来的稀缺换取当下的缓解，最终让总稀缺加深。

**反常识在哪**：直觉认为"先解决眼前再说"是务实，借用未来是合理选择。穆来纳森论证：在稀缺状态下，借用几乎总是错误的——它用短期缓解换取长期加深，且因为管窥效应，借用者无法看到长期代价。

**核心证据/论据**：
1. **发薪日贷款研究**：使用发薪日贷款的人，破产概率显著上升——短期救命变长期负债
2. **睡眠借用**：熬夜赶工 → 第二天效率下降 → 需要更多熬夜
3. **维护延迟**：跳过保养 → 设备故障 → 更长停机
4. **社交借用**：忽视关系 → 关系变差 → 需要更多精力修复
5. **借用者的认知偏差**：未来在管窥之外，借用代价被系统性低估

**可被挑战**：
- 有些借用是必要的：紧急医疗、突发失业——拒绝借用不现实
- 时间贴现理论：未来资源本来就应被贴现，借用合理
- 富人也会借用（信用卡、房贷），为什么不会陷入陷阱？因为有余闲缓冲
- 借用与投资的边界模糊：教育贷款是借用还是投资？
