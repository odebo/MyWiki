# 大脑将所有信息当真相输入决定输出

**主张**：大脑和电脑一样，把传达给它的信息当真相处理——输入"你棒极了"大脑就相信，输入"你不行"大脑也相信。因此输入决定输出，建立积极过滤系统不是自我欺骗，而是利用大脑特性。

**反常识在哪**：常识认为大脑会"判断"信息的真伪——"开玩笑！我比你更了解你自己"。布兰佳主张相反：大脑不会主动否定输入，而是被动处理所有信息——"垃圾进，垃圾出"。

**核心证据/论据**：
- 电脑隐喻：电脑不会说"你是从哪儿得到这些信息的？它们是错误的"——人脑也是
- 镜子实验：早晨对自己说"你棒极了"，大脑不会反驳"开玩笑"
- 童年标签化：被标签"不擅长写作" → 大脑相信 → 限制行为；被肯定"写作好" → 大脑相信 → 强化行为
- 布兰佳本人经历：被系主任鼓励写作 → 40 年后仍在写教科书
- 与 [[期望效应-罗布森]] 的"具体信念改变现实"一致

**两层含义**：
1. **外部输入塑造内部信念**：从小接收的信息形成自我认知
2. **内部输入（自我对话）强化信念**：自己对自己说的话被大脑当真相
- 因此：主动选择信息源 + 主动管理自我对话 = 主动塑造信念

**可被挑战**：
- 大脑并非完全被动——批判性思维确实存在
- 信息真伪判断部分由前额叶完成——这是大脑的功能
- "大脑相信一切"过于简化——人们会抗拒与核心信念冲突的信息（[[证真偏差-莎罗特]]）
- 心理学研究表明，强烈反信念的信息会被拒收（回旋镖效应）
- 自我肯定运动（"每天对自己说我真棒"）的实证效果有限

**与相关观点的对比**：
- 与 [[期望效应-罗布森]] 一致：信念塑造现实
- 与 [[吸引力法则-希克斯]] 部分重叠，但布兰佳不依赖超自然机制
- 与 [[证真偏差-莎罗特]] 形成微妙张力：大脑既被动接受信息，又主动过滤冲突信息——这两个机制并存
- 与 [[积极心理学-塞利格曼]] 的"习得性乐观"一致

**实践含义**：主动选择信息源（媒体、朋友、环境）；管理自我对话（用积极陈述替代消极自语）；教育孩子时强化积极行为而非只纠正消极；用绿灯思维处理新信息。
