# 打破常识才能开创新事业

**主张**：开创新事业的前提是打破"行业默认"的常识——所谓常识往往只是被默认接受的做法，未必合理。7-Eleven 的每项重大创新（在日本开便利店/密集选址/共同配送/便利店开银行/朝令夕改）都是打破常识的结果。

**反常识在哪**：常人把"行业常识"作为行动依据——大家都这么做，所以这么做是对的。铃木敏文指出这是"被牵制"——常识是过去的累积，环境变化时常识就过时。开创新事业需要先质疑常识。

**核心证据/论据**：
- 1970 年代日本没有便利店，业内认为便利店不可能在日本生存——铃木敏文打破这一常识
- "每个厂商各自配送"是行业常识——共同配送打破它，物流效率大幅提升
- "便利店不能开银行"是常识——Seven 银行打破它，三年内盈利
- "决策要稳定"是管理常识——朝令夕改打破它，反而更敏捷
- 这些创新都遭到内部强烈反对，但都取得成功

**可被挑战**：
- 不是所有常识都该打破——某些常识是经验的精华
- "打破常识"需要承担风险——失败的案例不会被记录
- 铃木敏文的成功有偶然性——不能简单复制
- 有些"打破常识"是企业为了差异化而差异化，未必真正解决问题

**判别标准**：
- 常识是基于过去环境的——环境变化时该质疑
- 常识是否真正服务客户需求——若只是行业惯例该质疑
- 打破常识是否创造真实价值——若只是营销噱头则不必

- 与 [[把你的思维横起来-斯隆]] 的"把所有既定假设抛到脑后"同源
- 与 [[横向思维四特征-斯隆]] 印证——质疑默认假设
- 印证 [[一次只做一件事-拉塞尔]] 的"深挖真正的问题"
