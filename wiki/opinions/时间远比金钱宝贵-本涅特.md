# 时间远比金钱宝贵

**主张**：时间远比金钱宝贵。金钱可以赚取、被偷、借贷、储存、贬值——时间不可借、不可偷、不可储存、人人平等、每日重置。把金钱当作最宝贵资源是根本性误判，时间才是真正应该审慎管理的财富。

**反常识在哪**：整个消费文化都在讨论"有多少钱过多少钱的日子"——报纸、杂志、电视、社交媒体都在贩卖"理财"。但从未见"如何度过每天的24小时"成为热门话题。本涅特指出——这是颠倒的优先级。金钱是最普通的东西，世上到处都有金钱的影子；而时间是日复一日的奇迹，每天早晨钱包被重新装满24小时——这是属于个人最宝贵的财富。

**核心证据/论据**：
- **金钱可被夺走，时间不可**：金钱可以被偷、被骗、贬值；时间偷不走，谁也夺不去
- **金钱不平等，时间平等**：金钱财富和知识都换不来时间特权——就算是天才，一天也不会变成25小时
- **金钱可借贷，时间不可**：你不能预支未来，所以不可能欠下时间债；只能浪费当下的时间，不能浪费明天
- **金钱可储存，时间不可**：金钱可以存银行，时间一去不返
- **金钱可赚取，时间不可**：金钱可以多干活挣回来；时间无论你做什么，明天都是固定的24小时
- **时间比政府债券还可靠**：支付不受礼拜天影响——总量永远不变

**机制**：
1. 误以为金钱是最宝贵资源 → 把精力放在赚钱上
2. 忽视时间财富 → 任由时间在通勤、刷手机、瘫坐中流失
3. 错误地把时间看作工作的附属 → 16小时非工作时间被浪费
4. 等到"有时间"才做想做的事 → 永远等不到——因为不会有"更多时间"
5. 临终时才觉知 → 已经来不及

**可被挑战**：
- 对贫困群体，金钱确实比时间更紧迫——本涅特作为中产阶级作家可能低估生存压力
- 金钱可以"买到时间"——雇佣他人、购买工具、改善效率
- 时间虽平等，但不同人的时间"质量"不同——疲劳、病痛、家庭责任影响时间的可支配性
- 本涅特1908年的伦敦郊区上班族情境——与现代远程办公、零工经济情境不同
