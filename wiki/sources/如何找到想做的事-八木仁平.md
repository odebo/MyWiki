# 如何找到想做的事（珍藏版） — 八木仁平

## 书籍信息

- **作者**：八木仁平（日本自我认知方法研究者、咨询师）
- **出版**：机械工业出版社，2025年6月（珍藏版），原版 2015
- **字数**：58千字
- **译者**：徐艺菊

## 作者简介

八木仁平，日本自我认知方法（self-cognition method）研究者。早稻田大学毕业后曾陷入"不知道想做什么"的迷茫期，通过自创"自我认知法"找到自己的人生方向，后成立公司帮助他人寻找想做的事，每年咨询客户约200人。是日本"Ikigai（生存价值）"方法论的当代实践者之一。

## 核心论点

寻找"想做的事"不是直觉问题、行动问题或运气问题，而是**方法论问题**。作者提出"自我认知法"公式：

> **真正想做的事 = 喜欢的事 × 擅长的事 × 重要的事**

- **重要的事（价值观）**：决定"为什么工作"——内在动机源泉
- **擅长的事（才能）**：决定"如何工作"——能力杠杆
- **喜欢的事（热情）**：决定"做什么"——领域兴趣

三者缺一不可，且顺序至关重要：先价值观，再才能，最后热情。

## 章节结构

- 第一章：阻碍找到"想做的事"的5种误区
- 第二章：为什么会因找不到"想做的事"而迷茫
- 第三章：自我认知法公式（三大支柱）
- 第四章：找到"重要的事"（价值观）——5步法
- 第五章：找到"擅长的事"（才能）
- 第六章：找到"喜欢的事"（热情）
- 第七章：组合出"真正想做的事"
- 第八章：自我认知的魔法
- 附录：90个问题清单 + 300个关键词示例

## 核心方法

1. **5种误区破除**：①必须是坚持一生的事 ②命中注定感 ③必须对别人有益 ④必须多行动 ⑤不能成为工作
2. **价值观5步法**：回答5问 → 思维导图 → 由"以他人为中心"转向"以自我为中心" → 优先级排序 → 确定工作目的
3. **才能识别**：通过5个问题找出"无意识中在做"的能力，写《自己的使用说明书》
4. **热情识别**：区分"可作为工作的爱好"与"不能作为工作的爱好"
