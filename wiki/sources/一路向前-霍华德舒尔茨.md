# 一路向前

**作者**：霍华德·舒尔茨（Howard Schultz），星巴克创始人、前CEO。1953年生于布鲁克林公租房，半工半读上完大学，1982年加入只有4家门店的星巴克任销售，1987年收购星巴克并将其打造为全球品牌。

**出版信息**：2011年出版，中信出版社中译版，167页。

**一句话**：舒尔茨2008年重返星巴克CEO职位后的救赎故事——如何在金融危机中面对增长失控、核心价值流失和股价暴跌，带领公司走出低谷。

## 结构

五部分：
- **爱**（第1-7章）：星巴克的文化根基，2008年2月全国7100家门店同一天停业培训咖啡师
- **信心**（第8-14章）：重建信任、重塑咖啡品质
- **痛**（第15-24章）：2008年金融危机中的艰难裁员、关店、股价跌至谷底
- **希望**（第25-28章）：创新回归——星巴克速溶咖啡Via、会员计划
- **勇气**（第29-30章+后记）：数字时代的转型

## 核心故事线

2000年舒尔茨卸任CEO → 星巴克从1000店扩张到16000店 → 自动浓缩咖啡机取代手工调制 → 三明治气味掩盖咖啡香 → 股价暴跌42% → 2008年舒尔茨回归 → 关店/裁员/再培训/重振核心价值 → 2010年创历史最佳业绩
