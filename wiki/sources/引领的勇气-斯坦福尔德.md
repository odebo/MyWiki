# 《引领的勇气：转化自我，创造改变》— 布莱恩·斯坦福尔德

**作者**：布莱恩·斯坦福尔德（R. Brian Stanfield，1931-2006），澳大利亚出生，国际文化事业促进会（ICA）全球学院院长，长期在加拿大和世界各地工作
**出版**：华夏出版社，2024年6月（英文第一版2000年，第二版2012年）
**字数**：186千字

## 一句话总结

领导力不是职位，而是通过对生命经历的持续反思发展的内在智慧——"领导力指南针"包含4个基本关系（与生活/与世界/与社会/与自我），每个关系3个立场，共12个立场作为内在驱动力。

## 全书结构

### 领导力指南针 — 4个基本关系

| 关系 | 核心问题 | 三章/三立场 |
|------|----------|-------------|
| **与生活的关系** | 我每天生活的意义在哪里？ | 每日的关注 / 清醒看待生活 / 持续的肯定 |
| **与世界的关系** | 我基于什么做决定？ | 全面的视角 / 对历史的参与 / 广泛性责任 |
| **与社会的关系** | 在社会变迁中我希望扮演什么角色？ | 社会先锋 / 社会转换方式 / 符号性存在 |
| **与自我的关系** | 我怎样从自身经历中学习，并相信我的内在智慧？ | 自我意识反思 / 每日生活的意义 / 深远的使命 |

### 生命的三个基本问题
1. **我是谁？** — 阅读第1、2、3、10章
2. **我来做什么？** — 阅读第4、5、6、7、8、12章
3. **我怎么做到？** — 阅读第1、3、9、11章

## 作者简介

布莱恩·斯坦福尔德是ICA全球学院院长。本书英文第一版2000年出版，受ICA委托所写——当时协会准备把很多年轻人送往世界较贫穷国家帮助社区发展，年轻人不知将面对什么，ICA希望用一本书呈现"推动社会积极转变的底层哲学"。

斯坦福尔德每天凌晨3:00起床整理书稿。他是"既能综合大量信息、又从许多思想领袖那里汲取智慧"的"一个人的智囊团"。本书内容来自ICA加拿大50多年工作人员和义工的口述智慧，被转化为书面形式。
