# 批判性思维（原书第4版）

**作者简介**：理查德·保罗（Richard Paul，1937–2015），美国批判性思维基金会主席，批判性思维运动的奠基人之一。琳达·埃尔德（Linda Elder），教育心理学家，批判性思维基金会主席。两人合著多部批判性思维教材，致力于将批判性思维推广到各级教育。

**出版信息**：英文原版 *Critical Thinking: Learn the Tools the Best Thinkers Use*；机械工业出版社中文第4版；译者闫庆贺；约380千字。

## 全书结构

### 核心章节

- **绪论** — 批判性思维初始定义+扩展概念
- **第1章 成为公正的思考者** — 弱批判性思维vs强批判性思维、公正心七美德
- **第2章 批判性思维的发展阶段** — 六阶段（非反思型→接受挑战→初级→实践型→高级→成功）
- **第3章 复杂世界中的自我理解** — 自我中心主义、心智三功能、互联网渗透
- **第4章 思维的要件** — 八要素（目的/问题/信息/概念/推论/假设/蕴含/看问题的角度）
- **第5章 理智的标准** — 九大标准（清晰性/准确性/精确性/相关性/深度/广度/逻辑性/重要性/公正性/充分性/一致性）
- **第6章 提出能培养良好思维的问题** — 苏格拉底式诘问、三种问题类型、五聚焦法
- **第7章 掌握思考，掌握内容** — 内容与思维的关系、深度学习
- **第8章 揭晓善思者的学习之道** — 增强学习效果的20个观念、六大学科的逻辑
- **第9章 重新评估自己的思考和学习水平** — 自我评估策略
- **第10-11章 论证** — 批判性思维与论证的关系
- **第12章 非理性思维** — 自我中心与社群中心
- **第13-14章 媒体偏见** — 媒体中的扭曲与谬误
- **第15章 战略思考** — 解决问题的策略
- **第16-17章 学科和专业学习** — 批判性思维工具在学科中的应用

## 核心论点链

1. **诊断**：人类思维天然以自我为中心和以社群为中心，存在缺陷
2. **区分**：批判性思维分强弱两种——弱批判性思维是诡辩，强批判性思维才配称批判性思维
3. **核心**：强批判性思维的核心是公正心，而非单纯技能
4. **结构**：思维由八要素构成，可用九大理智标准评估
5. **方法**：苏格拉底式提问是培养批判性思维的核心方法
6. **过程**：批判性思维发展分六阶段，多数人终生停留在第一阶段
7. **愿景**：批判性思维是终身事业，践行"未经省察的人生不值得度过"

## 经典案例

- **小杰和小静**——派对调情争执，用八要素拆解日常冲突
- **哥伦布与印第安人**——理智的傲慢典型案例，相信奴役符合上帝旨意
- **学术诡辩者**——利用思维技能获高分但未成为公正思考者的学生
- **萨姆纳1906描述**——对强批判性思考者的经典刻画
- **酗酒者比喻**——第三阶段初级思考者类似酗酒者承认酗酒
- **达尔文自述**——靠毅力和不断反思进行自我追问的典范
- **死刑论证信息**——展示信息要素如何为推理增加砝码
- **萨姆纳引语**——强批判性思考者"不仓促行事、不急于相信……"

- 与 [[学会提问-尼尔布朗]] 同源——布朗的10个批判性问题即保罗式提问工具的实操版

- 与 [[认知觉醒-保罗·斯隆]] 区分——斯隆的觉醒偏情绪洞察，保罗的觉醒偏结构省察
- 与 [[控制二分法-爱比克泰德]] 共鸣——斯多葛修行亦分阶段、亦需持续

## 阅读建议

绪论和第1章是核心——定义了批判性思维的本质（强 vs 弱）。第4-5章（八要素+九标准）是核心工具，反复使用即内化。第6章苏格拉底式提问是落地方法。第2章六阶段用于自我定位。第12章非理性思维揭示自我中心和社群中心的根因，是诊断章节。全书不适合略读——需要边读边做"独立思考"练习。
