## 作者简介

布莱恩·阿瑟，复杂性科学与经济学思想家。加州大学伯克利分校运筹学博士，37 岁成为斯坦福大学最年轻的经济学讲席教授。圣塔菲研究所（Santa Fe Institute）外聘教授，主持"复杂性"课题组。1980 年代提出**收益递增理论**（Increasing Returns）——领先者进一步领先、主导市场的正反馈机制，挑战传统经济学的收益递减假设。1990 年获熊彼特奖。研究涵盖复杂系统、认知经济学、技术进化。《技术的本质》是其技术哲学代表作。

## 核心论点

传统技术定义模糊——技术是"科学的应用"、"知识分支"、"实践"——这些定义相互矛盾且未触及"技术的本性"（technology-ness）。阿瑟从三个原理重建技术理论：

1. **组合原理**：新技术是由已有技术组合而成的
2. **递归原理**：技术的组件本身也是技术，递归下去直到基本现象
3. **现象原理**：所有技术都建立在被捕获并使用的自然现象之上

由此得出**技术的本质**：**技术是被捕获并加以利用的现象的集合，或者说，技术是对现象有目的的编程**。技术不是科学的附属品——技术引领科学，技术自我创造，经济是技术的表达。

## 三个技术定义

| 定义 | 范畴 | 形成机制 |
|------|------|----------|
| 单数技术（technology-singular） | 蒸汽机、GPS | 新概念+内部构件修正 |
| 复数技术（technology-plural） | 电子技术、生物技术 | 围绕现象簇建构 |
| 整体技术（technology-general） | 所有过去+现存技术总和 | 旧要素组合成新要素，有机成长 |

## 章节结构

- 前言 技术的追问
- 第1章 问题（缺失了本质的技术、技术的进化、组合进化）
- 第2章 组合与结构（技术结构形成、模块化、递归性）
- 第3章 现象（技术的本质、有目的的系统、捕捉现象、技术与科学）
- 第4章 域（域定、设计如同语言表达、参与的世界）
- 第5章 工程和对应的解决方案（标准工程、解决问题的工程）
- 第6章 技术的起源（基本原理、概念物化、基于现象的发明、因果性金字塔）
- 第7章 结构深化（内部替换、锁定与适应性延伸）
- 第8章 颠覆性改变与重新域定（域如何进化、经济的重新域定、创新与国家竞争力）
- 第9章 进化机制（组合、机会利基、核心机制、思想实验、与生物进化比较）
- 第10章 技术进化所引发的经济进化（经济是技术的表达、结构性变化、解决方案带来的新问题）
- 第11章 我们的立场是什么（技术具有生物属性、繁衍性经济、纯粹秩序与混质活力）

## 与既有知识库的对话

- 与 [[技术元素是天然存在的人类只是发现而非发明-凯文凯利]] 直接对话：凯利提出"技术元素"（technium），阿瑟接受这一概念但主张技术是"被捕获的现象"而非神秘实体
- 与 [[技术以指数而非线性速度增长-库兹韦尔]] 互补：阿瑟解释为什么是组合进化带来指数增长
- 与 [[破坏性技术市场进入策略-克里斯坦森]] 同源：阿瑟的"颠覆性改变与重新域定"是克里斯坦森"破坏性创新"的技术哲学基础
- 与 [[破局者思维-克里斯滕森]] 同源：克里斯滕森关注破坏的市场维度，阿瑟关注破坏的技术维度
- 与 [[复利思维]] 同源：组合进化是复利结构——新技术成为旧技术组合的构件
- 与 [[合作作为第三进化原则-诺瓦克]] 互补：诺瓦克的进化论扩展合作，阿瑟的技术论扩展组合——都是对达尔文式竞争叙事的修正
- 与 [[摩根财团-彻诺]] 历史对照：摩根时代的金融基础设施 vs 阿瑟的技术基础设施——经济如何从基础设施中涌现
- 与 [[进化中的重大转变-诺瓦克]] 同源：技术进化也有"重大转变"——域的颠覆性改变
- 与 [[稀缺陷阱源于借用未来资源-穆来纳森]] 互补：技术创造机会利基 vs 资源稀缺创造借用——机会与稀缺的对偶
- 与 [[无限的游戏-斯涅克]] 同源：技术进化是无限游戏——一旦开始没有理由结束
