# 如何打造你的爆款创意

## 基本信息

- **作者**：戴维·穆雷（David Murray），美国营销创新专家
- **出版年**：2018.7（中文版）
- **出版社**：江西人民出版社·后浪
- **ISBN**：9787210084945
- **字数**：158千字

## 作者简介

戴维·穆雷，美国营销创新专家。曾创办 Preferred Capital 信贷公司，资产从5万美元增长到300名员工、收入超过20万美元、季度翻倍增长。1999年秋天与银行签署5000万美元收购意向书，但银行被联邦存款保险公司关闭，公司随之倒闭，穆雷背负3000万美元债务申请个人破产。

破产后的穆雷隐居亚利桑那州坦佩市，博览创新、商业、心理学、科学、神经病学书籍。创立 Kord Marketing Group 咨询公司，为硅谷著名软件公司提供直销计划咨询，使客户自留额比率提高、收入增加5000万美元。后被任命为《财富》500强服务公司的创新副总裁，担任"创意负责人"职位。本书即来自他"如何教人创新"的实践总结。

## 内容结构

全书六步法 + 结论：

### 第一部分：创意的起源（建筑比喻）
- **第一步：定义**——搞清楚你到底要解决什么问题
  - 湖心岛寓言：定义为岛需要造木筏，定义为半岛走着去就行
  - 识别问题 → 确定根源 → 理解范围 → 选择问题
- **第二步：借鉴**——到处搜集素材，找别人的创意借来用
  - 材料决定设计；来源决定感知
  - 学习竞争对手 → 从观察中借鉴 → 学习其他人 → 从反面借鉴 → 从类似处借鉴 → 从远方借鉴
- **第三步：结合**——将这些不完整的创意排列组合
  - 创意带来复杂性
  - 把比喻当作结构；建立/扩展/舍弃比喻

### 第二部分：创意的进化（进化比喻）
- **第四步：孵化**——搁置一晚沉淀思绪，解决方案自会浮上心头
  - 潜意识思维三阶段：输入 → 孵化 → 产出
  - 爱因斯坦散步寓言
  - 矛盾意向（写作障碍的根源）
- **第五步：判断**——解答会衍生新问题，反复检验看出优缺点
  - 迷姆和创意的进化
  - 判断是观点的结果
  - 消极判断 + 积极判断 + 情绪判断
  - 直觉是判断的结果
- **第六步：提升**——校正每次的失误，你会愈借愈神准
  - 左脑思维 + 右脑思维 = 全脑思维与自组织
  - 天才的模拟
  - 重新定义/借用/组合/孵化/判断——回到前面五步

### 结论：四个创造性的悖论
1. **客观存在的悖论**：复制和创造相互衍生，原创性来自盗贼
2. **智慧悖论**：通过持续学习创造，可以保持年轻头脑（曼卡托修女案例）
3. **情人的悖论**：抓住想法会阻止它发展，必须让想法自由行走（爱因斯坦拒绝自己的相对论）
4. **天才悖论**：创造力需要混乱中的井井有条

## 核心思想

1. **创意是借来的六步法**（[[创意是借来的六步法-穆雷]]）：定义→借鉴→结合→孵化→判断→提升
2. **借用的距离决定创意质量**（[[借用的距离决定创意质量-穆雷]]）：离自身领域越远，想法越有创意
3. **比喻作为创意结构**（[[比喻作为创意结构-穆雷]]）：所有创意都从比喻或类比开始
4. **潜意识思维三阶段**（[[潜意识思维三阶段-穆雷]]）：输入→孵化→产出
5. **迷姆与创意的进化**（[[迷姆与创意的进化-穆雷]]）：判断驱动创意进化

## 核心方法论

- **建筑比喻**（前三步）：问题=地基，借用的想法=材料，组合=结构
- **进化比喻**（后三步）：潜意识=子宫，判断=生存斗争，提升=物种进化
- **比喻四步**：建立→扩展→舍弃→重新选择
- **潜意识三阶段**：输入（喂养）→孵化（让它工作）→产出（聆听）
- **判断三动作**：找出弱点并消除 / 找出优点并提升 / 描述完美解决方案
- **三种判断模式**：消极判断（怀疑论）+ 积极判断（提升优点）+ 情绪判断（直觉）

## 经典案例

- **5000万美元失败**：Preferred Capital 公司被银行关闭导致3000万美元债务，穆雷破产——"花5000万买的真知灼见"
- **湖心岛寓言**：穆雷小时候造木筏去湖心岛，结果是半岛——对问题的定义决定了解决方案
- **韦斯特伯鲁精神病院的比利**：喃喃自语"我要一把枪"（实际是"口香糖"）——重复思想的囚徒
- **牛顿**：苹果=月亮，结合地球物理学和天体物理学
- **达尔文**：选择性育种=自然，结合政治经济学和生物学
- **约翰·纳什**：扑克=微观经济学
- **迪士尼**：电影=游乐园
- **乔治·卢卡斯**：神话=科幻电影（《星球大战》）
- **弗洛伊德**：水力/军事=心理学
- **比尔·盖茨**：桌面=电脑屏幕
- **雅虎 vs 谷歌**：门户比喻 vs 图书馆比喻——后者更有效
- **iPod 进化链**：留声机→随身听→iPod
- **乔布斯**："这些产品太糟糕了！他们都没有差异。"——怀疑论者案例
- **爱因斯坦散步寓言**：忘记自己要去哪个方向——与潜意识深刻连接
- **曼卡托修女**：90岁仍自如生活、无人患阿尔茨海默病——持续学习创造保持年轻头脑
- **爱因斯坦拒绝自己的相对论**：想法要让它自由行走
