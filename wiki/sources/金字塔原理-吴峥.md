# 金字塔原理 — 吴峥（2021）

**作者简介**：吴峥，本书作者，以通俗易懂的中文系统介绍麦肯锡经典思维方法"金字塔原理"，面向职场人士讲解如何用结构化思维提升思考、表达、沟通、写作与解决问题的能力。原书由江苏凤凰文艺出版社·酷威文化于 2021 年 3 月出版，字数约 92 千字。

**全书摘要**：全书以芭芭拉·明托提出的"金字塔原理"为纲，从"想不对、说不对、做不对"的根源切入，系统阐述结构化思维。核心主张是：思维决定行为，而思维可以被结构化、可以被训练。书中先讲原理（四项基本规则、纵向与横向关系、序言、演绎与归纳推理），再讲应用（沟通、工作文章、演示、解决问题），最后升华到"金字塔原理的本质是组织思想的模式"，并以大脑可塑性与外展推理收尾。

**章节结构**：
- 引言：登顶金字塔，见证成长
- 第一部分 原理篇
  - 第一章 说不对，做不对，根源在于想不对（思维决定行为 / 别让沟通添堵 / 解决问题还是制造问题 / 演绎与归纳）
  - 第二章 金字塔的基石——认识金字塔原理（结构特点 / 四项基本规则 / 纵向与横向关系、序言）
  - 第三章 利用金字塔原理重塑思维（逻辑先行 / 5W2H、演绎与归纳、MECE / 概括分组思想）
- 第二部分 应用篇
  - 第四章 实现精准表达与高效沟通（沟通准备 / 会说与会听 / 总分总、TOPS、GROW、FABE、SPIN）
  - 第五章 打造完美的工作文章（自上而下与自下而上 / 工作文体套路 / SCQA、模仿、关键句、逻辑规律 / 演示结构）
  - 第六章 如何分析和解决问题（界定问题 / 诊断框架 / 逻辑树）
  - 第七章 应用金字塔原理的进一步探索（金字塔原理的本质 / 无结构问题与外展推理）
