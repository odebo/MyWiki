# 个人破局指南系列（共六册） — 九边（2018—2023）

**作者简介**：本系列为得到 APP 推出的「个人破局指南」六册套装，元数据署名作者为九边（本系列首册《复杂世界的明白人》作者，程序员出身、全网近千万关注者的成长类博主，另著有《向上生长》《弹性生长》）。六册实为六位不同作者的作品合辑：九边《复杂世界的明白人》、郑毓煌与苏丹《理性的非理性》、顾及《破圈》、剽悍一只猫《一年顶十年》、张萌《让你的时间更有价值》、张萌《加速》。

**全书摘要**：六册书围绕「个人如何破局、向上生长」这一共同主题，分别从宏观认知、决策心理、自我认知、实战方法论、时间价值、效率体系六个角度切入。九边讲「选择、努力与国运」的底层逻辑（三道窄门、15% 法则、位置与圈层、财富与运气）；郑毓煌讲人（消费者）的「非理性决策」规律（十大效应）；顾及讲「认知破圈」的方法（情绪体、记忆体、信念体三法则）；剽悍一只猫讲「一年顶十年」的实战成长术（时间投资、见牛人、打造个人品牌）；张萌讲「让人生更贵」的财富高效能与逆袭系统；再以《加速》收束于精力、认知、思维、人脉、健康的完整效率体系。全套书的共同底色是：破局的关键不在于拼蛮力，而在于认知升级、价值输出与主动选择。

**章节结构**（按套装顺序）：
1. 《复杂世界的明白人》（九边，2021）：选择和努力都重要 / 大神是怎样炼成的 / 起点不高该如何向上攀爬 / 国运向上，个人怎样赶上潮头 / 立足当下，看清未来发展趋势 / 放眼全球，我们该如何突围。
2. 《理性的非理性》（郑毓煌、苏丹，2023）：对比效应 / 评估模式 / 折中效应 / 沉没成本 / 损失规避 / 禀赋效应 / 心理账户 / 交易效用 / 锚定效应 / 过度自信，共十章。
3. 《破圈》（顾及，2021）：什么是认知破圈 / 认知破圈三步骤 / 摆脱你的情绪体（法则一）/ 扭转你的记忆体（法则二）/ 击穿你的信念体（法则三）/ 升级心智，终身成长。
4. 《一年顶十年》（剽悍一只猫，2020）：打基础（时间、状态、情商、学霸、读书、写作、讲课、牛人）、大升级（贵人、团队、社群、销售、品牌、冠军、赚钱、写书）、终极（财富与影响力升级的十大心法）。
5. 《让你的时间更有价值》（张萌，2020）：时间价值很高的人生是什么样子的 / 改变是怎么发生的 / 你的私人定制版人生应该是什么样的 / 奋斗的路上白骨森森，成功的人凭什么 / 你的人生需要强大的助力系统 / 没有核心加速器，外挂开过头会怎么样。
6. 《加速》（张萌，2018）：精力管理 / 认知管理 / 思维管理 / 人脉管理 / 健康管理，内含 SMART 法则、甘特图、目标分解三法、18 个周期礼物法、单点突破法、刻意练习、心理表征等 49 个效率方法。
