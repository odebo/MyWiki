# 大教堂与集市 — Eric S. Raymond（1999）

**作者简介**：Eric S. Raymond（ESR），美国程序员、黑客文化理论家与开源运动代言人。他自称"互联网黑客的观察者/参与者人类学家"，长期以参与者身份研究黑客群体的习俗、信念与关系，被誉为"黑客文化第一理论家"。他是《新黑客词典》（The New Hacker's Dictionary）的主编，GNU 早期贡献者，开源邮件程序 fetchmail 的作者；1998 年参与创造了"开放源码"（Open Source）一词，并担任开放源码促进会（OSI）首任主席、VA Linux Systems 董事。他极力为"黑客"正名——黑客是着迷技术、通过编程创造价值的人，与搞破坏的"骇客"（cracker）严格区分。本书中文版 2014 年由机械工业出版社出版，译者为卫剑钒。

**全书摘要**：本书是 Raymond 写于 1992—1999 年间的系列文章合集，是开源运动最重要的理论文献之一。核心命题是：以 Linux 为代表的"集市"开发模式（松散、并行、开放、早发布常发布）在生产力、bug 控制与创新上优于传统商业软件的"大教堂"模式（集中、封闭、等级森严）。作者以自己把 popclient 改造成 fetchmail 的亲身经历验证这套理论，提炼出 19 条开源开发格言；继而从社会动力学（礼物文化、声誉竞争、Lockean 财产权惯例）和经济学（使用价值 vs 销售价值、九种开源商业模式）两个层面解释开源为何能持续运转，并记录了 1998 年网景开放 Mozilla 源码所引爆的"开源革命"及其媒体战略。

**章节结构**：1. 黑客圈简史——从"真程序员"、MIT 早期黑客、UNIX 兴起到 Linux 与 Web 大爆发的黑客文化史；2. 大教堂与集市——核心文章，对比两种开发模式，19 条格言与 fetchmail 案例；3. 开垦心智层——黑客所有权惯例、礼物文化与声誉竞争的社会动力学；4. 魔法锅——开源经济学，批驳"工厂模型"，提出九种开源商业模式；5. 黑客的反击——1998 开源革命与"开放源码"品牌再塑。另附"如何成为一名黑客"与 fetchmail 成长统计两个附录。
