# 翻过自己的山

## 书籍信息

- **原书名**：《How I Learned to Understand the World》
- **作者**：汉斯·罗斯林（Hans Rosling，1948-2017，瑞典）
- **合作者**：范妮·黑尔格斯坦（Fanny Häggström，后记作者，完成手稿整理）
- **出版**：瑞典自然与文化出版社；中文版2021年
- **类型**：回忆录（与《事实》为姊妹篇，本书聚焦个人经历）

## 作者简介

汉斯·罗斯林，瑞典公共卫生学家、卡罗琳医学院国际卫生系教授。1948年生于瑞典乌普萨拉工人阶级家庭，14岁与妻子阿格妮塔相识。1979-1981年携家赴莫桑比克纳卡拉担任地区医生，后转向流行病学研究（konzo疾病、古巴流行病调查）。1990年代末与儿子奥拉、儿媳安娜共同创立Gapminder基金会，开发动态气泡图。2006年起在TED演讲，成为全球知名公共知识分子。2017年因癌症去世，享年68岁。

## 全书结构

全书7章+后记，按时间顺序讲述罗斯林如何通过实地工作"学会理解世界"：

1. **从目不识丁到教授职位** — 家族史：曾祖母文盲→祖母初小→父亲技工→本人教授，三代人浓缩瑞典百年发展
2. **探索世界的冒险** — 搭车穿越欧洲、柏林墙、印度；父亲咖啡豆里的硬币启发全球好奇心
3. **来到纳卡拉** — 莫桑比克地区医生；自行车事件、恩里克爸爸的眼镜、"起初只改变必须改变的"
4. **从医生到研究员** — konzo疾病调查；露西亚妈妈；50万人口普查；从临床转向研究
5. **古巴的意外发现** — 卡斯特罗邀请调查流行病；马埃斯特拉山的研究方法；黑市价格数据
6. **走上达沃斯讲台** — 气泡图诞生；Gapminder基金会；TED演讲；达沃斯精英测试
7. **抗击埃博拉** — 2014利比里亚；卢克·巴沃；阶段性转变；米亚塔的选择
- **后记**（范妮·黑尔格斯坦）— 罗斯林最后一年与本书写作过程

## 核心论证链

罗斯林通过个人经历展示"理解世界"是如何被习得的：

1. **家庭微缩模型** → 三代人文盲到教授，瑞典发展通过经济增长+社会服务+公民组织实现
2. **实地工作** → 莫桑比克/古巴/利比里亚的经历打破"我们vs他们"的二元观
3. **数据可视化** → 气泡图让学生看到世界是连续的图，不是分裂的两类国家
4. **消除偏见** → 学生比黑猩猩还差（36% vs 33%），说明问题不是知识空白而是先入之见
5. **可能性论者** → 既非乐观也非悲观，基于事实判断什么有可能改变

## 关键洞见

- **"小毯子"原则**：在资源极度匮乏环境工作，不要把毯子撕成两半试图覆盖所有需求——保持自己囫囵个儿才能持续工作
- **2×2优先级矩阵**：重要/不重要 × 容易/困难，用于在100倍需求vs1%资源的处境中排序
- **基于信任的实地调查**：先与村中权势人物搞好关系，为采访者创造空间和时间
- **"起初只改变必须改变的"**：文化敏感性——自行车在莫桑比克让白人成笑柄，先适应再改变
- **数据必须民用**：安娜的"美元街"程序让官方统计数据进入普通人的视野
- **指数增长的恐惧**：埃博拉每三周翻倍，9周后是8倍
- **阶段性转变**：从"救火阶段"转"侦查阶段"，从数字转姓名，从收治转追踪
- **"想说放弃什么时候都不晚，我们不如改天再说放弃吧"**

## 与《事实》的关系

《事实》是方法论（如何用数据消除认知偏差），《翻过自己的山》是个人史（这些认知是如何从实地工作中长出来的）。两书互为表里——本书回答"罗斯林凭什么能看清楚世界"，《事实》回答"普通人如何像他一样看清楚世界"。
