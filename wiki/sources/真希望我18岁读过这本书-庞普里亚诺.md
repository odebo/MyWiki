# 真希望我18岁读过这本书 — 庞普里亚诺

## 书籍信息

- **作者**：安东尼·庞普里亚诺（Anthony Pompliano，美国企业家、投资家、社交媒体影响者）
- **出版**：中信出版集团，2025年10月
- **字数**：71千字

## 作者简介

安东尼·庞普里亚诺，美国企业家、投资家、社交媒体影响者。曾在美国陆军步兵服役，2008-2009年被派遣到伊拉克。游历过30多个国家，组建幸福家庭并实现财务自由。以"Pomp"为名在社交媒体拥有大量关注者，专注投资与个人成长内容创作。

## 核心定位

这不是一本系统性方法论著作，而是**65封给子女的信**——作者原本因"怕活不过35岁"而写给孩子的家书，后扩展为出版书籍。每章独立成文，既有相辅相成的呼应，也有相互矛盾的张力（作者强调"语境很重要"）。这种"家书式"的写作使内容具有温度和具体性。

## 65封信的核心主题

| 主题簇 | 代表信 |
|--------|--------|
| 行动与努力 | 把小事做到尽善尽美、所有努力总会派上用场、未完成就是未开始 |
| 长期主义 | 日复一日才是关键、最完美的持有期限是永远、与"复利者"同行 |
| 人际与真诚 | 真诚是必杀技、为什么是人际破局的关键、奔赴每场"面对面"的联结 |
| 心态与韧性 | 不要向下比较、生活不会一坏到底、总有办法应对生活的乱拳 |
| 财务与投资 | 不要负债、有钱的朋友出手早、最完美的持有期限是永远 |
| 学习与思考 | 想法要跟着事实变、清晰写作有助于清晰思考、选择性输入信息 |
| 健康与生活 | 睡眠是最好的药方、运动锻炼内心、散步解决问题 |
