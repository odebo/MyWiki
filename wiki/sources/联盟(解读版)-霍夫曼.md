# 联盟（解读版） — 里德·霍夫曼（2015）

**作者简介**：里德·霍夫曼（Reid Hoffman），领英（LinkedIn）联合创始人、硅谷知名天使投资人，PayPal「黑帮」核心成员，现为风险投资机构 Greylock Partners 合伙人。他与管理学者、创业者本·卡斯诺查（Ben Casnocha）、克里斯·叶（Chris Yeh）此前合著过《至关重要的关系》（The Startup of You）。本书英文原版《联盟》（The Alliance: Managing Talent in the Networked Age，2014）系统提出「联盟」这一新型雇佣关系框架，是霍夫曼「个人职业即创业」思想在组织层面的延伸。本书为精简解读版，由林杨攀解读。

**全书摘要**：核心论断——终身雇佣制的时代已经过去，取而代之的是「联盟」式的雇佣关系：雇主与雇员自愿达成有明确条款的互惠约定，围绕共同目标（公司的成长）相互投资，实现双赢。全书给出了建立联盟的完整路径：先明确三种任期（轮转期、转变期、基础期），确定联盟只适用于「转变期」员工；再通过开诚布公的双向对话协调双方的目标与价值观、制定具体的任期计划；然后投资于人脉情报网，把员工个人人脉变成公司的情报来源；最后投资于同事联络网，让前员工成为公司终身互惠的资产。全书的核心是「互惠」二字——这一关系永远是双向的：管理者公开谈论他愿意在员工身上的投入与期望的回报，员工也谈论他期望的成长与能做的贡献。

**章节结构**：1. 导读（提出人才流动背景与全新人才观）→ 2. 终身雇佣制的时代已经过去，联盟式的新型雇佣时代来临（交易式雇佣的困境、共同目标=公司成长、联盟的互惠定义）→ 3. 通过开诚布公的双向对话建立联盟（三种任期、协调目标与价值观、制定任期计划）→ 4. 重视人脉情报，它将给公司带来意想不到的收获与灵感（人脉情报网的作用与实施计划）→ 5. 投资于同事联络网，才能保证联盟发挥持续互惠的作用（前员工的价值与联络网策略）→ 6. 总结（联盟的核心观点）。
