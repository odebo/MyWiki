# 进化的力量 3 — 刘润（2024）

**作者简介**：刘润，润米咨询创始人、前微软战略合作总监、商业顾问，得到APP《5分钟商学院》主理人，著有《底层逻辑》系列与《进化的力量》系列。从2021年起每年举办「进化的力量·刘润年度演讲」，本书即2023年度演讲（主题「寒武纪大爆发」）的文字化扩展。作者以每年约120天出差实地调研（问道中国、黑马私董会、季度盛宴三项活动）作为核心输入，辅以「须鲸式」读书、电脑里维持约1400份报告、进化岛社群答疑（上万岛民），最后闭关一个月把11个月的输入打磨成4小时输出，再扩写为本书。

**全书摘要**：全书用「寒武纪大爆发」作隐喻解释2023年商业世界的扑朔迷离——一边是「越降价越增长」的消费降级，一边是「越涨价越好卖」的消费升级；一边是史诗级裁员，一边是历史性投资。作者的核心命题是「所有结果的复杂，都是因为原因的多样」：寒武纪物种大爆发并非单一原因，而是「雪球地球」腾出生态位、氧气大幅增加、HOX基因带来形态多样、捕食者问世加速进化这四条线索交织的结果。以此类推，2023年的迷雾背后也藏着六条关键线索——增长收敛、人口老化、情绪生长、智能涌现、服务崛起、出海加速。作者的方法论立场是「越是巨大的变化，越是蕴藏着巨大的机会」，长期主义者应当「踏平波动，穿越周期，拥抱趋势」。

**章节结构**：
- 序言：输入方法论（120天调研 + 读书 + 读报告 + 进化岛），解释为何「寻找比思考更重要」
- 第1章 寒武纪大爆发：区分「难」（努力程度）与「复杂」（混乱程度）；确立全书总纲与六条线索
- 第2章 增长收敛：索洛收敛、中速区间奖励竞争力、波特三大战略、三阶段驱动（市场→领导力→创新）
- 第3章 人口老化：人口抚养比、延迟退休、萎缩市场与行业集中、人机协同、老年市场的差异化本质
- 第4章 情绪生长：情绪价值定义、产品三价值、疗愈/陪伴/优越三种情绪价值来源
- 第5章 智能涌现：连接主义与涌现、生产率公式、智能副驾、人机关系
- 第6章 服务崛起：品类分化与触点集中、做别人「不会做」的事、三产融合与预制菜
- 第7章 出海加速：全球化的震荡与重置、靠技术创新走得更深、扬科技的帆划当地的桨
- 第8章 逆风飞扬：抢风航行、三轮生态位争夺赛、五三一战略法、战略与执行
- 后记：少年的模样——三个创业者（钟承湛、赵德力、荣耀中）逆势增长的故事
