# 《可复制的极简学习法》— 清水章弘

**作者**：清水章弘，日本学习法教练，东京·京都 Plus-T 辅导班创办人，初中至高中学习法主讲
**出版**：机械工业出版社，2024年4月
**字数**：56千字

## 一句话总结

学习的本质是把"不会"变为"会"，全过程分为"预习→上课→复习→考试"四个步骤；掌握学习方法而非死记硬背内容，自学能力的核心是享受的能力。

## 全书结构

- **特辑 即日可做的5个"输出学习法"**
  - 锻炼语文能力的"报纸学习法"（画线学习法→200字总结作文）
  - 巩固所学的"回针缝记忆法"（前进一下，返回，再次前进）
  - 课堂上就能总结的"消失笔记术"（橙色笔+红色卡片自创问题集）
  - 课堂上掌握要点的"测试笔记术"（以Q&A形式记录板书）
  - 压缩学习时间的"前后1分钟复习法"（课前1分钟+课后1分钟）
- **第1章 学习前要知道的事** — "初一反差"、自学能力、学习是把"不会"变为"会"
- **第2章 学习的四个步骤** — 预习/上课/复习/考试各自的意义与做法
- **第3章 各学科的学习方法** — 英语/数学/语文/理科/文科的具体方法

## 清水式9大法则

| 阶段 | 法则 |
|------|------|
| 预习 | ①把疑问写在课本或笔记本上；②事先准备好"自己的答案" |
| 上课 | ③张弛有度地全面运转大脑；④记录之后想要回看的笔记；⑤在课堂上尽力记忆 |
| 复习 | ⑥"记忆型"复习；⑦"解答型"复习 |
| 考试 | ⑧把握考试出题的"趋势"；⑨根据趋势制定"对策" |

## 作者简介

清水章弘自20岁创办公司，长期在日本初高中开展学习法讲座。本书是其第6本著作，专门为初中生所写——他认为"初一反差"是日本教育的普遍问题：升入初中后学习难度骤增、学科分化、排名压力，导致大量学生厌学。他的方法论核心是把"学习"从模糊概念拆解为四个明确步骤，每步都有具体动作与意义。
