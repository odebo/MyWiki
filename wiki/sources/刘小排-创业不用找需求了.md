# 刘小排 · 创业不用找需求了，给产品加个 Open 就行

## 来源

抖音作品《创业不用找需求了，给产品加个 Open 就行！？》（2026-05），原始链接已脱敏，内容综合自刘小排的公开沙龙实录与专访（Linkloud 第四十二期《烧掉 77 亿 Token 前，我如何发现 AI 产品的真需求》、十字路口播客《揭秘 Claude Code 榜一大哥》）。

## 作者简介

刘小排，87 年生，重庆大学本科毕业。前猎豹移动产品总监（十年，师从傅盛），2024 年 12 月离职创业。**Raphael AI** 创始人（文生图平台，2026 年 1 月月活 145 万）、AI 编程课程讲师、SCAI 孵化器联合创始人；因每月消耗约 5 万美元的 Claude Code Token 而被称为"Claude Code 榜一大哥"。3 年上线约 50 款产品，团队仅 6-7 人、未融资。

## 核心观点摘要

1. **"Open 生态就是新需求池"**：他关注创业者围绕 OpenClaw 等开源生态做产品（2026-03 微博分享过 7 个生态案例）——底层工具开放后，新的产品机会就涌现了。
2. **真需求只能被发现，不能被发明**：起点是"我注意到（I've noticed）"，而非从技术/履历推导方向（见 [[真需求只能被发现不能发明-刘小排]]）。
3. **收集抱怨是最朴素的需求发现法**：线下收集抱怨，对方愿意当场付定金才是真需求。
4. **用 AI 实现"能力跃迁"而非"效率提升"**：数字员工替代岗位（Codex 替代 12 个岗位），一个人+Agent 完成过去一个人做不到的事（见 [[执行在贬值判断在升值-刘小排]]）。
5. **MVP 快速试错、大胆放弃**："拿出去让用户骂"，付费率不达标就放弃。
