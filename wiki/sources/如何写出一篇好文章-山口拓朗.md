# 如何写出一篇好文章：不动笔就能学会写文章的训练法 — 山口拓朗（2019）

**作者简介**：山口拓朗，日本职业撰稿人，曾做过编辑、记者、文案设计者、作家，靠笔杆子为生十八年，曾每月为十到十五家杂志供稿。刚做自由职业者时，因编辑接连批评「写得复杂」「没考虑读者感受」「没有说服力」，他一度动摇职业信心，转而大量研读公认「有趣、通俗易懂、深刻、犀利」的文章，最终意识到自己与优秀作家的差距不在「写作技巧」而在「思考」和「准备」，由此摸索出「不动笔就能学会写文章」的自我钻研训练法，并出版本书向大众讲授。

**全书摘要**：全书的核心命题是「在开始动笔之前，文章是好是坏，十有八九就已经定了」——写好文章靠的不是繁琐的写作技巧，而是动笔前的「思考」与「准备」。作者围绕「如何写出通俗易懂、有说服力、有深度、吸引人的文章」四大目标，把 32 项「不动笔」训练编排成六章：每项训练几乎都不需要纸笔，可在通勤、吃饭、洗澡、散步时用两三分钟完成。方法覆盖读者定位、说写输出、自问自答、专注开关、截稿冲刺、近义词储备、结论先行、删减一半、抽象转具体、术语共识、比较与范围、5W3H、目的与目标、信息加原因、举例、事实与判断、事实导出结论、总而言之、比喻、多视角、深挖情绪、细节描写、乘法发现力、开头广告词、引号临场感、诚实表达、谈体验、讲故事、自信与决心、逻辑与情感、拟声拟态词等，最后以「写文章改变人生」的七个建议收束。

**章节结构**：
- 前言：提出「你也有写文章的才能」与「动笔前文章好坏已定」的核心理念
- 第1章 全面提高写作能力的训练（1-6）：以读者为中心 / 说和写 / 自问自答 / 发现开关 / 设定最后期限 / 列举近义词
- 第2章 写出通俗易懂的文章的训练（7-11）：确定尺度 / 删减一半 / 抽象→具体 / 简单明了说明 / 比较与设定范围
- 第3章 写出有说服力的文章的训练（12-19）：5W3H / 目的与目标 / 信息+原因 / 举例 / 分辨事实 / 用「所以」导出结论 / 用「总而言之」 / 比喻
- 第4章 写出有深度的文章的训练（20-23）：收集视角 / 「为什么」与喜怒哀乐 / 描写细节 / 「乘法」
- 第5章 写出吸引读者的文章的训练（24-31）：领会广告词 / 表达心情 / 认可他人 / 唤起体验 / 讲故事 / 斩钉截铁 / 区分逻辑派情感派 / 拟声拟态词会话
- 第6章 通过写文章改变你的世界和人生（32）：为文章增添光彩的七个建议
- 结语：重申「文章就是你自己」，鼓励读者挖掘沉睡的潜能
