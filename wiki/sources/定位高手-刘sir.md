# 定位高手：找准你的人生赛道，持续占领用户心智 — 刘sir（2023）

**作者简介**：刘sir（刘杰辉），资深出版策划人、内容操盘手。26 岁成为磨铁图书最年轻高管，创立财经图书品牌「黑天鹅图书」，30 岁前在两家头部公司任高管，30 岁后连续创业，现任合生载物创始人、「书香学舍」主理人，个人 IP 为「刘sir一书一课」。20 年操盘 2000 多本书、200 余套课程，与李开复、罗振宇、古典、于丹、韩秀云等大咖合作过内容作品，个人经历为「问题青年—民工—大学生—出版高管—连续创业者」的逆袭轨迹。

**全书摘要**：本书把特劳特/里斯的品牌定位理论从企业迁移到个人，核心主张是「人生需要做减法」——个人定位的本质是在「少」里面看到更多。全书沿五条主线展开：个人定位的原则与逻辑、个人品牌与内容输出、可持续的超级个体进化、定位与优势探索的方法、动态平衡的赢家策略，另附「人生进阶的职业框架模型」八张图。作者以自身经历为暗线反复论证：定位不对，努力白费；认知站在高处，一切生产要素都能被组织。

**章节结构**：
- 序言「人生需要做减法」：作者自述与核心命题「一本书定位的底层逻辑是 IP 定位，IP 定位的底层逻辑是职业定位，职业定位的底层逻辑是人生定位」。
- 第 1 章「个人定位的原则与逻辑」：八个定位误区、定位是什么（点线面体）、定位三原则（少就是多／慢就是快／后发先至）、定位的四层逻辑、定位必经的四个阶段、个人定位的五个「一」。
- 第 2 章「个人品牌与内容输出」：知识经济时代的机会、内容输出原则（定位垂直／内容漏斗／知识分层）、立好人设、IP 名与核心标签、个人简介写法、从图文语言到口头语的回归、内容变现四层次、100 个基本问题、搭输出框架、写作练习、成为教练、写工作手册。
- 第 3 章「可持续的超级个体进化原则」：超级 IP 核心能力（现实扭曲力场）、IP 持续成长四原则、原创理论五步搭建、创始人 IP 四维度、讲 IP 故事方法论、自成长系统、如何提问、每个人都可以出一本书。
- 第 4 章「定位与优势探索的方法」：找准职业定位（24 型心力测评）、稀缺性原则、优势是特质的正向发挥、发现真正的优势、优势的三个层次、刻意练习、放大优势链接力、守住核心能力圈。
- 第 5 章「动态平衡的赢家策略」：成事最重要的是愿力、远离焦虑、将心智成本转化为心智资本、摆脱自动化陷阱、成长型思维、思维破限找利益结合部、助推成长、开启指数成长的思维模型。
- 附录：成长进阶、向上生长、沟通策略、T 型能力、达克效应、第二曲线、登梯策略、把握趋势八张框架图。
- 后记「初心常在，未来可期」：总结「专业力是 1，分享力加 0，品牌力再加 0」的价值放大公式，主张守住专业力这个「1」。
