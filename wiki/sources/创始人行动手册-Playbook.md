# 《The Founder's Playbook》— 创始人行动手册

- **类型**：创始人实战行动手册（中译本）
- **规模**：约 36 页（精编手册）
- **核心主题**：把创始人从 0 到 1 的关键动作系统化为可执行清单——涵盖角色/PMF/团队/融资/股权/危机六大模块

## 全书摘要

本书不是"创业故事"也不是"创业理论",是**行动清单**——每页都给出具体动作、检查项、决策框架。

六大模块：
1. **创始人角色**：愿景建构者 + 团队组建者 + 资本筹集者三重身份
2. **PMF 验证**：早期唯一重要指标,验证前不扩张
3. **团队组建**：联合创始人选择 + 早期招聘原则
4. **融资轮次**：种子/A/B/C 各阶段策略
5. **股权设计**：创始团队股权分配原则
6. **危机管理**：创业危机清单化处理

## 章节结构

### 模块一：创始人三角色
- 愿景建构者：定义公司方向
- 团队组建者：招募核心团队
- 资本筹集者：保证现金流不断

### 模块二：PMF 验证
- PMF 的 3 个标志
- 验证 PMF 的 4 个方法
- PMF 之前的"小而精"原则

### 模块三：团队组建
- 联合创始人选择：互补 > 相似
- 早期招聘：能力 > 经验
- 团队文化：早期决策影响长期

### 模块四：融资轮次
- 种子轮：验证想法
- A 轮：验证商业模式
- B 轮：规模化扩张
- C+ 轮：市场领导地位

### 模块五：股权设计
- 创始团队股权分配原则
- 期权池设计
- 股权成熟机制（vesting）

### 模块六：危机管理
- 现金流危机
- 团队危机
- 产品危机
- 公关危机

## 关键洞见

1. **创始人三角色不可分割**——任何一角色弱都导致失败
2. **PMF 是早期唯一重要指标**——其他都是噪音
3. **股权设计决定公司命运**——早期错误难以纠正
4. **危机是创业常态**——不是"是否发生",是"何时发生"
5. **融资轮次有清晰阶段性目标**——错位的融资目标导致失败
6. **联合创始人互补 > 相似**——同质团队是早期杀手
