# 时间盒

**作者简介**：马克·曹-桑德斯（Marc Zao-Sanders），英国科技公司 Filtered 创始人兼 CEO，时间盒管理法的现代倡导者。曾在《哈佛商业评论》发表关于时间盒的文章，成为热门文章。10 年间创建 44000 个时间盒，将方法从个人实践扩展为系统方法论。

## 核心论点链

1. **诊断**：知识型工作永无止境 + 选择过多 + FOMO + 算法控制 + 时间有限
2. **方法论**：在干扰出现前预先决策 + 待办清单与日历结合 + 专注单任务 + 接受不完美
3. **区别**：时间盒 ≠ 时间块——前者承诺完成，后者只预留时间
4. **科学依据**：专家共识 + 科技巨头（Google/Microsoft）的功能集成 + 44000 个实践案例
5. **6 大优势**：从留存记录到人生充实层层递进
6. **15 分钟原则**：每天早上 15 分钟计划，决定 15 小时成败
7. **正念同源**：时间盒是实用版正念，都聚焦当下
