# 汉密尔顿规则与亲缘选择

**定义**：亲缘选择（kin selection）是合作进化的第 5 机制——亲缘关系越近，越容易合作。霍尔丹 1955 年酒吧闲谈提出直觉（"我会为两个亲兄弟或八个表兄弟赴汤蹈火"），汉密尔顿 1964 年为它加上数学：**r > c/b**——当亲缘关联系数 r 大于成本收益比 c/b 时，利他基因得以进化。诺瓦克、塔尼塔、威尔逊 2010 年在《Nature》发文挑战：内含适应性理论只在极受限的假设下成立，且在这些条件下与标准自然选择给出完全相同的预测——它是冗余的"会计学"。

**汉密尔顿规则**：
- **r**：亲缘关联系数（克隆=1，亲兄弟姐妹=0.5，半同胞=0.25，表亲=0.125）
- **c**：利他行为的成本
- **b**：接受者获得的收益
- **规则**：r > c/b → 利他基因能进化

**霍尔丹的原始直觉**：
- 救自己孩子：50% 概率携带同样基因，1 个大人死亡换 5 个孩子基因得救
- 救孙子/侄子：25% 相关，1 个大人死亡换 2.5 个基因
- 救堂兄：微乎其微
- "我会为两个亲兄弟或八个表兄弟这样做"——亲兄弟相关 50%，2×0.5=1；表兄弟相关 12.5%，8×0.125=1

**单倍二倍体假设**（曾被视为亲缘选择的强证据）：
- 膜翅目昆虫（蚂蚁、蜜蜂、黄蜂）：雌性二倍体、雄性单倍体
- 姐妹间亲缘 75%，比母女 50% 还高
- 因此蚂蚁更愿抚养姐妹（皇后）而非自己的女儿
- 这曾是亲缘选择的"神奇钥匙"

**诺瓦克的挑战**：
1. **假设过严**：内含适应性只在"近似中性"（几乎无选择）的群体中成立，且互动必须递增成对（但蚂蚁搬运大型食物需要多人协作）
2. **冗余**：在它成立的有限世界里，与标准自然选择给出相同预测——办繁琐入会手续却没享受到特权
3. **汉密尔顿规则失效**：即使在内含适应性的"理想国"，r > c/b 也未必成立，需修订成本/收益参数，但修订会丢失预测能力
4. **以基因为中心 vs 以个体为中心**：内含适应性表面是基因中心，实际是个体中心（以"行动者"为会计主体）
5. **真社会性的真解释**：威尔逊晚年转向——巢穴防御 + 弹簧承载的适应 + 群体选择，不需要亲缘选择

**单倍二倍体假设的衰落**：
- 白蚁是双倍体却同样真社会性——单倍二倍体非必要
- 粉蠹虫、海绵虾、裸鼢鼠都是双倍体真社会性
- 约一半真社会性物种是双倍体血统
- 70000+ 已知膜翅目寄生昆虫都是单倍二倍体，却无一种真社会性
- 威尔逊问亲缘选择支持者："为什么要提这个？"答："为什么要提？"

**诺瓦克的让步**：
- 亲缘选择仍是合作机制之一，但不是核心
- "有条件机制"：基于亲缘识别的条件行为（为兄弟跳河、不为陌生人跳河）
- 回归霍尔丹最初的火花，超越汉密尔顿规则的局限

**与既有框架的关系**：
- 与 [[五大合作机制-诺瓦克]] 同源：亲缘选择是五大机制之一，但被诺瓦克"降级"
- 与 [[超个体-诺瓦克]] 同源：真社会性进化不需要亲缘选择解释
- 与 [[多层选择-诺瓦克]] 互补：诺瓦克主张用多层选择替代亲缘选择
- 与 [[付出者获取者互利者-格兰特]] 张力：亲缘选择解释家族利他，但人类对陌生人也会牺牲

**应用边界**：
- 汉密尔顿规则作为启发式工具仍有价值，引导大量实证研究
- 亲缘相关性测量对理清群体结构有用，但不等于测试内含适应性理论
- 现代人类社会对陌生人的利他（如奥特利救人）超出亲缘选择范围
