# 稀缺陷阱

**提出者**：塞德希尔·穆来纳森、埃尔德·沙菲尔，《稀缺》

**核心定义**：稀缺陷阱（scarcity trap）是稀缺心态自我强化的恶性循环——稀缺 → 管窥 → 借用未来 → 余闲消失 → 更深的稀缺。一旦进入，所有行为都在加深稀缺而非摆脱它。

## 陷阱的四个组件

1. **稀缺**：客观拥有少于需要
2. **管窥**：稀缺俘获注意，视野变窄
3. **借用**：为缓解当下挪用未来资源（高利贷、熬夜赶工、延迟维护）
4. **余闲缺失**：没有缓冲，下一个冲击直接转化为新稀缺

## 陷阱的自我强化机制

```
稀缺 → 管窥 → 忽视长期 → 错失根治机会
  ↓
借用未来 → 当前缓解 → 未来稀缺加重
  ↓
余闲消失 → 抗冲击能力为零 → 任何意外都触发更深稀缺
  ↓
带宽税加剧 → 决策更差 → 进一步错失机会
  ↓
（回到原点，循环加深）
```

## 典型表现

- **贫穷陷阱**：穷人借高利贷 → 还款压力更大 → 更稀缺 → 借更多
- **忙碌陷阱**：加班赶进度 → 睡眠减少 → 效率下降 → 加更多班
- **孤独陷阱**：渴望联系 → 表现过于急切 → 推开他人 → 更孤独
- **节食陷阱**：饥饿 → 暴食 → 自责 → 更严格节食 → 更饿

## 与班纳吉迪弗洛"贫穷陷阱"的对话

[[贫穷陷阱与S形曲线-班纳吉迪弗洛]] 描述了陷阱的**形态**（S 形曲线下凹，富者愈富穷者愈穷），穆来纳森补充了陷阱的**心理学机制**——为什么穷人会做出加深陷阱的决策。两者结合形成完整的贫穷陷阱理论。

## 跳出陷阱的方向

- 不能从稀缺端解决稀缺（如让穷人更努力、让忙碌者更高效）
- 必须从富足端着手：建立余闲、保护带宽、降低冲击频率
- 制度设计应自动建立缓冲（自动储蓄、自动备份、强制休息）
