# 名声的眼睛效应

**定义**：名声的眼睛效应（Eyes Effect）指人类在被观察——哪怕只是被一双画出来的眼睛注视——时会显著表现出更慷慨、更合作的行为倾向。这是一种深层进化痕迹：祖先在采集狩猎部落中，被他人观察意味着需要维护名声以换取未来间接互惠，这一动机通过世代传承固化为人对"目光"的本能敏感。

**经典实验**：
- **纽卡斯尔大学诚实箱实验**：心理学院休息室茶水咖啡自愿付费，柜门上轮换悬挂"眼睛"与"花朵"图片。10 周结果显示，眼睛图片各周收款几乎是花朵图片各周的 3 倍。
- **脑电证据**：从正常被试头部收集的脑电活动显示，一双孤立的眼睛比一张完整面部能激发更丰富、更活跃的脑电活动。
- **机器人效应**：有着与人类相仿大眼的机器人也能产生同样的合作激发效果。
- **图腾柱**：原住民在木柱上雕刻圆睁怒目，是因为他们直觉知道——人们觉得自己被注视时会更宽厚仁慈。

**机制解读**：
- 间接互惠要求每个个体既被观察也观察他人
- "被观察"的暗示激活名声管理子系统，触发利他行为
- "观察者效应"是双向博弈：观察者艾丽斯需要隐蔽观察，被观察者鲍勃需要假装没察觉，双方都在进行二阶心智推理
- 人类良心本身可被视为"在他人眼中是何形象"的内化衡量标准

**自然界的对应**：
- 清洁鱼濑鱼在有其他客户鱼围观时会友善为大鱼清洁，无观众时则咬破客户皮肤
- 独裁者博弈中，若受赠方不知捐赠者是谁，捐赠数额下降 50%

**政策含义**：
- 气候保护政策可利用"眼睛"设计——如家用电器耗能率公开、家庭能源成本在本地报刊公开、公司碳排放排名
- 美国可为燃油效率低、污染大的车辆贴标签，欧洲可缩短高耗油车驾驶年限
- "广而告之"是利用名声力量的核心机制

- 与 [[间接互惠与名声-诺瓦克]] 直接同源：眼睛效应是间接互惠的认知/心理基础
- 与 [[公开个人行为是避免公地悲剧的关键-诺瓦克]] 应用：眼睛效应是公地治理的廉价工具
- 与 [[大脑是为闲言碎语而进化的-诺瓦克]] 同根：名声管理是大脑的核心功能
- 与 [[透明是最有效的管理机制，桥水几乎公开一切信息-瑞·达利欧]] 同源：达利欧的组织透明是眼睛效应的制度化

**应用边界**：
- 眼睛效应是短期触发，长期合作需要制度化的名声系统
- "被观察"可能引发反效果——若个体感觉被监控而非被注视，会触发抵触
- 跨文化效果可能不同——集体主义文化中眼睛效应可能更强，个人主义文化中可能更弱
- 实验室效应（3 倍）在真实社会场景中会被其他变量稀释
