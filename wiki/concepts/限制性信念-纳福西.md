# 限制性信念

显化七步法第2步要清除的对象——人对自己、世界、可能性持有的隐性负面假设。纳福西认为愿景再清晰，若限制性信念没被识别重写，行动会被自我破坏（拖延/逃避/自我设障）。

## 限制性信念的形成

- 童年教养（"不要张扬""我们家没出过大学生"）
- 创伤经验（一次失败总结为"我不行"）
- 社会文化（"钱是脏的""男人不该哭"）
- 反复重复固化成默认认知

## 识别方法

纳福西要求写下关于某愿望的所有"但是……"——每个"但是"后面都藏着一条限制性信念。例如愿望"我想创业"：
- "但我没有商业头脑" → 信念：能力是固定的
- "但我会失败丢脸" → 信念：失败等于身份贬值
- "但家人会反对" → 信念：他人认可以先于自我认可

## 重写四步

1. **识别**——把隐性信念写出来（写出来才能看见）
2. **追问起源**——这是谁的信念？是我的还是被植入的？
3. **找反例**——有没有反证？过去哪些时刻这条信念不成立？
4. **替换**——用赋能信念替换，新信念需自己能相信（不能从"我不行"跳到"我最棒"，可先到"我可以学"）

## 与既有概念的关系

- 与 [[自我效能-西多昌规]] 同源：限制性信念就是低自我效能的内在叙事
- 印证 [[大多数限制是自我设限-奎克]]：奎克从脑科学角度说同样的话
- 与 [[习惯引力-古川武士]] 同构：习惯引力是行为层的阻力，限制性信念是认知层的阻力

## 与"积极思考"的差异

积极思考是用正面话语覆盖负面感受，限制性信念重写是先看见再改写底层叙事。前者是表面贴纸，后者是改地基。
