# 稳住不动

**核心**：当敌人"侵掠如火"，你要"不动如山"。当大家都哭的时候你不能哭，因为流泪的眼睛会看不清楚。当左眼挨打的时候右眼要睁大，因为跟着可能飞来另一拳。

**不是不怒，是先要稳住**：
- 稳住不是压抑情绪，是给情绪一个延迟通道
- 当下不发火，等事情过去再一一究责
- "当家不闹事"和"无故加之而不怒"就是这个道理

**四类需要稳住的场景**：

1. **危机时刻**：爆炸发生时急着救难，而不是骂人
2. **冲突现场**：被激怒时先稳住，避免说出不可挽回的话
3. **团队低谷**：领导慌则团队散，必须装作不动如山
4. **重大决策前**：情绪上来时不做决定，等情绪过去再判断

**与相关概念的关系**：
- 与 [[情绪调节-格罗斯]] 一致——稳住是"认知重评"在冲突场景的应用
- 与 [[延迟满足-米歇尔]] 互补——延迟满足针对欲望，稳住不动针对情绪
- 与 [[WYSIATI使人在信息越少时反而越自信-卡尼曼]] 形成对照——WYSIATI 是冲动判断，稳住是反冲动

**实践难点**：
- 稳住 ≠ 委屈自己，事后必须真究责，否则变成 [[隐忍-刘墉]] 的反面（被动承受）
- 稳住需要心力，长期高强度稳住会耗竭，要配合 [[隐形藤蔓-刘墉]] 的日常清理
