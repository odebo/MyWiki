# 灰度决策五大问题

**定义**：小约瑟夫·巴达拉克提出的灰度决策框架，针对极度不确定且利益攸关的复杂难题，用五个根本性人文问题替代了"找正确答案"的思路，作为管理者做判断的实用工具。

**五大问题**：
1. **"净"结果是什么？** — 充分考虑所有利益方的全部后果，避免被单一指标或短期结果简化
2. **我们的核心义务是什么？** — 超越合同与利益相关者分析，回到作为人对他人所负的根本义务
3. **当今世界什么奏效？** — 现实主义/马基雅维利视角，承认权力、利益、人性的实际运作
4. **我们是谁？** — 把自我置于关系网与组织叙事中，看决策如何嵌入更大故事
5. **我能接受什么？** — 锻造后的直觉判断，做"我能接受"而非"应做什么"的决定

**核心特征**：
- 不是步骤流程，而是五个审视维度，需"一并使用"而非依次进行
- 不提供答案，而是锐化判断力，让决策者从不同角度逼近问题
- 根植于人文主义传统（亚里士多德、马基雅维利、尼采、威廉·詹姆斯等）
- 承认分析工具的天花板：信息、数据、专家意见不足以解决灰度问题

**与既有框架的关系**：
- 与 [[MECE原则-艾森拉塞尔]] 互补：MECE 用于结构化拆解，五大问题用于处理 MECE 之后的"剩余不确定性"
- 与 [[系统1系统2-卡尼曼]] 互补：五大问题强迫系统2介入，但也接受系统1直觉的最终作用
- 与 [[反思性思维-杜威]] 同源：都把判断视为反复反思而非一次性推演
- 与 [[灰度思考-西多昌规]] 同根：都拒绝非黑即白，但巴达拉克偏决策框架，西多偏情绪管理

**适用边界**：
- 适用于"极度不确定 + 利益攸关 + 无标准答案"的灰度问题
- 不适用于有清晰规则、数据充足、后果可控的常规决策——此时直接套规则即可
