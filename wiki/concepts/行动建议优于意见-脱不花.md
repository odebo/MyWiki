# 行动建议优于意见

脱不花提出的反馈与建议方法论——把"提意见"升级为"给行动建议"。核心是**意见指向过去,行动建议指向未来**。

## 意见 vs 行动建议

| 维度 | 意见 | 行动建议 |
|------|------|---------|
| 时间指向 | 过去（你做错了） | 未来（下次可以） |
| 情绪色彩 | 批评、指责 | 建设、帮助 |
| 接收方感受 | 防御、抵触 | 接受、改进 |
| 可执行性 | 模糊 | 具体 |
| 关系影响 | 破坏 | 加强 |

## 行动建议的五要素

脱不花给出"行动建议"的标准结构：

### 1. 情境（Situation）
- 具体什么时候、什么场景
- 不泛泛而谈"你总是"

### 2. 行为（Behavior）
- 具体做了什么/没做什么
- 不评价动机,只描述行为

### 3. 影响（Impact）
- 这个行为产生了什么影响
- 客观描述后果

### 4. 建议（Suggestion）
- 下次可以怎么做
- 具体到可执行的步骤

### 5. 收益（Benefit）
- 这样做对谁有什么好处
- 让对方有动力改

简称 SBISB 模型——比 SBI 多了"建议"和"收益",从反馈升级为建议。

## 行动建议的三种场景

### 场景1：给上级建议
- 上级做错了,怎么提？
- 错误做法：当众指出 / 背后议论
- 正确做法：私下沟通 + 数据支撑 + 备选方案
- 关键：让上级有台阶下

### 场景2：给同事建议
- 同事配合不到位,怎么提？
- 错误做法：指责 / 抱怨
- 正确做法：先讲共同目标 + 描述行为影响 + 给具体建议
- 关键：让对方感到被帮助而非被指责

### 场景3：给下属建议
- 下属表现不佳,怎么提？
- 错误做法：批评 / 否定
- 正确做法：明确期望 + 描述差距 + 给改进路径
- 关键：让对方有信心改进

## 反面：意见式反馈

主流反馈常见错误：
- **泛化**——"你总是这样"（具体行为变人格评判）
- **动机猜测**——"你是不是不在乎"（不可证伪）
- **情绪宣泄**——"我很失望"（让对方防御）
- **无建议**——只说不该怎样,不说该怎样
- **公开化**——当众提意见（让对方难堪）

## 与"坦率文化"的对话

主流讲"坦率"——直接说真话。
脱不花论点：
- 坦率不等于嘴硬
- 坦率是讲真话,但讲法要建设性
- "你这个做得不对"是坦率但低效
- "下次可以这样改"是坦率且高效
- 坦率 + 行动建议 = 高质量反馈
- 坦率 - 行动建议 = 情绪宣泄

## 与"三明治反馈"的对话

主流讲"三明治反馈"——表扬-批评-表扬。
脱不花论点：
- 三明治反馈让对方只记住表扬,忘记批评
- 三明治反馈让对方产生"被套路感"
- 行动建议更直接,也更被尊重
- 现代职场人不需要被哄,需要被尊重
- 行动建议 = 尊重的反馈

## 与"建设性批评"的对话

主流讲"建设性批评"——批评中带建议。
脱不花论点：
- "建设性批评"本身是矛盾词
- 批评指向过去,建设指向未来
- 与其"建设性批评",不如"完全建设"
- 行动建议 = 完全建设
- 把"批评"从反馈中剔除
