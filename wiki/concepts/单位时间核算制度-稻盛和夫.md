# 单位时间核算制度

**定义**：稻盛和夫为阿米巴经营设计的业绩衡量指标——把每个阿米巴的"销售额－费用"差额除以总劳动时间，得出每小时创造的价值（"单位时间附加值"）。

**公式**：
```
单位时间附加值 = (销售额－费用) ÷ 总劳动时间
```

**核心逻辑**：
- **销售最大化、费用最小化**——经营的两大原点
- **时间也是经营资源**——员工的工作时间直接计入成本，倒逼阿米巴长减少无效劳动
- **每天核算、每天反馈**——每天结算昨天业绩，让员工每天看到自己工作的经营成果

**与一般会计的区别**：
| 一般会计 | 单位时间核算 |
|---------|------------|
| 月度结算 | 每日结算 |
| 财务部门做账 | 阿米巴长自己算 |
| 关注利润 | 关注每小时附加值 |
| 滞后反馈 | 即时反馈 |
| 仅管理层看得到 | 全员可见（[[玻璃般透明原则]]） |

**为什么除以时间**：
- 不除以时间，阿米巴会靠堆人力来增加附加值
- 除以时间后，"用更少的人创造更多的价值"成为唯一路径
- 把"人海战术"从激励结构中剔除

**哲学根基**：单位时间核算不是单纯的技术工具，而是稻盛哲学"追求全体员工物质和精神两方面幸福"的量化体现——每个员工每天的劳动都直接看到价值，工作就有了意义感。
