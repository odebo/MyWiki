# 根回与 hansei

**根回（Nemawashi）** 与 **hansei（反省）** 是 [[丰田模式14项原则-莱克|丰田模式第 13、14 原则]] 中的两个日语概念，分别描述决策前的共识过程与项目后的反思机制。

## 根回（Nemawashi）

**根回**原意是"修整树根"，在丰田管理中指**和所有相关者、受影响者共同讨论问题及可能的解决方法，收集他们的意见，并对解决途径取得共识**。

### 核心特征

- **决策前**：在正式决策前进行
- **广泛咨询**：和所有相关者、受到影响者共同讨论
- **收集意见**：收集多方意见，全面寻求解决方案
- **追求共识**：对解决途径取得共识
- **耗时但值得**：虽花时间，但有助于全面寻求解决方案

### 与西方决策模式的对比

| 维度 | 西方多数决/顶层决策 | 根回共识 |
|------|------------------|---------|
| 决策速度 | 快 | 慢 |
| 执行速度 | 慢（需说服反对者） | 快（已达成共识） |
| 决策质量 | 取决于决策者 | 综合多方意见 |
| 失败责任 | 决策者承担 | 集体承担 |
| 组织学习 | 局限于决策圈 | 扩散到所有参与者 |

### 第 13 原则的完整表述

> "制定决策时要稳健，穷尽所有的选择，并征得一致意见；实施决策时要迅速。"

- **稳健**：在还没有周全考虑所有其他选择之前，不要武断地选定一个方向
- **穷尽选择**：考虑所有可能性
- **征得一致意见**：通过根回达成共识
- **实施迅速**：一旦做出决定，便应该快速执行

## hansei（反省）

**hansei**（反省）是 [[丰田模式14项原则-莱克|丰田模式第 14 原则]] 的核心，指**通过不断省思与持续改善以成为一个学习型组织**。

### 反省的四个层面

1. **找出根本原因**：在建立了稳定的流程后，运用不断改进的工具以找出导致缺乏效率的根本原因，并采取有效的对策
2. **暴露浪费**：设计几乎不需要存货的流程，使所有人明显看出时间与资源的浪费；一旦浪费出现，要求员工改进流程、去除浪费
3. **稳定人事**：制定人事稳定、缓慢升迁及非常谨慎的接班人制度，以保护企业的知识库
4. **里程碑反思**：使用"反省"作为重要的里程碑，在完成某计划后，诚实地找出此计划的所有缺点，然后制定避免相同错误再发生的对策

### hansei 与一般反思的差异

| 维度 | 一般反思 | hansei |
|------|---------|--------|
| 触发 | 失败后 | 每个里程碑后 |
| 态度 | 自我批评 | 诚实找出缺点 |
| 目标 | 总结经验 | 制定避免相同错误的对策 |
| 制度化 | 个人行为 | 组织流程 |
| 与改善关系 | 间接 | 直接驱动持续改善 |

### 标准化促进学习

> "把最佳实务标准化，以促进学习，而不是在每个新计划及每位新经理人上台后，又重新发明新方法。"

hansei 的成果必须沉淀为标准，否则学习会随人员变动而流失。

## 两者在丰田模式中的位置

```
现地现物（原则 12）— 收集现场真实数据
    ↓
根回（原则 13）— 基于数据建立决策共识
    ↓
hansei（原则 14）— 实施后反思并标准化
    ↓
回到现地现物 — 新一轮循环
```

## 与其他概念的关系

- 与 [[丰田模式14项原则-莱克]] 第 13、14 原则直接绑定
- 与戴明 PDCA 循环：hansei 是 Check + Act 的丰田版本
- 与 [[现地现物-莱克]] 互补：现地现物是事前信息收集，根回是事中共识，hansei 是事后反思
- 与 [[威尼斯十人委员会-盐野七生]] 的"委员长3位轮值月度避嫌不能散步"对照——两者都是制度化的避偏机制
