# 合作的四大特征

**定义**：阿克塞尔罗德通过分析锦标赛前 15 名策略，提取出成功合作策略的四大共同特征：**友善（Nice）、报复（Retaliatory）、宽恕（Forgiving）、不嫉妒（Non-envious）**。这四特征既是 TFT 的胜利密码，也是任何长期合作策略的必要条件。

## 1. 友善性（Nice）

**定义**：永远不首先背叛。

**为何重要**：
- 首先背叛引发连锁报复
- 双方进入相互背叛陷阱
- 友善避免冲突升级

**反例策略**：
- "永久背叛"（不友善）—— 短期赢，长期输
- "机会主义背叛"—— 试图占便宜，引发报复

**现实映射**：
- 永远先给合作机会
- 不主动攻击
- 假设对方善意

## 2. 报复性（Retaliatory）

**定义**：对方背叛立即报复，不软弱。

**为何重要**：
- 无报复=被持续剥削
- 软弱策略被"永久背叛"吃光
- 报复建立威慑

**反例策略**：
- "永远合作"—— 被"永久背叛"碾压
- "宽容过头"—— 被反复利用

**现实映射**：
- 边界清晰
- 不当老好人
- 报复及时而非延后

## 3. 宽恕性（Forgiving）

**定义**：对方回归合作立即宽恕，不记仇。

**为何重要**：
- 不宽恕陷入相互报复循环
- 一次背叛演变为永久冲突
- 宽恕恢复合作可能

**反例策略**：
- "记仇到底"—— 一次背叛后永久背叛
- "梯度报复"—— 升级报复引发对方升级

**现实映射**：
- 对方示好即收手
- 不扩大冲突
- 给回头机会

## 4. 不嫉妒性（Non-envious）

**定义**：不追求相对优势，只追求绝对收益。

**为何重要**：
- 嫉妒导致破坏对方收益
- 双输以求"赢"
- 长期合作需要互利

**反例策略**：
- "比较型"策略—— 追求压倒对方
- "破坏型"策略—— 自己输也要对方更输

**现实映射**：
- 不与他人比较
- 专注自身长期收益
- 接受对方也赢

## 四特征的协同

```
友善 + 报复 = 不可欺
报复 + 宽恕 = 不陷入循环
宽恕 + 友善 = 持续合作
四者合一 = 长期最优
```

**缺失任一即失败**：
- 缺友善：挑起冲突
- 缺报复：被剥削
- 缺宽恕：陷入死循环
- 缺不嫉妒：破坏互利
