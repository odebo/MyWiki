# 记忆三原则

威林厄姆在《大脑想要这样学》中提出的三大记忆原则，是贯穿全书的核心框架。所有高效学习方法都可归约为对这三条原则的组合运用，而所有低效方法（重读、抄写、标记重点）都至少违反其中一条。

## 三大原则

### 1. 记忆是思想的残渣

记忆不是"被存进去"的，而是"思考的副产品"。你对某件事想得越深、与之建立的联想越丰富，记得就越牢。

- 电影情节容易记，因为每个场景都与其他场景紧密关联
- 随机数表难记，因为数字之间没有意义联系
- 注意力是记忆的闸门：你在课堂上想什么，就记住什么（包括走神的内容）

推论：判断一个学习方法是否有效，只需问——它是否迫使你对内容进行**有意义的思考**？

### 2. 结构能够帮助记忆

26 词实验：给被试一个有层次结构的 26 词清单，回忆率 65%；打乱顺序后仅 18%。结构让信息从"一堆事实"变成"一张网"，每个节点都是其他节点的检索线索。

- 老师讲课时构建的是层次结构（主题→3-7 要点→证据/例子/解释）
- 学生听到的是线性流水（一句话接一句话）
- **学习就是主动重建层次结构的过程**：画树状图、列大纲、写摘要，都是把线性输入重新结构化

### 3. 提取练习可以巩固记忆

想长期记住什么，**测验比学习更重要**。典型实验：两组学生学同一章教材，第二组在学习中间插入一次测验（题目与最终考试不同），最终成绩高出 10-15%。详见 [[提取练习-威林厄姆]]。

## 三原则的组合使用

| 方法 | 原则1 残渣 | 原则2 结构 | 原则3 提取 |
|------|-----------|-----------|-----------|
| 反复阅读 | ✗ | ✗ | ✗ |
| 抄写笔记 | ✗ | ✗ | ✗ |
| 标记重点 | ✗ | ✗ | ✗ |
| 总结/列大纲 | ✓ | ✓ | ✗ |
| 针对概念举例 | ✓ | ✗ | ✗ |
| 抽认卡 | ✗ | ✗ | ✓ |
| 模拟测验 | ✗ | ✗ | ✓ |
| 学习指南（问答式） | ✓ | ✓ | ✓ |

**反直觉**：学生最常用的方法（反复阅读、重读教材、标记重点）恰恰是三种原则都不满足的方法。高效方法需要主动付出脑力，大脑天然倾向于选择"看起来容易成功"的简单方法——这就是为什么"临时抱佛脚"在感觉上很好但效果差。
