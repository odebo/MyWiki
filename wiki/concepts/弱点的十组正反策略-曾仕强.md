# 弱点的十组正反策略

**核心内涵**：曾仕强用一个公式统领全书的修身方法——人性的优点 = 合理(求生存 + 自私 + 求快乐)，人性的缺点 = 不合理(求生存 + 自私 + 求快乐)。优点还是缺点，关键只在「合理与否」，而合理与否取决于策略的选择与运用。策略正确，所有弱点都成优点；策略错误，所有弱点都成缺点。

**运作机制**：他沿着十对关键变项，给出一反一正、一一对应的策略表：有钱时（想自己 / 想别人）、得意失意时（爱炫耀穷诉苦 / 不炫耀不诉苦）、位尊位卑时（耻闻过善讨好 / 不虚妄不讨好）、势强势弱时（欺侮人隐忍 / 多助人要自持）、体健体衰时（不爱惜依赖人 / 应爱惜多锻炼）、年轻年老时（逞固执显聪明 / 不固执要谦恭）、进退时（得罪人不救人 / 想退路要救人）、主从时（立威严爱逢迎 / 不苛刻不逢迎）、施受时（小气易忘记 / 要舍得要感谢）、正误时（不饶人常辩解 / 能恕人要坦承）。

**意义与边界**：曾仕强特别强调这十组正反策略「不是绝对的」。例如年轻时显聪明，若恰好遇到喜欢提拔人的贵人，未必不好；势强时多助人，也可能养出「饲养老鼠，咬破布袋」的白眼狼。真正的用法是把正、反当作「上下限」，在两者构成的空间中因人、因时、因事弹性调整，找到中间合理点——这才是中庸之道。他同时点出中西之别：西方求真、中国求善，所以在中国社会「道理很难讲」，必须守经达变。
