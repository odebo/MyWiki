# 加倍下注或果断退出

**提出者**：伊利亚·斯特雷布拉耶夫、亚历克斯·邓。

## 核心命题

**在不确定性的决策中，中间状态最危险**——要么加倍下注（commit），要么果断退出（quit），不要骑墙。骑墙消耗资源却不解决问题。

## 与传统决策的对比

### 传统决策的渐进主义

- 逐步增加投入
- 边走边看
- 不做激进选择
- 保留灵活性

### 风投式决策的二元化

- 快速判断 commit 还是 quit
- commit 则重仓
- quit 则彻底退出
- 不留中间状态

## 中间状态的问题

### 问题1：资源消耗

骑墙项目持续消耗资源但产出有限。这些资源本可用于真正的 commit 项目。

### 问题2：注意力分散

中间项目占据团队注意力，让团队无法聚焦于真正重要的项目。

### 问题3：决策延迟

中间状态让决策被无限推迟——"再看看"成为逃避决断的借口。

### 问题4：机会成本

骑墙的时间本可用于识别与执行新机会。

### 问题5：心理负担

未决的项目持续消耗心理能量，影响其他决策质量。

## Commit 的含义

### Commit 不是赌徒式押注

不是情绪化的"全押"——是基于证据的判断：
- 已验证关键假设
- 团队已证明执行力
- 市场机会清晰
- 加倍投入能产生指数级回报

### Commit 的具体表现

- 大幅增加资源投入
- 团队扩编
- 加速执行
- 长期承诺
- 拒绝短期退出诱惑

### Commit 的勇气

多数人在该 commit 时犹豫——害怕"全错"。但风投数据显示：识别出的大赢必须重仓才能获得指数级回报。半心半意的 commit 等于不 commit。

## Quit 的含义

### Quit 不是失败

Quit 是承认现实——这个项目不会成为大赢。及时 quit 释放资源给真正有潜力的项目。

### Quit 的具体表现

- 完全停止投入
- 团队转岗或解散
- 资产清算或转让
- 不留"也许还能成"的尾巴
- 不情感化坚持

### Quit 的勇气

多数人在该 quit 时拖延——已经投入太多，舍不得放弃。但沉没成本谬误让坏项目持续吞噬资源。果断 quit 是稀缺能力。

## 决策框架

### Step 1：清晰评估

每个项目定期评估：
- 关键假设是否被验证？
- 团队是否证明执行力？
- 市场机会是否仍然成立？
- 大赢潜力是否仍在？

### Step 2：二元判断

基于评估，做出明确判断：
- 是 → Commit
- 否 → Quit
- 也许 → 倾向 Quit（骑墙的代价高于错失的潜在收益）

### Step 3：坚决执行

- Commit → 立即增加资源，加速执行
- Quit → 立即停止，不留尾巴

### Step 4：定期复审

Commit 不是永久——定期重新评估。如果情况改变，从 Commit 转 Quit。

## 风投案例

### Commit 的成功案例

- **Sequoia 投资 Google**：早期识别潜力，重仓投入，长期持有
- **Benchmark 投资 Uber**：在质疑声中加倍下注
- **a16z 投资 Coinbase**：在加密行业低谷期重仓

### Quit 的成功案例

- **风投切断失败项目**：在假设被证伪后果断退出
- **Y Combinator 的"rats"机制**：明确标记死亡项目，快速清理
- **初创公司的 pivot**：及时放弃原方向，转向新方向

### 中间状态的失败案例

- **许多企业内部创新项目**：既不 commit 也不 quit，持续消耗
- **传统公司的不死不活项目**：每年投入一点，没有大产出

## 与传统企业决策的对比

### 传统企业的"骑墙"常态

- 年度预算分配——每个项目分一点
- 没有明确的 commit/quit 决策
- 项目持续多年不死不活
- 资源分散，无重点

### 风投式企业的二元化

- 季度评估所有项目
- 明确 commit 或 quit
- 资源集中投入 commit 项目
- 快速清理 quit 项目

## 为什么中间状态如此普遍

### 原因1：避免艰难决策

Commit 和 Quit 都是艰难决策。骑墙避免做出选择。

### 原因2：情感依恋

团队对项目产生情感，不愿放弃。

### 原因3：沉没成本谬误

"已经投入这么多" → 继续投入。

### 原因4：政治阻力

Quit 某个项目意味着某个人失败——政治上困难。

### 原因5：信息不完整

"也许再多投入一点就能看清"——但多数情况，更多信息只会让决策更模糊。

## 与其他思想的对话

### 与 [[本垒打原则-斯特雷布拉耶夫]]

本垒打原则要求少数大赢决定整体。Commit/Quit 是其执行机制——只有把资源集中到少数 commit 项目，才可能产生本垒打。

### 与精益创业的"pivot or persevere"

精益创业主张定期判断"坚持还是转向"。风投式 Commit/Quit 是更激进的版本——不只是转向，是 commit 或 quit。

### 与安迪·格鲁夫的"only the paranoid survive"

格鲁夫强调战略转折点的果断决策。Commit/Quit 是这种果断的具体方法。

### 与 [[园丁式领导-哈克曼]]

哈克曼说领导者应像园丁——修剪与培育并重。Quit 是修剪，Commit 是培育。

## 启示

对投资者：
- 定期评估所有持仓
- 优质标的果断加仓
- 失败标的果断止损
- 不留"也许"的中间仓位

对企业：
- 季度评估所有项目
- 明确 commit 或 quit
- 资源集中到 commit 项目
- 快速清理 quit 项目

对个人：
- 定期评估生活中的承诺
- 真正重要的加倍投入
- 不重要的果断放弃
- 不留"也许"的中间状态

对组织：
- 建立 commit/quit 的决策机制
- 容忍 quit 的文化
- 奖励果断决策
- 惩罚骑墙拖延

## 可被挑战

- 在某些情况下，渐进式投入有道理（如未验证领域）
- 过度二元化可能让团队抗拒冒险（怕被 quit）
- Commit 的"重仓"需要资本支持——小公司难以实施
- Quit 的"果断"在大型组织中有政治成本
- 该原则可能被用来为冲动决策辩护
