# 纳瓦尔财富公式

纳瓦尔在书中给出的"生命公式一"（2008年笔记），是其财富哲学的结构化表达：

## 公式链

```
幸福 = 健康 + 财富 + 良好的人际关系
健康 = 锻炼 + 饮食 + 睡眠
财富 = 收入 + 财富 × 投资回报率
收入 = 责任 + 杠杆 + 专长
责任 = 个人品牌 + 个人平台 + 承担风险
杠杆 = 资本 + 人力 + 知识产权
专长 = 无法通过培训获得的知识
投资回报 = "买入并持有" + 估值 + 安全边际
```

## 核心逻辑

1. **财富创造的入口是专长**：没有专长就没有差异化定价权
2. **杠杆放大专长的价值**：专长 × 杠杆 = 规模化收入
3. **责任承担带来不对称回报**：公开承担风险（品牌+平台）是高收入的前提
4. **财富 ≠ 收入**：收入是流量，财富是资本存量 × 复利增长率

## 股权是唯一路径

纳瓦尔的强主张：**没有股权就不可能实现财务自由**。用时间换金钱的人，无论薪资多高，出售的都是线性时间，永远无法通过复利积累真正的财富。股权/所有权才能让资产在你睡觉时继续增值。
