# 应激反应与压力回应

**来源**：[[正念减压实操指南-斯塔尔]] 第二章

**核心定义**：斯塔尔借赫伯特·本森（Herbert Benson）的"放松反应"理论与卡巴金的区分，明确区分"应激反应"（stress reaction，自动化反射）与"压力回应"（stress response，觉察后的有意回应）。前者由杏仁核-下丘脑-肾上腺轴（HPA 轴）驱动，几毫秒内启动战斗/逃跑/僵住；后者在前额叶皮层介入后产生，允许选择如何行动。

## 应激反应（Stress Reaction）

- **生理机制**：感知威胁 → 杏仁核激活 → 下丘脑释放信号 → 肾上腺素与皮质醇释放 → 心率血压上升、消化暂停、免疫抑制
- **特征**：自动、快速、无意识、刻板
- **问题**：现代威胁多为心理性（邮件、社交媒体、未来焦虑），但身体仍按物理威胁反应，导致皮质醇慢性升高
- 与 [[膈肌呼吸法-奥仲哲弥]] 互文：浅快呼吸是应激反应的组成部分

## 压力回应（Stress Response）

- **生理基础**：前额叶皮层对杏仁核的抑制回路，可被训练强化
- **过程**：暂停 → 觉察 → 命名情绪 → 选择回应
- **关键**：在刺激与反应之间创造"空间"（维克多·弗兰克尔意义上的）
- **可训练性**：神经可塑性使 8 周 MBSR 训练后前额叶-杏仁核功能连接增强

## 三分钟呼吸空间

MBSR 的标志性微练习，在应激时刻插入：
1. 第一分钟：觉察当下（身体感受、情绪、念头）
2. 第二分钟：收缩到呼吸
3. 第三分钟：扩展到全身

是把"压力回应"技能带入日常生活的桥梁。

## 与其他概念的关系

- 与 [[自我决定论-德西]] 互补：自主需求的核心是"在刺激与反应之间有选择空间"
- 与 [[化解反意志九原则-马泰]] 同源：都是先接纳而非抗拒
- 与 [[初始假设-拉塞尔]] 同源：在反应前先建立觉察位置
- 与 [[正念的九种态度-斯塔尔]] 配合：回应需要"不评判、接纳、放下"
