# 现实世界奏效主义

**定义**：巴达拉克五大问题的第三问——"当今世界什么奏效？"要求决策者放下纯粹的理想主义，以马基雅维利式现实主义审视权力、利益、人性在现实中的实际运作，是实用主义与现实主义结合的判断维度。

**操作步骤（弹性测试的五个步骤）**：
1. **画出相关权力和利益的领域地图** — 看清现实力量格局
2. **保持诚实、灵活、把握机会** — 不欺骗自己，也不被既有立场锁死
3. **保证过程灵活推进** — 计划要可调整，路径要可重选
4. **准备好打一场硬仗** — 接受现实推行需要权力与斗争
5. **不要给自己找借口** — 警惕"我尽力了"式的自我开脱

**核心洞察**：
- 理想主义的失败往往不是理想错了，而是忽视了现实如何运作
- 现实主义不是犬儒主义：它承认权力与利益，但不放弃核心义务
- "奏效"不等于"成功"——是看在真实条件下能否实际推动
- 弹性测试：计划在压力下是否还成立，反对者是否会反扑，资源是否够用
- 马基雅维利传统：理解世界本来的样子，而非它应有的样子

**与其他现实主义框架的关系**：
- 与 [[初始假设-艾森拉塞尔]] 互补：假设需在现实权力场中检验
- 与 [[二阶预测-庞德斯通]] 同源：都要求预测他人反应
- 与 [[考虑最坏情况-塔勒布]] 互补：现实主义要求特别关注敌对方反应
- 与 [[核心义务优先-巴达拉克]] 张力但互补：义务定义"应该"，奏效主义定义"可能"
- 与 [[破局者思维-克里斯滕森]] 同源：都要求看透表面秩序下的真实力量

**反例**：
- 只看应该做什么，不看能否实际做到——纯理想主义
- 只看能否做到，不看是否应该做——纯马基雅维利主义
- 巴达拉克要求两者并用，第三问与第二问并置
