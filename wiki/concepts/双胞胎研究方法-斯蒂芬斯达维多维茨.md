# 双胞胎研究方法

行为遗传学的核心方法，用于**分离先天与后天**对某项特质的贡献比例。基本逻辑：同卵双胞胎基因 100% 相同，异卵双胞胎基因 50% 相同；若同卵双胞胎在某特质上比异卵双胞胎更相似，超出部分归因于基因。

## 双胞胎公式

```
基因影响 ≈ 2 × (r_同卵 - r_异卵)
```

其中 r 是双胞胎在该特质上的相关系数。共同环境贡献 = r_同卵 - 基因影响；独特环境贡献 = 1 - r_同卵。

## 运动基因影响差异

不同运动的基因贡献度差异巨大：

| 运动 | 基因影响 |
|------|----------|
| 篮球 | ~75% |
| 棒球 | ~25% |
| 橄榄球 | ~25% |
| 跳水 | ~0% |
| 举重 | ~0% |
| 马术 | ~0% |
| 射击 | ~0% |

**含义**：篮球靠天赋（长人赢），跳水/举重靠苦练（天赋差异小），棒球/橄榄球介于两者之间。

## 霍尔特项目收养研究

布鲁斯·萨塞尔多特（Sacerdote）研究韩国霍尔特收养机构送到美国的双胞胎/兄弟姐妹：

- **父母整体影响约 26%**（家庭环境对子女经济结果的方差贡献）
- **先天因素是后天培养的约 2.5 倍**
- 收养家庭的社会经济地位对养子女的最终收入影响有限——养在富裕家庭并不能保证孩子未来更富裕

## 切蒂社区研究

拉吉·切蒂（Raj Chetty）利用纳税数据研究 3000 万美国人的代际流动：

- **社区影响约 25%**——成长社区的特质对子女未来收入的因果效应
- 关键不是学校师生比或家庭教育支出，而是**成年榜样作用**（innovation exposure rate）
- 社区里同性别、同种族的成功成年人密度，预测孩子未来发明/致富概率

## 三层结论

1. **基因层**：双胞胎研究测得，约占一半变异
2. **社区层**：切蒂研究测得，约 25%
3. **家庭层**：霍尔特项目测得，仅约 26%（且无法证明是"教育方式"的贡献，可能仍是基因）
