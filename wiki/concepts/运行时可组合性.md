# 运行时可组合性（时间与空间）

DeepSeek Harness 的 Cordis 内核只做一件事：插件的加载、卸载和依赖管理。它能在 Agent 运行过程中随时更换插件，且保证运行状态不崩。支撑这一点的两个特性：

**时间可组合性（Temporal composability）**：一个插件被卸载后，它此前产生的副作用能否被完整撤销。若能，则插件的"生命周期"可以在运行时安全关闭，不影响已进行的会话状态。

**空间可组合性（Spatial composability）**：一个插件若依赖其他插件，当被依赖者出现、消失或改变时，它能否动态地重新解析自己的依赖关系，而不是崩溃或僵死。

两者合起来，定义了"热插拔"的真正含义：不只是能装卸，而是装卸后系统仍自洽。这是 Agent **自进化**的底层机制——Agent 可以在运行中为自己造一把"扳手"（新插件），插到身上，接着用它继续干活，事后还能把扳手干净地卸掉。

这个抽象不局限于 DeepSeek：任何希望"运行时增删能力且不崩"的系统（操作系统、微内核、插件化 IDE）都面对同样的时间/空间可组合性问题。
