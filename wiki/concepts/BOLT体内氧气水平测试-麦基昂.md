# BOLT体内氧气水平测试

**定义**：麦基昂采用的核心评估指标——Body Oxygen Level Test。测试方法：自然呼气后捏住鼻子屏息，直到出现明确的"想呼吸"的生理冲动（不是想憋多久憋多久）。BOLT值是屏息秒数，反映身体对二氧化碳的耐受度，是呼吸健康的核心指标。

## 测试方法
1. 静坐10分钟，自然呼吸
2. 自然呼气后捏住鼻子
3. 计时直到出现第一个明确的"想呼吸"信号（不是强行憋气）
4. 时间秒数 = BOLT值

## BOLT值分级

| BOLT值 | 状态 |
|--------|------|
| <10秒 | 健康状况不佳，呼吸过度，易疲劳/哮喘/焦虑 |
| 10-20秒 | 一般健康，仍有改善空间 |
| 20-30秒 | 良好健康状态 |
| 30-40秒 | 优秀，运动员水平 |
| 40+秒 | 卓越呼吸健康 |

## 核心原理
- BOLT值反映的不是肺活量，是身体对CO2升高的耐受度
- BOLT值低 = 对CO2敏感 = 容易感到气短 = 倾向过度呼吸
- 训练能提高BOLT值，提高CO2耐受度

- 评估起点：测试初始BOLT值
- 选择训练方案：根据BOLT值选不同练习
- 监控进步：每周测一次BOLT
- 目标：BOLT值40秒以上
