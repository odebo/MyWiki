# 竞争性定位-跨越鸿沟

跨越鸿沟必须"创造竞争"——实用主义者不购买没有竞争的产品，竞争的存在证明市场已经成熟。通过选定两个参照竞争对手，把自己定位在他们的交叉点。

## 竞争性定位罗盘

四个象限，横轴=客户兴趣（技术专家↔普罗大众），纵轴=市场态度（怀疑↔支持）：

- **早期市场**（左侧）：目标客户关注技术和产品价值
- **主流市场**（右侧）：目标客户关注市场领导地位和企业稳定性
- **跨越鸿沟**：从产品价值体系→市场价值体系的转移

## 两个参照竞争对手

**市场对手（market alternative）**
= 客户多年来一直付钱的老供应商
= 他们的现有预算就是你要抢的钱
作用：说明目标客户群体和预算来源

**产品对手（product alternative）**
= 开发同类颠覆性产品的另一家公司
= 证明技术可信度，说明创新方向
作用：说明你的技术差异化

## 定位公式（交叉点定位）

```
市场对手 + 产品对手 → 你在交叉点
= 既有市场对手的客户群/预算，又有产品对手的技术优势，但针对特定细分市场
```

**Box案例**：市场对手=SharePoint（目标企业用户预算）+ 产品对手=Dropbox（易用性/云存储技术）→ 既有企业文档标准又有Dropbox的易用性

**WorkDay案例**：市场对手=PeopleSoft（被甲骨文收购的HR软件客户）+ 产品对手=Salesforce → 承诺用SaaS重做HR

## 找不到市场对手是危险信号

Segway / Better Place：找不到明确的市场对手（没有现成预算可以抢），无法让实用主义者理解"为什么现在买"。结果：无法形成市场，最终失败。

## 定位四原则

1. 定位是**名词不是动词**（是脑海中的属性，不是营销行为）
2. 最有效的定位策略是变化最小的策略（人们不喜欢被干扰现有认知）
3. 定位要让产品**易于购买**，而非易于销售——聚焦客户的购买决策而非销售话术
4. 定位要通过电梯测试：两句话说清楚（目标客户/他们不满/我们是/能满足/不像/我们已集成）

## 举证的责任（图6-3）

跨越鸿沟需要的证据（按顺时针方向，从技术狂热者到实用主义者）：
- 技术狂热者：系统架构、设计原理、测试版
- 高瞻远瞩者：行业标准、产品测评、初上市销售额
- 保守主义者：营收利润、战略合作伙伴、顶级客户
- 实用主义者：市场份额、第三方支持、垂直媒体报道
