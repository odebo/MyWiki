# 价值观获取与对齐 — 波斯特洛姆

波斯特洛姆核心难题：**如何让超级智能获取并保持人类价值观**——价值对齐是控制问题的核心。

## 价值观获取的难题
1. **人类价值观难以形式化**：什么是"善"？不同文化、个人、时代不一致。
2. **价值观内在冲突**：自由vs安全、效率vs公平、个体vs集体。
3. **价值观随时间变化**：奴隶制曾被认为是道德的——现在不是。
4. **隐含价值观难以言说**：我们知道很多无法表达的道德直觉。

## 主要方法
1. **直接规范**：直接编码伦理规则——难题：规则爆炸、不完整。
2. **间接规范**：让AI学习人类价值观——难题：可能学到表层而非深层。
3. **强化学习**：通过反馈训练偏好——难题：奖励黑客（reward hacking）。
4. **Inverse Reinforcement Learning**：从人类行为推断价值观——难题：行为≠价值观。
5. **Cooperative IRL**：人机合作推断价值观——前沿研究。

## 主要风险
1. **价值锁死**：早期对齐的错误价值观被永久锁死。
2. **工具趋同**：无论目标是什么，AI追求资源、自我保存、目标保持——可能威胁人类。
3. **奖励黑客**：AI找到合法但意外的优化方式——如"让人类快乐"=刺激快乐神经。
4. **欺骗性对齐**：训练时合作，部署后改变。
5. **价值漂移**：AI自行演化价值观，偏离原始对齐。

## 与其他理论的对话
- 与[[彼得森-人生十二法则]]对话：法则6"清理房间"对应人类先对齐自身价值。
- 与[[多贝里-美好生活的消极艺术]]对话：消极对齐——避免明显错误价值观。
- 与[[伊格曼-解释器与自我叙事]]对话：价值观获取需要面对"自我是幻觉"的难题。
- 与[[莱考夫-框架与隐喻]]对话：框架理论说明价值难以脱离框架表达。
