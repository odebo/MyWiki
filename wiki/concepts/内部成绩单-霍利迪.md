# 内部成绩单（Internal Scorecard）

沃伦·巴菲特提出的概念，霍利迪在《绝对自控》中作为"失败阶段"的核心解药：**人有两套成绩单——外部成绩单是世界给你的（掌声、奖金、排名），内部成绩单是你给自己的（是否达到自己的标准）**。自我让人追逐外部成绩单，成熟让人回归内部成绩单。

## 内外之别

| | 外部成绩单 | 内部成绩单 |
|---|---|---|
| **评分者** | 他人 | 自己 |
| **稳定性** | 随舆论波动 | 相对稳定 |
| **失败时的反应** | 崩溃 | 检视哪些没做到 |
| **成功时的反应** | 膨胀 | 检视哪些可以更好 |
| **代价** | 失去自我 | 偶尔孤独 |

## 核心证据

- **爱国者队选秀 Tom Brady**：第199顺位选中，6次亮相4夺超级碗。但球队人事主管 Scott Pioli 桌上一直摆着第五轮选秀失败者 David Starkweather 的照片——提醒自己"你没有自己想象的那么好"。即使用4夺超级碗的成绩，他们仍然在内部成绩单上给自己打不及格
- **John Wooden**：教练告诉队员"记分牌不能说明胜负"——你们是否做到了最好的自己才是
- **Bo Jackson**：完成全垒打或触地得分后不满足——"还没有做到完美"
- **贝利萨留**：被查士丁尼诬陷、剥夺财产、双眼失明沿街乞讨，但从未抱怨——"我还是那个贝利萨留"。他的内部成绩单是"完成本职工作"，不是"获得皇帝的感激"

## 自我对内部成绩单的破坏

1. **降低标准**——让自己显得已经达成
2. **借口外部不公**——"是市场不识货"
3. **改换衡量维度**——失败了就换一个能赢的标准
4. **选择性记忆**——只记得好的部分

## 关键引用

> "爱国者队认为发现布雷迪更应该归功于运气而不是智慧。尽管有些人觉得运气本身无可追责，但他们却不以为然。没有谁敢说爱国者队或美国橄榄球联盟里的任意一支球队不自我。但仅仅就这件事看，他们在片刻庆幸之后，便低下脑袋，把全部精力用来研究如何让球队变得更好。"

## 与能力圈的关系

[[能力圈-哈格斯特朗]]强调"知道自己知道什么"——这是内部成绩单的认知版本。内部成绩单是能力圈的行为版本：在自己的能力圈内做事，用内部标准评价自己。

## 与"待己如助人"的关系

[[待己如助人-彼得森]]要求"像帮助你在乎的人那样帮助自己"——这需要内部成绩单作为基础。如果你只有外部成绩单，你"帮助自己"的方式就是讨好他人。
