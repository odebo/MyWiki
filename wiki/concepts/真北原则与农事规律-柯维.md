# 真北原则与农事规律

柯维"以原则为中心"生活哲学的核心——生活质量取决于生活与"真北"现实的吻合程度。"真北"是客观存在的因果规律，独立于我们的价值观、愿望或信仰。

## 原则不是什么

柯维明确区分原则与四个易混淆概念：

1. **原则≠价值观**——价值观是你重视的东西，原则是客观因果规律。你可以重视中彩票，但这不创造财富；你可以重视健康，但只有遵循锻炼/营养/休息的**原则**才有效。**价值观不会带来生活质量提升，除非我们重视原则。**

2. **原则≠惯例**——惯例是特定情境下的具体做法，新情境下失效；原则是普遍的，可适应任何情境。教孩子原则而非惯例，让他们能面对未知的未来挑战。

3. **原则≠宗教**——原则在各大宗教经典中都有体现，但原则本身不依赖任何神学体系。佛教/基督教/印度哲学/世俗哲学都指向相同原则。

4. **原则≠"个人魅力论"**——不是"积极思维""信仰魔力"等速成法；原则需要时间和过程。

## 农事规律

柯维最核心的比喻——**农事规律**制约生活的所有领域：

- 春天播种、夏天养护、秋天收获——**无法跳过任何季节**
- 学校可以临时抱佛脚，但农事不能
- 性格不能临时抱佛脚变成诚实勇敢
- 婚姻不能靠捷径和魅力手段解决根本问题
- 与孩子的关系不能靠权威训斥走捷径

> "短期而言，临时抱佛脚在社会系统看起来可能管用。但是从长远来说，农事规律制约着生活的各个方面。"——柯维

## 真北原则的具体内容

柯维列举的原则：
- **服务与互惠**——给予才能得到
- **信任**——来自值得信任
- **成长与变化**——受学习规律制约
- **协作增效**——两块板一起承受大于分别之和
- **诚实**——内在诚信是安全感基础
- **适度/自律/忠贞/责任感**——历代智慧文献共识

## 与已有知识库的关联

- 与 [[控制二分法-爱比克泰德]] 共鸣——区分可控（选择）与不可控（结果/原则）
- 与 [[斯多葛式接受-萨尔茨格伯]] 共鸣——接受外在原则而非试图主宰
- 与 [[牺牲使承诺关系更牢固-克里斯坦森]] 互证——农事规律制约人际关系
- 与 [[平凡时刻的积累决定了人生结果，而非少数'大决策'-沙恩·帕里什]] 互补——农事规律即长期积累的规律
- 与 [[时间统计法-格拉宁]] 互补——柳比歇夫56年的连续性正是农事规律的实践

## 实践含义

- 谦虚：我们无法控制生活，原则可以——安全感来自诚信而非比较
- 当失败时问："我能从中吸取什么教训？"——求助于原则
- 教孩子原则而非惯例，准备面对未知未来
- 投资第二象限（预防/准备/能力建设）就是尊重农事规律
