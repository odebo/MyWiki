# 所有行为都是沟通 — 佩里

**定义**：孩子所有的行为（包括不得体行为）都是沟通——表达未被满足的需要、未被回应的感受、未被理解的想法。**父母的工作不是纠正行为，而是解读行为背后的沟通**。当你理解了孩子在沟通什么，行为自然会改善。

**核心理念：行为是冰山一角**：
- 看得见的：发脾气/打人/不合作/撒谎
- 看不见的：饥饿/疲惫/恐惧/孤独/不被理解/需要连接
- 父母只处理冰山一角（行为），问题反复出现
- 父母回应冰山之下（需要），行为自然消解

**输赢游戏**：
- 父母常陷入与孩子的"输赢"——"我要让他知道谁说了算"
- 这是权力斗争，不是教育
- 输赢心态让孩子学到：力量决定对错
- 替代：合作心态——"我们一起面对这个问题"

**先考虑当下可行的状况**：
- 别想未来可能发生什么——焦虑驱动的不当干预
- 看此刻孩子的需要是什么
- 一个3岁孩子发脾气不是"将来会变成罪犯"——只是此刻不舒服

**行为得体所需要的特质**：
- **情绪调节**：能识别和表达情绪
- **冲动控制**：在反应前暂停
- **同理心**：理解他人感受
- **沟通能力**：用语言表达需要
- 这些特质需要被教导，不能被期待

**不得体行为意味着什么**：

| 行为 | 真实沟通 |
|------|---------|
| 发脾气 | "我承受不了这种情绪，请帮帮我" |
| 打人 | "我不会用语言表达愤怒" |
| 撒谎 | "我害怕说实话的后果" |
| 黏人 | "我需要更多安全感" |
| 不合作 | "我没有被听见" |
| 哭闹 | "我累了/饿了/overstimulated" |

**早点积极投入时间，就不需要后来被迫投入**：
- 早期花时间建立连接，比后期修复问题省力10倍
- "高质量的5分钟"胜过"心不在焉的1小时"
- 屏幕时间最大的问题是父母不在场

**用语言表达感受，有助于改善行为**：
- 教孩子说出情绪："你现在是不是很难过？"
- 当情绪被命名，情绪强度下降（神经科学研究支持）
- 父母也要示范："妈妈现在很累，需要休息5分钟"

**不要随意为孩子的不得体行为找借口**：
- 错：找借口"他只是累了"——但不解决
- 对：识别原因"他累了，所以我们需要休息"——然后行动
- 借口让孩子学到"行为不重要"，原因让孩子学到"行为可被理解"

**管教孩子应该多严格**：
- 管教 ≠ 惩罚
- 管教 = 教导
- 严厉的代价：孩子学会隐瞒而非改变
- 温和的代价：边界不清——但比严厉的代价小得多
- **理想**：温和而坚定——边界清晰，态度温和

**当孩子发脾气时**：
- 不是孩子"故意"——是孩子真的承受不了
- 父母任务：保持冷静，做孩子的容器
- 不解释不讲理——大脑在情绪风暴时无法处理逻辑
- 等情绪过去再讨论

**莫名其妙的哭闹**：
- 检查生理需要：饿/渴/累/冷/热/病
- 检查环境变化：新地方/新人/新规则
- 检查情感需要：被忽视/被批评/被比较
- 如果都不在，可能只是过载——陪伴等待

**父母的谎言**：
- 父母撒谎会被孩子学到——"善意谎言"也是谎言
- "我没有骗你"被孩子发现是谎言时，信任崩塌
- 即使难堪，也尽量诚实——孩子能承受真相

**孩子的谎言**：
- 3-4岁的"谎言"常是想象与现实混淆
- 5岁以上的谎言常是"避免惩罚"
- **惩罚性环境培养谎言**——孩子为自我保护而撒谎
- 替代：创造"诚实安全"的环境——孩子知道说实话不会受到过度反应

**界限：界定你自己，而不是孩子**：
- 错：界限 = 控制孩子（"你必须这样做"）
- 对：界限 = 界定自己（"我不能接受这种行为，所以我会…"）
- 例："我不能让你打我。如果你继续打，我会把你的手握住"——而非"不许打人！"
- **界限是父母的责任，不是孩子的任务**

**为年龄较大的孩子及青少年设定界限**：
- 青春期孩子需要更多自主权
- 界限应是协商而非命令
- "我担心你深夜回家的安全，我们一起想个方案"
- 父母仍需明确不可妥协的核心界限（安全/尊重）

**反常的青春期**：
- 青春期不是"反常"——是正常的发育阶段
- 大脑前额叶还在发育，情绪系统已成熟——失衡是常态
- 父母需要更多耐心，更少评判

**孩子长大成人后**：
- 亲子关系不会终结——但需要重新定义
- 成人孩子需要的是平等关系，不是权威关系
- 父母的"建议"常被解读为"评判"——慎言

**与已有概念的关系**：
- 与[[亲子教养的传承-佩里]]：父母对自己行为模式的觉察是解读孩子行为的前提
- 与[[回应感受而非处理感受-佩里]]：行为背后是感受，回应感受自然改善行为
- 与[[非暴力沟通-罗森伯格]]：所有行为都是沟通——非暴力沟通的核心假设
- 与[[拖延与心理游戏-伯恩]]：行为是心理游戏——伯恩的视角与佩里一致
