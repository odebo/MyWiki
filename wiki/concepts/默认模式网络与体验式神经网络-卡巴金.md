# 默认模式网络与体验式神经网络

**定义**：大脑存在两个相互拮抗的神经网络——**默认模式网络（DMN）**负责走神、自我叙事、反刍过去未来；**体验式神经网络**负责当下感官觉知。两者此消彼长，正念练习的核心神经机制就是**让两网络分离、增强切换能力**。

**默认模式网络（DMN）**：
- 解剖位置：前额中线下方、后扣带回、楔前叶。
- 功能：人不专注于外部任务时的"待机模式"——回忆过去、想象未来、构建自我叙事、揣度他人。
- 默认陷阱：DMN过度活跃与抑郁、焦虑、反刍思维强相关。"我在想我"是DMN的标志。

**体验式神经网络**：
- 解剖位置：头部侧面的感觉皮层、岛叶。
- 功能：当下感官体验——呼吸、身体感觉、声音、视觉。
- 状态：当人专注于此刻的感受，DMN活动下降，体验式网络激活。

**多伦多大学8周MBSR研究**：
- 8周正念训练后，被试的DMN与体验式网络在fMRI上呈现**显著分离**——更容易从走神切换到当下。
- 这不是"压制DMN"，而是**增强两个网络之间的切换肌肉**。走神不可消除，但可以更快识别"我走神了"并回到当下。
- 表观遗传效应：研究观察到端粒长度等基因表达层面的变化——心智训练影响生物学衰老指标。

**左右脑不对称与性情原点**：
- **性情原点**（temperamental set point）：曾被认为终生不变的天生情绪基线。
- 左前额叶激活高 → 积极情绪倾向；右前额叶激活高 → 抑郁倾向。
- 8周MBSR后，被试左前额叶激活显著升高，**性情原点被改写**——天生不是命运。
- 流感疫苗实验：MBSR组的抗体反应与左脑激活程度线性相关——**大脑变化与免疫变化同步**。

**杏仁核与腹内侧前额叶皮层**：
- 杏仁核：恐惧反应中枢。
- 腹内侧前额叶皮层：调节杏仁核。
- MBSR后两区功能连接增强——**恐惧反应更易被觉察与安抚**，而非被压住。

**实践含义**：
1. 走神不是失败，是DMN的默认状态。**觉察走神本身就是训练**。
2. 性情不是命运，**8周足以改变大脑的情绪基线**。
3. 身心不是二元的——大脑变化、免疫变化、基因表达变化是**同一次练习的不同侧面**。
