# 四笔钱资产配置框架

**核心内涵**：四笔钱是且慢基金投资研究所提出的家庭资产配置框架，把全部资金按「用途 + 使用期限」分成四笔：活钱管理的钱、稳健理财的钱、长期投资的钱、保险保障的钱。前三笔属于「投资部分」（生钱），保险属于「保障部分」（护钱），两者缺一不可，共同构成一个完整体系。它本质上不是按收益高低分，而是按「这笔钱什么时候要用、用来做什么」来分。

**运作机制**：划分标准有三条——活钱是随时要用的钱（日常开支 + 应急资金），通常配流动性好、风险低的货币基金；稳健理财的钱是半年以上、3 年以内有具体用途的钱（年底旅游、明年买车），配债券基金或「固收+」；长期投资的钱是 3 年以上不用的闲钱（养老金、教育金），配高波动的权益类资产以拉长期限换收益；保险保障的钱是托底的钱，用小保费撬动大保额，防止因病返贫、意外返贫。书中给出一套可执行的配置顺序：先留至少 3 个月生活开支做应急（货币基金）→ 再腾出 3 年内有明确用途的钱（「固收+」）→ 配置好保障型保险 → 最后把 3 年以上不用的闲钱做长期投资。

**为什么不用风险偏好定级**：书中明确否定了「先测风险偏好再推产品」的传统做法，理由是两点：其一，人是会变的，牛市里人人觉得自己是高风险偏好者，熊市里又变成低风险偏好者，风险偏好受市场预期、收入、认知变化影响，难以客观评估；其二，人的需求是多样化的，即使一个高风险偏好的投资者，也有日常开支这种承受不了任何风险的钱。因此四笔钱框架「从投资者自身情况出发」，比例千人千面，没有统一答案。

**意义与边界**：资产配置不仅决定大部分收益，也决定大部分风险和波动水平——「全球资产配置之父」加里·布林森说，从长远看约 90% 的投资收益来自成功的资产配置。四笔钱框架为普通投资者提供了一个可落地的分层容器，把「什么时候用、能承受多大波动」这件事显性化。它的边界在于：它只解决「钱怎么分层」，不解决「每层具体买什么、何时买卖」，后者仍需结合估值、周期、定投等方法；且书中强调「资产配置没有万能模板」，每笔钱的配置比例必须结合个人财务状况、风险承受能力和目标动态调整。
