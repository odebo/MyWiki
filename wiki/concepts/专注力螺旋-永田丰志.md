# 专注力螺旋-永田丰志

**定义**：永田丰志提出的"专注力螺旋"——专注力不是单次状态，而是一个自我强化的螺旋上升过程。从发现挑战到自主专注，再到实现目标的幸福感，最后到肉体精神成长——四个阶段循环往复，每轮循环使专注力更强、更容易进入下一轮。

## 四阶段螺旋

```
阶段1：发现挑战的机会
   ↓
阶段2：自主和专注的体验
   ↓
阶段3：实现目标所带来的幸福感
   ↓
阶段4：肉体和精神的成长
   ↓ （更强能力 → 发现更大挑战）
阶段1（更高水平）
```

## 各阶段解析

| 阶段 | 核心 | 关键条件 |
|------|------|---------|
| 1. 发现挑战 | 找到难易度匹配的挑战 | 难度略高于当前能力 |
| 2. 自主专注 | 进入深度专注状态 | 自主选择+无干扰环境 |
| 3. 实现幸福 | 完成目标的内在奖励 | 内在动机而非外在奖励 |
| 4. 成长 | 能力与心智提升 | 反思+复盘 |

## 螺旋的自我强化机制

- 阶段4的成长 → 使阶段1能接受更大挑战
- 阶段3的幸福感 → 强化阶段2的专注动机
- 阶段2的专注 → 提升阶段3的实现质量
- 阶段1的挑战 → 引发阶段2的专注深度

## 反直觉点

- 专注力不是"努力"出来的，是螺旋出来的
- 螺旋的起点是"挑战"而非"意志力"
- 内在幸福感（阶段3）比外在奖励更驱动持续专注
- 专注力可通过反复循环不断提升

## 与既有概念的关系

- 与 [[刻意练习-核心定义与特征]] 同源——刻意练习的"走出舒适区"对应阶段1，"即时反馈"对应阶段3
- 与 [[心流状态五步法-奎克]] 互补——心流五步法是状态进入方法，专注力螺旋是长期成长机制
- 与 [[40定律-戈金斯]] 互补——40定律说"大脑在40%潜能时骗你累了"，专注力螺旋说"突破40%进入成长循环"
