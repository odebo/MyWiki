# 余闲

**提出者**：塞德希尔·穆来纳森、埃尔德·沙菲尔，《稀缺》

**核心定义**：余闲（slack）是拥有的资源超出当前需要的部分——既是物质的（多出的钱、空闲时间、空余房间），也是认知的（多余的带宽、灵活的安排）。余闲不是浪费，而是**抵御稀缺冲击、保持判断力的关键资源**。

## 余闲的反直觉价值

| 直觉 | 实际 |
|------|------|
| 余闲是浪费 | 余闲是抗冲击缓冲 |
| 节省时间就要塞满日程 | 留白才能保证重要决策 |
| 富人的余闲是低效 | 余闲是富足的本质属性 |
| 紧急时挤余闲做事 | 余闲被挤后系统变脆弱 |

## 余闲的三大功能

1. **吸收冲击**：意外支出/延误/生病时不必借用未来
2. **保持判断力**：有余闲时不必进入管窥状态
3. **允许反思**：带宽充足才能做长期规划

## 余闲缺乏的连锁反应

- 余闲少 → 任何冲击都需借用未来 → 稀缺陷阱形成
- 余闲少 → 进入管窥 → 忽视长期重要事务
- 余闲少 → 带宽税加剧 → 决策质量下降 → 余闲更少

## 不同情境下的余闲

- **金钱余闲**：储蓄账户、应急基金
- **时间余闲**：日程留白、不预订的时段
- **认知余闲**：不被紧迫任务占据的思考时间
- **社交余闲**：可调用的关系网络冗余
