# 贫穷陷阱与S形曲线

**定义**：贫穷陷阱指穷人因为贫穷而陷入"今天的收入低于明天的收入"的下行螺旋——越穷越穷。班纳吉和迪弗洛用两条曲线刻画这一争论：S形曲线（存在贫穷陷阱）和反向L形曲线（不存在贫穷陷阱）。判断陷阱是否存在，关键不是理论立场，而是曲线的形状——而形状只能通过具体领域的实证研究确定。

**S形曲线**：
- 一开始很平坦，然后突然升起，之后又逐渐变平
- 从对角线（今天的收入=明天的收入）看，曲线低于对角线的区域就是"贫穷陷阱地带"
- 起点 A1 → A2 → A3 ……的轨道会持续向下，最终在 N 点陷入贫穷
- 起点 B1（在陷阱地带之外）→ B2 → B3 的轨道则持续向上

**反向L形曲线**：
- 一开始上升得很快，然后慢慢放缓
- 最穷的人也能挣到比原来更多的钱，会变得越来越富
- 不存在贫穷陷阱——一次性的施舍最多让人前进得更快，但不能改变最终方向

**关键洞察——形状不是理论问题而是实证问题**：
- 仅靠理论不够，要回答"贫穷陷阱是否存在"必须了解现实世界能否由图表体现
- 如果故事与化肥有关——需了解化肥市场的现实情况
- 如果是关于存钱的分析——需了解穷人是怎样存钱的
- 如果是关于营养和健康——需研究相关领域
- **找不到一个普遍适用的答案**——贫穷陷阱并不是存在于每个领域

**陷阱存在的典型领域**：
- **营养陷阱**：极穷的人吃不饱→体力不足→收入更低→更吃不饱。但班纳吉迪弗洛实证发现当今绝大多数穷人并非处于饥饿陷阱中——食品补贴政策常错配
- **健康陷阱**：蚊帐、驱虫、口服补液、疫苗——小投入撬动大回报的领域确实存在陷阱
- **教育陷阱**：家长对教育回报的期望与实际错位，让天资聪颖的穷孩子被剥夺机会
- **储蓄陷阱**：穷人无法储蓄→无法投资→收入无法增长

**陷阱不存在的领域**：
- 大多数微观经济行为在临界点之上呈现反向L形
- 一次性现金转移与无条件现金转移效果相同——家长不需要被强迫送孩子上学

**与普遍误解的对照**：
- 误解1：所有穷人都在所有领域陷入陷阱 → 实证显示陷阱是局部的
- 误解2：扶贫只需一次性给钱 → 若陷阱存在需持续干预直到跨过临界点，若不存在则一次性施舍就够
- 误解3：靠理论就能判断 → 形状只能由实地随机对照实验确定

**政策含义**：
- 陷阱存在领域：免费发放关键产品（蚊帐/驱虫药/口服补液盐）直到穷人跨过临界点
- 陷阱不存在领域：消除小障碍（信息缺失/小费用/便利性）即可，无需大笔补贴
- 错误的政策常来自政策制定者头脑中错误的世界模式——他们认为某处有陷阱而实际没有，或反之
