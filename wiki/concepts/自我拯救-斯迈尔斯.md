# 自我拯救

自我拯救（Self-Help），塞缪尔·斯迈尔斯在同名著作（收录于 [[羊皮卷-合集]]）中提出的核心主张——自立是打开成功之门的钥匙，外界的帮助必须建立在自立的基础上才能生效。该书是"自助"（self-help）一词的源头（1859 年出版）。

## 核心命题

- 自立者天助——外界帮助基于自立才能生效
- 恒心与毅力是胜利的前提
- 力量与勇气是成功的助推器
- 勤奋造就天才——天赋论被夸大

## 五大要素

1. **自立**：用双手托起蓝天。自立是成功之门的钥匙。
2. **恒心与毅力**：有恒心和毅力才能取得胜利，毅力可以助你完成一生的追求。
3. **力量与勇气**：每个人都拥有巨大力量，勇气是力量的助推器，助你走上成功的金字塔。
4. **勤奋与天赋**：勤奋造就天才，不是天赋是勤奋。
5. **行动**：行动改变命运，行动才能成功。

## 与"等待救赎"的对比

| 姿态 | 操作 | 结果 |
|------|------|------|
| 等待救赎 | 等待外界帮助/运气降临 | 失望、被动、无所成就 |
| 自我拯救 | 用双手托起蓝天 | 主导命运、积累成就 |

## 历史地位

- 1859 年出版，是"self-help"一词的起源
- 影响西方 150 年的自助传统
- 在维多利亚时代英国成为现象级畅销书
- 与达尔文《物种起源》同年出版——共同塑造了"自助力=适应力"的时代精神

## 与相关主张的关系

- 与 [[被讨厌的勇气-阿德勒]] 中"自我决定性"一致
- 与 [[柯维-七个习惯]] 中"积极主动"一致
- 与 [[自证预言-罗布森]] 互补：斯迈尔斯主张自助，罗布森提供科学机制（信念塑造现实）
- 与 [[被讨厌的勇气-阿德勒]] 的"目的论"一致——不是过去决定现在，而是当下的选择

## 实践含义

- 不等待外界救援——任何困境先问"我能做什么"
- 接受外界帮助前先建立自助基础
- 持续行动而非等待灵感
- 勤奋优于天赋——长期投入是关键
- 失败时不归因于"运气差"，而问"我哪里没做到"

## 跨书关联

- 与 [[被讨厌的勇气-阿德勒]] 一致：自我决定性
- 与 [[柯维-七个习惯]] 中"积极主动"一致
- 与 [[刻意练习-艾利克森]] 一致：勤奋造就天才，非天赋
- 与 [[原子习惯-克利尔]] 一致：持续行动改变命运
- 与 [[富兰克林自传-富兰克林]] 主题一致

## 局限

- "自立者天助"在系统性困境面前显得单薄
- 部分成功归因于勤奋可能忽视结构性优势（[[别相信直觉-史蒂芬斯]]）
- 维多利亚时代的价值观未必完全适用当代
- 与 [[期望效应-罗布森]] 互补：罗布森承认期望效应有边界，斯迈尔斯的"自助"同样有边界
