# 净结果思维

**定义**：巴达拉克五大问题的第一问——"净结果是什么？"要求决策者全面深刻地思考每个选项的所有后果，包括对各个利益方的短期与长期、直接与间接影响，避免被单一指标或最显眼的后果简化决策。

**操作步骤（确保过程正确的五个步骤）**：
1. **拦下"火车"** — 当本能反应想冲过去时，强制暂停
2. **聚焦过程** — 关注决策过程是否正确，而非结果
3. **找对人选** — 让多元视角参与，避免群体思维
4. **画决策树** — 系统化呈现各选项的后果链
5. **协同策略** — 让决策被共同塑造而非独断

**核心洞察**：
- 灰度问题中，最容易看见的后果往往不是最重要的后果
- "净"字强调总和思维：所有利益方、所有时段、所有维度
- 决策质量取决于过程质量，而非结果是否"正确"——因为灰度问题本身就没有标准正确答案
- 拦下火车：阻止"必须立刻做决定"的焦虑驱动决策

**与其他思维框架的关系**：
- 与 [[初始假设-艾森拉塞尔]] 互补：先形成假设，再用净结果思维检验
- 与 [[二阶预测-庞德斯通]] 同源：都要求超越一阶后果
- 与 [[考虑最坏情况-塔勒布]] 互补：净结果要求全面，塔勒布要求特别关注尾部风险
- 与 [[系统1系统2-卡尼曼]] 互补：拦下火车即强制系统2介入

**反例**：只看财务指标、只看短期股价、只看上级反应——这些都是非"净"结果的简化决策
