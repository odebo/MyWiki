# 闪电式扩张

踩中风口时的作战法则。来源：里德·霍夫曼《闪电式扩张》（LinkedIn 创始人）。

## 核心思想

> 踩中风口，面对市场的不确定，优先考虑的是**速度**，而不是效率。

为了速度：
- 接受混乱
- 容忍糟糕的管理
- 忽略客户投诉
- 募集超额资金

**这就是野蛮人法则。**

## 野蛮人 vs 文明人

| | 野蛮人（滴滴/快手/抖音） | 文明人（易到/早期快手） |
|--|---------|--------|
| 核心选择 | 速度第一，燃烧资金 | 理性、稳步，讲效率 |
| 结果 | 赢 | 输 |

**易到周航**：先驱，体验极好（甚至可定制车内音乐偏好），但面对滴滴的补贴大战，选择不卷入野蛮战争 → 输。

**抖音 vs 快手（2019 春节）**：
- 快手：不花推广费 = "产品力不足的表现"
- 张一鸣：5 亿美金砸 8 天 → 用户数拉开差距，此后无法追回

> 在抢滩点，两种宿命：疯了一样冲过去，或者慢慢死去。

## 四个作战阶段

```
海盗 → 海军陆战队 → 军队 → 警察
野蛮人法则        文明人法则
```

| 阶段 | 特征 | 作战方式 |
|------|------|---------|
| **海盗** | 草莽期，靠灵活性和默契存活 | 快速出击，承担大公司不愿承担的风险 |
| **海军陆战队** | 风口期，抢滩 | 不惜一切代价，速度第一，猛攻 |
| **军队** | 市场净空减少，开始讲效率 | 引入架构/职级，规范管理 |
| **警察** | 成熟市场，维持秩序 | 精益运营，确保客户按秩序运作 |

**小米的演变**：
- 闪电扩张期：3 层结构（高管/核心主管/员工），去管理化，决策极快
- 市场净空结束：引入职级，从 3 层变 10 层，向"军队"演进

## 适用条件

闪电式扩张的前提：**市场净空足够大**

- 市场净空 = 有条件但还没使用的用户
- 智能手机份额 10% 时，净空 90% → 冲！
- 人人都用智能手机时，净空不足 → 停止扩张，转军队/警察模式

## 与玩家地图的关系

- 海盗 = 草莽阶段（→[[玩家地图与增长生态位]]）
- 海军陆战队 = 从草莽冲向头部的关键窗口
- 军队/警察 = 头部/顶级的稳定运营

外企人用警察习惯来当海盗，所以难以适应创业。
