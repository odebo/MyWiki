# 人生方程式

**定义**：稻盛和夫提出的核心方程式——**人生·工作的结果 = 思维方式 × 热情 × 能力**。三要素中，"能力"是先天禀赋（0-100分），"热情"是后天努力（0-100分），"思维方式"是态度取向（**-100 到 +100分**）。关键在乘法而非加法——尤其"思维方式"可正可负，决定结果方向。

**三要素详解**：

1. **能力（0-100）**：智能、运动神经、健康等——父母或上天给予的先天资质。不涉及个人意志和责任。稻盛自评"60分能力"。
2. **热情（0-100）**：又称"努力"——从懒散潦倒到火焰般拼命。**完全由自己意志决定**。稻盛自评"90分热情"。
3. **思维方式（-100 到 +100）**：最为重要。正向思维方式——不厌辛劳、愿他人好、为大众幸福拼命工作；负向思维方式——愤世嫉俗、怨天尤人、否定真诚人生态度。

**为什么是乘法不是加法**：
- 加法：90分能力 + 30分努力 = 120分
- 乘法：90分能力 × 30分努力 = 2700分
- 反过来：60分能力 × 90分努力 = 5400分（**高出前者一倍**）
- 启示：能力平凡者通过拼命努力可弥补能力不足，取得巨大成功

**思维方式为何是负值**：
- 能力、热情都≥0；唯有思维方式可为负
- 哪怕-1分的思维方式，乘积立即变为-5400分
- 能力越强、热情越高，负向思维方式造成的破坏越大
- 现实案例：风险企业经营者才华出众、热情洋溢，上市获巨额财富后变得旁若无人、一意孤行，最终失足落马——思维方式由正转负

**正向思维方式清单**：积极向上、具有建设性；善于与人共事、有协调性；性格开朗、对事物持肯定态度；充满善意；同情他人、宽厚待人；诚实、正直；谦虚谨慎；勤奋努力；不自私、无贪欲；有感恩心、懂得知足；能克制自己的欲望。

**稻盛的提出背景**：
- 初中、大学、就职考试每次都不理想，志愿都落空
- 观察周围既有成功者也有失败者，思考"是否有法则可循"
- 京瓷创业后不久想出此方程式
- 70余年人生实践验证——"真实地、准确地表述了我们的工作和人生"

**机制——为什么这个方程式有效**：
1. **乘法效应**：努力可放大天赋；思维方式决定方向
2. **可控性分配**：能力不可控；热情可控；思维方式最可控
3. **方向优先于强度**：思维方式是方向；热情是强度；能力是基数
4. **负值的警示**：才华+热情+错误方向 = 巨大灾难
5. **平凡的解放**：能力平凡者通过热情×正向思维方式可超越天才

**与其他方程式的对照**：
- 多贝里[[思维工具比学识和金钱更重要-多贝里]]：工具>学识>金钱>智商——元能力优先
- 稻盛：思维方式>热情>能力——方向优先于强度优先于基数
- 共通：都把"元层"（工具/思维方式）放在首位
- 区别：多贝里反卵巢彩票；稻盛承认能力是天赋但用乘法解放平凡者

**与"成长型思维"的关系**：
- 德韦克成长型思维：能力可通过努力发展
- 稻盛"能力要用将来进行时"[[能力要用将来进行时-稻盛和夫]]：能力在未来一定会提高
- 共通：都拒绝"我现在不行"的固定判断
- 稻盛更激进——把"将来进行时"作为目标设定的前提

**与"品格技能"的呼应**：
- 格兰特[[品格技能-格兰特]]：品格技能（proactivity、fit-for-role、sacrificing for mission）可学
- 稻盛：思维方式是后天可改的品格取向
- 共通：都把"态度/品格"作为可习得的核心变量

**适用边界**：
- 适用于：长期人生与工作的方向判断
- 适用于：能力平凡者的自我激励
- 适用于：成功者防止思维方式转负的警醒
- 不适用于：精确量化——这是定性框架不是数学公式
- 不适用于：基本生理/结构限制——乘法不创造物理不可能

**实践含义**：
- 先审视思维方式——是否有怨恨、愤世、否定倾向
- 把热情作为自己可控的杠杆——能力不够热情补
- 不以"能力不足"为借口——能力是放大器不是限制器
- 警惕"能力强+热情高+方向错"的组合——这是最大风险
- 把正向思维方式具体化（感恩、谦虚、利他）——而非空泛口号
