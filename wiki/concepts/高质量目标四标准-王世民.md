# 高质量目标四标准

**核心内涵**：王世民提出，目标的最大价值不在于目标本身是否实现，而在于实现它的过程中能力是否提升、资源是否积累。基于洛克的目标设置理论、德西与瑞安的自我决定理论、班杜拉的自我效能理论，他总结出高质量目标的四个标准。

**四个标准**：

1. **自主设定**：目标源于自己内心的渴望，而非外部激励或压力。自我决定理论的「自我一致性」指出，与内在兴趣或核心价值观一致的目标更可能实现，即使没实现也有满足感。
2. **可衡量**：具体、可量化。洛克发现「明确的目标」比「尽力而为」更能提高绩效（如「每周减重 1 千克」优于「体重要比去年轻」）。
3. **有挑战性**：要「跳一跳」才够得到。有挑战的目标更能集中注意力、精力充沛、坚持不懈、发现更有效策略。
4. **高频反馈**：支持高频次进度反馈，及时了解进展以增强自我效能。这也是 OKR 比年度目标管理更受欢迎的原因。

**四步法**：

1. **确立定性目标**：动词开头（提升……）→加有挑战性的程度（「到能打动人心」）→以可实现的标准修正（「在提前准备下能说服别人按建议行事」）。
2. **用 5why 法验证目标合理性**：追问动机，发现目标背后的驱动力；外部强加的目标可与本能欲望挂钩（如「给爱人做饭」让你更想学做饭）。
3. **拆解出定量目标**：设定不超过 5 个可衡量的量化目标（SMART 验证），要有挑战性。
4. **周期性反馈和更新**：把定量目标进一步拆到适合自己的检查频次（周或月）。

**意义与边界**：高质量目标是[[远大的梦想会降低动力-王世民]]的正面承接——不是放弃目标，而是把目标从「空想」降维成「可执行、可反馈」的抓手；它也是[[333时间管理法-王世民]]「以终为始」原则的理论来源。
