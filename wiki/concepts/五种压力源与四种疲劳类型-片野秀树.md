# 五种压力源与四种疲劳类型-片野秀树

**定义**：片野秀树对疲劳的结构化分解——疲劳的根源是5种压力源（物理/化学/生物/心理/社会），不同压力源导致4种疲劳类型（自主神经紊乱型/免疫系统紊乱型/内分泌系统紊乱型/综合型）。识别疲劳类型是选择对应休息方式的前提。

## 五种压力源

| 压力源 | 内容 | 例 |
|-------|------|---|
| 物理性 | 环境、温度、姿势 | 久坐、噪音、温差 |
| 化学性 | 物质摄入 | 添加剂、咖啡因、酒精 |
| 生物性 | 病原、免疫 | 病毒、细菌、过敏 |
| 心理性 | 情绪、认知 | 焦虑、抑郁、决策疲劳 |
| 社会性 | 关系、角色 | 人际冲突、角色冲突 |

## 四种疲劳类型

1. **自主神经紊乱型**：最早显现的疲劳信号，交感与副交感失衡
2. **免疫系统紊乱型**：容易生病，反复感冒
3. **内分泌系统紊乱型**：血糖升高、激素失衡
4. **综合型**：多系统同时紊乱，慢性疲劳综合征

## 疲劳的掩盖机制

- **功能饮料和咖啡**：暂时掩盖疲劳感，不解决根本
- **持续掩盖的后果**：慢性疲劳综合征
- **疲劳感可被掩盖但疲劳本身仍在累积**——这是最危险的陷阱

## 疲劳不是乳酸

片野辟谣：疲劳的根源不是乳酸（传统认知），而是压力源的累积效应。乳酸只是高强度运动后的副产品，与日常疲劳无关。

## 与既有概念的关系

- 与 [[呼吸是唯一可控的自主神经入口-奥仲哲弥]] 同源——自主神经紊乱是疲劳的最早信号，呼吸是干预入口
- 与 [[过度呼吸症-奥仲哲弥]] 互补——过度呼吸是自主神经紊乱的重要诱因
- 与 [[90的身体不适源自呼吸与姿势错误-奥仲哲弥]] 互补——片野的"5种压力源"丰富了奥仲的"呼吸+姿势"模型
