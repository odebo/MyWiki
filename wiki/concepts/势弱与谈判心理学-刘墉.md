# 势弱与谈判心理学

**核心**：谈判中显示急切就势弱。古董大佬明明捡了漏还要还价，明明一眼看上小瓷瓶却顾左右而言他——这些都是避免"见猎心喜"暴露价值的功夫。

**三大原则**：

1. **见猎心喜必势弱**：你太想要、太急、太兴奋，都让对方看出你的底牌。等不及接电话、急着答应对方报价、第一眼就盯上目标——都在暴露你
2. **侵前是为了退让**：谈判开始各进一步，最后各退一步回到中间。一开始没"往前多站几步"，最后很可能吃亏
3. **说大人则藐之**：愈是跟自以为了不起的人说话，愈要表现得自信。你的那股"气"会让他不敢小觑

**声东击西技术**：
- 古董大佬想买值钱小瓷瓶，故意先问旁边的烂东西，一样样问，最后才"不经意"问到目标
- 如果直接眼睛发亮一把抓起，摊贩立刻起疑——三百涨成三千甚至上万
- 商业订单：客户说20万箱，你立刻答应，他八成隔天反悔说要降数量或单价；你说"最少25万箱否则提单价"，胜券八成在你手中

**价值由比较产生**：
- 张五常卖橘子树故意安排另一个摊子在旁边卖同样的——有比较才放心
- 一个人站白墙前看不出高矮，站在车前或人群里才看得出
- 价格锚定效应——摊贩喊40、另一摊喊50，顾客就有谱了

**势弱的常见信号**：
- 接电话秒接（应等响两声再装从容说"喂"）
- 急着答应对方第一次报价
- 主动打电话次数过多
- 皮鞋太新（应征时显得菜鸟）

**与相关概念的关系**：
- 与 [[锚定效应-特沃斯基]] 一致——先开高价就锚定了谈判区间
- 与 [[稀缺-西奥迪尼]] 同源——稀缺感的制造需要隐藏急切
- 与 [[WYSIATI使人在信息越少时反而越自信-卡尼曼]] 形成对照——见猎心喜是系统1冲动，势弱是反制
- 与 [[离舍断-刘墉]] 互补——离舍断是关系的减法，势弱管理是谈判的加法
