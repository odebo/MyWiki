# 集中投资

**定义**：巴菲特的投资组合管理方法——把大部分资金集中投在少数几个深入了解的优质公司上，而非广泛分散。与"分散投资降低风险"的传统智慧形成对比，集中投资认为：深入了解的少数标的比浅尝辄止的多个标的风险更低。

**集中投资的核心逻辑**：
- 风险来自不了解，而非持仓数量——10个不了解的公司比3个深度了解的公司风险更高
- 伯克希尔75%普通股投资集中于5只股票
- 巴菲特40年职业生涯中，12项决策决定其与众不同
- 凯利公式数学支持：当胜率与赔率明显有利时，应集中下注

**集中投资的操作要点**：
1. **只投能力圈内的少数公司** — 深度研究而非广泛覆盖
2. **在安全边际显著时大幅买入** — 大机会出现时不能小气
3. **长期持有** — 让复利发挥作用，减少交易成本与税务摩擦
4. **忽略短期波动** — 集中组合波动更大，必须情绪稳定

**集中投资的心理挑战**：
- 短期波动剧烈：集中组合下跌幅度远大于分散组合
- 需要极强的信念：承受市场先生挑衅的能力
- 需要深度研究：不能依赖他人意见
- 需要长期视角：短期表现可能落后市场

**与其他框架的关系**：
- 与 [[二阶预测-庞德斯通]] 张力：集中投资假设可以识别"胜率与赔率明显有利"，但庞德斯通警告二阶预测的困难
- 与 [[群体智慧优于单个专家-庞德斯通]] 张力：群体智慧支持分散，集中投资拒绝群体
- 与 [[考虑最坏情况-塔勒布]] 互补：塔勒布主张"杠铃策略"——大部分极度安全+小部分极度冒险，与集中投资在优质企业上不完全相容
- 与 [[三度影响力-克里斯塔基斯]] 同源：集中投资要求深度理解网络影响
- 与 [[MECE原则-艾森拉塞尔]] 互补：MECE 用于深度分析少数标的
- 与 [[付出者网络-格兰特]] 同源：格兰特证明深度关系网络优于广撒网，集中投资是其在资本配置的应用

**反例**：
- 以"集中投资"为借口不做研究就重仓——这不是集中，是赌博
- 在能力圈外集中——比分散更危险
- 集中后频繁调整——失去集中投资的长期优势

**适用边界**：
- 集中投资需要非平凡的研究能力与情绪控制力
- 不适合需要流动性的短期资金
- 不适合没有时间深度研究的投资者——他们应被动指数投资
