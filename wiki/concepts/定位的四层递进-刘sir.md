# 定位的四层递进

**核心内涵**：刘sir 把个人定位抽象成一条「层层递进、由表及里」的推导链——一本书定位的底层逻辑是选题定位，选题定位的底层逻辑是 IP 定位，IP 定位的底层逻辑是职业定位，职业定位的底层逻辑是人生定位。反过来读就是：你不清楚想活成什么样的人生，就很难搞清楚要做什么工作；不清楚为什么工作，就不知道要做什么 IP；不清楚 IP 的核心价值，也出不好一本书。定位因此不是「找到一个点」，而是一套系统。

**运作机制**：这套递进关系在实操上体现为一个不断「向下追问」的动作。作者用书名来示范三个层级——三流的书名卖噱头（如《揭秘樊登读书会的成功》），二流的书名卖功能性（如《如何打造中国第一大知识网红》），一流的书名卖价值观（如《简单做事》）。价值观之所以是最高层，是因为它普适、与 IP 本人自洽，让他人到哪都讲得出来，也更容易被其他 IP 免费传播。作者给樊登读书会郭俊杰出的《简单做事》，之所以能把「讲知识 IP／讲创业」的窄读者群解决掉，正是因为它落到「简单做事」这个普适价值观，读者定位从圈内扩到所有追求个人成长的大众。

**意义与边界**：这条链解释了为什么很多 IP「越努力越错」——当 IP 与职业定位相互排斥、核心能力与 IP 定位不一致时，书和内容离核心能力圈越远，推广时间越少，销量越差。作者给出一条可操作的判断标准：跟一个人聊三到五分钟，如果他还说不清自己最核心的那个点是什么，他的职业发展大概率走过弯路。但也要注意，这套递进是「推导问题的方法」而非「替你思考」——作者反复强调别人帮你定位只是助推，最终核心仍是自己向内追问「我想成为什么样的人」。
