# 爆款文案——金句4种模板

> 金句是文章持续传播的要素，更是"发酵剂"。

## 金句的本质

金句之所以有威力，原因有二：
1. **观点深刻**——能击中要害，引发共鸣
2. **简短有力**——利于传播和记忆

金句不需要高深的文学功底，只需要掌握4种模板。

---

## 金句模板1：1221句式

**前后语句内容反转，形成对比反差。**

结构：`A从来不只属于B，但B会永远属于A`（内容前后反转，韵律上形成回环）

### 4种写法

**第一种：重新定义**
找到核心对象，重新赋予内涵。
- "没有什么武器可以俘获爱情，爱情本来就是武器"
- "哪有什么带刺的玫瑰，玫瑰本来就是刺"

步骤：确定描述对象 → 找核心类比对象 → 重新定义

**第二种：抓住从属关系**
颠覆常规从属关系，建立新的归属逻辑。
- "孩子从来都不属于父母，但父母会永远属于孩子"
- "奢侈品的标签从来不依附于任何人，反倒是多数人依附于标签来体现自己的身份"

**第三种：利用反义词**
前后半句包含意思相反的词对，制造冲突感。
- "我以为等待可以收获爱情，没想到错过爱情恰恰是因为等待"
- "我以为有钱可以变得自由，没想到我的自由却结束于有钱"
- 泰戈尔："有时候爱情不是因为看到了才相信，而是因为相信才看到"

**第四种：变换主被动**
前半句主动，后半句被动，境界更高远。
- "当你在凝视深渊的时候，深渊也在凝视着你"（尼采）
- "我们之所以这么拼，不是为了被世界看见，而是想看见整个世界"
- "有自己的风格，意味着是人穿衣服，而不是衣服穿人"

## 金句模板2：1213句式

**前后两句共享一个关键词，核心词相反或递进。**

来自《小王子》的例子：
> 如果不去遍历世界，我们就不知道什么是我们精神和情感的寄托，但我们一旦遍历了世界，却发现我们再也无法回到那美好的地方去了。

结构：`[共同关键词]…[核心词A]…[共同关键词]…[核心词B]`

### 两种关系

**核心词相反关系**
- "后来的我们，为了谁四处迁徙，为了谁回到故里？后来的我们，有多少衣锦还乡，有多少放弃梦想？"
- "考研这场博弈，有几多人得偿所愿，有几多人名落孙山"

**核心词递进关系**
- "别人这么努力是为了生活，我这么努力是为了生存"（生存 > 生活）
- "普通人的早起是自律，牛人的早起是习惯"（习惯 > 自律）
- "三流员工想的是如何加薪，一流员工想的是如何提升能力"

技巧：找场景（考研/婚姻/职场），发现其中的人生对比。

## 金句模板3：搜词法

**锁定核心词，搜索同族词语，组合造句。**

案例：
- 高德地图顺风车广告："**世界上最好的套路，就是顺路**"
  - 核心词：顺路 → 搜索带"路"的词 → 发现"套路" → 组合
- 学员名字"楚楚"："**经历了很多酸楚是为了把世界看得更清楚**"
  - 核心词：楚 → 搜索含"楚"的词（酸楚/苦楚/清楚）→ 组合

工具：百度搜索 + "文案狗"微信公众号（输入核心词自动返回相关词语）

步骤：锁定核心词 → 搜索同族词 → 排列组合 → 找到既押韵又有内涵的搭配

## 金句模板4：拆字法

**根据汉字结构赋予新含义。**

案例：
- "思" = 田 + 心 → "**勤耕'心'上'田'，'思'想才会获得丰收**"
- "绝路"的"绝" = 丝 + 色 → "**人走上绝路，大都与'色'有着千丝万缕的联系**"
- "穷" = 宝盖头（公司）+ 八（朝九晚五）+ 力（卖力）→ "**一直穷，就是你在一个公司里，卖力工作8小时**"
- "功" = 工 + 力 → "**工作不卖力，你还想成功？**"
- "香" = 禾苗 + 烈日 → "**若禾苗未经历烈日的考验，怎得日后稻香千里**"

## 金句的最高原则：视觉化

> 人的爬行脑更喜欢视觉化信息，而不是抽象信息。

| 抽象版 | 视觉化版 |
|--------|----------|
| 小体积、大容量的MP3 | 把1000首歌放到口袋里（iPod广告） |
| 只要抓住机会，即使能力不高也能成功 | 在风口上，猪也会飞 |
| 同时实现多个目标 | 一石二鸟 |
| 早点行动更有机会 | 早起的鸟儿有虫吃 |

**写金句时，追求的首先是共鸣感和场景感，而非文字的优美和押韵。**
