# 随机词法

**定义**：斯隆提出的横向思维训练法——通过引入随机刺激因素（最简单的是随机词），强迫大脑脱离传统思维路径，建立新的连接。这是激发创造性思维最简单也最有效的工具之一。

## 操作步骤

1. **拿一本字典，随便挑选一个名词**写在纸上
2. **列出这个名词的几种属性**
3. **强迫自己思考**纸上的内容与要解决的问题之间的联系
4. **记录脑海中浮现的各种想法**

## 实例：如何吸引最优秀的人才

**问题**：如何吸引最优秀的人才加入你的公司？

**随机词**：桉树（eucalyptus）

**桉树的属性**：
- 原产于澳大利亚
- 是考拉的唯一食物
- 生长迅速
- 根系深，能吸收大量水分
- 叶子有强烈香气
- 树皮容易剥落
- 木材坚硬

**与人才吸引的连接**：
- **原产于澳大利亚** → 是否可以从海外招聘？（地理多样性）
- **考拉的唯一食物** → 公司能否成为某类人才的"唯一选择"？（专精定位）
- **生长迅速** → 公司能否提供快速晋升通道？
- **根系深** → 是否能提供长期深度培训？
- **叶子有香气** → 公司文化是否有独特"味道"吸引人？
- **树皮容易剥落** → 是否可以定期"剥落"旧制度保持活力？
- **木材坚硬** → 是否强调组织的稳健性？

每一个连接都可能启发一个具体的招聘策略。

## 为什么随机词有效

### 1. 打破思维定式
大脑天然倾向沿熟悉路径思考。随机词强迫大脑跳出熟悉路径，建立新连接。

### 2. 强制连接
随机词与问题的"无关"反而激发创造力——大脑会强行建立连接，这种连接是非传统的。

### 3. 多样性
不同人用同一个随机词，会产生完全不同的想法——因为每个人的经验不同。

### 4. 客观性
随机词是真正随机的，不受主持人或会议政治影响。

## 随机词的变体

- **随机图片法**：翻杂志随机选一张图片
- **随机物体法**：从桌上随便拿一个物体
- **随机人物法**：从通讯录随机选一个联系人
- **随机地点法**：地图上随机选一个地点

核心都是引入"非问题域"的刺激，激发跨域连接。

## 与"抓住偶然性"的关系

随机词法是[[横向思维四特征-斯隆]]中"抓住偶然性"的主动化——
- 历史上的偶然发现（青霉素、X射线）是被动抓住偶然
- 随机词法是主动制造偶然，让大脑进入"偶然发现"状态

## 与已 ingest 概念的关系

- 是 [[横向思维四特征-斯隆]] 中"抓住偶然性"的工具化
- 配套 [[发散思维与趋同思维-斯隆]]——随机词是发散阶段工具
- 与 [[可得性偏差与思维错误-斯隆]] 形成对照——可得性偏差是大脑的"近因效应"，随机词法是主动打破近因效应
- 与 [[类比法-斯隆]] 互补——类比是有意识找相似，随机词是无意识碰撞
