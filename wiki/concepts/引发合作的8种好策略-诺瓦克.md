# 引发合作的 8 种好策略

**定义**：诺瓦克与卡尔·西格蒙德在重复囚徒困境的进化动力学中识别出 8 种能引发合作的"好策略"。它们构成合作的进化阶梯——从永远背叛到无条件合作，策略沿着确定性→概率性、严苛→宽容的轴进化。每一种策略都是阶段性的赢家，没有一种能永生——合作与背叛周而复始地轮回。

**8 种策略的进化阶梯**（从最严苛到最宽容）：

1. **永远背叛（All D）** — 最低级，但对无条件合作者占优
2. **以牙还牙（Tit for Tat）** — 第一轮合作，之后复制对方上一轮行为；Axelrod 竞赛的初代赢家
3. **宽宏以牙还牙（Generous Tit for Tat）** — 在对方背叛后偶尔原谅；防止报复循环
4. **赢定输移（Win Stay, Lose Shift）** — 得分好就重复上一动作，得分差就切换；比以牙还牙更"人性化"
5. **无条件合作（All C）** — 最高阶，但会被背叛者盘剥

中间还有 3 种过渡形态（同步与交替博弈中略有差异）。**8 种**这一数字来自确定性策略中"记忆一步"的所有可能行为规则组合。

**关键策略详解**：

**以牙还牙（Tit for Tat）**
- 4 个属性：善良（永不主动背叛）、可激怒（被背叛必报复）、宽恕（对方回合作即原谅）、清晰（行为可预测）
- 致命弱点：在噪声中引发血腥复仇——一次失误触发无限报复
- 适合：完美信息、零噪声环境

**宽宏以牙还牙（Generous Tit for Tat）**
- 在以牙还牙基础上加入概率 p 的原谅
- 适合：有噪声的真实环境
- "永远不会忘记对方的好意，但会偶尔谅解对方的恶行"
- 鲍勃·梅："你永远不会因为太过宽容而输掉游戏"

**赢定输移（Win Stay, Lose Shift）**
- 极简规则：上轮得分高于阈值就重复，否则切换
- 比 Generous Tit for Tat 更简单——只需关心自己得分，不需建模对方
- 同步博弈中的最终赢家
- 缺点：会盘剥无条件合作者，可能在背叛者海洋中错过合作机会
- 米林斯基棘鱼实验：30% 玩家类似 Generous TFT，70% 用 Win Stay Lose Shift

**同步 vs 交替博弈的关键差异**：
- 同步博弈（双方同时出手）→ Win Stay Lose Shift 称王
- 交替博弈（一方先动，对方观察后再动）→ Generous Tit for Tat 称王
- 现实生活介于两者之间——我们总能得到一些对方意图信息，但不完整

**合作的兴衰轮回**：
- All D → Tit for Tat → Generous TFT → Win Stay Lose Shift → All C → 背叛死灰复燃 → All D
- 没有策略真正稳定——"进化动力学"取代"进化静力学"
- "幸运女神不会永远向一个人招手，合作的天堂终究会被充满背叛的地狱所取代"
- 合作成功的衡量：合作维持多久 + 多长时间能再次繁荣

**核心洞察**：
- 合作不是终点，是动态平衡
- 完美策略不存在——每个策略都有它的盲区
- 真实生活介于同步与交替之间，因此 Generous TFT 与 Win Stay Lose Shift 共存
- 噪声/失误是合作进化的关键变量——它淘汰了过严苛的策略

**与既有框架的关系**：
- 与 [[囚徒困境-诺瓦克]] 同源：8 策略是囚徒困境的解空间
- 与 [[五大合作机制-诺瓦克]] 互补：直接互惠机制下这 8 种策略胜出
- 与 [[真正的赢家无须惩罚-诺瓦克]] 同源：宽容策略胜出印证"奖励优于惩罚"
- 与 [[付出者获取者互利者-格兰特]] 互补：格兰特的"matcher"≈ Tit for Tat
- 与 [[灰度决策五大问题-巴达拉克]] 张力：8 策略是清晰规则，灰度决策拒绝规则化

**应用边界**：
- 8 策略基于"一步记忆"假设，更多记忆的策略空间巨大未探明
- 真实博弈中策略可能混合使用而非纯一
- 文化差异影响策略选择（如跨文化惩罚实验中希腊/俄罗斯的报复倾向）
- 现代社会中"重复相遇"概率下降，传统以牙还牙有效性减弱
