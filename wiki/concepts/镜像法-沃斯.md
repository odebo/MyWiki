# 镜像法 — 沃斯

## 定义

**镜像法**（Mirroring）：重复对方最后说的1-3个关键词，用升调——简单但强大的谈判工具，让对方感到被听见并主动展开。

## 操作方法

### 步骤
1. 倾听对方说话
2. 重复最后1-3个关键词
3. 用升调（问句语气）
4. 暂停，等待对方回应

### 示例
```
对方："这个价格我们真的很难接受，预算太紧了。"
你："预算太紧了？"
对方："是的，我们今年削减了30%的采购预算..."
```

## 镜像法为什么有效

### 1. 触发"被听见"感
- 人渴望被理解
- 重复让对方确认"你听到了"
- 建立"我们在沟通"的信任

### 2. 引导对方展开
- 升调的重复 = "请继续"
- 对方会自动解释、补充
- 你获得更多信息

### 3. 放慢节奏
- 重复创造停顿
- 让情绪降温
- 避免冲动反应

### 4. 避免假设
- 不预设对方意思
- 让对方自己澄清
- 减少误解

## 镜像法的应用场景

### 1. 信息收集
- 你不知道对方真实意图
- 用镜像让对方多说
- 揭示隐藏信息

### 2. 情绪安抚
- 对方激动时
- 镜像让对方感觉被理解
- 情绪自然降级

### 3. 反对抗拒
- 对方说"不行"
- 镜像"不行？"——引发对方解释
- 重新打开对话

### 4. 价格谈判
- 对方报出价格
- 镜像关键数字
- 让对方主动调整或解释

## 与"自我镜像"的区分

### 沃斯的镜像 ≠ 心理学的"镜像"
- 心理学镜像：模仿对方肢体语言、语速
- 沃斯镜像：重复最后几个词

### 沃斯镜像更精准
- 不是模仿全部
- 而是聚焦关键词
- 引导对方在该关键词上展开

## 注意事项

### 1. 用升调
- 升调表"请继续"
- 降调表"我同意"——可能终止对话
- 平调效果较差

### 2. 暂停
- 镜像后停3-5秒
- 让对方有时间回应
- 不要急于补充

### 3. 不要过度使用
- 每次对话用2-3次
- 过度显得机械
- 自然融入

### 4. 配合其他工具
- 镜像 + 标注
- 镜像 + 校准型问题
- 镜像 + 深夜FMDJ声音
