# CORE 四维度

CORE 是衡量逆商（AQ）的四个维度，由保罗·史托兹（Paul Stoltz）提出，源自塞利格曼归因理论、抗逆性研究、自我效能、内外控倾向等综合研究。

## 四个维度

- **C — Control 掌控感**：你觉得对不利事件有多大掌控？关键词是"觉得"——实际掌控力几乎测不出，**掌控感**才决定行动。低逆商者说"我无能为力"，高逆商者说"我肯定能做些什么"。
- **O — Ownership 担当力**：你在多大程度上愿担起责任改善现状（不论起因）？担当不是自责，是担责解决问题。低逆商者推卸、抱怨，高逆商者从错误中学习并承担后果。
- **R — Reach 影响度**：逆境会蔓延到生活其他方面吗？低逆商者让坏事扩散（一场糟糕会议毁掉一天），高逆商者把问题限制在当前事件（一场争执就是一场争执）。
- **E — Endurance 持续性**：逆境会持续多久？起因会持续多久？低逆商者用"总是""绝不""我就是个拖延症患者"等永久性标签，高逆商者把挫折归因于暂时性因素（不够努力、策略不佳）。

## 关键洞察

CORE 不是单一分数，而是**四个独立的子能力**。总分不能告诉你为什么低、怎么改，必须看分维度曲线。就像网球得分不能说明你需要练发球还是步法。

掌控感是其他三维的**基石**——没有掌控感就没有希望和行动；担当力是唤起行动的号角；影响度决定压力扩散范围；持续性决定你被困多久。

**永久性标签最危险**。"我是个拖延症患者"（永久）和"我要谨防把事情拖到最后一分钟"（暂时）之间是行动与借口的分野。

## 与已有知识的关联

- 源自 [[习得性无助]]（塞利格曼）的归因理论：悲观者把逆境归为永久的、普遍的、个人的；乐观者反之。
- 与 [[归因风格]]（卡罗尔·德维克）呼应：儿童把失败归因于稳定能力 vs 暂时努力，学习效果差异巨大。
- 与 [[抗逆性三要素]]（奥雷特：承诺度+挑战意识+掌控感）部分重合。
