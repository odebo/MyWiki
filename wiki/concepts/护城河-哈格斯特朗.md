# 护城河

**定义**：巴菲特提出的核心概念——企业拥有的可持续竞争优势，像中世纪城堡的护城河一样保护企业免受竞争者入侵。护城河的宽度与深度决定企业长期盈利能力的可持续性。

**护城河的来源**：
1. **特许经营权**：产品/服务被需要、没有替代品、价格不受管制
2. **品牌**：消费者心智中的不可替代性（可口可乐、吉列）
3. **网络效应**：用户越多价值越大（美国运通、Facebook）
4. **成本优势**：规模效应或结构性低成本（GEICO）
5. **转换成本**：客户更换供应商的成本高（企业软件）
6. **规模优势**：规模带来采购、分销、研发的成本优势

**护城河的检验**：
- 提价能力：能否在不流失客户的情况下提价
- 行业危机中的表现：危机时份额是否增长
- 资本回报率的可持续性：高 ROE 是否能长期维持
- 竞争者的进入难度：新进入者需要多少投入

**护城河的动态性**：
- 护城河会侵蚀也会加深——必须持续监控
- 技术变革可能填平护城河（柯达、西尔斯）
- 优秀管理层会加深护城河，平庸管理层会侵蚀它
- 护城河不是静态地位，是动态能力

**与其他框架的关系**：
- 与 [[破局者思维-克里斯滕森]] 张力但互补：护城河防御破坏性创新，但克里斯滕森警告护城河可能被破坏性创新绕过
- 与 [[购买企业十二准则-哈格斯特朗]] 同源：护城河是"良好长期前景"的具体化
- 与 [[复利思维]] 互补：护城河让复利可持续
- 与 [[考虑最坏情况-塔勒布]] 互补：护城河是反脆弱的企业版本
- 与 [[MECE原则-艾森拉塞尔]] 互补：护城河是分析企业竞争力的 MECE 框架

**反例**：
- 把市场份额等同于护城河——份额可能因价格战而失去
- 把短期高利润率等同于护城河——可能是周期性而非结构性
- 把"行业龙头"等同于护城河——必须看龙头地位的来源是否可持续
