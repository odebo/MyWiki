# 复利者同行-庞普里亚诺

**定义**：庞普里亚诺提出的"复利者同行"概念——选择与那些理解复利效应、坚持长期主义、做事有耐心的人同行。"复利者"的识别和结交，比单次合作的对象选择更重要，因为复利者会在长期产生指数级的关系收益。

## "复利者"的特征

1. **长期视角**：思考以年/十年为单位，而非天/月
2. **复利思维**：理解指数增长，不追求即时回报
3. **持续学习**：每天进步一点点，相信累积
4. **耐心品格**：能忍受前期缓慢，等待拐点
5. **价值创造导向**：先给予后获取，长期互惠

## 与"非复利者"的对照

| 维度 | 复利者 | 非复利者 |
|------|--------|---------|
| 时间视角 | 长期 | 短期 |
| 回报期待 | 指数增长 | 即时回报 |
| 关系经营 | 长期互惠 | 一次性交易 |
| 学习态度 | 持续累积 | 间歇努力 |
| 信用模式 | 信用累积 | 信用消耗 |

## 复利者同行的复利效应

- 复利者之间的关系本身也是复利的
- 早期相识的复利者会在彼此成长中相互放大
- 5年、10年、20年后的合作机会呈指数级增长
- 复利者网络是个人成长的杠杆

## 反直觉点

- 不要追求"名人朋友圈"——名人未必是复利者
- 复利者早期可能默默无闻——识别需要眼光
- 与复利者同行比"向上社交"更重要
- 复利者关系不需要频繁维护，但需要长期忠诚

## 与既有概念的关系

- 与 [[复利效应-达克沃思]] 同源——将复利思维从个人成长迁移到人际关系
- 与 [[早期接触稀缺资源带来指数级优势-盖茨]] 互补——盖茨强调早接触，庞普强调早同行
- 与 [[关系作为中国式社会资本-克拉克]] 形成 cross-cultural 对照——中国式关系强调长期互惠，庞普的"复利者"是西方版
