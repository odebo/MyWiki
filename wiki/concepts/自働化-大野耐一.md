# 自働化

**定义**：自働化（Jidoka，带"人"字旁的"働"）是丰田生产方式的第二大支柱（与准时化JIT并列）。其核心是"让机器拥有人的智慧"——机器在发生异常时能自动停止运转，而不是继续生产不合格品。这一概念源于丰田集团创始人丰田佐吉（1867-1930）发明的自働纺织机：经纱断了一根或纬纱用完时立即停止，避免次品出现。

**关键区别：自働化 ≠ 自动化**

| 维度 | 自动化（普通） | 自働化（带人字旁） |
|------|--------------|----------------|
| 字面 | 自动运转 | "动"字有人字旁 |
| 异常处理 | 继续运转，次品堆积 | 立即停止，杜绝次品 |
| 监视功能 | 不具自动监视故障功能 | 内置判断状态的装置 |
| 人的角色 | 人盯机器，异常时人代替作业 | 机器正常时不需要人，异常时才需人 |
| 管理含义 | 一人一机 | 一人管理多台机器 |

**自働化的实现装置**：
- 固定位置停止系统
- 全面运转系统
- 防错装置（poka-yoke）
- 安东（andon）生产线停止显示板——任何故障状况一目了然

**自働化的连锁效益**：
1. 机器异常时自动停止 → 不产出次品
2. 异常暴露而非被掩盖 → 问题可视化
3. 人在机器正常时无需盯守 → 一人管理多台机器
4. 多余人员自然出现 → 可被有效使用而非解雇
5. 异常停止 → 暴露根本原因 → 通过五个为什么追溯 → 系统性改进

**手工生产线的自働化延伸**：大野耐一把自働化理念扩展到手工生产线——如果发生异常，作业人员要主动按下停止按钮让生产线立即停止工作。这把"机器自动停止"的理念转化为"人主动停止"的权限与文化。

**"给发臭的东西盖上盖子"的批判**：日本谚语"臭いものにはフタをする"（给发臭的东西盖上盖子）——指掩盖事实。大野耐一批评传统做法：明知材料、机器存在问题，人们在修理时刻意避开管理监督人员的耳目。这种做法永远无法改进，无法实现成本下降。自働化通过"异常时停止"强制暴露问题，正是反其道而行。
