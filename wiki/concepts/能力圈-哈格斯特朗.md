# 能力圈

**定义**：巴菲特投资哲学的核心概念之一——每个投资者应清楚自己理解哪些业务、不理解哪些业务，只在自己能力圈范围内投资。能力圈大小不重要，知道其边界至关重要。

**核心洞察**：
- 能力圈边界比大小更重要：知道自己不知道什么，比知道什么更关键
- 能力圈可扩展但需时间：通过持续学习与刻意练习逐步扩大
- 巴菲特不投科技股不是保守，是承认能力圈边界——"在你能力圈外的机会不是机会，是陷阱"
- 能力圈与"持续学习"互补：能力圈是当下的状态，持续学习是扩展的过程

**能力圈的来源**：
- 格雷厄姆：强调"理解企业"是投资前提
- 费雪：通过"闲聊调研"深化对行业与人性的理解
- 芒格：跨学科思维模型扩展能力圈边界

**操作要点**：
- 诚实评估自己：不欺骗自己懂不懂
- 在能力圈内深化比在圈外扩展更重要
- 拒绝"看似容易"的圈外机会——它们往往是陷阱
- 持续学习但不急于扩展投资范围

**与其他框架的关系**：
- 与 [[思考极点-多贝里]] 形成对话：能力圈是"想清楚的边界"，思考极点是"想太多的边界"——投资者要在两者间找平衡
- 与 [[初始假设-艾森拉塞尔]] 互补：在能力圈内形成初始假设更可靠
- 与 [[灰度决策五大问题-巴达拉克]] 互补：能力圈定义"我能接受什么"的可决策范围
- 与 [[破局者思维-克里斯滕森]] 张力：克里斯滕森要求破坏性创新，巴菲特要求守住能力圈——投资与经营逻辑不同
- 与 [[学会如何学习-吉姆奎克]] 同源：能力圈扩展需要元学习能力

**反例**：
- 不懂科技却追逐科技股泡沫——典型能力圈越界
- 因为"研究过几天"就认为自己懂了——能力圈是深度而非广度
- 把"熟悉"等同于"理解"——熟悉产品不等于理解商业模式
