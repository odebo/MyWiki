# 跨部门协作同理心

脱不花提出的跨部门协作核心方法论——把"求人办事"思维升级为"互利共赢"思维。核心是**站在对方立场设计协作**。

## 同理心协作四原则

### 1. 先理解对方 KPI
- 每个部门有自己的考核指标
- 你的请求如何帮助对方完成 KPI？
- 不帮对方完成 KPI 的请求 = 道德绑架
- 帮对方完成 KPI 的请求 = 双赢合作

### 2. 用对方的语言沟通
- 技术部门用"实现成本"
- 业务部门用"业绩影响"
- 财务部门用"ROI"
- 法务部门用"风险等级"
- 用错语言 = 鸡同鸭讲

### 3. 给对方留出空间
- 不要逼对方当场答复
- 给出 deadline 时预留 buffer
- 给对方留"考虑时间"和"拒绝空间"
- 强势推进 = 一次性合作,留空间 = 长期关系

### 4. 闭环反馈给对方
- 协作完成后告诉对方结果
- 对方贡献的部分被认可
- 复盘时邀请对方参与
- 让对方有"被尊重感"

## 跨部门协作的三层结构

脱不花把跨部门协作分三层：

### 第一层：信息同步层
- 你知道什么、对方知道什么
- 互相通报进度
- 这层失败 = 信息孤岛

### 第二层：资源交换层
- 你需要对方的什么资源
- 对方需要你的什么资源
- 这层失败 = 各扫门前雪

### 第三层：目标共识层
- 共同要达成的目标
- 各自在目标中的角色
- 这层失败 = 合力无法形成

**多数跨部门协作失败在第二层和第三层**——大家只做了信息同步,没做资源交换和目标共识。

## 跨部门协作的常见错误

### 错误1：用职级压人
- "我是 XX 总让我来找你的"
- 短期有效,长期结仇
- 正确做法：找对方上级协调,但不要拿对方上级压对方

### 错误2：只讲自己需求
- "我需要 X 周内完成 Y"
- 没讲对方能得到什么
- 正确做法：先讲共同目标,再讲各自角色

### 错误3：甩锅式协作
- "这事归你们部门"
- 把责任推给对方
- 正确做法：明确各自边界,共同对结果负责

### 错误4：事后不反馈
- 协作完成就消失
- 下次再找人对方不理
- 正确做法：闭环反馈,认可对方贡献

## 与"求人办事"文化的对话

中国传统职场讲"求人办事"——找人帮忙要送礼、要客套。
脱不花论点：
- 求人办事 = 单方面索取
- 跨部门协作 = 双方互利
- 送礼客套 = 一次性交易
- 同理心设计 = 长期关系
- 现代企业里,礼物不如 KPI 帮助管用

## 与"流程驱动"的对话

主流管理学讲"流程驱动协作"——定流程、定 SLA、定 RACI。
脱不花论点：
- 流程是底线,同理心是上限
- 没有流程 = 协作混乱
- 只有流程 = 协作僵化
- 流程 + 同理心 = 协作高效且灵活
- 流程让人不得不帮,同理心让人愿意帮
