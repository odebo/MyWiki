# MBSR八周课程

**来源**：[[正念减压实操指南-斯塔尔]]

**核心定义**：MBSR（Mindfulness-Based Stress Reduction，正念减压）由乔·卡巴金于 1979 年在马萨诸塞大学医学院开发，是一个结构化的 8 周课程，每周一次 2.5 小时团体课，加上每日 45 分钟家庭作业，第八周通常为全天静修。课程将佛教内观冥想去宗教化，整合当代心理学与心身医学，针对慢性疼痛、压力、焦虑、抑郁等世俗问题。

## 八周课表

| 周次 | 主题 | 核心练习 |
|------|------|---------|
| 第一周 | 何谓正念、自动导航模式 | 葡萄干练习、身体扫描初体验 |
| 第二周 | 思维与身体的联结 | 身体扫描、日常活动正念 |
| 第三周 | 当下的力量 | 坐姿冥想引入、正念呼吸 |
| 第四周 | 压力反应与压力回应 | 应激反应识别、3 分钟呼吸空间 |
| 第五周 | 对压力的回应 | 坐姿冥想加深、心理陷阱识别 |
| 第六周 | 沟通与人际正念 | 人际正念、难相处之人练习 |
| 第七周 | 自我慈悲与生活方式 | 慈爱冥想、营养与运动 |
| 第八周 | 维持与深化 | 全天静修、长期计划 |

## 设计哲学

- **结构化渐进**：从身体扫描（被动觉察）→ 坐姿冥想（主动觉察）→ 瑜伽（动中觉察）→ 人际正念（关系觉察）
- **正式 + 非正式并行**：每日既有正式坐禅，也有把觉察带入吃饭、走路、洗澡等日常活动
- **团体动力**：团体课提供镜映与共Normalization，是课程效果的重要载体
- **不针对具体疾病**：MBSR 不是治疗而是教育，"参与者"而非"患者"

## 证据基础

- 已被多项 RCT 研究证实对慢性疼痛、焦虑、抑郁复发预防、失眠、PSA（压力生理指标）有效
- 神经影像研究显示 8 周后前额叶皮层活动模式改变、杏仁核反应性降低
- 衍生出 MBCT（正念认知疗法，预防抑郁复发）、MBCR（正念癌症康复）等专门版本

## 与其他正念传统的关系

- 渊源：上座部佛教内观（Vipassana）
- 去宗教化：去除佛教仪式与教义，保留觉察技术
- 与 [[六扇门自我发展体系-尤赫曼]] 第二扇门"正念"同源
- 与藏传佛教慈爱冥想（Metta）同源，被 MBSR 第七周采用
