# 无限可能模式（Limitless Model）

吉姆·奎克的突破极限框架——**思维模式 × 内在动力 × 方法方式 = 无限可能**。三者必须一致对齐，才能突破自我设限。

## 三大支柱

### 1. 思维模式（Mindset）
- 是什么限制了你的信念、往事、根深蒂固的想法、态度、关于自己的设想
- 检查、挖掘并根除自我设限
- 问："什么限制了我？"——通常限制来自思维模式、动力或方法

### 2. 内在动力（Motivation）
- 三要素：目的、能力、方法
- **目的**：搞清楚为何努力——比"想做什么"更深层
- **能力**：能量管理（食物/锻炼/睡眠/压力/沟通）+ 小步累积
- **方法**：5 种关键方法（专注/学习/记忆/速读/批判思维）

### 3. 方法方式（Method）
- 21 世纪需要新学习方法，19-20 世纪的方法已经过时
- 五种关键方法：**专注、有效学习、长久记忆、快速阅读、敏锐思考**

## 突破极限的流程

```
觉察限制 → 挖掘根源（思维/动力/方法）
   → 重构思维模式（破除限制性信念）
   → 激发内在动力（找到目的+能量+小步）
   → 应用新方法（5 种学习技能）
   → 突破极限 → 无限可能
```

## 与"英雄之旅"的关系

奎克用约瑟夫·坎贝尔的"英雄之旅"框架作为隐喻：
- 平凡世界 → 冒险召唤 → 接受召唤 → 导师训练 → 新能力 → 终极考验 → 回归分享
- 学习任何新技能都是一次英雄之旅
