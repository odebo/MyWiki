# 分化定律（特劳特）

> **任何一个品类起步时都是单一形态，随着时间推移必然分化为多个细分品类。**

特劳特在《与众不同》第1章提出，分化定律是推动选择激增的根本动力，最早在《22条商规》中论述。

## 分化机制

类比生物学：如在培养皿里持续分裂的变形虫，营销战场是一个不断扩展的品类汪洋。

**电脑品类的分化轨迹**：
```
主机电脑 → 小型机 → 工作站 → 个人电脑 → 膝上型 → 笔记本 → 掌上电脑 → 智能手机 → 平板 → 智能手表 → ...
```

**汽车品类的分化**：雪佛兰/福特/普利茅斯三大品牌 → 豪华/中等/经济型 × 大/中/小型 × 跑车/四驱/微面/越野...

**电视业**：ABC/CBS/NBC 90%收视率 → 电视网/独立电视/有线电视/卫星电视/公共电视/流媒体，单户家庭可选500+频道

## 分化的战略含义

1. **新品类诞生 = 新差异化机会**：分化创造的每一个细分品类，都为新品牌提供了占据领导地位的机会
2. **老品类不会消失，但被细分**：原品类市场被切分，主导品牌的相对份额下降
3. **分化不可逆**：试图"融合"多个品类的产品几乎总是失败（参见[[品牌延伸陷阱]]）

## 与融合论的对照

特劳特明确反对"融合产品"思维（如智能手机融合一切功能）。他认为：
- 融合是工程师视角，分化是顾客心智视角
- 顾客心智按品类组织记忆，融合产品在心智中找不到位置
- 即使技术上能融合，营销上仍是分化趋势

## 与既有wiki页面关系

- 是[[战略本质-特劳特]]第一维度"生存之道"的展开
- 推动了[[品类货品化-特劳特]]：分化越细，老品类越容易货品化
- 与[[品牌延伸陷阱]]互为反面：分化要求"创建新品牌"，延伸陷阱是"借用老品牌"
- 对应特劳特"分化定律"在[[从0到1-垄断哲学]]中可对应蒂尔的"小市场垄断"——细分品类的领导者比大市场的跟随者更有价值

## 经典案例

- **可口可乐 vs 单一品牌**：单一品牌占30%市场份额
- **吉列 6品牌战略**：TracII/Atra/Sensor/锋速3/Fusion/Good News，占65%市场份额
- **西班牙雷普索尔石油**：3品牌（雷普索尔/坎萨/波特诺）覆盖不同细分，守50%市场份额
- **大宇集团反面案例**：从方便面到卫星25子公司，不分化只扩张 → 负债500亿美元崩溃

## 启示

分化定律提示：**与其在红海中做"更好"，不如在分化中做"第一"**。每次品类分裂都是创建新品牌的机会窗口。
