# 会话即事件日志

DeepSeek Harness 把一次会话设计成一份**只追加（append-only）的事件日志**。会话中发生的一切——系统提示词、用户消息、模型推理内容、工具调用与结果、权限变化、上下文注入与压缩、子 Agent 调度——都作为离散事件追加到日志中。

下一轮模型看到的"历史"，并不是一份被直接维护的对话 buffer，而是从这份事件日志**重新推导**出来的。

这样做的价值：

- **可观测**：轨迹视图可按来源查看每一次运行，Agent 在哪一步跑偏一目了然，而不是只看到"任务失败"或"无限循环"的最终状态。
- **可审计**：权限变化、工具调用都有不可篡改的记录。
- **可复现**：从日志可重放出完全相同的 Agent 轨迹，适合研究与基准测试。

这是 Agent 从"黑箱产品"走向"可研究对象"的工程前提。
