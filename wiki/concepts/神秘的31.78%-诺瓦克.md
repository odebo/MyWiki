# 神秘的 31.78%

**定义**：诺瓦克与罗伯特·梅在空间博弈中发现的合作者稳定出现频率——在空间囚徒困境中，合作者与背叛者的相对丰度永远围绕 31.78% 上下浮动。这一数值对对称图形适用（鲍勃·梅用心算 ln(2)≈0.69 推出），对最不对称的图形也适用——但为何如此，至今仍是谜。1992 年发表于《Nature》。

**核心机制**：
- **空间结构改变合作命运**：均匀混合群体中合作者永远输给背叛者；引入空间后，合作者可形成簇自保
- **动态分形**：合作者与背叛者的边界不断变化，呈分形几何（云朵/花椰菜式自相似）
- **"漫步者"现象**：10 个合作者组成的"L"型可在背叛者海洋中向前漫步
- **"焦土"效应**：合作者被背叛者吃光后，背叛者也会因孤立而死——空格被新一轮合作者填满

**31.78% 的意义**：
- 在不确定的混沌世界中找到了一个固定点
- 即使没有复杂策略，没有大脑——空间结构本身就能促成合作
- 合作不需要智慧——单细胞、分子、化学系统也能涌现合作

**核心洞察**：
- **空间选择 = 第三合作机制**（前两个是直接互惠、间接互惠）
- **结构即策略**：你住在哪、和谁做邻居，决定了你是否会合作
- **生命起源推论**：在某种"原生比萨"表层播撒合作种子，比在充分混合的原生汤中更有效——空间让生命起源变简单

**与既有框架的关系**：
- 与 [[网络结构与合作-诺瓦克]] 同源：空间选择是网络选择的特例
- 与 [[Σ结构系数-诺瓦克]] 互补：31.78% 是空间博弈中 Σ 临界值的体现
- 与 [[五大合作机制-诺瓦克]] 同源：空间选择是五大机制之一

**应用边界**：
- 31.78% 是特定回报矩阵下的值，改变矩阵会改变数值
- 实验验证有限——主要在计算机仿真中
- 现实世界中"空间"已不仅是地理位置，社会网络、虚拟社区、专业社群都是空间
- "邻居借糖"类比：地理邻居间的合作确实现实存在，但现代社会流动性高，地理空间合作被弱化
