# 特朗普谈判法则

特朗普在《永不放弃》末尾总结的谈判法则——与 [[哈佛经典谈判术-马哈拉]] 形成鲜明对照。特朗普的谈判偏直觉、强势、心理战，马哈拉的谈判偏系统、研究、双赢。两者代表两种不同的谈判范式。

## 主要法则

### 1. 知道自己想要什么

- 谈判前明确目标价、底线、BATNA
- 不被对方节奏带偏

### 2. 比对方更了解标的

- 信息搜集——但特朗普版本偏"市场直觉"而非"系统研究"
- 知道标的的真实价值，不被对方锚定

### 3. 心理战

- 让对方觉得你随时可以走开——制造稀缺感
- 不要暴露自己的迫切
- 用沉默和停顿施压

### 4. 强势首次报价

- 报价要敢报——锚定效应（与马哈拉一致）
- 但特朗普偏激进——可能远超合理范围

### 5. 知道何时止损

- 不要为了"永不放弃"而无止境投入——具体项目可以放弃
- 止损是策略，放弃目标是失败

### 6. 让对方觉得自己赢了

- 即使你占便宜，也要让对方有"胜利感"
- 这与马哈拉的"创造价值"互补——但特朗普偏心理操纵

## 与马哈拉谈判术的对比

| 维度 | 特朗普 | 马哈拉 |
|------|------|------|
| 心态 | 对抗+心理战 | 研究+合作 |
| 信息 | 直觉+市场感 | 系统搜集+研究型谈判 |
| 报价 | 激进锚定 | 基于准备的首报 |
| 关系 | 短期为主 | 长期关系维护 |
| 价值创造 | 较少关注 | 核心维度 |
| 心理学 | 利用对方恐惧/贪婪 | 识别偏见+利用偏见 |
| 道德 | 灵活 | 强调道德困局 |
| 适用 | 一次性大交易 | 复杂多方谈判 |

## 两种范式的适用场景

- **特朗普范式适用**：一次性交易/对方不熟悉谈判/品牌效应强/有筹码方
- **马哈拉范式适用**：长期合作关系/复杂多方/信息不对称大/需要执行落地

## 与既有概念的关系

- 与 [[哈佛经典谈判术-马哈拉]] 形成对照
- 与 [[索取价值与创造价值-马哈拉]] 形成对照——特朗普偏索取
- 印证 [[不要盯竞争对手要盯客户-铃木敏文]] 的反面——特朗普常盯对手

## 可挑战

- 心理战在某些文化中破坏信任——长期合作生意难用
- "让对方觉得自己赢了"可能演变为欺骗
- 特朗普的谈判风格被多方批评——未必可复制
- 在政界和商界的谈判不同——法则未必通用

- 是 [[永不放弃-特朗普]] 末尾谈判法则总结
- 与 [[哈佛经典谈判术-马哈拉]] 形成对照——两种谈判范式
