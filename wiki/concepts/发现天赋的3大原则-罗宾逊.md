# 发现天赋的3大原则

**来源**：[[发现天赋的15个训练方法-罗宾逊]]

**核心定义**：罗宾逊提出发现天赋的 3 大原则作为方法论的哲学基础。这些原则不是技巧而是态度，决定一个人是否能真正发现自己的天赋。

## 原则 1：天赋独一无二

每个人的天赋组合都是独特的：
- 多元智能的不同分布
- 热情的不同方向
- 个人经历的不同积累
- 因此，比较他人没有意义

**反例**：教育系统试图用统一标准衡量所有学生，扼杀独特性。

## 原则 2：创造自己的人生

不是"思考人生"而是"创造人生"：
- 思考 = 被动分析
- 创造 = 主动尝试
- 天赋在尝试中显现，不在思考中找到
- 行动优于完美计划

与 [[过度计划是隐性拖延-摩根]] 同源、与 [[过度分析阻碍行动-庞普里亚诺]] 同源。

## 原则 3：可塑的人生

人生不是固定的：
- 任何年龄都可以重新发现天赋
- 不存在"太晚"
- 已有路径可以调整
- 旧天赋可为新天赋铺路

与 [[什么能改变什么变不了-塞利格曼]] 互补：天赋可塑但限度存在。

## 3 原则的整合

- 独一无二 → 接纳自己的不同
- 创造人生 → 主动尝试
- 可塑人生 → 持续调整

3 原则共同反对"被动接受命运"的态度。
