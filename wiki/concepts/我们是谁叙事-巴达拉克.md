# 我们是谁叙事

**定义**：巴达拉克五大问题的第四问——"我们是谁？"要求决策者关闭分析工具，把自己置于关系网与组织叙事中，看决策如何嵌入更大的故事，是从关系性自我出发的判断维度。

**操作步骤（设计思考的五个步骤）**：
1. **不要从这里开始** — 不从孤立的"我"出发，从关系网出发
2. **关闭分析工具** — 暂时放下数据与框架，进入叙事模式
3. **思考真正的自我利益** — 在关系网中的长期自我利益，而非短期孤立利益
4. **考虑组织的"故事"** — 决策是否符合组织长期叙事
5. **解释自己** — 把决策放进能讲给自己的故事里

**核心洞察**：
- 自我不是孤立的原子，而是关系网中的节点——"我们是谁"先于"我是谁"
- 组织有"故事"：长期形成的身份叙事，决策应符合或推进这个故事
- 神秘的记忆之弦：决策与过去的承诺、价值观、传承相呼应
- 关闭分析工具：分析工具在关系性判断中反而成为障碍
- 真正的自我利益：在长期关系与叙事中的利益，与短期孤立利益常不同

**与其他关系性框架的关系**：
- 与 [[三度影响力-克里斯塔基斯]] 同源：都把自我置于网络中
- 与 [[付出者网络-格兰特]] 同源：都强调关系性身份
- 与 [[解释器与自我叙事-伊格曼]] 互补：伊格曼从神经科学解释叙事自我，巴达拉克提供决策应用
- 与 [[小我-托利]] 张力：托利要超越叙事自我，巴达拉克要善用叙事自我
- 与 [[意义比快乐更根本-彼得森]] 互补：意义来自叙事嵌入

**应用边界**：
- "我们是谁"可能被滥用为群体偏见——巴达拉克要求这是"长期叙事"而非"短期群体利益"
- 组织叙事可能掩盖问题——需与第二问（核心义务）和第三问（奏效）并用
