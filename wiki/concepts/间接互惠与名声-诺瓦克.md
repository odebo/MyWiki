# 间接互惠与名声

**定义**：诺瓦克五大合作机制之一——我帮你不是因为你将来会帮我，而是因为帮助行为会建立"名声"，拥有好名声的人会从他人那里获得帮助。间接互惠要求认知能力——记住谁帮过谁、谁背叛过谁，这可能是人类大脑进化的主要驱动。

**间接互惠的机制**：
- 直接互惠：我帮你→你帮我（双向关系）
- 间接互惠：我帮你→建立名声→别人帮我（多向关系）
- 名声是合作的"间接货币"
- 名声需要在群体中传播——闲言碎语是名声传播机制

**认知能力的要求**：
- 记得谁帮过谁——记忆能力
- 知道谁在看着——元认知
- 评估帮助的价值——价值判断
- 传播名声——语言能力

**大脑进化的驱动**：
- 诺瓦克假说：人类大脑进化主要是为了处理名声信息
- 大脑不是为了制造工具，是为了处理"谁可信、谁不可信"
- 闲言碎语（gossip）是名声管理工具，不是无聊消遣
- 语言可能进化出来就是为了传播名声信息

**名声的力量**：
- 即使没人看着，"感觉被看"也让人更合作
- 名声是长期资产，背叛的短期收益小于名声损失
- 网络时代名声传播更快——间接互惠机制被放大

**直接互惠 vs 间接互惠**：
- 直接互惠看"脸"——重复相遇的对手
- 间接互惠看"名"——通过名声传播
- 直接互惠要求小群体，间接互惠支持大群体合作

**与其他名声框架的关系**：
- 与 [[付出者网络-格兰特]] 同源：付出者建立好名声，获得长期回报
- 与 [[三度影响力-克里斯塔基斯]] 互补：名声通过网络三度传播
- 与 [[群体智慧优于单个专家-庞德斯通]] 互补：群体智慧依赖个体名声聚合
- 与 [[公地悲剧]] 互补：名声机制可解决公地悲剧

**应用边界**：
- 名声机制要求群体足够小，名声可被记住与传播
- 名声机制在匿名社会中被削弱——需要制度补偿
- 网络时代名声传播过快可能让"名声"失真——网络暴力的根源

**反例**：
- 假名声——伪造的帮助记录
- 名声贬值——名声传播失真后失去信号功能
- 名声陷阱——一次背叛毁掉一生名声的代价过大
