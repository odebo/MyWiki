# 正念日

一行禅师提出的每周一次的正念修炼法——选定一周中的一天作为正念日，从醒来开始就提醒自己"今天是正念日"，全天保持正念觉知。一行禅师断言：**只要实行每周一次的正念日，三个月后就会看到生命中巨大的改变。**

## 设定方法

1. **选定一天**：任何一天都可以，但建议固定
2. **醒来时提醒**：在天花板或墙上挂标识（树枝/"笑"字），一睁眼就看到
3. **缓慢起床**：随顺呼吸，安静起身
4. **正念完成所有日常**：洗脸/吃饭/洗碗/扫地/喝茶/散步——都保持觉知
5. **静默为主**：刚开始的人最好保持静默（不是不能说话，是有觉知地说话）
6. **正念偈语**：穿衣/洗碗/如厕/叠被都可默念相应偈语

## 一行禅师的偈语示例

- 睡眠始寤："睡眠始寤，当愿众生，一切智觉，周顾十方。"
- 洗手："以水盥掌，当愿众生，得清净手，受持佛法。"
- 起源：宝华山读体见月律师《毗尼日用切要》

## 与其他周期性修炼的关联

- 与 [[舒式一小时-霍姆斯]] 互补——舒尔茨每周一小时战略反思，一行禅师每周一天正念觉知
- 与 [[柳比歇夫五原则-格拉宁]] 互补——柳比歇夫的"每天睡10小时"是日常守护，一行禅师的"每周一天"是周期守护
- 与 [[安息日]] 传统共鸣——亚伯拉罕传统中的安息日是"不工作日"，正念日是"觉知日"
- 与 [[时间统计法-格拉宁]] 互补——柳比歇夫统计每天，一行禅师用一天反观一周

## 为什么有效

1. **持续提醒**：一天的正念训练让正念成为"习惯"——影响其他六天
2. **节奏校准**：现代人生活节奏由外部决定，正念日是主动夺回节奏
3. **情感积累**：一天的正念让负面情绪得以照顾——一周的情绪累积得以释放
4. **能力建设**：第二象限投入——参见 [[第二象限是质量象限必须在其中投入时间-柯维]]

## 一行禅师的承诺

> "我相信，只要实行每周一次的正念日，你就会在三个月后看到生命中巨大的改变。正念日会开始影响其他六天。"
