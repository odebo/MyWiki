# 核心义务优先

**定义**：巴达拉克五大问题的第二问——"我们的核心义务是什么？"要求决策者超越利益相关者分析与法律义务，回到作为人对他人所负的根本道德义务，是唤醒道德想象的方法。

**操作步骤（唤醒道德想象的五个步骤）**：
1. **忽略经济因素** — 暂时关闭"成本-收益"框架，避免经济逻辑压倒人性
2. **忽视利益相关者** — 不按权力大小排序，回到对每个受影响者的义务
3. **唤醒你的道德想象** — 想象对方的具体处境与痛苦
4. **攻克道德想象的壁垒** — 警惕"合理化"机制如何削弱同理心
5. **尝试感同身受** — 真正站在对方位置感受

**核心洞察**：
- 利益相关者分析把人按权力/重要性排序，但核心义务要求把人当作"人"
- 经济逻辑会自然压制道德义务，必须主动忽略才能让义务浮现
- 道德想象是可训练的能力，不是天生的品德
- 黑格尔："视自己为人，并尊重他人为人"——这是核心义务的哲学根基

**与其他伦理框架的关系**：
- 与 [[付出者获取者互利者-格兰特]] 同源：都把他人利益放在分析中心
- 与 [[待己如助人-彼得森]] 互补：巴达拉克扩展到"待他人如人"
- 与 [[意义比快乐更根本-彼得森]] 同根：都拒绝把人生简化为效用最大化
- 与 [[长期主义-达利欧]] 张力：长期主义可能为长期牺牲当下个体，核心义务要求每个个体都被认真对待

**典型应用场景**：
- 解雇资深员工时，超越"赔偿金是否合规"看对人生的影响
- 产品安全风险时，超越"诉讼成本"看对使用者的根本义务
- 供应链决策时，超越"成本最优"看对工人尊严的义务
