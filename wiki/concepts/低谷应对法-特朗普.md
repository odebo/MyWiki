# 低谷应对法

特朗普应对人生和事业低谷的方法论——不让消极情绪长时间笼罩，保持冷静客观，相信转机。这套方法在 1990 年代数十亿美元债务危机中被验证。

## 五个核心原则

### 1. 不长时间陷于消极

- 短暂抱怨和情绪低落是人之常情
- 但不能让消极情绪长时间笼罩
- 特朗普用打高尔夫球作为情绪转换——找到自己的情绪出口

### 2. 保持冷静头脑

- 低谷时容易被情绪带偏——焦虑/愤怒/绝望
- 冷静才能看到出路
- 特朗普反思：被媒体"点石成金"的赞美冲昏头脑就是失去冷静的代价

### 3. 把困境视为暂时

- "此地无人生还"是悲观说法，特朗普反其道——大家都遇到困难，区别在应对
- 低谷是状态而非终点
- 时间是低谷的解药——坚持就有转机

### 4. 客观评估局势

- 列出所有事实，不夸大也不缩小
- 区分"小意外"和"大灾难"——很多低谷实际是小意外被情绪放大
- 特朗普自问："这是小意外还是大灾难？"

### 5. 准备应对不期而遇的问题

- 低谷常由意外触发——已准备好预案就能从容应对
- 特朗普反复强调"准备好应对不期而遇的问题"
- 9·11 事件案例：特朗普团队的应急预案让其物业快速恢复

## 与"积极心理学"的关系

特朗普的低谷应对法与积极心理学有重合：
- 不压抑情绪（接纳）
- 但不让情绪主导（管理）
- 用行动转化情绪（重建）

但特朗普的版本更强调"战斗力"——不只是积极，还要战斗。

## 与既有概念的关系

- 与 [[40定律-戈金斯]] 同源——戈金斯通过痛苦磨砺，特朗普通过低谷战斗
- 与 [[考验是显化过程的一部分不是显化失败-纳福西]] 互补——纳福西说考验是过程，特朗普给出应对方法
- 与 [[好心情练习手册-西多昌规]] 中的"烦恼是默认状态需要切替"同源
- 与 [[习惯化三阶段-古川武士]] 的"瓶颈期"概念同构

## 可挑战

- "保持冷静"在严重抑郁/焦虑时不可行——需要专业帮助
- "战斗"模式可能掩盖真实问题——某些低谷需要退出而非坚持
- 特朗普的案例有其特殊性——亿万富翁的低谷与普通人不同
