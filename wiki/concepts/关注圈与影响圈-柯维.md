# 关注圈与影响圈

**定义**：柯维提出的注意力分配模型——"关注圈"是我们关心但无法直接影响的事务集合（天气、国际冲突、宏观经济、他人评价）；"影响圈"是我们能做力所能及之事的事务集合（自己的健康、工作态度、家庭关系、技能提升）。高效能人士聚焦影响圈，低效能人士困在关注圈。

## 两个圈的关系

```
┌─────────────────────────┐
│       关注圈             │
│  ┌───────────────┐      │
│  │   影响圈       │      │
│  │  （能改变的）  │      │
│  └───────────────┘      │
│   （关心的但无法改变的）  │
└─────────────────────────┘
```

## 两个圈的行为特征

| 维度 | 关注圈型人 | 影响圈型人 |
|------|----------|----------|
| 关注点 | 别人怎么想、环境多糟、政策多不公 | 我能做什么、我能改变什么 |
| 语言 | "他们应该..." "如果只有..." | "我可以..." "我决定..." |
| 能量 | 抱怨消耗能量 | 行动产生能量 |
| 结果 | 影响圈缩小（越来越无力） | 影响圈扩大（越来越有影响力） |

## 关键洞察：两个圈是动态的

柯维指出两个圈会随行为模式变化：
- **关注圈型人**：把能量投入无法改变的事，影响圈**逐渐缩小**
- **影响圈型人**：聚焦能做力所能及之事，影响圈**逐渐扩大**——做好本职工作，别人会更信任你，给你更多责任

这是一个自我强化循环——你的注意力模式决定了你的影响力边界。

## 与"积极主动"的关系

关注圈与影响圈是[[积极主动-柯维]]的具体应用工具：
- 积极主动的人天然聚焦影响圈（"我能做什么"）
- 消极被动的人天然困在关注圈（"为什么我这么惨"）
- 区分两个圈是判断一个人是否真的积极主动的最直接观察

## 与"控制二分法"的关系

这个概念与斯多葛学派的[[控制二分法-爱比克泰德]]（待 ingest）本质相同：
- 爱比克泰德：分清"我能控制的"和"我不能控制的"
- 柯维：分清"影响圈"和"关注圈"
- 两者都源自同一个智慧传统——把能量投向能改变的事

## 尼布尔祷文

柯维引用神学家莱因霍尔德·尼布尔的祷文作为影响圈哲学的诗意表达：
> "上帝，请赐我平静，去接受我无法改变的事；请赐我勇气，去改变我能改变的事；请赐我智慧，去分辨这两者的不同。"

## 与已 ingest 概念的关系

- 是 [[积极主动-柯维]] 的应用工具
- 印证 [[控制二分法-爱比克泰德]]（待 ingest）——古斯多葛智慧的现代管理学术语
- 与 [[时间管理四象限-柯维]] 互补——一个分维度（重要/紧急），一个分范围（能/不能改变）
- 反例 [[嗜急成瘾是现代社会的时间病-柯维]]（待 ingest）——嗜急成瘾者常被困在关注圈
