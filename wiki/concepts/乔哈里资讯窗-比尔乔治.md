# 乔哈里资讯窗

**定义**：**乔哈里资讯窗**（Johari Window）是 1955 年由约瑟夫·勒夫（Joseph Luft）和哈里·英格拉姆（Harry Ingram）设计的自我意识与表露工具——**用四个象限描述"自己知道/不知道"与"他人知道/不知道"组合而成的资讯区域**，帮助领导者扩大公开区、缩小盲区和隐秘区，从而变得真诚透明。

## 四象限模型

```
                  他人知道       他人不知道
              ┌──────────────┬──────────────┐
   自己知道   │  ① 公开区    │  ③ 隐秘区    │
              │ (Open)       │ (Hidden)     │
              ├──────────────┼──────────────┤
   自己不知道 │  ② 盲目区    │  ④ 未知区    │
              │ (Blind)      │ (Unknown)    │
              └──────────────┴──────────────┘
```

## 四个象限详解

### ① 公开区（Open Area）

自己知道、他人也知道的信息。对大多数人来说极其微小。**扩大公开区能让你变得更真诚**。

### ② 盲目区（Blind Area）

他人知道、自己不知道的特征、习性、倾向。**最难搞定**。几乎所有人在别人眼中都有自己看不到的特点。**发现盲区的唯一方法是从别人那里获取诚实反馈**。

### ③ 隐秘区（Hidden Area）

自己知道、他人不知道的信息——你的秘密、弱点、艰难经历。**主动暴露可缩小此区**，扩大公开区。

### ④ 未知区（Unknown Area）

自己和他人都不知道的潜在特质，通过新经历和深度反思才能浮现。

## 扩大公开区的两条路径

```
路径1：缩小隐秘区 → 主动暴露
  - 公开人生故事和艰难时期
  - 主动暴露弱点
  - 真诚分享恐惧和不确定

路径2：缩小盲目区 → 寻求反馈
  - 匿名 360 度反馈
  - 主动询问同事"我有什么可以改进？"
  - 接受批评时不立即辩解
```

## 领导者的应用

### 主动暴露的力量

乔治强调：主动暴露弱点不是示弱，而是真诚。隐藏弱点的代价远大于暴露。

**案例：蒂姆·库克公开同性恋身份**

> 我为自己的性取向而感到自豪。同性恋者的身份让我更加理解成为人群中的少数是怎么样的感受。

库克的公开不仅让他自己获得自由，也鼓励了其他少数群体。**真诚的暴露让领导者获得更深的信任**。

### 反馈女王的故事

威瑞森的朱迪·哈伯肯被称为"反馈女王"：

> 在这个世界上，你能找到的最好的东西，就是那些真正关心你的人提出的反馈意见。

克罗格 CEO 戴维·迪龙的做法：听到批评先辩解，然后道歉：

> 我的反应是针对我自己的，而不是你。我的辩解只是我的自我保护。我可以向你保证，听到你的反馈之后，我会更加尊重你。
