# 品类货品化（特劳特）

> **当一个品类中所有品牌在顾客心智中都没有特定含义时，该品类就沦为"货品"——只能靠价格竞争。**

特劳特在《与众不同》第2章用Brand Keys公司对75品类1847产品的研究揭示：**只有21%的品牌真正有差异化**，剩下79%是品类占位者，距离沦为货品仅一步之遥。

## 货品化的三大原因

特劳特明确指出，**货品化不是市场自然演化的结果，而是营销人员自己造成的**：

### 1. 过度依赖促销活动
生产商把资金从品牌打造转向价格促销（折价券、赠品），让分销商高兴。**越是让消费者关注便宜买卖，就越分散他们对品牌的注意力**。

### 2. 没有约束广告公司的错误直觉
广告公司陷入两个诅咒：
- **按键诅咒**：为防止观众换台，专注于吸引眼球的画面而非品牌信息
- **克里奥广告奖诅咒**：为获奖制作耍聪明、娱乐观众的广告，却缺少让消费者分辨品牌的独特信息

研究公司Copernicus调查黄金时段340条电视广告，**只有7%能让人们找到品牌差异化信息**。

### 3. 管理咨询顾问不懂顾客心智
咨询顾问不懂得市场竞争在顾客心智中展开，反而谈论"质量、授权、以客户为导向、领导力"等通用理念。讽刺的是，管理咨询之父彼得·德鲁克却懂得顾客心智。

## 货品化程度的品类差异

Brand Keys研究75品类差异化比例：

| 品类 | 差异化比例 |
|------|-----------|
| 香皂 | 100% |
| 信用卡 | 50% |
| 汽车 | 38%（丰田=可靠、宝马=驾驶、沃尔沃=安全、奔驰=尊贵、法拉利=速度） |
| 银行 | 0% |
| 润滑油 | 0% |

**银行业0%的原因**：并购狂热症。经历多次并购后，没人搞得清楚"哪个是哪个"。心理学家说："没有过去的线索，如何确信通向未来的线索？"

## 货品化的临界点

```
品牌有清晰差异化 → 品牌占位者 → 品类货品化 → 仅靠价格竞争 → 利润下降 → 死亡螺旋
```

**CEO的警告责任**：品牌如果没有清晰的差异化概念，激励消费者就只能靠价格。竞争对手也能降价，所以没有强大品牌打造，价格必然下降，利润随之下降。

## 货品也能差异化（莱维特5法）

哈佛西奥多·莱维特："你可以为任何东西实施差异化，甚至是货品。"5种方法：

1. **识别** — 普通香蕉贴上金吉达小标签 → 更好的香蕉；都乐在菠萝上贴标签
2. **拟人化** — 绿巨人蔬菜家族；弗兰克·柏杜鲜嫩鸡肉背后的强硬人物
3. **开创新品类名** — 大个香瓜 → "克伦什瓜"；迷你鸡 → "考尼司游乐鸡"
4. **换个名字** — 中国猕猴桃 → "奇异果"，世界突然多了受欢迎的水果
5. **为品类重新定位** — 猪肉搭上鸡肉顺风车 → "另一种白肉"（摆脱"泥中打滚小动物"认知）
