# 个体心理学

**定义**：
**个体心理学**（Individual Psychology）是阿尔弗雷德·阿德勒创立的心理学流派，1911年与弗洛伊德决裂后形成。这里的"个体"（individual）不是"孤立个人"，而是**不可分割的整体**——拉丁词源 *individuum* 意为"不可分"。

个体心理学反对把人割裂为本我/自我/超我，反对把心理还原为性本能，强调人是**追求目标的统一整体**，受未来目标引导而非过去事件决定。

## 核心命题

### 1. 人是统一整体
- 身心统一——不是身体+心理两实体
- 意识与无意识统一——不是对立两系统
- 思想、情感、行为都服务于**同一生活目标**

### 2. 目的论而非决定论
- 弗洛伊德：童年创伤决定成年神经症（原因论）
- 阿德勒：未来目标引导当前行为（目的论）
- "人不是被过去推动——是被未来吸引"
- 过去事件的影响取决于个体**赋予它们的意义**

### 3. 优越追求
- 所有人都追求优越——从自卑到超越
- 这是生命的根本动力
- 不是支配他人——是完善自我

### 4. 社会兴趣
- 健康的优越追求指向社会贡献
- 社会兴趣是心理健康的衡量标准
- 详见 [[社会兴趣-阿德勒]]

### 5. 生活风格
- 个体独特的追求优越的方式
- 4-5岁形成，终身稳定但可修改
- 详见 [[生活风格在童年早期形成且可改变-阿德勒]]

### 6. 创造性自我
- 个体可以创造自己的生活风格
- 不是被动接受遗传与环境的产物
- 主观意义比客观事实更重要

## 与弗洛伊德精神分析的对立

| 维度 | 弗洛伊德 | 阿德勒 |
|------|----------|--------|
| 核心动力 | 性本能（力比多） | 优越追求 |
| 人性观 | 决定论 | 目的论 |
| 意识作用 | 意识是冰山一角 | 意识可主动塑造 |
| 童年作用 | 童年创伤决定 | 童年形成生活风格但可改 |
| 无意识 | 压抑的本我冲动 | 未被理解的生活目标 |
| 治疗目标 | 让无意识变意识 | 识别并修改错误目标 |
| 社会因素 | 次要 | 核心地位 |
| 性别 | 阉割焦虑/阴茎羡妒 | "男性抗议"=自卑感的表达 |

## 与荣格分析心理学的差异

| 维度 | 荣格 | 阿德勒 |
|------|------|--------|
| 核心动力 | 自性化 | 优越追求 |
| 无意识 | 集体无意识+原型 | 生活风格的未明部分 |
| 宗教态度 | 肯定宗教体验 | 世俗化解释 |
| 神秘主义 | 接受共时性 | 拒绝神秘化 |
| 治疗目标 | 自性化（整合） | 重新定向社会兴趣 |

## 个体心理学的方法

### 1. 早期记忆分析
- 最早记忆揭示生活风格
- 不是看内容——看故事的选择与解释
- 详见 [[早期记忆与人格形成-阿德勒]]

### 2. 梦的解析
- 梦支持生活风格——不是愿望满足
- 留下感受而非思想
- 与弗洛伊德的梦解析根本不同

### 3. 出生顺序分析
- 家庭中的位置塑造人格
- 不是决定——是提供特定环境
- 详见 [[出生顺序影响人格发展-阿德勒]]

### 4. 生活风格评估
- 通过记忆、梦、行为模式识别生活目标
- 评估社会兴趣水平
- 找出"原初错误"

## 个体心理学的应用

### 1. 儿童指导
- 阿德勒在维也纳首创儿童指导诊所
- 重视家庭教育、母亲作用
- 影响现代儿童心理学与教育

### 2. 教育
- 合作型课堂优于竞争型
- 教师作为合作的促进者
- 阿德勒学派教育心理学至今活跃

### 3. 婚姻与家庭治疗
- 婚姻作为合作任务
- 平等关系
- 影响现代家庭治疗

### 4. 犯罪学
- 罪犯作为合作失败者
- 治愈=合作训练而非惩罚
- 影响「矫正心理学」

### 5. 心理治疗
- 阿德勒学派治疗至今存在
- 影响认知疗法、人本主义疗法
- 短程治疗、焦点解决治疗的先驱

## 个体心理学的遗产

阿德勒直接影响的心理流派：
- **自我心理学**：哈特曼、埃里克森——自我的独立功能
- **人本主义心理学**：马斯洛、罗杰斯、奥尔波特——自我实现
- **存在主义心理学**：弗兰克尔、罗洛·梅——意义追寻
- **积极心理学**：塞利格曼——幸福=意义+享受
- **理性情绪行为疗法**：埃利斯——非理性信念
- **认知疗法**：贝克——认知歪曲
- **建构主义**：凯利——个人建构
- **叙事治疗**：重构生活故事
- **家庭治疗**：系统视角
